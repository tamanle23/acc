# Backend Implementation Plan - Iteration 51: Zero-Stub Cryptographic Security, Route Unification to `/api/v1/...` & Persistence Hardening

## 1. Problem & Context
1. `PayOsBillingService.java` violates the `ZERO-STUB-PROHIBITION` rule by accepting hardcoded bypass signatures (`"mock_signature_ok"`, `"test_valid_sig"`), synthesizing mock transactions when history is empty, and using in-memory hash maps for billing inquiries.
2. Workflow controllers have inconsistent route versioning: some map dual routes (`{"/api/v1/...", "/api/..."}`) while others map only `/api/v1/...`. Following alignment decisions, all workflow endpoints will be strictly unified under the canonical `/api/v1/...` path.
3. Corporate VAT invoice details in `PayOsBillingService` are currently held in an in-memory `ConcurrentHashMap` with a hardcoded mock company default, rather than being persisted in the existing `TenantBilling.billingMetadata` JSONB column.
4. Quota calculation catches exceptions and returns fake numbers (`schemasUsed = 3`, `recordsUsed = 1250L`) instead of clean `0` defaults and logging.

## 2. Agreed Architectural Specifications (Phase 1)
- **`PayOsBillingService.java`**:
  - Remove backdoor string checks in `verifySignature` (`"mock_signature_ok"`, `"test_valid_sig"`).
  - Enforce constant-time `MessageDigest.isEqual` comparison of HMAC-SHA256 hex string.
  - Return honest empty list `Collections.emptyList()` when billing transactions are empty; remove synthetic transaction injection.
  - Store and retrieve VAT invoice preferences from `TenantBilling.billingMetadata` JSONB column; return `null` when not set by tenant.
  - Remove hardcoded catch constants in `buildQuotaUsage`; default to `0L` on missing records or repository errors with a warning log.
- **Workflow Controllers Route Unification (`apps/backend/acc-ms-aio`)**:
  - Unify all workflow controllers strictly to canonical `/api/v1/...` routes:
    - `WorkflowExecutionController`: `@RequestMapping("/api/v1/workflow/executions")`
    - `WorkflowDefinitionController`: `@RequestMapping("/api/v1/workflow/definitions")`
    - `WorkflowApprovalsController`: `@RequestMapping("/api/v1/workflow/approvals")`
    - `WorkerFleetController`: `@RequestMapping("/api/v1/workflow/workers")`
    - `TaskWorkerController`: `@RequestMapping("/api/v1/workflow/tasks")`
    - `WorkflowDlqController`: `@RequestMapping({"/api/v1/workflow/dlq", "/api/v1/system/dlq"})`
- **Formal Verification Suites**:
  - `/autogenerated-tests/backend-security/`: Test authentic HMAC generation, rejection of fake signatures, and empty history honesty.
  - `/autogenerated-tests/backend-routes/`: Verify HTTP 200/201 on all `/api/v1/workflow/...` endpoints.
