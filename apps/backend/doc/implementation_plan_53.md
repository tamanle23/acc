# Implementation Plan - Acc Backend Iteration 53
# Two-Tier Safeguards & In-Process PGlite WebAssembly Driver Integration

## 1. Context & Objectives
In `pnpm dev:sandbox`, Spring Boot failed with `PSQLException: FATAL: database "acc" does not exist` because `PgLiteDatasourceConfiguration` caught `ClassNotFoundException` and fell back to local PostgreSQL.

Following interactive `/grill-me` alignment, this plan executes the backend-specific tasks for Iteration 58:
1. **In-Process PGlite WASM**: Replace `pglite-spring-boot-test` with `io.roastedroot:pglite4j:0.0.3` in `acc-sandbox/pom.xml` and `pom.xml`, and refactor `PgLiteDatasourceConfiguration.java` to strictly fail-fast with zero external fallback.
2. **Level 1 Startup Safeguard**: Implement early `SandboxEnvironmentPostProcessor` in `acc-sandbox` aborting startup with `SecurityException` if `application.sandbox.enabled=true` under `prod`, `production`, `sit`, `uat`. Ensure `application-prod.yml`, `application-sit.yml`, `application-uat.yml` set `application.sandbox.enabled=false`.
3. **Level 2 Build-Time Safeguard**: Move `acc-sandbox` in `acc-ms-aio/pom.xml` under a `sandbox` profile excluded during `-Pprod`, `-Psit`, `-Puat`, or `-DexcludeSandbox` builds. Add convenience npm scripts `build:prod` and `build:no-sandbox`.
4. **Dual Verification**: JUnit 5 test `SandboxEnvironmentPostProcessorTest.java` and Bun suite in `autogenerated-tests/backend_sandbox_safeguards.test.ts`.

## 2. Target Files & Modifications

### [MODIFY] `apps/backend/pom.xml`
- Add `io.roastedroot:pglite4j:0.0.3` to `<dependencyManagement>`.
- Add profiles `sit` and `uat` matching `prod` to define `<excludeSandbox>true</excludeSandbox>`.

### [MODIFY] `apps/backend/acc-sandbox/pom.xml`
- Replace `io.github.jakvbs:pglite-spring-boot-test` with `io.roastedroot:pglite4j:0.0.3`.
- Remove `<optional>true</optional>`.

### [MODIFY] `apps/backend/acc-sandbox/src/main/java/com/acc/sandbox/db/PgLiteDatasourceConfiguration.java`
- Enforce `io.roastedroot.pglite4j.jdbc.PgLiteDriver` for PGlite URLs (`jdbc:pglite:memory://` in TEST, `jdbc:pglite:file:...` in DEV).
- Strip `localhost:5432/acc` fallback and throw `IllegalStateException` on missing driver.

### [NEW] `apps/backend/acc-sandbox/src/main/java/com/acc/sandbox/config/SandboxEnvironmentPostProcessor.java`
- Implement `EnvironmentPostProcessor` checking active profiles against `[prod, production, sit, uat]`.
- Throw `SecurityException` if sandbox is enabled under restricted profile.

### [NEW] `apps/backend/acc-sandbox/src/main/resources/META-INF/spring.factories`
- Register `org.springframework.boot.env.EnvironmentPostProcessor=com.acc.sandbox.config.SandboxEnvironmentPostProcessor`.

### [NEW] `apps/backend/acc-sandbox/src/test/java/com/acc/sandbox/config/SandboxEnvironmentPostProcessorTest.java`
- Unit test verifying early abort when sandbox is enabled in prod/sit/uat.

### [MODIFY] `apps/backend/acc-ms-aio/src/main/resources/application-prod.yml`, `application-sit.yml`, `application-uat.yml`
- Explicitly declare `application.sandbox.enabled: false`.

### [MODIFY] `apps/backend/acc-ms-aio/pom.xml`
- Move `acc-sandbox` dependency under profile `sandbox` (active when `!excludeSandbox`).
- Add profiles `prod`, `sit`, `uat` setting `<excludeSandbox>true</excludeSandbox>`.

### [MODIFY] `package.json` & `apps/backend/package.json`
- Add `build:prod` and `build:no-sandbox` scripts.
