# Studio Companion Plan 61: TransformGizmoOverlay Studio-Grade Elevation

## Overview
Elevates `TransformGizmoOverlay.tsx` and the underlying `useGizmoTransform` hook to studio-grade quality by dynamically calculating target sequence bounding boxes, repairing clip-space text centering, and introducing professional on-canvas NLE HUD features aligned during the `/grill-me` session.

## Resolved Architecture & UX Decisions
1. **Target Boundary Wrapping**: Exact geometry with configurable 8px breathing padding around text strokes, badge plates, and shapes.
2. **Local Object Center Pivot**: Bounding box centers on the object's authored coordinates (`normX`, `normY`), with an in-box center reticle crosshair (`+`).
3. **Pro NLE Transform Interactions**:
   - Corner handles: Uniform scaling by default (Shift to free-scale; Alt to scale from center).
   - Edge handles: Directional 1D axis stretch (`scaleX` / `scaleY` or width / height).
   - Rotation knob: Laser stem with 15° magnetic snapping.
4. **Live Telemetry HUD Badge**: Floating contextual pill positioned just beneath the gizmo displaying live `X/Y`, `W/H`, `Scale`, and `Angle`.
5. **Keyboard Nudging & Hotkeys**: Arrow keys for 1px nudging (Shift+Arrow for 10px), Delete/Backspace to delete, Escape to deselect, and double-click to edit text.

### Phase 1: Coordinate System & Plugin Centering
- Edit `packages/ir/src/plugins/text/TextModifierPlugin.ts` to always translate to `(originX, originY)` in clip space.
