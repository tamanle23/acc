# Implementation Plan 60 - Studio RightSidebar Property Modification and Timeline Sequence Preview Popup Positioning

## Overview
Companion local implementation plan for `@acc/studio` addressing the two core issues identified during audit:
1. Modifying properties in RightSidebar causes DOM teardown due to object reference churn in Solid `<For>` loops.
2. Timeline sequence preview popup (`ClipHoverHUD` / `ClipInsightCard`) is mispositioned at `(0, 0)` due to `display: contents` on `HoverCardTrigger`.

## Phases & Tasks

### Phase 1: Fix HoverCard Trigger & Sequence Preview Popup Positioning
- File: `apps/studio/src/components/ui/hover-card.tsx`
  - Strip `local.asChild && "contents"` from `HoverCardTrigger`.
  - Pass all props directly to `HoverCardPrimitive.Trigger`.
- File: `apps/studio/src/components/timeline/ClipHoverHUD.tsx`
  - Forward trigger attributes or allow polymorphic trigger wrapping.
- File: `apps/studio/src/components/timeline/ClipItem.tsx`
  - Integrate `HoverCardTrigger` as the physical clip element with `leftPx()` and `widthPx()`.

### Phase 2: Fix Modifier List DOM Churn in `SequenceInspector.tsx`
- File: `apps/studio/src/components/inspector/SequenceInspector.tsx`
  - Replace `<For each={filteredModifiers()}>` with `<Index each={filteredModifiers()}>`.
  - Use `mod().params` reactively in `DynamicModifierInspector`.
  - Retain open accordion keys stably using `(mod() as any).id || `${mod().type}_${idx}``.

### Phase 3: Stabilize Schema Fields in `DynamicModifierInspector.tsx`
- File: `apps/studio/src/components/inspector/DynamicModifierInspector.tsx`
  - Memoize static schema fields from `registry.getSchema()`.
  - Prevent re-allocating `[fieldKey, descriptor]` tuples on every reactive param change.

### Phase 4: Synchronize Timing Properties in `SequenceInspector.tsx`
- File: `apps/studio/src/components/inspector/SequenceInspector.tsx`
  - Read `seq().time` reactively for `currentStartNumber()` and `currentDurationNumber()`.
  - Use `IRStateManager.getInstance().updateSequenceProps(selectedSeqId(), { time: ... })` with reactive values.

### Phase 5: Verification
- File: `autogenerated-tests/studio_right_sidebar_properties_and_popup.test.ts`
- Run `bun test autogenerated-tests/studio_right_sidebar_properties_and_popup.test.ts`.
- Run production build `pnpm --filter @acc/studio build`.
