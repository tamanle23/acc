# Phase 31 Walkthrough: Complete Elimination of @dnd-kit and Implementation of StagingDragManager (Phase 3)

## Overview
Successfully achieved 100% elimination of `@dnd-kit` from `@acc/studio`. Global cross-container drag and drop (from the Left Sidebar preset/vault drawers into the Preview canvas viewport or Timeline track lanes) is now powered by `StagingDragManager` and `@neodrag/react`.

## Key Accomplishments
1. **Engineered `StagingDragManager.ts`**:
   - Clean singleton and observer pattern (`subscribe`, `startDrag`, `updateDrag`, `endDrag`, `cancelDrag`).
   - Spatial hit-testing via `document.elementsFromPoint(x, y)` supporting virtualized track lanes and preview canvas dropzones.
   - Built-in frame calculation with magnetic snapping to playhead.
2. **Refactored `LeftSidebar.tsx`**:
   - Replaced `@dnd-kit`'s `useDraggable` with `@neodrag/react`'s `useDraggable` in `DraggablePresetCard` and `DraggableAssetCard`.
   - Wired 6px activation threshold and smooth card opacity transitions during dragging.
3. **Decoupled Drop Targets (`Preview.tsx` & `DroppableTrackLane.tsx`)**:
   - Removed all `useDroppable` hooks and `@dnd-kit/core` imports.
   - Added semantic `data-drop-zone="canvas-viewport"` and `data-drop-zone="track-lane"`.
   - Integrated `useStagingDrag()` for specular drop highlights.
4. **Refactored Root Workspace (`App.tsx`)**:
   - Removed `<DndContext>` and `<DragOverlay>`.
   - Rendered hardware-accelerated floating ghost preview element following pointer coordinates.
   - Registered atomic drop handler with `IRStateManager` (handling single sequences and linked A/V splits).
5. **Pruned Dependencies**:
   - Removed `@dnd-kit/core` and `@dnd-kit/utilities` from `apps/studio/package.json`.
   - Resulted in a net ~41 KB bundle reduction (`index.js` shrank to 1,671 kB).
