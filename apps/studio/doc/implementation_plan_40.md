# Implementation Plan - Iteration 40: Scoped Native GPU Resource Engine & Zero-Alloc Continuous Playback Pipeline

Companion local plan for Studio viewport playback engine, integrating `@acc/core-isomorphic`'s `NativeResourceManager` and eliminating native buffer memory accumulation.

---

## 1. Problem Statement & Root Cause
During continuous timeline playback (30–60 FPS) in `@acc/studio`, memory steadily climbed from baseline up past 1 GB within seconds of playback.
- **Root Cause**:
  1. V8 GC blindness: V8 only monitors the 64-byte JS wrapper, unaware of 8.3 MB native GPU textures.
  2. Ad-hoc native allocations: Video decoders, plugins, and texture caches allocate native `ImageBitmap`s and `OffscreenCanvas`es without an RAII scope or global memory budget.
  3. Continuous seeking in Mediabunny: `canvasSink.getCanvas(timestamp)` runs seeking pipelines per frame instead of streaming, yielding fresh canvases that are copied to `ImageBitmap`s.
  4. React UI render loop thrashing: `useViewportRenderStrategy` re-synchronizes textures on every React render tick while worker is playing.

---

## 2. Architectural Solution
1. **Scoped Native Resource Engine (`NativeResourceManager` & RAII)**:
   - Introduce `NativeResourceManager` in `@acc/core-isomorphic` with `FrameScope` and `SequenceScope`.
   - Enforce a hard 64 MB native GPU memory ceiling; synchronously evict and `.close()` unpinned textures when budget is reached.
2. **Strict Zero-Alloc Frame Loop in Plugins**:
   - `Depth3DPlugin` and `Camera3DPlugin` pre-bake all masks, cutouts, depth maps, and blur passes in Phase 1 (`execute()`) into `SequenceScope`.
   - Phase 2 (`renderClipSpace()`): Must be synchronous. Only blits pre-baked textures and borrows from `UniversalCanvasProvider`. Zero runtime allocations.
3. **Zero-Copy Ping-Pong Streamer for Video Playback**:
   - `SequentialVideoReader` with 2 pre-allocated `OffscreenCanvas` ping-pong slots. Decodes directly into slots; zero intermediate `ImageBitmap` copies.
4. **Decouple React UI from Worker Playback**:
   - When `isPlaying === true`, `useViewportRenderStrategy` and `WorkerRenderStrategy.syncTextures()` block all main-thread texture sync.
