## 1. Executive Summary & Design Principles

Per user architectural directive:
1. **Battle-Tested Industrial Libraries:** No reinventing the wheel or writing fragile custom virtualization or waveform decoders.
   - **Timeline Virtualization:** `@tanstack/react-virtual` (v3 headless windowing, React 19 compatible, horizontal item windowing & vertical track windowing).
   - **Waveform Rendering:** `wavesurfer.js` (official industry standard audio visualization suite).
2. **Frame-Accurate J-K-L Shuttle Engine:**
   - Playback rates: J = reverse `[-1x, -2x, -4x, -8x]`, K = stop `[0x]`, L = forward `[1x, 2x, 4x, 8x]`.
   - **Frame Jump Rule:** All shuttle transitions, playhead advancements, and scrubbing MUST jump in exact discrete integer frame increments (`frame = Math.round(timeSec * fps)`), NEVER arbitrary continuous float durations.
   - Hardware audio clock sync (`AudioContext.currentTime`) mapped directly to frame-accurate discrete steps, maintaining Web Audio pitch preservation up to ±2x and cleanly muting at 4x+ speeds or in reverse.

## 2. Proposed Architecture & Component Wiring

### A. Dependencies Addition
In `apps/studio/package.json`:
- `@tanstack/react-virtual`: `^3.13.0`
- `wavesurfer.js`: `^7.8.0`

### B. Track & Sequence Virtualization (`Timeline.tsx`)
1. **Vertical Track Virtualization:**
   - Use TanStack `useVirtualizer` with `count: tracks.length`, `estimateSize: () => 64` (lane height) over the outer track viewport.
2. **Horizontal Sequence Virtualization:**
   - Measure timeline viewport scroll width (`totalDuration * zoomLevel`).
   - Use TanStack `useVirtualizer` horizontally or horizontal range-filtering so only sequences within visible `[scrollLeft - buffer, scrollLeft + clientWidth + buffer]` are rendered into the DOM.
   - Retain full drag-and-drop (`@dnd-kit/core`) compatibility for sequence clips.

### C. Industrial Audio Waveforms (`WaveSurferWaveform.tsx`)
1. Wrap `wavesurfer.js` headless decoder/renderer or Canvas renderer:
   - Instantiate WaveSurfer on audio clip sequences.
   - Cache decoded peaks per audio URL/blob to avoid redundant re-decoding when zooming or scrolling.
   - Render responsive peak visualizer synced to clip trim bounds (`startOffset`, `duration`).

### D. Frame-Accurate J-K-L Shuttle State Machine (`useShuttleEngine.ts` / `Timeline.tsx`)
1. **Discrete Frame Advancement:**
   - Global project FPS constant (e.g., 30 or 60 fps).
   - Frame step: `frameIndex = Math.round(currentTime * fps)`.
   - On 'J': decrement playback speed index (`-1x -> -2x -> -4x -> -8x`).
   - On 'K': halt immediately, snap current position to `Math.round(currentTime * fps) / fps`.
   - On 'L': increment playback speed index (`1x -> 2x -> 4x -> 8x`).
   - Arrow Left/Right: discrete single-frame step (`±1 / fps`).
2. **Deterministic Audio Clock Sync:**
   - When playing forward at 1x or 2x, Web Audio `playbackRate` follows speed with `preservesPitch = true`.
   - When playing in reverse (`< 0`) or high speed (`>= 4x`), Web Audio output is safely muted to avoid audio distortion while video frames shuttle accurately.
