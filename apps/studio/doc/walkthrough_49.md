## 2. Key Architecture Components

### 2.1 Strict 4-Domain Target Taxonomy (`packages/ir/src/types/modifiers.ts`)
```typescript
export type ModifierTargetScope = 'standalone' | 'sequence' | 'track' | 'timeline';
```
- `standalone`: Discovered in **Left Sidebar** library tabs (`vfx`, `shapes`, `typography`, `audio`). Spawns a sovereign `type: 'overlay'` (or `'audio'`) sequence on the timeline.
- `sequence`: Contextual clip-level modifier attached to an existing video, image, or text sequence.
- `track`: Track-level stream modifier (e.g. `timed_text/style` on subtitle track).
- `timeline`: Global master canvas compositing effect (e.g. bloom, glare).

### 2.2 Dynamic Registry Query & Compatibility APIs (`packages/ir/src/plugins/ModifierPluginRegistry.ts`)
- `getAvailableModifiersForTarget(targetScope, sequenceType)`: Dynamic cached query for the Right Sidebar Inspector. When `sequenceType === 'overlay'`, returns strictly `transform`, `overlay/blend_mode`, and transitions.
- `getGeneratorsForLibrary(category?)`: Queries standalone generators for Left Sidebar drag-and-drop.
- `isModifierAllowedOnEntity(modifierType, targetContext)`: Validates modifier compatibility before attaching or during document schema validation.

### 2.3 Strict Rename `text/style` $\to$ `timed_text/style`
- Reserves `text/*` cleanly for future standalone typography overlay plugins.
- Renamed in `CaptionModifierPlugin.ts`, `VideoIRSchemaValidator.ts`, `IRCanvasCompositor.ts`, `modifierCatalog.ts`, and all 6 demo projects (`complexSciFiDemoIR.ts`, `astroTelemetryDemoIR.ts`, `quantumPhysicsDemoIR.ts`, etc.).
- Automated backward-compatible migration on document load in `IRStateManager.loadDocument()`, `loadFromJSON()`, and `applyJSONEdit()`.

### 2.4 Four New Studio-Grade Plugins
1. **`motion/vector_blur`**:
   - Convolves temporal sub-samples along the instantaneous velocity vector:
     $$\vec{v}(f) \approx \frac{\mathbf{p}(f + \Delta t) - \mathbf{p}(f - \Delta t)}{2 \cdot \Delta t}, \quad T_{exposure} = \frac{\theta_{shutter}}{360^\circ \cdot \text{fps}}$$
2. **`generator/solid_backdrop`**:
   - Standalone solid color, linear gradient, and radial gradient backdrop generator.
3. **`timeline/photometric_bloom`**:
   - Dual-pass photometric bloom isolating pixels where $Y > L_{th}$ ($Y = 0.2126 R + 0.7152 G + 0.0722 B$), applying Gaussian blur and additive compositing.
4. **`timeline/anamorphic_glare`**:
   - Cinematic horizontal anamorphic streak flare across bright highlights.
