## 1. Executive Summary & Problem Formulation

In complex video editing workflows with mixed media modalities, Studio timelines and the canvas rendering engine require strict structural organization and visual layering guarantees:
1. **Unconstrained Cross-Modality Reordering**: When tracks are reordered without grouping constraints, video tracks can accidentally be moved below audio tracks or interleave with subtitle tracks, causing confusing UI states and rendering order anomalies.
2. **Subtitle Occlusion & Stacking Collisions**: Subtitle tracks (`timed_text`) must unconditionally render at the highest visual layer (above video plates, B-roll overlays, particles, and volumetric cards). When multiple `timed_text` tracks are active concurrently (e.g., bilingual subtitles, translations, karaoke + captions), drawing them naively causes overlapping text collisions at identical anchor positions.

## 2. Implementation Roadmap

### Phase 1: VideoIR Schema & Authoring Engine Foundations (`packages/ir`)
- Add `groupOrder?: number` to `IRTrack` and `ResolvedTrack` in `packages/ir/src/types/VideoIR.ts`.
- Add schema validation for `groupOrder` in `VideoIRSchemaValidator.ts` and `schema/video-ir.schema.json`.
- Pass `groupOrder` through in `RelationalDAGCompiler.ts`.
- Implement `groupTracksByType`, `getTrackModalityGroup`, and `reorderTrackInGroup` in `VideoIRAuthoringEngine.ts`.

### Phase 2: Subtitle Anti-Collision & Supreme Flat Stack Compositor (`packages/effect-engines`, `packages/ir`)
- Update `drawCanvasCaptionsFromSnapshot` in `captions-canvas.ts` to compute vertical slot offsets using `slotIndex`.
- Update `IRCanvasCompositor.ts` to promote all `timed_text` tracks into an isolated flat stack pass on top of all visual layers, sorted by `groupOrder`.
- Implement concurrent subtitle slot calculation to prevent text collisions.

### Phase 3: Studio Reordering Command & State Integration (`apps/studio`)
- Update `ReorderTrackCommand.ts` to execute intra-group swaps with complete undo/redo snapshot safety.
- Update `IRStateManager.reorderTrack` to respect modality boundaries.
- Expose modality-aware track addition helpers in `Timeline.tsx` (`+ Video`, `+ Text`, `+ Audio`).

### Phase 4: Studio Timeline UI Grouping & Liquid Glass Dividers (`apps/studio`)
- Group tracks into `timed_text`, `video`, and `audio` in `TimelineDom.tsx`.
- Render Liquid Glass group headers with title, icon, and track counters.
- Update `TrackHeaderCard.tsx` `canMoveUp` and `canMoveDown` to reflect intra-group limits.

### Phase 5: Automated Verification & Documentation
- Create test suite in `autogenerated-tests/track_group_order_and_stack.test.ts`.
- Document walkthrough in `apps/studio/doc/walkthrough_51.md`.
- Register history entry `docs/history/398_track_grouping_and_timed_text_flat_stack.md` and update `docs/history/README.md`.
