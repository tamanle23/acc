## 1. Executive Summary & Goals

In Iteration 13, the Studio Timeline engine was upgraded to industrial NLE standards to address:
1. **Large Timeline Virtualization**: Elimination of DOM bloat when rendering 100+ tracks and 1,000+ clips.
2. **Industrial Audio Waveforms**: Elimination of redundant PCM waveform decoding and lag during timeline zooming.
3. **Frame-Accurate J-K-L Shuttle Engine**: Elimination of continuous float time drift during playback and scrubbing, ensuring exact discrete integer frame stepping (`frame = Math.round(timeSec * fps)`), multi-speed shuttle state transitions (`[-8x, -4x, -2x, -1x, 0x, 1x, 2x, 4x, 8x]`), and hardware audio clock synchronization.

Per explicit user direction, battle-tested industrial libraries were employed:
- **`@tanstack/react-virtual`** (`^3.13.0`): Headless vertical track windowing and horizontal sequence range filtering.
- **`wavesurfer.js`** (`^7.8.0`): Peak caching and responsive audio waveform visualization.

## 2. Key Architecture & Deliverables

### A. Dependencies Addition
In `apps/studio/package.json`:
- Added `@tanstack/react-virtual` (`^3.13.0`)
- Added `wavesurfer.js` (`^7.8.0`)

### B. Track & Sequence Virtualization (`apps/studio/src/components/Timeline.tsx`)
1. **Vertical Track Virtualization**:
   - Integrated TanStack `useVirtualizer` with `count: tracks.length`, `estimateSize: () => 48`, and `overscan: 4`.
   - Outer container height matches `rowVirtualizer.getTotalSize()`.
   - Sticky track headers (`sticky left-0`) remain pinned and aligned with sticky timecode ruler and playhead needle.
2. **Horizontal Sequence Virtualization**:
   - Monitored timeline viewport horizontal scroll (`scrollLeft`, `clientWidth`).
   - Calculated active visible frame window `[visibleStartFrame, visibleEndFrame]` with 400px safety buffer.
   - Filtered sequence clips per track so offscreen clips are omitted from the DOM while **always retaining actively dragged sequences** (`activeDragState?.seqId === seq.id`) to guarantee `@dnd-kit` drag session integrity without unmounting.

### C. Industrial Waveforms (`WaveSurferWaveform.tsx` & `AudioWaveform.tsx`)
1. Implemented `WaveSurferWaveform.tsx` using `wavesurfer.js`:
   - Instantiates WaveSurfer instance on audio sequences.
   - Decoded peak cache (`Map<string, number[]>`) prevents redundant audio peak re-calculations across zoom or scrub actions.
   - Connected `AudioWaveform.tsx` to `WaveSurferWaveform` for full backward compatibility.

### D. Frame-Accurate J-K-L Shuttle Engine (`useShuttleEngine.ts` & `shuttleTypes.ts`)
1. **Discrete Frame Advancement Math**:
   - Strict discrete frame snapping: `frame = Math.round(timeSec * fps)`.
   - Single frame discrete stepping via Arrow Left (`-1` / `-10`) and Arrow Right (`+1` / `+10`).
   - Boundary-safe clamping: halts at 0 (reverse) and `totalFrames` (forward); restarts from 0 when forward playback is triggered at the end.
2. **J-K-L Shuttle State Machine**:
   - J (reverse): `[-1x, -2x, -4x, -8x]`
   - K (stop): immediately halts shuttle to `0x` and snaps playhead to discrete integer frame.
   - L (forward): `[1x, 2x, 4x, 8x]`
   - Space: toggles play/pause between `1x` and `0x`.
   - Defensive speed snapping: snaps any arbitrary float/integer speed to nearest valid standard NLE shuttle rate.
3. **Hardware Audio Clock Synchronization**:
   - Forward playback at 1x and 2x preserves pitch (`preservesPitch = true`) with matching Web Audio `playbackRate`.
   - High forward speeds (`>= 4x`), reverse playback (`< 0`), and stopped state (`0x`) safely mute Web Audio output and stop previous buffer sources.
   - Restarts audio playback cleanly synchronized to the `currentFrame` to prevent float buffer drift.
4. **Clean Keybinding Decoupling**:
   - Transport controls (`Space`, `ArrowLeft`, `ArrowRight`, `J`, `K`, `L`) centralized in `useShuttleEngine`.
   - `Timeline.tsx` decoupled from transport keybindings to eliminate duplicate Space/Arrow firing.
