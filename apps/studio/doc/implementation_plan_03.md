# Implementation Plan 03: Enterprise-Grade Studio Dual-Sidebar Workspace Architecture with @dnd-kit

## 1. Goal Description
Transform `apps/studio` into an enterprise-grade Digital Content Creation (DCC) and Non-Linear Editing (NLE) workstation by:
1. **Replacing HTML5 Drag and Drop with `@dnd-kit`** (`@dnd-kit/core`, `@dnd-kit/utilities`):
   - PointerSensor with `distance: 6px` activation constraint to separate clicks from drags.
   - Smooth hardware-accelerated `DragOverlay` without OS ghost image glitches.
   - Pointer-within collision detection on the Canvas Viewport.
2. **Far-Left Enterprise Activity Rail (48px) + Slide-out Drawer (300px)** for Library presets and Assets Vault.
3. **Right Dedicated Property Inspector (336px)** with Full NLE Action Bar, Add Modifier dropdown, and Project Settings fallback when nothing is selected.
4. **Workspace Velocity & Zen Mode**: Titlebar toggles and `[`, `]`, `\` hotkeys.

---

## 2. Key Architecture Elements

### 2.1 `@dnd-kit` Staging Pipeline
- `DndContext` in `App.tsx` wrapping the workspace.
- `useDraggable` in `LeftSidebar.tsx` on preset cards and media assets.
- `useDroppable` in `Preview.tsx` on the Canvas Viewport.
- `<DragOverlay>` rendering crisp floating preview card following pointer.

### 2.2 Left Sidebar & Activity Rail (`LeftSidebar.tsx`)
- 48px vertical rail with `Library` and `Assets Vault` icons and collapse trigger.
- 300px slide-out drawer:
  - Library: 12 draggable preset cards across Text, Shapes, Partial VFX with instant search, category filters, and `+ Insert` center button.
  - Assets Vault: Media assets with search, type filter pills (`All`, `Video`, `Audio`, `Image`), and direct canvas drag-and-drop staging.

### 2.3 Right Dedicated Inspector (`RightSidebar.tsx`)
- Selected Sequence Inspector:
  - Header: Sequence ID, copy button, Track routing, Type badge, In/Out timing.
  - Action Bar: Duplicate Sequence, Delete Sequence, Lock/Bypass toggle.
  - Add Modifier dropdown with checkmark indicators.
  - Accordions: Transform, 3D Relighting, 3D Camera, Particle VFX, Typography, Audio Ducking.
- Fallback State (No selection):
  - Project & Canvas Settings: Resolution, FPS, Color Space, Master Duration, Tracks count.

### 2.4 Canvas Viewport (`Preview.tsx`)
- Registered with `useDroppable({ id: 'canvas-viewport-drop-zone' })`.
- Responsive centering during sidebar collapse/expand.

### 2.5 App Orchestration (`App.tsx`)
- Dual-sidebar layout with `isLeftOpen`, `isRightOpen`.
- Global shortcuts: `[` (left drawer), `]` (right inspector), `\` (Zen mode).
