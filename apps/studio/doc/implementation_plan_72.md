## 1. Overview & Objectives
Directly implement and integrate Phase 1 to Phase 4 in `apps/studio` and shared core packages:
1. Eliminate mono-to-stereo channel packing corruption in `MediabunnyClientStrategy` and `MediabunnyServerStrategy`.
2. Preserve detected source sample rates across audio demuxing to allow accurate linear resampling.
3. Replace `Math.tanh()` master bus overdrive with transparent peak limiting in `UniversalAudioMixer`.
4. Enlarge `AudioAssetCache` from 16 MB to 128 MB (32 entries).
5. Implement dynamic sliding-window preloading around the active playhead in `WebAudioEngine`, supporting video tracks with audio and eliminating the 6-second restriction.
6. Hot-swap active audio buffer upon `AudioAssetCache` decode notification to eliminate the 5-second initial playback silence.

## 2. Phased Implementation Tasks

### Phase 1: Mediabunny Client & Server Audio Normalization
- [ ] Update `packages/core-web/src/media-engine/MediabunnyClientStrategy.ts`:
  - Detect `sample.sampleRate` or `audioTrack.getSampleRate()`.
  - For `numChannels === 1`: Duplicate mono sample into stereo interleaved pairs `[mono, mono]`.
  - For `numChannels >= 2`: Extract Left and Right channels into interleaved stereo pairs.
  - Return true source sample rate in `DecodedAudioPCM`.
- [ ] Update `packages/core/src/media-engine/strategies/MediabunnyServerStrategy.ts` with identical logic for server execution.

### Phase 2: Master Bus Limiter & Ducking Clean-Up
- [ ] Update `packages/ir/src/renderer/audio/UniversalAudioMixer.ts`:
  - In `mixStereo`, replace `Math.tanh()` with transparent linear pass-through and proportional soft peak limiting only when peaks exceed 1.0.
  - In `rebuildDuckingProfile`, remove the hardcoded `0.25` synthetic voice energy.

### Phase 3: AudioAssetCache Expansion & Dynamic Lookahead Pool
- [ ] Update `apps/studio/src/lib/audio/AudioAssetCache.ts`:
  - Set `MAX_CACHE_ENTRIES = 32`.
  - Set `MAX_TOTAL_PCM_BYTES = 128 * 1024 * 1024` (128 MB).
- [ ] Update `apps/studio/src/lib/audio/WebAudioEngine.ts`:
  - Update `syncFromIR` lookahead to preload around `currentFrame` (`[currentSec - 2s, currentSec + 30s]`).
  - Scan both audio and video tracks (`track.type === 'audio' || track.type === 'video'`).

### Phase 4: Reactive Hot-Swap for Instantaneous Preview
- [ ] In `WebAudioEngine.ts`:
  - When `AudioAssetCache` notifies of a finished decode while `isPlaying` is true:
    - If the current source buffer was synthesized while assets were missing, immediately synthesize the remaining active chunk from the current playhead time and start it, smoothly replacing the silent buffer.

- [ ] Run all audio unit tests with `bun test`.
