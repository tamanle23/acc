# Walkthrough 29: Deterministic Single-Owner Cache & Post-Render Drain in Studio Preview

## Overview
Permanently resolved the `InvalidStateError: The image source is detached` exception during video canvas rendering in Studio Preview (`apps/studio/src/workers/preview.worker.ts` and `IRCanvasCompositor.ts`) without heuristic `setTimeout` delays.

## Changes Made

### 1. Architecture Refactor: Pure Single-Owner Cache
- **`apps/studio/src/workers/MediabunnyWorkerReader.ts`**:
  - Eliminated the internal `ringBuffer` and removed all internal `.close()` calls.
  - Refactored `requestFrame()` to act as a pure, stateless WebCodecs decoder that decodes directly from `CanvasSink.getCanvas()` and returns the bitmap without holding or closing secondary references.
- **`apps/studio/src/workers/PreviewFrameMemoryManager.ts`**:
  - Established as the single authority for decoded video frame lifecycle management.
  - Eliminated `setTimeout(..., 50)`.
  - Added a deterministic staged disposal queue (`pendingDisposal`).
  - Added `drainDisposalQueue(protectedBitmaps?: Set<ImageBitmap>)` which closes evicted bitmaps synchronously while sparing frames actively in use.

### 2. Preview Worker Post-Render Drain
- **`apps/studio/src/workers/preview.worker.ts`**:
  - Enclosed `engine.renderFrame(...)` in a `try ... finally` block.
  - Inside `finally`:
    - Collected active bitmaps from `textureCache` into a `protectedBitmaps` set.
    - Synchronously called `memoryManager.drainDisposalQueue(protectedBitmaps)`.
  - Guaranteed that frames are never detached while `ctx.drawImage` is running, and obsolete frames are closed synchronously immediately after the draw pass completes.

### 3. Automated Test Coverage
- **`autogenerated-tests/preview_frame_memory_manager_drain.test.ts`**:
  - Validates frame storage and retrieval.
  - Validates staging in `pendingDisposal` during `pruneOutsideWindow()`.
  - Validates `drainDisposalQueue()` sparing actively rendered frames.
  - Validates LRU eviction when global budget (64 frames) is exceeded.
- **`autogenerated-tests/mediabunny_ring_buffer.test.ts`**:
  - Harmonized with stateless decoder architecture and safe disposal.
