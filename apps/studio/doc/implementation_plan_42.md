# Implementation Plan - Iteration 42: Studio Architecture Remediation, Zero-Leak Memory Safety & State Integrity

**Companion Local Plan** for `@acc/studio`.  
**Master Plan Reference:** [docs/iterations/master_implementation_plan_iteration_48.md](../../../docs/iterations/master_implementation_plan_iteration_48.md)

---

## 1. Problem Statement & Root Cause
1. **ImageBitmap Lifecycle Conflict:** `preview.worker.ts` (`safeSetTexture`) closes overwritten textures while `PreviewFrameMemoryManager` holds them in LRU cache, causing invalid closed bitmaps on reverse scrubs.
2. **Abandoned Promises:** `PreviewWorkerCoordinator.reset()` clears `this.activeTasks` without rejecting pending promises, causing caller hangs.
3. **Keyboard Collision:** Five disparate `window.addEventListener('keydown')` listeners collide on `Cmd+K` vs pure `K` (shuttle pause), `Delete`/`Backspace` double-triggers, and `Space` (hand tool vs play toggle).
4. **Async Compilation Race:** `IRStateManager.dispatch()` triggers un-awaited async compilations that interleave during rapid dragging, overwriting newer state with stale timelines.
5. **Playhead Stuttering:** `useShuttleEngine.ts` throttles playhead ticks to 15 FPS (66ms) before notifying `StudioPlayheadController`, causing high-frequency canvas/needle animation to stutter.
6. **Command Duplication & Heavy Serialization:** `TimelineCommandDispatcher` retains unbounded history, while 60+ command instances use `JSON.parse(JSON.stringify(doc))` deep clones instead of native `structuredClone`.
7. **Audio RAM Churn:** `AudioAssetCache` caches raw uncompressed PCM in heap instead of streaming from OPFS via `ContentCacheRegistry`, and duplicates `AudioContext`.

---

## 2. Architectural Solution

### Phase 1: P0 Memory Ownership & Centralized Keyboard Safety
- **Single Bitmap Ownership:** `safeSetTexture()` in `preview.worker.ts` becomes a pure pointer setter without calling `.close()`. `PreviewFrameMemoryManager` exclusively manages LRU eviction and `.close()`.
- **Coordinator Task Cleanup:** `PreviewWorkerCoordinator.reset()` rejects all in-flight promises with an explicit error before clearing `activeTasks`.
- **Centralized `StudioKeyboardManager`:** Implement a prioritized keybinding manager (`apps/studio/src/lib/keyboard/StudioKeyboardManager.ts`) with priority stack:
  `modal` > `input` > `surface` > `transport` > `global`. Migrate listeners from `App.tsx`, `Timeline.tsx`, `usePreviewHotkeys.ts`, `Titlebar.tsx`, and `useShuttleEngine.ts`.

### Phase 2: P1 Concurrency, 60 FPS Motion & Preflight Hashing
- **Two-Tier Compilation Guard:** Make `IRStateManager.dispatch()` return `Promise<void>` with an internal sequential execution queue and monotonic epoch counter. Expose `isCompiling` to the UI to prevent overlapping edits.
- **60 FPS Playhead Decoupling:** In `useShuttleEngine.ts`, call `StudioPlayheadController.seek()` on **every** RAF frame tick (60 FPS) while keeping React state updates throttled to 10–15 Hz.
- **Preflight Content Hashing:** Hash `modifier.params` into the coordinator task key (`${targetId}:${type}:${contentHash}`) so parameter edits are never skipped.
- **Decoder Concurrency Gate:** Pause lookahead speculative decodes when sequential playback is actively streaming frames from `CanvasSink`.

### Phase 3: P2 Audio, OPFS Hygiene & Command Unification
- **Shared AudioContext:** Consolidate `WebAudioEngine` and `AudioAssetCache` to share a single lazily initialized `AudioContext`.
- **OPFS-First Audio Cache:** Stream and cache audio blobs in `AudioAssetCache` via `ContentCacheRegistry` (OPFS) instead of holding raw Float32Array PCM arrays in heap.
- **OPFS Lock Release:** Ensure `opfsWritable.abort()` or `close()` is always executed in `try ... finally` in `ClientExportOrchestrator.ts`.
- **Command Unification:** Eliminate `TimelineCommandDispatcher` in `TimelineCommands.ts`, redirecting timeline actions directly to `IRStateManager`. Refactor command classes to use `cloneIR()` (`structuredClone`).

### Phase 4: P3 Dead Code Elimination
- Delete orphaned `ThumbnailLRUCache.ts`.
- Clean up dead `_isTransient` references in `preview.worker.ts`.
- Synchronize `DESIGN.md` and `ROUTE.md`.
