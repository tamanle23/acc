# Implementation Plan - Studio Preview Engine Relocation & Universal Sidecar Worker

**Target App:** `apps/studio`  
**Iteration:** 39 (Studio Plan #32)  
**Parent Master Plan:** [`docs/iterations/master_implementation_plan_iteration_39.md`](file:///Users/anle/workspace/acc/docs/iterations/master_implementation_plan_iteration_39.md)

---

## 1. Goal Description
Relocate `IRPreviewEngine` from `@acc/ir` directly into `apps/studio/src/renderer/preview/` and establish a universal `StudioSidecarWorker` / `StudioSidecarCoordinator` architecture. This replaces the bespoke `visionWorker.ts` and `StudioVisionPipelineManager.ts` with a plugin-agnostic background preflight coordinator that runs `plugin.execute()` for any modifier (VFX, audio, motion, shaders) off the main thread.

---

## 2. Proposed Local Changes

### `apps/studio/src/renderer/preview/`
- **[NEW] `IRPreviewEngine.ts`**:
  Relocated preview renderer tailored for Studio. Integrates directly with Studio's `AssetTextureCache`, `UniversalAudioMixer`, and `StudioSidecarCoordinator`.
- **[NEW] `sidecar/SidecarTypes.ts`**:
  Defines contracts for `EXECUTE_MODIFIER`, `CANCEL_TASK`, `WARMUP`, and `RESET`.
- **[NEW] `sidecar/StudioSidecarCoordinator.ts`**:
  Manages background worker lifecycle, proximity prioritization, task abort on sequence deletion, and in-process fallback.

### `apps/studio/src/workers/`
- **[NEW] `preview-sidecar.worker.ts`**:
  Vite-compatible web worker running isomorphic core modifier plugin execution off-thread.
- **[DELETE] `visionWorker.ts`**:
  Removed in favor of universal `preview-sidecar.worker.ts`.

### `apps/studio/src/lib/vision/`
- **[DELETE] `StudioVisionPipelineManager.ts`**:
  Removed in favor of `StudioSidecarCoordinator`.

### Studio Component Integrations
- **[MODIFY] `apps/studio/src/components/Preview.tsx`**:
  Update imports to local `./renderer/preview/IRPreviewEngine`. Connect to `previewEngine.onModifierWarmed` for eager repainting.
- **[MODIFY] `apps/studio/src/App.tsx`**:
  Update imports to local `./renderer/preview/IRPreviewEngine`.
- **[MODIFY] `apps/studio/src/lib/audio/WebAudioEngine.ts`**:
  Update imports to local `./renderer/preview/IRPreviewEngine`.
- **[MODIFY] `apps/studio/src/workers/preview.worker.ts`**:
  Update imports to local `./renderer/preview/IRPreviewEngine`.
