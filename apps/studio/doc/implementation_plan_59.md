# Implementation Plan 59: Studio Memory Minimization & Multi-FPS Smooth Playback Optimization

Companion local implementation plan for `docs/iterations/master_implementation_plan_iteration_77.md`.

## User Review Required
- `#studio-overlay-canvas` downscaled to match `#studio-canvas` active resolution ($960\times 540$) and bypassed during playback.
- `packages/core-web` uses dynamic proxy strategies for Depth Anything V2 and RMBG.
- `AudioAssetCache` PCM memory ceiling set to 16 MB.
- Main thread `hotVideoLRU` eliminated from `AssetTextureCache`.
- `IrVisualEditorModal`, `OpfsExplorerModal`, and `ShortcutsModal` code-split with `<Suspense fallback={<ModalProgressFallback />}>`.

## Phases & Tasks

### Phase 1: Core Web Runtime Decoupling (`packages/core-web`)
- Modify `packages/core-web/src/index.ts`:
  - Implement `LazyNeuralDepthStrategy` and `LazyNeuralSegmentationStrategy`.
  - Remove top-level static imports of `@acc/effect-engines`.

### Phase 2: Audio Engine & PCM Optimization (`apps/studio/src/lib/audio`)
- Modify `apps/studio/src/lib/audio/AudioAssetCache.ts`:
  - Update `MAX_TOTAL_PCM_BYTES = 16 * 1024 * 1024`.
  - Update `MAX_CACHE_ENTRIES = 4`.
- Modify `apps/studio/src/lib/audio/WebAudioEngine.ts`:
  - Tune `syncFromIR` proximate lookahead to 6 seconds.

### Phase 3: Canvas Sizing & UI Layer Optimization (`apps/studio/src/components`)
- Modify `apps/studio/src/components/preview/useViewportRenderStrategy.ts`:
  - Downscale `overlayCanvas` to `options.width` and `options.height`.
- Modify `apps/studio/src/components/Preview.tsx`:
  - Bypass overlay canvas clearing and rendering when `props.isPlaying` is true.
  - Pass `virtualWidth()` and `virtualHeight()` to `renderGuides`.
- Modify `apps/studio/src/lib/textures/AssetTextureCache.ts`:
  - Remove `hotVideoLRU` and `document.createElement('video')`.
  - Reduce canvas and image cache bounds.
- Create `apps/studio/src/components/ui/ModalProgressFallback.tsx`:
  - Liquid glass styled progressive loading spinner.
- Modify `apps/studio/src/components/Titlebar.tsx`:
  - Code-split `IrVisualEditorModal`, `OpfsExplorerModal`, and `ShortcutsModal` using `lazy()`.
  - Wrap in `<Suspense fallback={<ModalProgressFallback />}>`.

### Phase 4: Worker Pipeline Limits (`apps/studio/src/renderer/workers`)
- Modify `apps/studio/src/renderer/workers/preview.worker.ts`:
  - Reduce `MAX_WORKER_TEXTURES = 8`.
- Modify `apps/studio/src/renderer/workers/WebCodecsDecoderPool.ts`:
  - Reduce default `maxHardwareDecoders = 4`.
- Preserve `SequentialVideoReader.ts` circular ping-pong buffer strictly unchanged.
