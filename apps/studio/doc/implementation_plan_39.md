# Implementation Plan - Studio Iteration 39: Elimination of In-Memory Texture Caches & Native Buffer Leaks

## 1. Context & Objectives
This app-specific implementation plan companions `docs/iterations/master_implementation_plan_iteration_44.md`. It targets memory accumulation in `@acc/studio`:
- Refactor [`AssetTextureCache.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/lib/textures/AssetTextureCache.ts) to eliminate unbounded in-memory `Map`s and standardize on [`ContentCacheRegistry`](file:///c:/Users/Admin/workspace/git/acc/packages/core-isomorphic/src/cache/ContentCacheRegistry.ts).
- Refactor [`PreviewFrameMemoryManager.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/renderer/workers/PreviewFrameMemoryManager.ts) into a strict size-capped LRU cache (`MAX_GLOBAL_FRAMES = 32`) with immediate synchronous `.close()` execution on eviction, overwrite, and pruning.
- Bifurcate playback vs scrubbing in [`preview.worker.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/renderer/workers/preview.worker.ts) and [`MediabunnyWorkerReader.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/renderer/workers/MediabunnyWorkerReader.ts): sequential playback frames are marked transient and closed immediately post-draw, preventing 2.5GB memory buildup.
- Pool scratch canvas instances across studio renderers and text caches via [`CanvasScratchPool`](file:///c:/Users/Admin/workspace/git/acc/packages/core-isomorphic/src/canvas/CanvasScratchPool.ts).

## 3. Detailed Refactoring Tasks
- [ ] **AssetTextureCache**: Replace 7 static/instance maps with Hot Decoders LRU ($\le 8$ images, $\le 4$ videos) and delegate all persistent storage to `ContentCacheRegistry.get()`.
- [ ] **PreviewFrameMemoryManager**: Cap capacity to 32 frames; synchronously execute `bitmap.close()` on eviction, overwrite, prune, and clear.
- [ ] **preview.worker.ts**: Tag sequential playback frames as `_isTransient = true`; wire `onAssetDrawn` hook to immediately execute `.close()` post-draw; synchronously close replaced/evicted bitmaps in `safeSetTexture()`.
- [ ] **MediabunnyWorkerReader**: Clean single-ownership tag on decoded `ImageBitmap`s.
- [ ] **ContentHashTextureCache**: Reuse single scratch canvas via `ctx.clearRect()`; strictly cap LRU at 32 items with synchronous closure on eviction.
- [ ] **Testing**: Verify with `bun test autogenerated-tests/memory_native_buffer_hygiene.test.ts`.
