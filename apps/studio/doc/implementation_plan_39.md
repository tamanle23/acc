# Implementation Plan - Iteration 39: IRPreviewEngine & Sidecar Worker Permanent Decoupling

Architectural decoupling of `IRPreviewEngine` from implicit `PreviewWorkerCoordinator` singleton instantiation, eliminating duplicate Web Worker loads.

---

## 1. Problem Statement & Root Cause
- When running `WorkerRenderStrategy`, `apps/studio/src/renderer/IRPreviewEngine.worker.ts` was loaded twice.
- **Root Cause**: `IRPreviewEngine` constructor contained a hidden dependency:
  `this.sidecarCoordinator = options?.sidecarCoordinator ?? PreviewWorkerCoordinator.getInstance()`.
  When `preview.worker.ts` (the dedicated viewport rendering worker) instantiated `new IRPreviewEngine(timeline)`, it executed in an isolated worker heap where `PreviewWorkerCoordinator.instance` was `null`. Because `preview.worker.ts` polyfilled `(self as any).window = self`, the environment check passed, spawning a second (nested) sidecar worker.
- Furthermore, because `IRPreviewEngine.ts` statically imported `PreviewWorkerCoordinator` as a runtime value, Vite was forced to bundle the worker code into the `preview.worker.js` output chunk.

---

## 2. Architectural Solution
1. **Pure Dependency Injection**:
   - `IRPreviewEngine` switches to `import type { PreviewWorkerCoordinator }`.
   - `options?.sidecarCoordinator` defaults to `null` and `autoPreflight` defaults to `false`.
   - Zero hidden worker spawns or preflight queues inside `new IRPreviewEngine()`.
2. **Bundler Tree-Shaking Isolation**:
   - Because `IRPreviewEngine` no longer has a runtime import of `PreviewWorkerCoordinator`, `preview.worker.js` chunk completely omits the sidecar worker code.
3. **Composition Root Ownership**:
   - The Main UI Thread (`useViewportRenderStrategy.ts` and `MainThreadRenderStrategy.ts`) explicitly injects `PreviewWorkerCoordinator.getInstance()`.
4. **Worker Realm Invariant Guard**:
   - `PreviewWorkerCoordinator.getInstance()` explicitly detects Web Worker environments (`WorkerGlobalScope` / `importScripts`) and throws, preventing worker recursion forever.

---

## 3. Verification Criteria
- `autogenerated-tests/studio_preview_engine_worker_decoupling.test.ts` passes with 100% assertions:
  - Default constructor sets `sidecarCoordinator: null` and `autoPreflight: false`.
  - Explicit injection works as expected.
  - Worker realm detection guards against accidental invocation.
