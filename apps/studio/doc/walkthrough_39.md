# Studio Iteration 39 Walkthrough: Elimination of In-Memory Texture Caches & Native Buffer Leaks

## Overview
Studio Iteration 39 (companion to Master Plan Iteration 44) completely resolved the 2GB+ native memory accumulation and GPU VRAM exhaustion during playback and scrubbing by:
1. Eliminating 7 unbounded in-memory `Map`s in [`AssetTextureCache.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/lib/textures/AssetTextureCache.ts) and integrating with isomorphic [`ContentCacheRegistry`](file:///c:/Users/Admin/workspace/git/acc/packages/core-isomorphic/src/cache/ContentCacheRegistry.ts).
2. Implementing an immediate synchronous `.close()` execution protocol on transient `ImageBitmap` and `VideoFrame` instances post-`drawImage()`.
3. Bounding timeline scrubbing cache to a strict 32-frame ceiling in [`PreviewFrameMemoryManager.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/renderer/workers/PreviewFrameMemoryManager.ts) with immediate synchronous `.close()` execution on eviction, overwrite, and pruning.
4. Pooling scratch canvas contexts via [`CanvasScratchPool`](file:///c:/Users/Admin/workspace/git/acc/packages/core-isomorphic/src/canvas/CanvasScratchPool.ts).

## Changes Summary

### 1. `apps/studio/src/lib/textures/AssetTextureCache.ts`
- Removed unbounded maps (`canvasCache`, `placeholderCache`, `dataUrlCache`, `directStorage`, `imageCache`, `videoCache`, `objectUrls`).
- Added strict Hot Decoders LRU ($\le 8$ images, $\le 4$ videos) with immediate cleanup (`URL.revokeObjectURL`, `video.load()`).
- Integrated `loadBlob()` with `ContentCacheRegistry.get().set(assetId, blob)`.
- Replaced DOM canvas allocations in `getThumbnailDataUrl` with `UniversalCanvasProvider.acquireScratchCanvas()` and `releaseScratchCanvas()`.

### 2. `apps/studio/src/renderer/workers/PreviewFrameMemoryManager.ts`
- Capped global frame budget to `MAX_GLOBAL_FRAMES = 32`.
- Synchronously executes `bitmap.close()` immediately upon LRU eviction, key overwrite, window pruning, and cache clearing.

### 3. `apps/studio/src/renderer/workers/preview.worker.ts`
- Bifurcated playback vs scrubbing: sequential playback frames tagged `_isTransient = true` and closed immediately post-draw via `onAssetDrawn`.
- In `safeSetTexture`: closes overwritten or evicted bitmaps synchronously.
- In `syncAssetSources`: synchronously closes old bitmaps of removed asset readers.

### 4. `apps/studio/src/renderer/workers/ContentHashTextureCache.ts`
- Reduced `MAX_ENTRIES` to 32.
- Added `delete()` with synchronous `.close()`.

### 5. `packages/ir/src/renderer/shared/IRCanvasCompositor.ts`
- Added `onAssetDrawn?(assetId: string, asset: any): void` to `IAssetSourceResolver`.
- Wrapped `ctx.drawImage()` in `try...finally` to immediately trigger `onAssetDrawn` or close single-use transient bitmaps.
- Integrated `getScratchContext` with `UniversalCanvasProvider.acquireScratchCanvas()`.

### 6. `packages/ir/src/renderer/IRMasterRenderer.ts`
- Added `onAssetDrawn` and `finally` block in `renderCanvasFrame()` to close all `activeVideoFrames` immediately after composite.
