# Implementation Plan 18: Pure TypeScript Runtime Modifier Parameters Validation

Implement deep, high-speed imperative validation of modifier parameters in `VideoIRSchemaValidator.ts` while preserving `video-ir.schema.json` and `modifiers.schema.json` as decoupled standalone JSON schemas.

## Proposed Changes

### Package `@acc/ir`

#### `packages/ir/src/schema/VideoIRSchemaValidator.ts`
- Implement `validateTemporalCurve` checking `intro`, `steady`, `outro`, and `keyframes`.
- Implement `validateModifierParams` covering all standard modifier types:
  - `transform` and `transform/scale`: validate numeric bounds or `TemporalCurve` objects, `animation.preset`, etc.
  - `vfx/camera_3d`: validate keyframe timing and 3D position vectors `[x, y, z]`.
  - `vfx/depth3d`: validate `mode` and `relighting` structures.
  - `color/lut`: validate required `lutAsset`/`lut` strings and intensity bounds.
  - `overlay/canvas_particles`: validate particle count, useSIMD boolean, and type strings.
  - `overlay/hologram_hud`: validate enabled flags, glitch intensity, and colors.
  - `overlay/blend_mode`: validate mode strings against canonical blend modes.
  - `text/style`: validate font size, font family, text align, and active word configs.
  - `audio/volume`: validate non-negative volume and fade times.
  - `audio/pan`: validate stereo pan within `[-1.0, 1.0]`.
  - `audio/filter`: validate filter type enum and cutoff frequency.
  - `audio/pitch`: validate playback rate and detune cents.
  - `sfx/dynamic_ducking`: validate ducking factor (numeric or TemporalCurve).
  - `audio/compressor`: validate threshold and ratio bounds.
  - `sfx/procedural`: validate synth type and duration.
  - `editorial/split_edit`: validate split mode and duration frames.
  - `transition/crossfade` / `editorial/transition`: validate transition duration.
- Enforce Open-Closed Principle (OCP): unknown/custom modifier types are permitted if they have a non-null object for `params`.
