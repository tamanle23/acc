# Studio Walkthrough 50: Universal Track Soft-Cap Constraints & Semantic Track Quotas in VideoIRAuthoringEngine

## 1. Overview & Verification Summary
Iteration 56 completes the implementation of **Universal Track Soft-Cap Constraints & Semantic Track Quotas** across `@acc/ir`, `apps/studio`, and `apps/cli`:
1. **Configurable Authoring Policy**: Defined `TrackAuthoringPolicy`, `SemanticTrackRole`, and `DEFAULT_TRACK_AUTHORING_POLICY` with default soft caps (1 main, 6 overlays, 3 text, 2 effects, 2 stickers, 4 audio) and hard caps (1 main, 10 overlays, 6 text, 4 effects, 4 stickers, 8 audio).
2. **Dynamic Semantic Role Classification**: Implemented heuristic role classifier without mutating the foundational `VideoIRDocument` schema.
3. **Dual-Mode Enforcement**:
   - Studio UI: Soft-cap warnings appear as ambient Liquid Glass badges (`TrackHeaderCard.tsx`); hard caps open a confirmation modal (`TrackQuotaModal.tsx`) with an explicit `[Add Track Anyway]` manual override.
   - CLI / AI Generator: Hard caps strictly prevent agent generators from spawning excess tracks and trigger automatic temporal whitespace reuse (`canPlaceSequenceOnTrack`, `findWhitespaceTrack`).
4. **Command & State Integration**: Implemented `AddTrackCommand.ts` and wired `canAddTrack`, `addTrack`, `checkCanAddTrack`, and `getTrackQuotas` into `IRStateManager` and `StudioTimelineState`.
5. **Formal Verification Suite**: Added comprehensive test coverage in `autogenerated-tests/track_soft_cap_policy.test.ts`.

## 3. Key Architecture Components

### 3.1 `VideoIRAuthoringEngine` Quota System (`packages/ir/src/authoring/VideoIRAuthoringEngine.ts`)
- `SemanticTrackRole`: `'main' | 'overlay' | 'audio' | 'text' | 'effects' | 'stickers'`
- `TrackAuthoringPolicy`: Limits configuration per semantic role with `allowHardCapOverride` flag.
- `classifyTrackRole(track, index)`: Heuristic classifier analyzing track index, id prefixes, names, and track modifiers.
- `evaluateTrackQuotas(doc, policy)`: Generates structured quota status per role.
- `canAddTrack(doc, roleOrType, policy, isManualOverride)`: Gatekeeper function returning approval, warnings, and reasons.
- `canPlaceSequenceOnTrack(track, startFrame, durationFrames)`: Checks if a sequence can fit on an existing track without temporal collision.
- `findWhitespaceTrack(doc, role, startFrame, durationFrames)`: Finds an existing track with available gap to reuse.

### 3.2 Studio UI Components (`apps/studio`)
- `AddTrackCommand.ts`: Implements undoable track insertion adhering to `ICommand` and `STATE-IMMUTABILITY`.
- `TrackHeaderCard.tsx`: Displays subtle ambient warning badge (`6/6`) when soft caps are exceeded.
- `TrackQuotaModal.tsx`: Liquid Glass dialog warning of compositing loads and offering `[Add Track Anyway]`.
- `Timeline.tsx`: Provides explicit "+ Add Track" interaction, connects quota check, and manages override modal state.
- `irState.ts`: Houses `checkCanAddTrack`, `getTrackQuotas`, and `addTrack` methods.

### 3.3 CLI Timeline State (`apps/cli/src/studio/StudioTimelineState.ts`)
- Added `getTrackQuotas()`, `checkCanAddTrack()`, and `addTrack()` to enforce track quotas in headless/remote environments.
