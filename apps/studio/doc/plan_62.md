# Studio Companion Plan 62: In-Place Text Editing, Sibling Smart Guides & HUD Anchor Tool

## Overview
Elevates Studio Viewport direct canvas manipulation to studio-grade quality across three core pillars:
1. **In-Place Canvas Text Editing**: Retires the modal dialog in favor of zero-backdrop direct text editing on the canvas with multi-line support (<kbd>Enter</kbd> inserts newline; blur, <kbd>Escape</kbd>, or <kbd>Cmd/Ctrl+Enter</kbd> commits).
2. **Sibling Smart Guides**: Extends `MagneticSnapEngine` to compute snap lines across all active sibling sequences on the canvas.
3. **Interactive Anchor Tool & HUD Status Chips**: Dedicated `[Tool: Move | Anchor]` toggle button on the HUD badge, interactive pivot reticle, tether visualization, and status chips (`[Snap: ON/OFF]`, `[Axis: Free/Lock]`, `[Scale: Corner/Center]`).
