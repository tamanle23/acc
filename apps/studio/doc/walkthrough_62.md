# Studio Companion Walkthrough 62: In-Place Text Editing, Sibling Smart Guides & HUD Anchor Tool

## Overview
Elevated Studio Viewport direct canvas manipulation to studio grade across three pillars:
1. **In-Place On-Canvas Text Editing**: Retired the intrusive center modal `InlineTextEditorModal.tsx` in favor of `InPlaceTextEditor.tsx`, a zero-backdrop auto-expanding textarea positioned over the sequence's exact canvas bounding box and affine transform.
2. **Sibling Smart Guides**: Upgraded `MagneticSnapEngine` to compute snap lines across all active sibling sequences on the canvas, snapping to closest matching edge or center with neon-cyan guide lines.
3. **Interactive Anchor Point Tool**: Made the center pivot reticle crosshair (`+`) draggable, added an anchor tether line, and exposed discoverable status chips (`[Tool: Move | Anchor]`, `[Snap: ON/OFF]`, `[Axis: Lock/Free]`, `[Scale: Center/Corner]`) in the floating HUD.

## Changes Implemented

### 1. In-Place Canvas Text Editor
- **`apps/studio/src/components/preview/InPlaceTextEditor.tsx`**:
  - Mounted directly in the preview canvas container, matching `bounds.normX`, `bounds.normY`, dimensions, scale, and rotation.
  - Dynamically extracts typography styles (`fontFamily`, `fontSize` scaled to canvas reference, `fontWeight`, `fontStyle`, `color`, `letterSpacing`, `lineHeight`, `textAlign`) from `text/draw` or `text/overlay` modifier params.
  - <kbd>Enter</kbd> inserts a newline; <kbd>Escape</kbd>, blur, or <kbd>Cmd/Ctrl+Enter</kbd> commits text to `IRStateManager`.
  - Suppresses keyboard and pointer bubbling to prevent timeline scrubbing or sequence deletion.
- **`apps/studio/src/components/Preview.tsx`**:
  - Replaced `InlineTextEditorModal` with `InPlaceTextEditor`.
  - Hides `TransformGizmoOverlay` while text editing is active to eliminate visual clutter.

### 2. Sibling Smart Guides & Snapping Math
- **`apps/studio/src/lib/gizmo/Gizmo2DTransformation.ts`**:
  - Added `SiblingGuideBox` interface and extended `MagneticSnapEngine.snap(...)` with `siblingBoxes`.
  - Re-engineered snapping to find the closest magnetic distance rather than stopping on first match.
  - Styled `sibling` guides in `#38bdf8` (sky cyan) with glowing dashed lines spanning the canvas.
- **`apps/studio/src/components/preview/useGizmoTransform.ts`**:
  - Dynamically harvests visible sibling sequences from `activeSequences.filter(s => s.id !== selectedSeqId)`.
  - Passed <kbd>Ctrl/Cmd</kbd> bypass flag and <kbd>Shift</kbd> orthogonal axis lock to `computeDragTransform`.

### 3. Interactive Anchor Point Tool & Tether Line
- **`apps/studio/src/lib/gizmo/Gizmo2DTransformation.ts`**:
  - Added `'anchor'` handle type in `TransformHandleType`.
  - Calculates displaced normalized anchor `[normAnchorX, normAnchorY]` in rotated box coordinate space.
- **`apps/studio/src/components/preview/TransformGizmoOverlay.tsx`**:
  - Reticle crosshair is draggable with `crosshair` cursor.
  - Renders a dashed SVG tether line from geometric center `(50%, 50%)` to the displaced anchor point.
  - Saves `anchorPoint` to the sequence's `transform` modifier upon pointer up.

### 4. Discoverable HUD Status Chips & Rotated Cursors
- **`apps/studio/src/components/preview/TransformGizmoOverlay.tsx`**:
  - Two-row floating HUD badge with clickable status chips:
    - `[Tool: Move | Anchor]`
    - `[Snap: ON | OFF]`
    - `[Axis: Lock | Free]`
    - `[Scale: Center | Corner]`
  - Real-time telemetry metrics (`POS`, `SIZE`, `ANGLE`, `PIVOT`, `Snap: [Label]`).
  - Implemented `getRotatedCursor` for all 8 handles based on $(angle_{base} + rotation) \pmod{360}$.
