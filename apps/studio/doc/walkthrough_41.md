# Walkthrough - Iteration 41: Unified Compositor Frame-Level RAII Parity & Headless Scoped Resource Engine

## 1. Summary of Changes
- **Isolated & Resolution-Aware `NativeResourceManager` (`@acc/core-isomorphic`)**:
  - Added `NativeResourceManager.createIsolated(maxGpuBytes)` factory for independent worker budgets in multi-worker chunk pipelines.
  - Added `NativeResourceManager.computeResolutionBudgetBytes(width, height, customMaxMemoryMb)` scaling default budgets dynamically (64 MB for $\le 1080$p, 128 MB for 2K, 256 MB for 4K+) with explicit `maxMemoryMb` override support.
  - Added `onExit(callback)` LIFO stack unwinding to `FrameResourceScope` and native backing destruction (`width = 0; height = 0`) to `CanvasScratchPool`.
- **Unified Frame-Level RAII in `IRCanvasCompositor` & `IRPreviewEngine`**:
  - Replaced the static `scratchCanvasInstance` singleton in `IRCanvasCompositor.ts` with frame-scoped scratch canvas acquisition registered to `FrameResourceScope.onExit()`.
  - Wired `FrameResourceScope` across both `IRPreviewEngine.renderFrame()` (`'preview'` profile) and `IRMasterRenderer.renderCanvasFrame()` (`'master'` profile).
- **Sliding Hybrid Sequence Eviction in `IRMasterRenderer`**:
  - Implemented `computeAssetLifespans()`, `ensureActiveSequencesPreflighted()`, and `evictExpiredSequences()`.
  - Sequence scopes and cached assets are immediately evicted as soon as a sequence's out-point passes, unless a subsequent sequence on the timeline shares the exact same asset key.
- **Multi-Worker Isolation in `IRChunkWorkerPool`**:
  - Each chunk worker receives an isolated `NativeResourceManager` instance and deterministically disposes all scopes in a `finally` block upon chunk completion.
