# Walkthrough - Iteration 38 (Phase 1): Timeline Waveform Virtualization

Implementation and verification of unified 2D Canvas lane virtualization for timeline audio tracks, replacing O(N) `wavesurfer.js` DOM instances with a single sticky viewport `<canvas>` powered by `WaveformLODPyramid`.

---

## Changes Summary

### 1. `apps/studio/src/components/timeline/TrackWaveformVirtualCanvas.tsx`
- Created a high-performance virtualized canvas component rendering only visible audio clip segments within the current viewport $[F_{\text{start}}, F_{\text{end}}]$.
- Batched vertical waveform line drawing with single-path execution (`ctx.beginPath() ... ctx.stroke()`).
- Retina / HiDPI support with $2\times$ DPR backing store scaling and CSS pixel clamping.
- Sticky positioning (`position: sticky; left: 0`) ensures zero layout shift during horizontal scrolling.

### 2. `apps/studio/src/components/timeline/DroppableTrackLane.tsx`
- Added `scrollLeft`, `viewportWidth`, `pixelsPerFrame`, and `fps` props.
- Automatically mounts `TrackWaveformVirtualCanvas` when `track.type === 'audio'`.

### 3. `apps/studio/src/components/timeline/TimelineDom.tsx`
- Wired `scrollLeft`, `clientWidth`, `pixelsPerFrame`, and `fps` into `DroppableTrackLane`.

### 4. `apps/studio/src/components/timeline/WaveSurferWaveform.tsx`
- Refactored `WaveSurferWaveform` from heavy `WaveSurfer.create()` DOM/AudioContext creation to direct, lightweight HTML5 `<canvas>` rendering.
- Retained 100% backward compatibility for `getCachedPeaks()`, `clearWaveSurferPeakCache()`, and prop interfaces.

### 5. `apps/studio/src/components/timeline/index.ts`
- Exported `TrackWaveformVirtualCanvas`.

## Phase 2: WebCodecs Hardware Decoder Quota Pool

Implementation of centralized hardware video decoder quota management, priority-based leasing, and OPFS poster frame graceful degradation.

### Changes Summary
1. **`WebCodecsDecoderPool.ts`**:
   - Caps concurrent hardware video decoders at $\le 8$.
   - Evaluates playhead frame proximity $P(clip)$ and evicts lowest-priority decoders when quota is reached.
   - QuotaExceededError auto-recovery ladder dynamically reduces ceiling ($8 \to 6 \to 4 \to 2$).
2. **`MediabunnyWorkerReader.ts`**:
   - Added `evictHardwareDecoder()` and `reacquireHardwareDecoder()` to close/re-open native GPU contexts without dropping metadata.
   - Added OPFS poster keyframe caching and fallback in `requestFrame()`.
3. **`preview.worker.ts`**:
   - Registered video readers with `WebCodecsDecoderPool`.
   - Wired `updatePriorities()` on every rendered frame to ensure foreground tracks receive active hardware decoder leases.

## Phase 3: Lock-Free AudioWorklet SPSC RingBuffer

Implementation of high-performance Single Producer Single Consumer (SPSC) circular queue backed by `SharedArrayBuffer` and synchronized using lock-free `Atomics` memory barriers for the Web Audio DSP render loop.

### Changes Summary
1. **`SharedArrayRingBuffer.ts`**:
   - 64-byte `Int32Array` control block (`READ_PTR`, `WRITE_PTR`, `CAPACITY`, `FLAGS`).
   - Planar stereo `Float32Array` buffers with zero garbage collection allocations.
   - Deterministic split circular boundary wraparound math.
   - Strict Acquire/Release memory barrier ordering via `Atomics.store()` and `Atomics.load()`.
   - Dynamic capability detection with transparent fallback to non-shared `ArrayBuffer`.
2. **`SpscAudioWorkletProcessor.ts`**:
   - AudioWorkletProcessor script executed on the real-time high-priority Web Audio render thread every 128 samples (~2.9ms).
   - Reads directly from shared memory with zero GC pauses, eliminating audio dropouts and pops.
   - Added `registerSpscAudioWorklet(ctx)` registration utility with blob URL lifecycle management.
3. **`UniversalAudioStreamWorklet.ts`**:
   - Backed by `SharedArrayRingBuffer` with 5ms cosine cross-fade on seek/scrub.
4. **`WebAudioEngine.ts`**:
   - Automatically initializes `AudioWorkletNode` when `SharedArrayRingBuffer` is active in cross-origin isolated contexts, with transparent fallback to chunk scheduling.
