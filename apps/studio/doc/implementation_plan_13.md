# Implementation Plan 13 - Studio Preview: Effect Engines Math Reuse & Subcomponent Decomposition

## Problem Statement
The Studio `Preview.tsx` component had become monolithic, containing complex UI controls (zoom HUD, pan hand tool, safe guide overlays, action pills, subtitle captions) intertwined with Canvas2D rendering and asset caching. Additionally, canvas compositing calculations—such as layer aspect ratio fitting (`cover` vs `contain`), modifier blend modes, and affine transform matrix operations—were written directly inside `Preview.tsx` as boilerplate, violating DRY and missing the reuse of `@acc/effect-engines`. Finally, asynchronous asset decodes in `AssetTextureCache` did not trigger reactive re-renders, leaving users looking at placeholders until the scrubber was moved.

## Proposed Architecture & Design Patterns
1. **Engine Layer Compositor Pattern (`UniversalCanvasEngine.renderLayers`)**:
   - Centralize multi-track layer sorting and Canvas2D rendering in `packages/effect-engines/src/canvas/UniversalCanvasEngine.ts`.
   - Provide a clean `VisualLayerItem` interface with `fitMode` (`cover` | `contain`), `blendMode`, and transform parameters (`x`, `y`, `scale`, `rotation`, `opacity`).
   - Eliminate duplicated canvas math in the UI component.
2. **Observer Pattern for Decoded Assets (`AssetTextureCache`)**:
   - Introduce `subscribe` and `notify` in `AssetTextureCache`.
   - Fire notifications when `Image.onload` or `HTMLVideoElement.onloadeddata` resolves.
   - React components subscribe to trigger state updates for immediate canvas redraws.
3. **Compound Component Decomposition**:
   - Extract UI concerns out of `Preview.tsx` into modular subcomponents under `apps/studio/src/components/preview/`:
     - `ViewportControlBar.tsx` (Zoom, pan, safe guides, checkerboard, VFX switches)
     - `ViewportSafeGuides.tsx` (16:9 Broadcast & 9:16 Social interactive safe guides)
     - `ContextualActionPill.tsx` (Floating action bar for duplicate, center, lock, reset, delete)
     - `SubtitlesOverlay.tsx` (Isolated subtitle caption overlay)
4. **Resilient Integration & Backward Compatibility**:
   - Maintain public re-exports from `Preview.tsx` (`export { ViewportControlBar, ... }`).
   - Ensure all quality gates, E2E benchmarks, and Vite builds remain 100% green.
