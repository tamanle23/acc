# Walkthrough - Phase 4: RightSidebar Inspector Panels for HUD & Particles

## 1. Summary of Changes
Phase 4 successfully implemented enterprise-grade, schema-aligned inspector controls in `apps/studio/src/components/RightSidebar.tsx` for both Hologram HUD and Particle VFX, coupled with reactive engine updates in `UniversalCanvasEngine` and `Preview.tsx`:

1. **Predefined Constants (`PARTICLE_PRESET_DEFAULTS`)**:
   - Implemented tailored emission rates, velocity, opacity, particle counts, and post-processing shader presets for 8 procedural types (`cyber_sparks`, `embers`, `dust`, `rain`, `snow`, `bokeh`, `matrix_rain`, `digital_glitch`).
2. **`AVAILABLE_MODIFIERS` Registration**:
   - Registered dedicated `overlay/hologram_hud` with icon `Monitor` and default parameters (`ringRadiusNorm: 0.35`, `scanlineDensity: 40`, `color: '#00ffff'`, `rotationSpeed: 0.5`).
   - Upgraded `overlay/canvas_particles` with defaults strictly aligned with `CanvasParticleOverlayParams` including nested `shaders`.
3. **Dedicated Hologram HUD Panel (`value="hologram_hud"`)**:
   - Supports Dual Schema: Dedicated `overlay/hologram_hud` and overlaid `overlay/canvas_particles` with `type: 'sci_fi_hud'`.
   - Ring Radius slider (0.10 to 0.80), Scanline Density slider (10 to 100), Rotation Speed slider (0.1 to 3.0 rad/s).
   - Preset Color Picker (`#00ffff` Cyan, `#ec4899` Magenta, `#f59e0b` Amber, `#10b981` Emerald, `#8b5cf6` Violet) with native hex picker.
   - Reset Defaults action and Enable/Disable switch via `AccordionTrigger` `actions` prop.
4. **Strict Schema-Aligned Particle VFX Panel (`value="particles"`)**:
   - Predefined Type Selector dropdown (`cyber_sparks`, `embers`, `dust`, `rain`, `snow`, `bokeh`, `matrix_rain`, `digital_glitch`, `sci_fi_hud`).
   - Sliders for Intensity (0.1–2.0), Speed (0.1–3.0), Opacity (0.0–1.0), and Particle Count (50–3000).
   - Collapsible Shader Post-Processing group:
     - Bloom & Glow toggle, threshold (0.1–1.0), and intensity (0.1–3.0).
     - Chromatic Aberration toggle and color fringe offset (0.0–10.0 px).
     - Full bidirectional sync with legacy flat properties (`bloomThreshold`, `chromaticAberration`).
   - Decoupled Controls UX: Preserves user slider values on type switch, with a dedicated "Reset Defaults" action button.
5. **UniversalCanvasEngine Reactivity**:
   - Added `getParticleCount(): number` to `UniversalCanvasEngine`.
   - Updated `Preview.tsx` render loop to re-initialize particle system when particle count changes, and mapped fallback HUD properties (`hp.speed`, `hp.intensity`) for `sci_fi_hud`.
6. **Rule 229 Guardrail Compliance**:
   - Zero nested `<button>` or interactive elements inside `AccordionTrigger`; all interactive action items pass via the `actions` prop.
