# Implementation Plan 14 - Studio Phase 3: Platform-Independent Audio Core & Multi-Track Mixing

## Problem Statement
The Studio application previously synthesized generic tones and laser SFX through `UniversalAudioMixer`, which was improperly placed inside `packages/effect-engines`. Audio mixing was coupled with visual effect rendering rather than the core intermediate representation (`packages/ir`). Furthermore, real audio assets defined in the VideoIR document were never decoded, and audio modifier plugins (volume envelopes, equal-power panning, biquad filtering, pitch adjustments) were not registered in the modifier plugin registry.

## Proposed Architecture & Design Patterns
1. **Architectural Relocation & Decoupling**:
   - Move `UniversalAudioMixer.ts` to `packages/ir/src/renderer/audio/` alongside `DecoupledAudioMixer.ts` and `DynamicAudioDuckingEngine.ts`.
   - Re-export `UniversalAudioMixer` from `packages/effect-engines/src/audio/UniversalAudioMixer.ts` and `packages/ir/src/client.ts` guaranteeing zero regressions for existing imports.
2. **Audio Source Adapter Pattern (`IAudioSourceProvider`)**:
   - `DecodedPcmSource`: Samples from real decoded Float32Array PCM channel buffers, performing linear resampling when source sample rate differs from mixer rate.
   - `ProceduralSynthesizerSource`: Deterministic DSP fallback generator when assets are offline or still buffering.
3. **Pure Buffer-Based Modifier Plugins (`packages/ir/src/plugins/audio/` & `sfx/`)**:
   - `VolumeModifierPlugin` (`audio/volume`): Gain scaling and cosine/linear fade-in and fade-out envelopes.
   - `PanModifierPlugin` (`audio/pan`): Equal-power stereo panning conserving energy across left/right channels.
   - `FilterModifierPlugin` (`audio/filter`): 2-pole Biquad IIR filter (lowpass, highpass, bandpass) with frequency cutoff and resonance Q.
   - `PitchModifierPlugin` (`audio/pitch`): Linear interpolation resampling for playback speed and cents detune.
   - `DynamicDuckingPlugin` (`sfx/dynamic_ducking`): Sidechain compression envelope calculation.
4. **Master Bus Architecture**:
   - Clip-level DSP pipeline $\to$ Track-level buses (Voice, SFX, BGM) $\to$ Master bus summation with sidechain ducking envelope and soft limiter (`Math.tanh`).
5. **Studio Audio Asset Cache (`apps/studio/src/lib/audio/AudioAssetCache.ts`)**:
   - Observer pattern (`subscribe(callback)`, `notify()`) mirroring `AssetTextureCache`.
   - Asynchronously decodes audio URLs via browser `AudioContext.decodeAudioData()`, caching Float32Array channels.
6. **WebAudioEngine Integration (`apps/studio/src/lib/audio/WebAudioEngine.ts`)**:
   - Subscribes to `AudioAssetCache` to automatically re-sync decoded audio into `UniversalAudioMixer`.
   - Extracts real PCM waveform peak profiles for visual timeline display.
