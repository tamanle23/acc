## 1. Executive Summary & Problem Formulation

Following the introduction of discrete spatio-temporal and particle motion plugins, the VideoIR modifier ecosystem requires a unified target model and dynamic registry validation to eliminate target ambiguities, prevent runtime crashes on transparent overlay sequences, and establish clean domain boundaries:
1. **Strict 4-Domain Target Taxonomy**: Every modifier declares strictly ONE `targetScope: 'standalone' | 'sequence' | 'track' | 'timeline'`.
2. **Dynamic UI Dispatching**: Left sidebar discovers `standalone` generators (spawning `type: 'overlay'` sequences), while right sidebar inspector queries target scope and sequence type compatibility.
3. **Overlay Whitelisting**: Standalone `overlay` sequences strictly allow `transform`, `overlay/blend_mode`, and transitions.
4. **Rename `text/style` $\to$ `timed_text/style`**: Enforces separation between subtitle tracks (`track.type === 'timed_text'`) and graphic typography overlays (`text/*`).
5. **Expanded Studio-Grade Plugins**: Implement `motion/vector_blur`, `generator/solid_backdrop`, `timeline/photometric_bloom`, and `timeline/anamorphic_glare`.

## 2. Implementation Roadmap

### Phase 1: Registry Contracts & Dynamic Query APIs (`packages/ir`)
- Implement `ModifierTargetScope = 'standalone' | 'sequence' | 'track' | 'timeline'` in `packages/ir/src/types/modifiers.ts`.
- Update `ModifierPlugin` interface in `packages/ir/src/plugins/ModifierPluginRegistry.ts`:
  - `readonly targetScope: ModifierTargetScope;`
  - `readonly allowedSequenceTypes?: readonly SequenceType[];`
- Add registry helper methods:
  - `getAvailableModifiersForTarget(targetScope, sequenceType)`
  - `getGeneratorsForLibrary(category?)`
  - `isModifierAllowedOnEntity(modifierType, targetContext)`
- Update all plugins in `packages/ir/src/plugins/` with explicit `targetScope` and `allowedSequenceTypes`.

### Phase 2: Strict Rename `text/style` $\to$ `timed_text/style` across Monorepo
- Update `CaptionModifierPlugin.ts` (`type = 'timed_text/style'`, `allowedSequenceTypes = ['timed_text']`).
- Update `packages/ir/src/types/modifiers.ts` and `packages/ir/src/schema/VideoIRSchemaValidator.ts`.
- Update `packages/ir/src/renderer/shared/IRCanvasCompositor.ts`.
- Update `apps/studio` presets, hit testers, commands, and all 6 demo IR files (`defaultDemoIR.ts`, `scifiDemoIR.ts`, `broadcastDemoIR.ts`, `visualizerDemoIR.ts`, `quantumPhysicsDemoIR.ts`, `astroTelemetryDemoIR.ts`).

### Phase 3: Studio UI Dynamic Wiring (`apps/studio`)
- Update `RightSidebar.tsx` and `SequenceInspector.tsx` to dynamically query available modifiers from `ModifierPluginRegistry`.
- Enforce that `'overlay'` sequences strictly display `Transform`, `Blend Mode`, and `Transitions` in Inspector.
- Wire `LeftSidebar.tsx` to surface `'standalone'` procedural generators in `vfx`, `shapes`, `typography`, and `audio` tabs.

### Phase 4: Expanded Studio-Grade Plugins (`packages/ir`)
- Implement `motion/vector_blur` plugin (`targetScope: 'sequence'`).
- Implement `generator/solid_backdrop` plugin (`targetScope: 'standalone'`).
- Implement `timeline/photometric_bloom` and `timeline/anamorphic_glare` plugins (`targetScope: 'timeline'`).
- Register new plugins in `registerCoreModifierPlugins()`.

### Phase 5: CLI & Cross-Package Verification (`apps/cli`, `packages/core`)
- Verify `UIStudioPreviewEngine.ts` and `FFISceneEngine.ts` handle `timed_text/style` and new modifiers with zero regressions.
- Execute automated verification test `autogenerated-tests/modifier_targets_dynamic_sync.test.ts`.
