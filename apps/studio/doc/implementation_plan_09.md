# Phase 9 Implementation Plan: Unified @dnd-kit Architecture

## Overview
Replace manual window mouse movement boilerplate in `Timeline.tsx` and `Preview.tsx` with a domain-isolated `@dnd-kit` architecture.

## Scope
1. **Command Pattern**: `MoveSequenceCommand` in `apps/studio/src/lib/commands/` and `IRStateManager.moveSequence()`.
2. **Timeline Direct Manipulation**: Wrap tracks in isolated `DndContext`, `DroppableTrackLane`, `TimelineClipItem`, `TrimHandle`.
3. **Preview Canvas Transform Overlay**: Wrap 2D bounding box and 8 handles in isolated `DndContext`, `TransformBodyDraggable`, `TransformHandle`.
4. **Automated Verification**: `autogenerated-tests/studio_move_sequence_command.test.ts` and `autogenerated-tests/studio_phase9_dnd_kit_architecture.test.ts`.
