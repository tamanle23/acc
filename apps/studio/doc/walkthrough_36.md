# Walkthrough 36: Unified Isomorphic Resource & Asset Management with Blob & Streaming

## 1. Overview
This walkthrough summarizes the unified isomorphic resource/asset caching architecture and memory leak fixes that reduced `@acc/studio` memory usage from ~1GB load and >2.5GB playback down to bounded, predictable footprints.

## 2. Key Architectural Components

### 2.1 Extended `IContentCacheStrategy`
`packages/core-isomorphic/src/cache/types.ts`:
- Optional methods: `getBlob`, `setBlob`, `getStream`, `setStream`, and `getMetadata`.
- 100% backward compatibility preserved for existing `get(key): Promise<Uint8Array | null>` and `set(...)`.

### 2.2 Isomorphic Streaming Utilities
`packages/core-isomorphic/src/cache/streamUtils.ts`:
- `uint8ArrayToStream(data)`: Zero-copy wrapping of byte arrays in `ReadableStream<Uint8Array>`.
- `streamToUint8Array(stream)`: Chunk-accumulated single-buffer reduction with proper reader lock disposal.
- `blobToStream(blob)`: Native `blob.stream()` with fallback array buffer streaming.
- `streamToBlob(stream, mimeType)`: Direct `Blob` construction from stream chunks without heap cloning.
- `blobToUint8Array(blob)`: Fast array buffer extraction.
- `computeStreamChecksumAndSize(stream)`: Streams through byte chunks calculating fast checksum and length while teeing into a replayable stream.

### 2.3 Memory & Web Cache Strategies
- `MemoryCacheStrategy`: Added `maxSizeBytes` LRU byte ceiling (default 64MB) and zero-copy `Blob`/`ReadableStream` storage.
- `WebCacheStrategy`: Backed by standard Web Cache API (`window.caches`). `getStream()` returns `response.body` directly from HTTP cache. `setBlob()` stores `new Response(blob)` without loading into RAM.
- `IndexedDbCacheStrategy`: Stores `Blob` objects natively in IndexedDB object stores.
- `NativeFileCacheStrategy`: Chunked Node/Bun filesystem streams via `fs.createReadStream` / `createWriteStream`.

### 2.4 Studio Memory Leak Remediations
1. **WorkerRenderStrategy**:
   - Deduplicated `createImageBitmap` calls using `syncedSources` map.
   - Eliminates generating a new 8.3MB bitmap every 60Hz frame when source elements have not changed.
2. **preview.worker.ts**:
   - `safeSetTexture()` bounds `textureCache` to 32 entries.
   - Explicitly calls `existing.close()` before replacing bitmaps, reclaiming GPU VRAM immediately.
3. **AudioAssetCache & WebAudioEngine**:
   - Replaced unbounded array decoding with LRU cache (`MAX_CACHE_ENTRIES = 8`, `MAX_TOTAL_PCM_BYTES = 64MB`).
   - Only preloads proximate clips within 10 seconds of the playhead.
4. **AssetTextureCache**:
   - Added bounded LRU maps for images (32), videos (6), canvases (32), data URLs (32), and placeholders (16).
   - Inactive videos paused and cleared (`video.src = ''`, `video.load()`).
5. **LeftSidebar**:
   - Ingests uploaded files directly into `ContentCacheRegistry.get().setBlob(assetId, file)`.
