# Walkthrough 36: Fix useShuttleEngine Indefinite Playback at Boundary

## Problem & Root Cause
In `apps/studio/src/lib/shuttle/useShuttleEngine.ts`, playback loop ran indefinitely once the playhead reached the end of the timeline because:
1. `DeterministicTimelineClock.tick(...)` bounds and clamps `targetFrame` to `Math.min(this.totalFrames - 1, targetFrame)`.
2. `useShuttleEngine` checked `if (targetFrame >= total)` where `total = totalFramesRef.current`. Since `targetFrame` never exceeded `total - 1`, the termination branch was unreachable, keeping `requestAnimationFrame(tick)` active.
3. Furthermore, when attempting to replay after stopping at the end, `setSpeed` checked `currentFrameRef.current >= totalFramesRef.current`, so it never wrapped back to frame 0.

## Changes Made
### `apps/studio/src/lib/shuttle/useShuttleEngine.ts`
- Adjusted `setSpeed` wrap-around boundary check:
  ```ts
  const maxBound = Math.max(0, totalFramesRef.current - 1);
  if (newSpeed > 0 && currentFrameRef.current >= maxBound) {
    currentFrameRef.current = 0;
    onScrubRef.current(0);
  }
  ```
- Corrected terminal frame condition in `tick`:
  ```ts
  const total = totalFramesRef.current || 300;
  const endFrame = Math.max(0, total - 1);
  if (targetFrame >= endFrame && currentSpeed > 0) {
    const discreteFrame = snapToDiscreteFrame(endFrame);
    currentFrameRef.current = discreteFrame;
    onScrubRef.current(discreteFrame);
    setSpeed(0);
    return;
  }
  ```
