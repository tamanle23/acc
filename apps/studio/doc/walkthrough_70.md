# Walkthrough 70: Fix Sidecar Worker Single Warmup Dispatch & Passive Barrier

## Overview
Resolved duplicate logging of `"Sidecar worker successfully warmed up."` by establishing `initWorker()` as the single source of truth for sidecar worker warmup, converting `waitForWarmup()` into a purely passive barrier, and enforcing warning diagnostics without silent message swallowing on duplicate responses.

## Key Changes
1. **PreviewWorkerCoordinator (`apps/studio/src/renderer/PreviewWorkerCoordinator.ts`)**:
   - Added `private isWarmingUp: boolean = false` with public getter `getIsWarmingUp()`.
   - Replaced deferred idle scheduling (`scheduleWarmup()`) with immediate dispatch via `this.warmup()` during worker initialization (`initWorker()`).
   - Pruned dead `scheduleWarmup()` method entirely.
   - Removed active `this.warmup()` trigger from `waitForWarmup()`, transforming it into a purely passive Promise barrier that awaits `this.warmupResolvers`.
   - Added guard inside `warmup()`: if already warmed up or actively warming up (`this.isWarmedUp || this.isWarmingUp`), immediately return; otherwise set `this.isWarmingUp = true` and dispatch `{ type: 'WARMUP' }`.
   - In `handleWorkerMessage('WARMED_UP')`: resets `this.isWarmingUp = false; this.isWarmedUp = true;`. Emits `Logger.warn` if duplicate response arrives while already warmed up, or `Logger.info` on initial warmup completion.
