# Studio Implementation Plan - Iteration 70: Sidecar Worker Single Warmup Dispatch

## Design Alignment
Following the `/grill-me` design review:
- **Sole Driver**: `initWorker()` in `PreviewWorkerCoordinator.ts` immediately triggers `this.warmup()`.
- **Remove `scheduleWarmup()`**: Deleted idle callback / setTimeout fallback entirely.
- **Passive Barrier**: `this.warmup()` is removed from `waitForWarmup()`, making it a purely passive barrier awaiting `isWarmedUp`.
- **Transparent Logging**: No silent idempotency drops in `handleWorkerMessage`. If an unexpected duplicate `WARMED_UP` response is received, log a warning via `Logger.warn`.

## Implementation Steps
1. In `apps/studio/src/renderer/PreviewWorkerCoordinator.ts`:
   - Add `isWarmingUp: boolean = false`.
   - Call `this.warmup()` directly in `initWorker()`.
   - Remove `scheduleWarmup()`.
   - Remove `this.warmup()` from `waitForWarmup()`.
   - Guard `warmup()` with `if (this.isWarmedUp || this.isWarmingUp) return`.
   - In `handleWorkerMessage('WARMED_UP')`: log info on first reception, log warning if `alreadyWarmed` is true.
2. Author unit test in `autogenerated-tests/studio_sidecar_warmup_single_dispatch.test.ts`.
3. Verify in browser via headless Edge script.
