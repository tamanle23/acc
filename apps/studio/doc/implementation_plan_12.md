# Implementation Plan 12 - Phase 2: Real Visual Media Compositor (Image & Video)

## Overview
Phase 2 transforms Studio's `Preview.tsx` from drawing purely abstract particle/vector overlays into an authoritative multi-track visual media compositor capable of rendering real decoded images, HTML5 video playback decoders, and isolated neutral video fallbacks.

## Problem Statement
Previously, `Preview.tsx` cleared the canvas and only rendered vector wireframes, particles, and hologram rings. Video tracks (V1 plate, V2 depth subject, etc.) defined in `VideoIR` were not drawn onto the Canvas2D context, causing the video stage to appear empty or dark.

## Solution Architecture
1. **AssetTextureCache Image & Video Decoder (`apps/studio/src/lib/textures/AssetTextureCache.ts`)**:
   - Added `getVisualAsset(assetId, src, assetType, timeSec)` returning a `VisualAssetResult` with real `HTMLImageElement`, offscreen hardware-decoded `HTMLVideoElement`, or a fallback canvas.
   - Added asynchronous image decoding (`img.crossOrigin = 'anonymous'`, `img.onload`).
   - Added offscreen HTML5 `<video>` element creation with muted transport, inline playback, and playhead frame seeking.
   - Implemented `renderMissingAssetPlaceholder(...)`: generates a dark video charcoal (`#151518`) card with dashed perimeter guides and asset type badges adhering strictly to Rule 235 isolation.
2. **Preview.tsx Multi-Track Canvas Compositing (`apps/studio/src/components/Preview.tsx`)**:
   - Queries active visual sequences at the current playhead frame from `IntervalTreeIndex`.
   - Sorts sequences by track index order: `V1 -> V2 -> V3 -> V4`.
   - Maps parent track `blendMode` (e.g. `screen`, `lighten`) to `ctx.globalCompositeOperation`.
   - Applies the dynamic GSAP affine transform matrix (`ctx.translate`, `ctx.rotate`, `ctx.scale`, `ctx.globalAlpha`) centered on the viewport.
   - Draws decoded media onto canvas via `ctx.drawImage()`.
