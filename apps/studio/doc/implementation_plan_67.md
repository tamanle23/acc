# Studio Implementation Plan - Iteration 67: Playhead Controller, Shuttle Engine & Deterministic Clock Unification

## 1. Executive Summary
This companion implementation plan details the studio-specific execution of Master Implementation Plan Iteration 81. It resolves the playhead desynchronization, micro-stuttering, and backward jumps into wrong timeframes across `PlayheadController.ts`, `useShuttleEngine.ts`, `Timeline.tsx`, and `App.tsx`.

---

## 2. Core Architectural Invariants
1. **PlayheadController as Real-Time SSOT**: `useShuttleEngine` must query `PlayheadController.getInstance().getFrame()` directly rather than relying on the 250ms throttled SolidJS signal `options.currentFrame`.
2. **Zero Circular Scrubbing**: The RAF `tick` loop in `useShuttleEngine` must not invoke `options.onScrub(discreteFrame)` every 250ms. `PlayheadController`'s internal `lowFreqSubscribers` handles throttled UI updates cleanly.
3. **Interactive Scrub Halts Playback**: In `App.tsx`, `handleScrub()` halts active playback (`shuttle.setSpeed(0)`) when the user interacts with the ruler or playhead needle, matching standard NLE behavior (Premiere / DaVinci Resolve) and preventing running clock snapbacks.
4. **Fractional Needle Gliding**: In `Timeline.tsx`, the needle element's `style` attribute must not reactively bind `transform` to `currentFrame()`, which clobbers high-frequency 60fps direct DOM transforms.
5. **Clock Mode Continuity**: In `DeterministicTimelineClock.ts`, `setSyncMode()` must re-anchor origin frames and elapsed times to maintain $C^0$ continuity on fallback to `monotonic_worker`.

---

## 3. Phased Implementation Roadmap

### Phase 1: Playhead SSOT & Shuttle Engine Unification
- Update `getCurrentFrame` in `apps/studio/src/lib/shuttle/useShuttleEngine.ts` to query `PlayheadController.getInstance().getFrame()`.
- Update `setSpeed(0)` to pause at the exact playhead location and eliminate backward jumps on pause.
- Remove redundant circular `options.onScrub(discreteFrame)` call in the RAF `tick` loop.

### Phase 2: High-Precision Fractional Clock & Mode Re-anchoring
- In `packages/core-isomorphic/src/math/clock/DeterministicTimelineClock.ts`, retain floating-point precision in `tick()` instead of quantizing with `Math.round()`.
- Implement re-anchoring inside `setSyncMode()` to guarantee continuity when switching between `audio_master` and `monotonic_worker`.
- Ensure `getRationalTime()` and `getState()` reflect sub-frame progression.

### Phase 3: Interactive Scrub Invariants & DOM Style Decoupling
- In `apps/studio/src/App.tsx`, update `handleScrub()` to halt active playback when scrubbing to eliminate snapback fights.
- In `apps/studio/src/components/Timeline.tsx`, replace the reactive `transform` binding on `needle` element with static initial style.
- Validate `subscribeHighFrequency` direct DOM updates glide without interference.

### Phase 4: Verification Suite & Telemetry Calibration
- Author formal tests in `autogenerated-tests/studio_playhead_and_shuttle_clock_precision.test.ts`.
- Verify pauses do not jump backwards.
- Verify mode transitions between `audio_master` and `monotonic_worker` maintain continuity.
- Run complete test suite and production build verification.
