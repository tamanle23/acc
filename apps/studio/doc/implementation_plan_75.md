# Implementation Plan 75: Eliminate Playground Memory Spike with SD Quality Canvas and Complete Shiki Removal

Eliminate the $> 500\text{ MB}$ transient heap spike on `IrPluginPlaygroundModal` open, reduce canvas backing store to Standard Definition (SD quality $\le 640\times 360$), eliminate the $1.32\text{ GB/sec}$ post-processing allocation firehose, stagger storyboard keyframe rendering, and completely remove `shiki` from `@acc/studio`.

## User Review Required

> [!IMPORTANT]
> - **Canvas Resolution Change**: `BentoHeroViewport` backing store is capped at SD resolution ($640\times 360$ for 16:9, $360\times 640$ for 9:16, $480\times 480$ for 1:1) with GPU hardware scaling to fill the stage. This locks physical canvas memory to $< 921\text{ KB}$ (down from $> 11\text{ MB}$).
> - **Dependency Removal**: `shiki` is completely removed from `apps/studio/package.json`. A zero-dependency, ultra-lightweight synchronous JSON lexer replaces it with zero runtime WASM/TextMate overhead.

## Proposed Changes

### 1. `apps/studio/src/components/debugger/playground/bento/BentoHeroViewport.tsx`
- Lock canvas backing store to SD quality:
  - Max width: 640px, Max height: 360px (for 16:9).
  - DPR clamped to 1.0.
  - CSS display dimensions retain full viewport layout (`width: 100%; height: 100%` or computed stage aspect ratio).
- Prevents `CanvasScratchPool` from escalating into the 4K tier ($3840\times 2160 = 33.2\text{ MB}$).

### 2. `packages/effect-engines/src/overlay-effects/simulators/PostProcessingShaders.ts`
- Downsample bloom extraction in `applyBloom()`:
  - Extract to a fixed $160\times 90$ scratch canvas ($57.6\text{ KB}$ buffer).
  - High-pass threshold the $57.6\text{ KB}$ buffer in 0.02ms.
  - Re-composite with screen blend mode using hardware GPU interpolation.
- In `applyChromaticAberration`:
  - Reuse/cache `ImageData` buffer to avoid creating new `Uint8ClampedArray` per frame.

### 3. `apps/studio/src/components/debugger/playground/bento/BentoStoryboardFilmstrip.tsx`
- Replace synchronous `kfs.forEach(...)` burst with sequential RAF scheduler:
  - Render 1 keyframe per `requestAnimationFrame` tick (83ms spread over 5 frames).
  - Debounce parameter reactive updates.

### 4. Zero-Dependency JSON Syntax Highlighter & Shiki Removal
- Create `apps/studio/src/components/debugger/code-editor/JsonCodeViewer.tsx`:
  - Pure synchronous regex tokenizer for JSON syntax.
  - Gutter line numbers, error line markers, synchronized scrolling with textarea.
  - Theme-aware token styling (keys, strings, numbers, booleans, null, punctuation).
- Replace `apps/studio/src/components/debugger/code-editor/ShikiCodeViewer.tsx` to export `JsonCodeViewer` as drop-in replacement.
- Remove `apps/studio/src/lib/highlighter.tsx`.
- Remove `"shiki"` from `apps/studio/package.json`.
- Remove `vendor-shiki` from `apps/studio/vite.config.ts`.
- Run `pnpm install` from root.
