# Implementation Plan 04: Refactor AI-Supervisor for Electrobun Techstack Best Practices

## 1. Executive Summary
Refactor `apps/ai-supervisor` to adhere to official Electrobun 2.x architectural standards, SOLID principles, and enterprise TypeScript clean coding. Deconstruct the 530-line monolithic `src/bun/index.ts` into modular, highly cohesive, single-responsibility domain services (`desktop/`, `server/`, `core/`), fix all pre-existing TypeScript compiler defects, and update outdated automated tests to achieve 100% test pass rates and zero regressions.

---

## 2. Architectural Blueprint

```
apps/ai-supervisor/src/bun/
├── index.ts                     # Declarative bootstrapper & shutdown lifecycle (< 80 lines)
├── desktop/                     # Electrobun desktop presentation layer
│   ├── WindowManager.ts         # BrowserWindow singleton, win.show(), win.activate(), Win32 HWND foreground
│   ├── TrayManager.ts           # System tray icon lifecycle, dynamic color states, context menu actions
│   └── DesktopApplication.ts   # High-level coordinator for window + tray + platform events
├── server/                      # Embedded HTTP & Telemetry streaming layer
│   ├── HttpServer.ts            # Bun.serve REST & SSE server instance
│   └── routes/
│       ├── telemetryRoutes.ts   # /api/telemetry/stream (SSE), /snapshot, /ingest, /audits
│       ├── serviceRoutes.ts     # /api/status, /api/services/:name/*, /api/vram/purge, /api/config
│       ├── workerRoutes.ts      # /api/worker/heartbeat
│       ├── staticRoutes.ts      # Electrobun packaged views (index.html, index.js, index.css, tray icons)
│       └── ttsRoutes.ts         # Neural TTS playground gRPC proxy
├── core/                        # Fleet and daemon lifecycle services
│   ├── SupervisorEngine.ts      # Multi-daemon fleet orchestrator (python-backend, worker, studio)
│   ├── HardwareProfiler.ts      # Hardware tier detection (tier1 - tier5, GPU VRAM, CPU)
│   ├── RuntimeManager.ts        # UV & Python virtual environment provisioning
│   ├── StartupManager.ts        # OS auto-launch registration (Windows Task Scheduler / Registry)
│   ├── UpdateManager.ts         # Boot watchdog and rollback management
│   ├── configStore.ts           # JSON config persistence in ~/.acc/supervisor-config.json
│   ├── portScanner.ts           # Dynamic TCP port collision detection
│   └── IProcessRunner.ts        # Process execution abstraction and Result pattern
└── telemetry/                   # Event streams and sidecar consumers
    ├── TelemetryEventBroker.ts  # Master event broker for fleet metrics and SSE
    ├── OSProcessSampler.ts      # Native CPU & RAM process resource sampler
    ├── DomainTelemetryPoller.ts # Periodic domain metric poller
    ├── PythonGrpcStreamConsumer.ts
    └── WorkerSseStreamConsumer.ts
```

---

## 3. Implementation Steps

1. **Fix Pre-existing TypeScript Compiler Defects**:
   - `HardwareProfiler.ts`: export `HardwareTierOption`, add `driverVersion` to `GpuInfo`.
   - `configStore.ts`: type `hardwareTierOverride` with `HardwareTierOption`.
   - `portScanner.ts`: replace invalid `Bun.spawn().output()` with `runner.execute`.
   - `StartupManager.ts`: remove duplicate `getWindowsStartupStatus` function implementation.
   - `RuntimeManager.ts`: add `provision()` method alias to `ensureRuntime()`.
   - `IProcessRunner.ts`: add `exitCode?: number | null;` to `ManagedProcess`.
   - `TelemetryGrid.tsx`: safe navigation for `activeJobId`.
   - `env.d.ts`: declare `*.css` module declarations.
   - `package.json`: add `"@acc/proto": "workspace:*"` dependency.

2. **Extract Electrobun Desktop Presentation Layer**:
   - Create `src/bun/desktop/WindowManager.ts` with Win32 `bringToForeground` helper, window restoration, explicit `win.webview.loadURL`, and window event listeners.
   - Create `src/bun/desktop/TrayManager.ts` with icon resolution, status color listener, menu dispatching, and fallback logic for worker thread constraints.
   - Create `src/bun/desktop/DesktopApplication.ts` coordinating window and tray.

3. **Extract Embedded HTTP Server & Routes**:
   - Create `src/bun/server/routes/` for telemetry, services, worker, static views, and TTS playground.
   - Create `src/bun/server/HttpServer.ts` wrapping `Bun.serve` and routing.

4. **Refactor Entrypoint `src/bun/index.ts`**:
   - Clean, declarative coordinator connecting `configStore`, `HardwareProfiler`, `HttpServer`, `DesktopApplication`, `SupervisorEngine`, and `telemetry`.

5. **Test Suite Modernization & Verification**:
   - Update `autogenerated-tests/supervisor_engine.test.ts` to test the 3-service fleet (`python-backend`, `worker`, `studio`).
   - Update `autogenerated-tests/supervisor_solid_ui.test.ts` to test Electrobun packaged views.
   - Run `bun test autogenerated-tests/*supervisor*` -> ensure 100% pass.
   - Run `pnpm --filter @acc/ai-supervisor build` and typecheck.
