# Walkthrough 161 - Unified Sandbox Platform Migration & Metadata Ad-Hoc Mock Pruning

## Overview
This walkthrough summarizes the migration of the metadata mock engine into `@acc/sandbox`, the pruning of 2,148 lines of ad-hoc mock code in `@acc/console`, the retirement of `MetadataServiceStrategy`, and the enforcement of token-derived tenant scoping in Phase 2 of Iteration 50.

## Changes Completed

### 1. Unified Sandbox Platform Integration (`packages/sandbox`)
- **`packages/sandbox/src/handlers/metadata-sandbox-handler.ts`**:
  - Implemented `MetadataSandboxRepository` managing tenant-partitioned entity types, attribute definitions, records, relationships, and compiled schemas.
  - Implemented `metadataSandboxHandler` matching `/api/v1/metadata`, `/v1/metadata`, and `/api/metadata`.
  - **Token-Derived Tenant Scoping:** Eliminated arbitrary `X-Tenant-Id` header spoofing; tenant identity is derived from `decodeJwt(token)?.tenantId` on the Bearer authentication token with session fallback.
  - Registered in `packages/sandbox/src/index.ts` and `sandboxResetRegistry`.
- **`packages/sandbox/src/handlers/data/metadata.ts`**:
  - Structured canonical seed metadata definitions (`Customer Account`, `Cloud Resource Spec`, `Deployment Policy`, and `Customer 360 View`).

### 2. Console Simplification & Ad-Hoc Mock Elimination (`apps/console`)
- **`apps/console/src/features/metadata/data/mock-metadata.ts`**:
  - **Pruned 2,148 lines of dead ad-hoc code**; permanently removed the monolithic local mock file.
- **`apps/console/src/features/metadata/api/metadata-service.ts`**:
  - Retired `MetadataServiceStrategy` dual-mode branching.
  - Re-exported `httpMetadataService` directly as `metadataService`.
  - Offline simulation is now handled transparently by `springApiClient`'s sandbox interceptor.
- **`apps/console/src/core/sandbox/handlers/metadata-sandbox-adapter.ts`**:
  - Simplified to re-export `metadataSandboxHandler` from `@acc/sandbox`.
- **Test Suite Imports Normalized**:
  - Updated all tests (`domain-blueprints-e2e.test.ts`, `metadata-workflows.test.ts`, `wide-telemetry-entity.test.ts`, `metadata-sandbox-adapter.test.ts`, `sandbox-integration.test.ts`) to import from `@acc/sandbox`.

### 3. Formal Verification
- **`autogenerated-tests/metadata_unified_sandbox_parity.test.ts`**:
  - Verified route matching across all namespaces.
  - Verified token-derived tenant resolution rejecting spoofed headers.
  - Verified entity type CRUD, compiled schema Draft-07 generation, record partitioning, and stateful resets.

### 4. Phase 3: Dead Code Elimination & Shared Primitive Consolidation
- **Orphaned Registration Pruning**:
  - Permanently deleted `apps/console/src/features/users/components/RegisterUserForm.tsx` and `apps/console/src/features/users/api/useRegisterUserFacade.ts`.
  - Audited and verified zero remaining occurrences of `/api/v2/users/register` across the entire codebase.
  - Production user workflows remain cleanly encapsulated in `users-action-dialog.tsx` and `use-users.ts`.
- **Bulk Actions Disambiguation & Primitive Composition**:
  - Renamed `features/users/components/data-table-bulk-actions.tsx` to `users-bulk-actions.tsx`, exporting `UsersBulkActions` and composing `@/components/data-table` primitives.

- **Formal Automated Test Suite**:
