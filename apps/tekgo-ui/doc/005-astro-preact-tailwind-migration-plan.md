# Companion Implementation Plan: Astro 5 + Preact Migration (`tekgo-ui`)
> **Iteration:** 70  
> **Master Reference:** `docs/iterations/master_implementation_plan_iteration_70.md`  
> **Target Framework:** Astro 5 (Hybrid/SSR) + Preact + Tailwind CSS v4  

---

## 1. Overview & Aligned Architectural Decisions
Migrate `tekgo-ui` from Next.js 15 to Astro 5 with Preact islands, keeping 100% feature parity, Liquid Glass design fidelity, and strict minimal JavaScript hydration.

Decisions confirmed via `/grill-me`:
1. **Canonical URLs:** Keep `/blog` and `/blog/[...slug]` exclusively.
2. **Content Layer:** Service Layer pattern (`contentProvider`) + Zod contracts for immediate SSR dynamic cache invalidation.
3. **Search Engine:** Native Preact Command Palette island (`SearchModal.tsx`) with `Cmd+K` and Liquid Glass styling.
4. **Content Renderer:** Server-only Preact component (`PortableTextRenderer.tsx`, zero client JS).
5. **Cutover Strategy:** Immediate clean cutover in Phase 1 (remove `app/`, `next.config.js`, etc.).

---

## 2. Phased Execution

### Phase 1: Environment & Project Scaffolding (Immediate Cutover)
- Remove `app/`, `next.config.js`, `next-env.d.ts`.
- Update `package.json` with `@astrojs/preact`, `@astrojs/node`, `preact`, `@nanostores/preact`, `nanostores`, `@tailwindcss/vite`, `tailwindcss` (v4).
- Configure `astro.config.mjs` with Node standalone adapter, Preact integration (`compat: true`), and Vite Tailwind plugin.
- Configure `src/styles/global.css` importing Tailwind v4 with all tokens and Liquid Glass classes.
- Configure `tsconfig.json` with Preact JSX settings (`"jsx": "react-jsx"`, `"jsxImportSource": "preact"`).

### Phase 2: Layouts, Fonts & Assets
- Create `src/layouts/BaseLayout.astro`.
- Implement SEO tags, OpenGraph meta, viewport, and favicon in `<head>`.
- Wire up Space Grotesk font and assets from `public/`.
- Insert anti-FOUC theme detection script in `<head>`.

### Phase 3: Content Layer & Route Implementation
- Port `lib/content.ts` and `lib/cms/` to `src/lib/` with Zod validation contracts.
- Create `src/pages/index.astro`, `src/pages/blog/index.astro`, `src/pages/blog/[...slug].astro`, and pagination pages.
- Create `src/pages/tags/index.astro`, `src/pages/tags/[tag]/index.astro`, `src/pages/projects/index.astro`, and `src/pages/about/index.astro`.

### Phase 4: Component Conversion & Islands Boundary
- Static components to `.astro`:
  - `src/components/Header.astro`
  - `src/components/Footer.astro`
  - `src/components/Card.astro`
  - `src/components/PageTitle.astro`
  - `src/components/Tag.astro`
  - `src/components/SectionContainer.astro`
  - `src/components/TableWrapper.astro`
- Interactive components to Preact `.tsx` islands:
  - `src/components/ThemeSwitch.tsx` (`client:load`)
  - `src/components/MobileNav.tsx` (`client:idle`)
  - `src/components/SearchModal.tsx` (`client:idle`)
  - `src/components/Comments.tsx` (`client:visible`)
  - `src/components/ScrollTopAndComment.tsx` (`client:visible`)
  - `src/components/BlogFilterList.tsx` (`client:idle`)
- Server-only Preact component:
  - `src/components/PortableTextRenderer.tsx` (emits zero client JS)
- Implement Nano Stores in `src/stores/theme.ts`, `src/stores/nav.ts`, and `src/stores/search.ts`.

### Phase 5: API Routes & SSR Endpoints
- Migrate newsletter endpoint to `src/pages/api/newsletter.ts` with WHATWG `Request`/`Response`.
- Migrate revalidation endpoint to `src/pages/api/revalidate.ts` with WinterTC Web Crypto HMAC-SHA256.
