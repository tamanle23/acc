# Visual Storytelling Generator (Bun + FFmpeg + Whisper)

Hệ thống tạo video visual storytelling tự động từ ảnh, âm thanh (VieNeu/TTS) và phụ đề, viết bằng **TypeScript** chạy trên nền **Bun** và **FFmpeg**.

---

## 🛠️ Bộ công cụ gồm 2 CLI chính:

### 1. Tool Tự Động Sinh Cấu Hình & Timestamps (`auto-config.ts`)
Menu tương tác thông minh (Interactive Wizard):
- Tự động phát hiện nếu thư mục đã có file cấu hình để hỏi **Merge & giữ lại cài đặt cũ** hay **Tạo mới hoàn toàn**.
- Cho phép chọn nhanh **Platform Preset** (TikTok, YouTube, Facebook, Web, Mobile...).
- Cho phép chọn nhanh **Caption Style Preset** (10 bộ phong cách: TikTok, Vlog, Cinematic, Neon Glow, Comic...).
- Cho phép chọn **Subtitle Mode** (`Hardsub` khắc vào video hoặc `Softsub` track rời).
- Tùy chọn bật **Hiệu ứng chuyển cảnh (Transitions)** (Fade, Wipe, Slide...) và tự động đệm âm thanh (Audio padding).
- Tùy chọn bật **AI Auto-Upscale** (Real-ESRGAN, UltraSharp) để tự động làm nét hình ảnh.
- Tùy chọn chạy **Whisper AI** để trích xuất word-level timestamps (tiếng Việt).

```bash
bun run auto-config.ts
# Hoặc truyền thẳng đường dẫn:
bun run auto-config.ts "C:/path/to/my-story-folder"
```

### 2. Tool Render Video Chính (`cli.ts`)
Đọc file `story-config.json`, tự động tối ưu hóa theo nền tảng (`platform: "tiktok" | "youtube" | "facebook" | "web" | ...`), hỗ trợ Hardsub (Burn-in) / Softsub (Track riêng cho MKV/MP4), giải mã GPU NVENC NVIDIA / CPU và xuất video siêu tốc.

```bash
bun run cli.ts
# Hoặc truyền thẳng đường dẫn:
bun run cli.ts "C:/path/to/my-story-folder"
```

### 3. Tool Sinh Hiệu Ứng Lớp Phủ (Overlay Effects CLI)
Tool sử dụng TypeScript và thư viện HTML5 Canvas hiệu năng cao (`@napi-rs/canvas`) để render các vòng lặp liền mạch (Seamless Loop) các hiệu ứng như Mưa, Tuyết, Bụi, Khói. Đồ họa được tính toán theo thuật toán nội suy vòng lặp và được truyền thẳng (pipe) vào `fluent-ffmpeg` để tạo video mà không sinh ra file rác.
- **Tính năng nổi bật:** Modular Variant Architecture (`--variant`), hỗ trợ 5 nhóm: Weather, Atmosphere, Action & Fire, Retro, Organic.
- **Thư mục đầu ra:** Tự động gom video và file metadata (`.json` định nghĩa màu BG, Blend Mode) vào thư mục `autogenerated/overlay-effects/`.

```bash
bun run overlay-effects-cli.ts --effect rain --variant storm --duration 3 --fps 30 --width 1920 --height 1080
```

## 📁 Cấu trúc thư mục Story

Tool `auto-config.ts` hỗ trợ linh hoạt 2 cách tổ chức thư mục:

#### Cách 1: Để chung cùng thư mục gốc
```text
my-story-folder/
├── scene1.jpg
├── scene2.jpg
├── voiceover1.mp3   (hoặc .wav)
└── voiceover2.mp3
```

#### Cách 2: Chia thành các thư mục con riêng biệt (Khuyên dùng)
```text
my-story-folder/
├── images/           (hoặc ./img, ./scenes)
│   ├── 01.jpg
│   └── 02.jpg
└── voiceover/        (hoặc ./audio, ./voices)
    ├── 01.mp3
    ├── 01.txt        (Kịch bản gốc slide 1 - giúp Whisper căn chỉnh chuẩn 100% chữ gốc)
    ├── 02.mp3
    └── 02.txt        (Kịch bản gốc slide 2)
```
*(Bạn cũng có thể dùng file chung `script.txt` hoặc `script.json` tại thư mục gốc thay vì từng file riêng)*.

Khi chạy `bun run auto-config.ts`, hệ thống sẽ tự động phát hiện kịch bản gốc để căn chỉnh timestamps chính xác 100% từ ngữ tiếng Việt. File `story-config.json` sẽ được tự động tạo ngay bên trong thư mục với nội dung chuẩn:

```json
{
  "settings": {
    "platform": "tiktok",
    "width": 1080,
    "height": 1920,
    "fps": 30,
    "container": "mp4",
    "videoCodec": "h264",
    "crf": 21,
    "preset": "p4",
    "pixelFormat": "yuv420p",
    "audioCodec": "aac",
    "audioBitrate": "192k",
    "gpuAcceleration": "auto",
    "concurrency": "auto",
    "fastStart": true,
    "captions": {
      "preset": "tiktok",
      "subtitleMode": "burn",
      "position": "bottom",
      "fontSize": 54,
      "primaryColor": "#FFFF00",
      "marginV": 90,
      "marginH": 40
    }
  },
  "slides": [
    {
      "image": "scene1.jpg",
      "audio": "voiceover1.mp3",
      "captions": [
        { "text": "Ngày", "start": 0.0, "end": 0.35 },
        { "text": "xửa", "start": 0.35, "end": 0.65 },
        { "text": "ngày", "start": 0.65, "end": 0.95 },
        { "text": "xưa...", "start": 0.95, "end": 1.6 }
      ]
    }
  ]
}
```
Sau đó bạn chạy `bun run cli.ts` để xuất video `output.mp4` (hoặc `.mkv`, `.webm`, `.mov`).

## ⚡ Quy tắc cấu hình nhanh (Cheat Sheet)

* **Thông số bắt buộc**: `slides` (cấp root), `image` (trong từng slide) và bắt buộc phải có `audio` HOẶC `text` (nếu dùng hệ thống AI Voice).
* **Tích hợp VieNeu-TTS v3 Turbo**: Hỗ trợ sinh giọng đọc trực tiếp ở local mà không cần API từ xa. Yêu cầu môi trường Python và đã cài thư viện: `pip install git+https://github.com/pnnbao97/VieNeu-TTS`.
* **Tất cả các trường còn lại là tùy chọn (Optional)**: Nếu bỏ qua `settings`, hệ thống tự lấy mặc định Full HD 1080p, H.264, AAC, MP4, Auto GPU, Concurrency Auto.
* **Thứ tự ưu tiên (Precedence)**: Thuộc tính tự viết cụ thể > Mặc định của `platform` > Fallback toàn cục (`"custom"`).
* **Render song song đa luồng (`concurrency: "auto"`)**: Tự động tận dụng nhiều luồng CPU và bộ mã hóa GPU NVENC để render đồng thời nhiều phân cảnh cùng lúc, tăng tốc độ render lên gấp 4 - 5 lần.
* **Chế độ phụ đề (`subtitleMode`)**:
  * `"burn"`: Khắc chết vào video (Mặc định - chuẩn TikTok/Shorts/Facebook).
  * `"soft"`: Mux thành Track Subtitle riêng biệt (chuẩn MKV/MP4 bật/tắt được trong VLC).
* **Hiệu ứng Chuyển cảnh (`transition`)**: Hỗ trợ xfade (fade, wipe, random) với cơ chế đệm âm thanh (`audioBehavior: "pad"`) chống đè giọng đọc. Cấu hình được ở mức Global hoặc từng Slide.
* **Hiệu ứng Tạo Nổi 3D Vượt Khung (`depth3d`)**: Đột phá thị giác 3D Out-of-Bounds (Frame-Breaker) với các phong cách khung viền (`polaroid`, `card`, `cinema`, `comic`), đổ bóng đa tầng (Elevation Drop Shadow) và dao động nổi bồng bềnh (Floating Motion). Hỗ trợ tách chủ thể tự động hoặc qua transparent cutout `subjectImage`.
* **AI Auto-Upscale (`upscale`)**: Tự động tải và chạy Real-ESRGAN/UltraSharp (Cross-Platform trên Windows/Mac/Linux) để làm nét ảnh trước khi render.
* **10 Bộ Caption Presets**: `tiktok`, `classic`, `cinematic`, `vlog`, `neon-glow`, `bold-retro`, `minimal-clean`, `karaoke`, `news-banner`, `retro-typewriter`.
