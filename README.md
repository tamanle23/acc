# ACC (Automated Content Creator) - Multi-Pipeline Engine

Hệ thống sản xuất nội dung video và đa phương tiện tự động toàn diện, xây dựng trên kiến trúc **Monorepo (Turborepo + Bun Workspaces)**, **FFmpeg C/FFI Zero-Copy Memory Processing**, **AI Vision (SAM 2 / Depth Anything v2)** và **Whisper AI / VieNeu-TTS**.

---

## 🏗️ Kiến trúc Monorepo & Turborepo

Dự án được phân rã thành các gói module chuyên biệt:

```text
acc/
├── apps/
│   ├── cli/                   # @acc/cli: Unified CLI Dispatcher & 6 Orchestrator Pipelines
│   └── python-backend/        # Backend Python gRPC (SAM 2, Depth Anything v2, Kokoro TTS)
├── packages/
│   ├── core/                  # @acc/core: FFI FFmpeg C-Bindings, Zero-Copy I/O, Registry, Prompts
│   ├── ir/                    # @acc/ir: Timeline IR Models, DAG AST Schemas
│   ├── effect-engines/        # @acc/effect-engines: 3D Depth, Canvas Overlays, Audio DSP, Transformers.js
│   ├── exporters/             # @acc/exporters: Multi-channel Exporters (Video, Audio, Social, Static Web)
│   └── proto/                 # @acc/proto: Protobuf & gRPC Contracts
├── autogenerated-tests/       # Hệ thống kiểm thử tự động (Unit, Stress, Regression)
├── docs/                      # Tài liệu kỹ thuật chi tiết
│   ├── CLI_GUIDE.md           # Sách hướng dẫn toàn diện Unified CLI & Monorepo
│   └── STORY_CONFIG_SPEC.md   # Đặc tả cấu hình chi tiết Story JSON
├── package.json               # Cấu hình Bun Workspaces & Scripts
└── turbo.json                 # Cấu hình Turborepo Pipeline & Caching
```

### Các lệnh Turborepo cơ bản:

```bash
# Chạy toàn bộ test suites trong monorepo
bun run test
# hoặc qua Turbo:
turbo run test

# Build toàn bộ project
turbo run build
```

## 🚀 Unified CLI v3.0 (`apps/cli` / `@acc/cli`)

Hệ thống CLI mới hợp nhất toàn bộ 6 Pipeline sản xuất nội dung, Universal Video IR renderer và các công cụ bổ trợ vào một điểm vào duy nhất:

```bash
bun run acc <command> [pipeline_id] [options]
# Hoặc thực thi trực tiếp:
bun run apps/cli/src/index.ts <command> [pipeline_id] [options]
# Hoặc render trực tiếp qua Universal Video IR:
bun run ir-render --config ./sample-story/story-config.json
```

### 📋 Danh mục Lệnh (Commands)

| Lệnh | Mô tả | Cú pháp ví dụ |
| :--- | :--- | :--- |
| `list` | Xem danh sách 6 Pipeline và các kênh Exporter hỗ trợ | `bun run acc list` |
| `run` | Thực thi Pipeline sản xuất nội dung | `bun run acc run story -c ./sample-story` |
| `ir-render` | Render trực tiếp qua Universal Video IR Engine (Phases 1-6) | `bun run ir-render --config ./sample-story/story-config.json` |
| `stream` | Phát luồng trực tiếp RTMP 24/7 (GOP 2.0s YouTube/Twitch) | `bun run acc stream ambient --rtmp <url>` |
| `serve` | Khởi động Webhook Ingestion HTTP Server daemon | `bun run acc serve --port 3000` |
| `overlay` | Sinh video hiệu ứng lớp phủ (Mưa, Tuyết, Khói, Lửa, VHS...) | `bun run acc overlay -e rain -v storm` |
| `sfx` | Sinh hiệu ứng âm thanh (Smart Router: AI/Synth/Freesound) | `bun run acc sfx -p "laser beam blast"` |
| `<story_folder>` | Shorthand tương thích ngược chạy Generative Story | `bun run acc ./sample-story` |

👉 **Xem hướng dẫn chi tiết từng tham số & recipes tại [docs/CLI_GUIDE.md](docs/CLI_GUIDE.md)**.

## 🛠️ Bộ Công Cụ CLI Chuyên Biệt

### 1. Tool Tự Động Sinh Cấu Hình Universal Auto-Config (`auto-config.ts`)
Interactive Clack UI Wizard xây dựng trên kiến trúc **Universal Auto-Config Engine (v3.0)** với 6 Enterprise GoF Design Patterns (`MediaAssetProberChain`, `PipelineClassifierRegistry`, `PipelineIRBuilder`, `DirectorPresetFactory`, `AutoConfigLegacyBridgeAdapter`, `AutoConfigEngineFacade`).

Tự động quét tài nguyên thư mục, nhận diện chính xác Pipeline (Pipelines 1–6), thiết lập Fine-Grained Director Video Config, và sinh đồng thời 3 artifacts:
- `pipeline-ir.json`: Universal PipelineIR (v3.0.0) DAG AST cho rendering đa kênh.
- `omnichannel-config.json`: Cấu hình đạo diễn đa kênh (Social, Video, Audio, Web, Interactive).
- `story-config.json`: File cấu hình Legacy Bridge đảm bảo tương thích ngược 100%.

```bash
# Wizard tương tác thông minh (@clack/prompts):
bun run auto-config.ts ./sample-story

# Tự động hóa không tương tác (Headless CI/CD):
bun run auto-config.ts ./sample-story --yes

# Chỉ định tham số trực tiếp:
bun run auto-config.ts ./my-project --pipeline 4 --aspect 9:16 --fps 30 --depth --transitions
bun run auto-config.ts ./my-project --dry-run
```

### 2. Tool Sinh Hiệu Ứng Lớp Phủ (`overlay`)
Render các vòng lặp seamless loop bằng HTML5 Canvas `@napi-rs/canvas` và FFI Zero-Copy encoder:

```bash
# Wizard tương tác:
bun run cli.ts overlay

# Chạy trực tiếp (Headless):
bun run cli.ts overlay --effect rain --variant storm --duration 3 --width 1920 --height 1080
bun run cli.ts overlay --composite retro_glitch_vhs
```

### 3. Tool Sinh Hiệu Ứng Âm Thanh SFX (`sfx`)
Tự động định tuyến (Smart Routing) giữa AudioLDM2 AI, Procedural Synth toán học và Freesound:

```bash
# Wizard tương tác:
bun run cli.ts sfx

# Prompt AI Headless:
bun run cli.ts sfx --custom-prompt "cinematic cinematic explosion with deep bass" --duration 3.0
```

Hệ thống hỗ trợ cấu trúc phân chia rõ ràng (Khuyên dùng):

```text

│   ├── 01.jpg
│   ├── 02.mp4
│   └── 03.jpg
├── voiceover/        # File âm thanh giọng đọc (.mp3, .wav) và kịch bản gốc (.txt)
│   ├── 01.mp3
│   ├── 01.txt        # Giúp Whisper căn chỉnh chính xác 100% ngữ nghĩa tiếng Việt
```

```json
      "image": "images/01.jpg",
      "audio": "voiceover/01.mp3",

        "enabled": true,
```

## ⚡ Tính Năng Cốt Lõi

* **Kiến trúc Monorepo Turborepo**: Phân rã theo trách nhiệm rõ ràng, độc lập kiểm thử và tận dụng tối đa caching.
* **FFmpeg C/FFI Zero-Copy Acceleration**: Tải thư viện FFI trực tiếp trong memory, loại bỏ hoàn toàn `fluent-ffmpeg` và `child_process.spawn`.
* **Hiệu ứng Tạo Nổi 3D Vượt Khung (`depth3d`)**: Đột phá thị giác Out-of-Bounds (Frame-Breaker) với đa dạng khung viền (`card`, `polaroid`, `cinema`, `comic`), đổ bóng đa tầng (Elevation Drop Shadow) và dao động nổi bồng bềnh (Floating Motion). Hỗ trợ tách chủ thể qua SAM 2 (`autoSegment: true`) và tạo bản đồ độ sâu metric qua Depth Anything v2 (`autoDepth: true`).
* **Hỗ trợ 10 Bộ Caption Presets & Dynamic Captions**: `tiktok`, `classic`, `cinematic`, `vlog`, `neon-glow`, `bold-retro`, `minimal-clean`, `karaoke`, `news-banner`, `retro-typewriter`. Hỗ trợ gộp cụm từ (`wordsPerPhrase`), bật/tắt hiệu ứng Karaoke Highlight (`activeWordHighlight`) và căn chỉnh độ trễ âm thanh chính xác (`timeOffset`).
* **Mix Video B-roll & Stock Footage**: Hỗ trợ chèn trực tiếp `.mp4`, `.mov`, `.webm` kèm xử lý thời lượng (`freeze`, `loop`, `trim`) và trộn âm thanh nền.
* **Kiến Trúc Multi-Track Timeline & Master Voiceover (`audioTrack`)**: Khóa trục thời gian video theo một file âm thanh chủ quyền duy nhất (Master Clock) giúp loại bỏ triệt để hiện tượng lệch phụ đề/âm thanh, tự do căn chỉnh độ dài hình ảnh/video B-roll mà không làm gián đoạn lời thoại.
* **Hệ Thống Sound Effects Đa Kênh (`sfx`)**: Tích hợp SFX ở cả cấp độ Scene (`scenes[].sfx`) và Global (`settings.sfx`), tự động điều hướng vào Sidechain Compression DSP để dìm BGM khi có hiệu ứng âm thanh quan trọng.
