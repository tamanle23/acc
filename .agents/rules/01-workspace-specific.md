# Project-Specific Rules: Visual Storytelling Generator

- **STORY-CONFIG-8POINT-SYNC**: On any `story-config.json` schema/property/behavior change, sync all 8 components:
  1. `src/types.ts`
  2. `schema/story-config.schema.json`
  3. `docs/STORY_CONFIG_SPEC.md`
  4. `docs/..._GUIDE.md`
  5. `cli.ts` / `src/renderer.ts` / `src/platforms.ts` / `src/styles.ts`
  6. `auto-config.ts`
  7. `sample-story/story-config.json` (verify via `bun run cli.ts ./sample-story`)
  8. `README.md`
- **HISTORY-GIT-ARCHIVAL**: Sequential 3-digit `docs/history/XXX_<task>.md`, index in `docs/history/README.md`, commit `[XXX] <type>(<scope>): <summary>`.
- **FFMPEG-MANAGER**: Entrypoints must call `await FFmpegManager.prepare()`. Pure `bun:ffi` (`getBinDir()`) for decoding, encoding, audio DSP, concat. NEVER use `Bun.spawn*`, `child_process`, or `fluent-ffmpeg`. Wrap pointer offsets in `BigInt()` before addition.
- **GLOBAL-STORAGE**: Cache binaries/models in `path.join(os.homedir(), '.acc')`. Never use `__dirname` or relative paths.
- **STREAM-LABELS**: Unique identifiers in FFmpeg `filter_complex` strings to prevent collisions.
- **BACKLOG-MANAGEMENT**: Sequential 3-digit `docs/backlogs/XXX_<epic_name>.md`, sync `docs/backlogs/README.md`. On completion: mark `[x]`, add date & history link.
- **AUTOGENERATED-TESTS-MANDATE**: Formal `bun:test` files in `/autogenerated-tests/` only. Never create root scratch tests; retain all tests to prevent regressions.
- **ZERO-ALLOC-FRAME-LOOP**: In frame loops & FFI encoding (`encodeRgbaFrame`, `sws_scale`, renderers):
  1. Zero heap cloning: never use `Buffer.from(rgbaBuffer)`. Pass raw `ptr(rgbaBuffer)` directly.
  2. Pre-allocated native C memory (`av_malloc`) for FFI pointer/stride arrays (`srcDataC`, `srcStrideC`). No typed arrays on nursery heap per frame.
  3. Cache structural phrases/regex calculations across frames (e.g. `WeakMap`).
- **System Architecture Anchor**: `docs/SYSTEM_ARCHITECTURE_DOCUMENT.md` is primary architectural SSOT. Must sync on any structural/pipeline change.
