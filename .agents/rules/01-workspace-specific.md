# Project-Specific Rules: Visual Storytelling Generator

- **VIDEO-IR-SCHEMA-SYNC**: On `VideoIR` stable version schema/property/topology/modifier change, sync all 8 components:
  1. `packages/ir/src/types/VideoIR.ts` (TypeScript interfaces & types)
  2. `schema/video-ir.schema.json` (JSON Schema Draft-07 validation)
  3. `packages/ir/src/schema/VideoIRSchemaValidator.ts` (Runtime validator & SerDe)
  4. `docs/ir/1. video_(IR)_specification.md` & `docs/SYSTEM_ARCHITECTURE_DOCUMENT.md`
  5. `packages/ir/src/adapters/` (`StoryConfigToUniversalIRAdapter`, `PipelineIRToUniversalIRAdapter`)
  6. `packages/ir/src/compiler/` (`RelationalDAGCompiler`, `IntervalTreeIndex`)
  7. `packages/ir/src/plugins/` & `packages/ir/src/renderer/IRMasterRenderer.ts`
  8. `autogenerated-tests/` (Unit, schema, serialization, & parity tests)
- **HISTORY-GIT-ARCHIVAL**: Sequential 3-digit `docs/history/XXX_<task>.md`, index in `docs/history/README.md`, commit `[XXX] <type>(<scope>): <summary>`.
- **FFMPEG-MANAGER**: Entrypoints must call `await FFmpegManager.prepare()`. Pure `bun:ffi` (`getBinDir()`) for decoding, encoding, audio DSP, concat. NEVER use `Bun.spawn*`, `child_process`, or `fluent-ffmpeg`. Wrap pointer offsets in `BigInt()` before addition.
- **GLOBAL-STORAGE**: Cache binaries/models in `path.join(os.homedir(), '.acc')`. Never use `__dirname` or relative paths.
- **STREAM-LABELS**: Unique identifiers in FFmpeg `filter_complex` strings to prevent collisions.
- **BACKLOG-MANAGEMENT**: Macro-epics only in `docs/backlogs/XXX_<epic_name>.md` (no per-phase micro-backlogs); phase execution logs live strictly in `docs/history/XXX_<task>.md`. On completion: mark `[x]`, add date & history link.
- **AUTOGENERATED-TESTS-MANDATE**: Formal `bun:test` files in `/autogenerated-tests/` only. Never create root scratch tests; retain all tests to prevent regressions.
- **ZERO-ALLOC-FRAME-LOOP**: In frame loops & FFI encoding (`encodeRgbaFrame`, `sws_scale`, renderers):
  1. Zero heap cloning: never use `Buffer.from(rgbaBuffer)`. Pass raw `ptr(rgbaBuffer)` directly.
  2. Pre-allocated native C memory (`av_malloc`) for FFI pointer/stride arrays (`srcDataC`, `srcStrideC`). No nursery heap allocations per frame.
  3. Cache structural phrases/regex calculations across frames (e.g. `WeakMap`).
- **DETERMINISTIC-HANDSHAKE-BACKPRESSURE**: In headless IR rendering & modifier plugins:
  1. Pure frame math only: `timeSec = globalFrame / fps`. NEVER use `Date.now()`, `performance.now()`, or `Math.random()`. Randomness via seeded `DeterministicNoiseGenerator`.
  2. Inviolable handshake backpressure: Every frame `f` must `await lock.acquire(f)` and be acked by sink before `f+1`.
  3. Bit-identical parity: Future performance tunings must preserve `res1.cumulativeHash === res2.cumulativeHash` across runs.
- **System Architecture Anchor**: `docs/SYSTEM_ARCHITECTURE_DOCUMENT.md` is primary architectural SSOT. Must sync on any structural/pipeline change.
