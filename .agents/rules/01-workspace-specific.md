# WORKSPACE SPECIFICATIONS

## Workspace Registry & Routing
- Specs: `pnpm` workspaces + Turborepo pipelines (`build`, `dev`, `lint`, `test`, `check-types`).
- Registry:
  - `@acc/backend`: `apps/backend` (Java 21 / Spring Modulith)
  - `@acc/console`: `apps/console` (React 19 / Vite 8) | Deps: `@acc/ui`, `@acc/i18n`, `@acc/typescript-config`
  - `mobile-ui`: `apps/mobile-ui` (Expo SDK 57 / React Native 0.86)
  - `tekgo-ui`: `apps/tekgo-ui` (Next.js 15 / React 19) | Deps: `@acc/ui`
  - Shared: `@acc/i18n` (`packages/i18n`), `@acc/typescript-config` (`packages/typescript-config`), `@acc/ui` (`packages/ui`)
- Directive: Scope commands directly to registered paths; no full-repo tree scans.

## Monorepo & Packaging Boundaries
- **Manager**: Strictly `pnpm` (never `npm`/`yarn`). Run `pnpm install` at root on dependency changes.
- **Linking**: `"workspace:*"` for all internal package references.
- **Execution**: Run from root with filters: `pnpm --filter <app> <cmd>` or `turbo run <task> --filter=<app>`. Never `cd`.
- **Isolation**: Apps never import from sibling apps via relative paths. Use `packages/`.
- **Outputs**: Never edit `dist/`, `.next/`, `out/`, `.vite/`, `target/`.

## I18N & Locale Synchronization
- Shared strings in `packages/i18n/src/locales/<lang>/common.json` (`common:` namespace).
- App strings in `apps/<app>/src/locales/<lang>/<app>.json`.
- UI: `useTranslation()` with English fallback: `t('key', 'Fallback')`. No hardcoded text.
- Synchronize all supported locales (`en`, `vi`) on changes. `sidebar-data.ts` keys must match locales.

## Liquid Glass UI & Design Specs
- **Aesthetic**: Liquid Glass mandatory across all clients.
- **Tokens**: Multi-layer backdrop blur (`backdrop-blur-md` to `2xl`) over tinted frosted scrims (`bg-white/65`, `dark:bg-slate-900/65`). Specular borders (`border-white/30 dark:border-white/10`) with inset highlights (`shadow-[inset_0_1px_1px_rgba(255,255,255,0.4)]`). Diffuse elevation (`shadow-xl`). WCAG AA contrast.
- **Specs Sync**: Every frontend/mobile app maintains `DESIGN.md` (tokens, typography, Stitch prompts) and `ROUTE.md` (screens, blueprints, user flows). Synchronize on every UI/route modification.

## Video-IR & Media Processing Invariants
- **Schema Sync**: Sync all 8 components on stable `VideoIR` changes: (1) `packages/ir/src/types/VideoIR.ts`, (2) `schema/video-ir.schema.json`, (3) `packages/ir/src/schema/VideoIRSchemaValidator.ts`, (4) `docs/ir/1. video_(IR)_specification.md`, (5) `packages/ir/src/adapters/`, (6) `packages/ir/src/compiler/`, (7) `packages/ir/src/plugins/` & `IRMasterRenderer.ts`, (8) `autogenerated-tests/`.
- **Zero-Alloc Loop**: Zero heap cloning (raw `ptr(rgbaBuffer)` directly to FFI). Pre-allocate native memory (`av_malloc`). Cache structural phrase regexes.
- **Deterministic Backpressure**: Pure frame math (`timeSec = globalFrame / fps`; seeded `DeterministicNoiseGenerator`). Handshake lock on every frame. Cumulative hash bit-identical parity.
- **Formal Tests**: `bun:test` files in `/autogenerated-tests/` only.

## Dynamic Metadata Engine
- **Schema Caching**: Key `schema:{id}:v{version}`; L1 parsed `JsonSchema` + L2 Hazelcast fallback (Hazelcast failures must not break compile/validation).
- **Evolution**: Increment `UNIPOST_ENTITY_TYPES.schema_version` on attribute definition mutation in same transaction.
- **Indexes**: Metadata tables require partial unique indexes `WHERE "deletedDate" IS NULL`.
- **Validation**: `additionalProperties: false`. Server-side defaults applied prior to JSON Schema validation. Reject cross-tenant relations.
