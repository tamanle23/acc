# Walkthrough 13 - Studio Preview: Effect Engines Math Reuse & Subcomponent Decomposition

## Changes Overview

### 1. packages/effect-engines/src/canvas/UniversalCanvasEngine.ts
- Added `VisualLayerItem` interface:
  ```ts
  export interface VisualLayerItem {
    id: string;
    trackId: string;
    drawable: CanvasImageSource;
    sourceWidth: number;
    sourceHeight: number;
    fitMode?: 'cover' | 'contain';
    blendMode?: GlobalCompositeOperation;
    x?: number;
    y?: number;
    scale?: number;
    rotation?: number;
    opacity?: number;
  }
  ```
- Implemented `renderLayers(ctx: CanvasRenderingContext2D, layers: VisualLayerItem[])` to handle:
  - Multi-track layer sorting (`V1 -> V4`).
  - Aspect ratio computation (`cover` for background plates, `contain` for overlays).
  - GSAP affine matrix transforms (`ctx.save()`, `ctx.translate()`, `ctx.rotate()`, `ctx.scale()`, `ctx.globalAlpha`, `ctx.drawImage()`, `ctx.restore()`).

### 2. apps/studio/src/lib/textures/AssetTextureCache.ts
- Implemented Observer pattern with `subscribers = new Set<() => void>()`.
- Added `subscribe(callback)` returning an unsubscribe function.
- Wired `notify()` into `img.onload` and `video.onloadeddata`.

### 3. apps/studio/src/components/preview/
- Decomposed monolithic UI elements into focused single-responsibility subcomponents:
  - `ViewportControlBar.tsx`: Viewport HUD controls.
  - `ViewportSafeGuides.tsx`: Broadcast & social safe guide overlays.
  - `ContextualActionPill.tsx`: On-canvas floating action toolbar.
  - `SubtitlesOverlay.tsx`: Styled subtitle captions.

### 4. apps/studio/src/components/Preview.tsx
- Removed duplicated canvas math and inline UI blocks.
- Subscribed to `AssetTextureCache` updates to trigger canvas redraws dynamically.
- Transformed active visual sequences into `VisualLayerItem[]` and called `engine.renderLayers(ctx, layersToDraw)`.
- Embedded modular subcomponents into JSX.
