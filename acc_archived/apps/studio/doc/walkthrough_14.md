# Walkthrough 14 - Studio Phase 3: Platform-Independent Audio Core & Multi-Track Mixing

## Changes Overview

### 1. packages/ir/src/renderer/audio/
- **`UniversalAudioMixer.ts`**: Relocated from `packages/effect-engines`. Implemented Master Bus architecture separating Voice, SFX, and BGM buses, sidechain dynamic ducking via `DynamicAudioDuckingEngine`, and soft-limiting analog master bus.
- **`AudioSourceAdapter.ts`**: Implemented `IAudioSourceProvider` contract with `DecodedPcmSource` (samples and linearly resamples channel buffers) and `ProceduralSynthesizerSource` (fallback).
- **`ProceduralAudioSynthesizer.ts`**: Relocated from `packages/effect-engines` to make `packages/ir` self-contained.

### 2. packages/ir/src/plugins/
- **`plugins/audio/VolumeModifierPlugin.ts`**: Implements `audio/volume` for linear volume scaling and fade-in/fade-out curves.
- **`plugins/audio/PanModifierPlugin.ts`**: Implements `audio/pan` with equal-power stereo balance.
- **`plugins/audio/FilterModifierPlugin.ts`**: Implements `audio/filter` with 2-pole Biquad IIR filter (lowpass, highpass, bandpass).
- **`plugins/audio/PitchModifierPlugin.ts`**: Implements `audio/pitch` with resampling for speed/detune.
- **`plugins/sfx/DynamicDuckingPlugin.ts`**: Enhanced with robust linear/dB gain parameter handling.
- **`plugins/ModifierPluginRegistry.ts`**: Added `processAudioStream` and `processStereoStream` hooks to `ModifierPlugin`.
- **`plugins/index.ts`**: Registered audio modifier plugins in core registry.

### 3. packages/effect-engines/
- **`src/audio/UniversalAudioMixer.ts`** & **`src/audio/ProceduralAudioSynthesizer.ts`**: Re-export canonical audio core from `@acc/ir/client` preserving backward compatibility with zero regressions.

### 4. apps/studio/
- **`src/lib/audio/AudioAssetCache.ts`**: Implemented reactive decoded audio pool with Observer pattern (`subscribe`/`notify`).
- **`src/lib/audio/WebAudioEngine.ts`**: Wired `AudioAssetCache` into `syncFromIR`, extracted real PCM waveform peaks, and connected to `UniversalAudioMixer`.
