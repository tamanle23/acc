# Implementation Plan 07: Phase 5 - GSAP Easing Inspector & Left Sidebar Enhancements

## 1. Overview & Objectives
Elevate Studio's animation tuning and asset discovery capabilities by integrating:
1. **Right Sidebar GSAP Easing Curve Selector**:
   - Visual SVG Bézier curve tiles for 7 standard GSAP easing curves (`linear`, `power2.out`, `power2.inOut`, `back.out`, `elastic.out`, `bounce.out`, `expo.out`).
   - Dynamic hover animations with traveling dot indicator and active highlight badge.
   - Synchronized directly to the selected sequence's `transform` modifier (`params.ease`).
2. **Dual SFX Strategy**:
   - **Left Sidebar**: Pre-generated SFX presets in `STAGING_PRESETS` (`sfx` category) for drag-and-drop staging into audio tracks.
   - **Right Sidebar**: On-the-fly Procedural Audio Synthesizer panel allowing live auditioning and custom SFX sequence generation.
3. **Left Sidebar Discovery & Assets Vault Enhancements**:
   - Real-time search filter bar across presets and vault assets.
   - Category filter pill tags: `All`, `Typography`, `VFX`, `Shapes`, `SFX`.
   - Non-intrusive micro-animations on preset cards (`hover:-translate-y-0.5`, subtle border glow, gentle icon pulse, quick `+` insert button).
   - Drag-and-drop file upload dropzone in Assets Vault with client-side `URL.createObjectURL` and metadata probing.

## 2. Technical Design & Architecture

### A. GSAP Easing Curve Component (`apps/studio/src/components/EasingCurveSelector.tsx`)
- Exports `GSAP_EASING_PRESETS`:
  - `linear`: `M 0 50 L 100 0`
  - `power2.out`: `M 0 50 Q 30 0 100 0`
  - `power2.inOut`: `M 0 50 C 40 50, 60 0, 100 0`
  - `back.out`: `M 0 50 C 40 0, 70 -15, 100 0`
  - `elastic.out`: `M 0 50 C 20 -20, 40 10, 60 -5, 80 2, 100 0`
  - `bounce.out`: multi-arc bounce curve
  - `expo.out`: `M 0 50 C 5 0, 20 0, 100 0`
- Renders a 2-column or 3-column compact grid of interactive SVG tiles with label and description.
- Hovering animates a glowing neon dot along the path via CSS offset-path or SVG animation.

### B. Right Sidebar Transform & SFX Generator Integration (`RightSidebar.tsx`)
- Embed `EasingCurveSelector` directly inside the Transform Accordion Panel below rotation/scale sliders.
- Add an on-the-fly **"Procedural Audio Generator"** panel under Audio Inspector with:
  - Preset type: `whoosh`, `impact`, `glitch`, `riser`, `drone`.
  - Base frequency (Hz), Duration (s), Resonance, Ducking factor.
  - "Audition SFX" button (invokes `ProceduralAudioSynthesizer` and plays via `WebAudioEngine`).
  - "Insert to Timeline" button (dispatches `AddSequenceCommand` to audio track).

### C. Left Sidebar Presets, Category Pills & Dropzone (`LeftSidebar.tsx` & `stagingPresets.ts`)
- Update `PresetCategory` in `stagingPresets.ts`: `'text' | 'shape' | 'vfx' | 'sfx'`.
- Add 4 SFX staging presets:
  - `sfx_impact`: "Cinematic Sub-Bass Impact"
  - `sfx_whoosh`: "Sci-Fi Air Whoosh"
  - `sfx_glitch`: "Cybernetic Glitch Stutter"
  - `sfx_riser`: "Tension Drone Riser"
- Update category pill tags: `All`, `Typography`, `VFX`, `Shapes`, `SFX`.
- Enhance `DraggablePresetCard` with non-intrusive micro-animations:
  - `-translate-y-0.5 hover:shadow-[0_4px_16px_var(--accent-glow)]/15`
  - Floating `+` quick-insert button.
- Implement file dropzone in Assets Vault (`activeNav === 'vault'`):
  - Ingests dropped files (`video/*`, `audio/*`, `image/*`).
  - Probes metadata via `document.createElement('video')` or `Image()`.
  - Registers asset into `irState.doc.assets`.
