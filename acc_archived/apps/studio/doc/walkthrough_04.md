# Walkthrough 04: Phase 1 — Complete Removal of Three.js & UniversalCanvasEngine Migration

## Overview
Successfully executed **Phase 1 of Iteration 7**:
1. Completely removed Three.js (`three`, `@types/three`) across the entire repository (`package.json`, `@acc/effect-engines`, `@acc/studio`).
2. Replaced `UniversalThreeScene` with an isomorphic `UniversalCanvasEngine` powered by **GSAP** and **Pts.js** on 2D canvas contexts (`HTMLCanvasElement` in Studio and `@napi-rs/canvas` on the server).
3. Re-architected `CanvasTransformOverlay` using Pts.js `Pt` vectors and native 2D canvas drawing (bounding box, 8 resize handles, rotation knob & stem, magnetic snapping guides).
4. Refactored `apps/studio/src/components/Preview.tsx` to mount `UniversalCanvasEngine` onto standard `canvas.getContext('2d')`, eliminating WebGL initialization overhead and reducing the production client bundle by over 600 KB.

## Key Changes
- **Workspace Dependencies**:
  - `package.json`, `packages/effect-engines/package.json`, `apps/studio/package.json`: Removed `three` and `@types/three`, added `gsap@^3.12.7`.
- **Effect Engines**:
  - Deleted `packages/effect-engines/src/three/`.
  - Added `packages/effect-engines/src/canvas/UniversalCanvasEngine.ts` and `CanvasTransformOverlay.ts`.
  - Updated `packages/effect-engines/src/client.ts` and `src/index.ts`.
- **Studio Application**:
  - `apps/studio/src/components/Preview.tsx`: Replaced Three.js WebGL rendering pass with 2D Canvas `engine.render(ctx, timeSec, popOutIntensity)`.
- **Testing**:
  - Added `autogenerated-tests/isomorphic_canvas_engine.test.ts` (5/5 tests passed).
  - Updated `autogenerated-tests/studio_canvas_transform.test.ts`.
  - Removed obsolete Three.js test `autogenerated-tests/isomorphic_three_pts.test.ts`.
