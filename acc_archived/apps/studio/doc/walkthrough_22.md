## 1. Executive Summary & Goals

In Iteration 10, the objective was to eliminate any rendering discrepancies between:
- **`IRPreviewEngine`**: Interactive browser/client preview renderer and client MP4 export engine.
- **`IRMasterRenderer`**: Headless server-side rasterizer feeding FFI video encoders and chunked pipelines.

By creating a canonical, stateless **`IRCanvasCompositor`**, formalizing **`TransformModifierPlugin`** and **`CaptionModifierPlugin`**, and standardizing viewport background `#000000`, both engines now produce **100% bit-identical visual output** (cryptographic SHA-256 byte parity and pixel-diff delta = 0).

## 2. Key Architecture & Deliverables

### A. Formalized Modifier Plugins
- **`TransformModifierPlugin`** (`packages/ir/src/plugins/transform/TransformModifierPlugin.ts`):
  - Target: `type = 'transform'`, `targetScope = 'clip'`, `targetPhase = 1`.
  - Evaluates deterministic motion easing curves (`intro`, `steady`, `outro`) via `evaluateSequenceMotion()`.
  - Stacks matrix transforms (`translate -> rotate -> scale -> globalAlpha`) around visual center origin.
- **`CaptionModifierPlugin`** (`packages/ir/src/plugins/text/CaptionModifierPlugin.ts`):
  - Target: `type = 'text/style'`, `targetScope = 'both'`, `targetPhase = 2`.
  - Wraps `BoundedAcousticCaptionStrategy` and `drawCanvasCaptionsFromSnapshot()` for karaoke word-by-word highlights and platform `SafeZoneManager` margins.

### B. Canonical Shared Compositor
- **`IRCanvasCompositor`** (`packages/ir/src/renderer/shared/IRCanvasCompositor.ts`):
  - Pure synchronous static rendering core (`renderFrame()`).
  - Implements the 5-phase lifecycle:
    1. Clear viewport with `#000000` (Pure Black).
    2. Visual tracks (`video`, `image`, `overlay`) rendered in **pure document order** ($0 \rightarrow N$) with scoped `ctx.save()/restore()` and blend modes.
    3. Hybrid pragmatic culling (`track.muted === true` or `sequence.enabled === false`).
    4. Timed-text tracks rendered strictly above all visual layers.
    5. Master composite modifier plugins.

### C. Engine Consolidation
- **`IRMasterRenderer`**: `renderCanvasFrame()` pre-fetches active video decoder frames into an `assetResolver` and delegates directly to `IRCanvasCompositor.renderFrame()`.
- **`IRPreviewEngine`**: `renderFrame()` delegates directly to `IRCanvasCompositor.renderFrame()`, eliminating ~180 lines of duplicate matrix and blitting code.
