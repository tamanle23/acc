# Implementation Plan - Phase 4: RightSidebar Inspector Panels for HUD & Particles

## 1. Overview
Phase 4 implements dedicated and schema-aligned inspector controls in `apps/studio/src/components/RightSidebar.tsx` for Hologram HUD and Particle VFX. These controls seamlessly integrate with the Video IR modifier ecosystem, bind reactively to `IRStateManager`, enforce Rule 229 (zero nested `<button>` / interactive elements inside `AccordionTrigger`), and reactively update `UniversalCanvasEngine` in `Preview.tsx`.

## 2. Requirements & Architectural Alignment
- **Dual Schema Hologram HUD**:
  - Support dedicated `overlay/hologram_hud` with parameters `ringRadiusNorm`, `scanlineDensity`, `color`, `rotationSpeed`, and `enabled`.
  - Fallback/overlaid support for `overlay/canvas_particles` with `type: 'sci_fi_hud'`.
- **`AVAILABLE_MODIFIERS` Registration**:
  - Register `overlay/hologram_hud` in `AVAILABLE_MODIFIERS` with icon `Monitor` and defaults `{ enabled: true, ringRadiusNorm: 0.35, scanlineDensity: 40, color: '#00ffff', rotationSpeed: 0.5 }`.
  - Update `overlay/canvas_particles` with defaults aligned to `CanvasParticleOverlayParams` (`type: 'cyber_sparks'`, `intensity: 1.0`, `speed: 1.0`, `opacity: 0.8`, `particleCount: 1500`, and nested `shaders`).
- **Dedicated Hologram HUD Accordion Panel (`value="hologram_hud"`)**:
  - Ring Radius slider: `ringRadiusNorm` (0.10 to 0.80, step 0.05, default 0.35).
  - Scanline Density slider: `scanlineDensity` (10 to 100, step 5, default 40).
  - Rotation Speed slider: `rotationSpeed` (0.1 to 3.0, step 0.1, default 0.5, unit `rad/s`).
  - Color Picker Row: Preset palette (`#00ffff`, `#ec4899`, `#f59e0b`, `#10b981`, `#8b5cf6`) + native color input.
  - Reset Defaults button + Enable toggle via `AccordionTrigger` `actions` prop.
- **Strict Schema-Aligned Particle VFX Accordion Panel (`value="particles"`)**:
  - Particle Type Selector: Dropdown for `cyber_sparks`, `embers`, `dust`, `rain`, `snow`, `bokeh`, `matrix_rain`, `digital_glitch`.
  - Sliders: `intensity` (0.1–2.0), `speed` (0.1–3.0), `opacity` (0.0–1.0), `particleCount` (50–3000).
  - Collapsible Post-Processing Shaders: Bloom (`threshold`, `intensity`) and Chromatic Aberration (`offsetPx`) with backward compatibility for flat legacy properties (`bloomThreshold`, `chromaticAberration`).
  - Decoupled controls UX: Preserves user sliders when changing type, with a "Reset Defaults" action button.
- **Preview Reactivity**:
  - Enhance `UniversalCanvasEngine` with `getParticleCount()` so `Preview.tsx` reactively re-spawns particle count changes.
  - Map `activeHudMod` fallback values (`hp.speed`, `hp.intensity`) for `overlay/canvas_particles` with `type: 'sci_fi_hud'`.
- **Rule 229 Compliance**:
  - All interactive buttons and switches in `AccordionTrigger` must be passed via `actions={...}` prop.

## 3. Proposed Changes

### `packages/effect-engines/src/canvas/UniversalCanvasEngine.ts`
- Add `public getParticleCount(): number` to inspect the active particle count.

### `apps/studio/src/components/Preview.tsx`
- In render loop, check `engine.getParticleCount() !== pCount` when updating particles.
- Map `hp.speed` and `hp.intensity` defensively for HUD rendering when using `sci_fi_hud`.

### `apps/studio/src/components/RightSidebar.tsx`
- Add `PARTICLE_PRESET_DEFAULTS` constant with tailored configurations for all 8 particle types.
- Add `overlay/hologram_hud` to `AVAILABLE_MODIFIERS`.
- Resolve `hologramHudMod` from `modifiers.find((m) => m.type === 'overlay/hologram_hud' || (m.type === 'overlay/canvas_particles' && m.params?.type === 'sci_fi_hud'))`.
- Add Hologram HUD accordion section with sliders, color picker, and reset button.
- Upgrade Particle VFX accordion section with preset dropdown, sliders, nested shader controls, and reset button.
