# Implementation Plan 04: Wiring UniversalThreeScene & UniversalAudioMixer in Studio App

## 1. Goal Description
Bridge the two core isomorphic rendering and DSP engines (`UniversalThreeScene` and `UniversalAudioMixer` from `@acc/effect-engines/client`) into the standalone Studio application:
1. **`UniversalThreeScene`**: Mount Three.js `WebGLRenderer` on the canvas in `Preview.tsx` to drive the 3D Depth Mesh, HUD hologram, particle warp tunnel, localized partial VFX, and transform overlay.
2. **`UniversalAudioMixer`**: Wire `WebAudioEngine` to `VideoIRDocument` to dynamically parse `sfx/dynamic_ducking` modifiers, synthesize Float32 stereo PCM buffers, and stream real-time peak/RMS audio levels to `MasterAudioMeter.tsx`.

---

## 2. Key Architecture Elements
- **Visual Engine**: `UniversalThreeScene` with Three.js `WebGLRenderer` in `Preview.tsx`.
- **Audio Engine**: `UniversalAudioMixer` connected to Web Audio API in `WebAudioEngine.ts`.
- **Telemetry**: Real-time VU metering in `MasterAudioMeter.tsx`.

---

## 3. Verification Plan
- Unit & Integration tests in `autogenerated-tests/studio_three_audio_wiring.test.ts`.
- Zero-regression check across existing suites.
- Production build validation with `bun run studio:build`.
