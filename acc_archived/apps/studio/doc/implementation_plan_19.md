# Implementation Plan 19: Dynamic Modifier Discovery in Studio RightSidebar via ModifierPluginRegistry

## Goal
Integrate `ModifierPluginRegistry` from `@acc/ir/client` into `RightSidebar.tsx` in `apps/studio` to replace static modifier arrays with runtime dynamic discovery, metadata catalog enrichment, and custom plugin fallback.

## Proposed Changes
1. **`ModifierPluginRegistry.ts`**: Add `listPlugins(): ModifierPlugin<any>[]` method.
2. **`clientRegistry.ts`**: Implement `registerClientModifierPlugins()` for browser runtime without native Node/FFI dependencies.
3. **`client.ts`**: Export `registerClientModifierPlugins` and plugin listing methods.
4. **`main.tsx`**: Bootstrapped client modifier plugin registration upon Studio startup.
5. **`RightSidebar.tsx`**: Replace hardcoded `ALL_AVAILABLE_MODIFIERS` with `MODIFIER_PRESENTATION_CATALOG` and `getAvailableModifiersFromRegistry()`.
