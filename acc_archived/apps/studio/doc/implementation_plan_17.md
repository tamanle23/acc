# Implementation Plan 17: Video IR Spec Modernization & 8-Component Synchronization

Modernize the Video Intermediate Representation (IR) specification across all 8 architectural components to support explicit sequence types, global document-level modifiers, domain-constrained modifier targets, dual-level blend modes, and decoupled modular schemas.

## Proposed Changes

### Component 1: Core Type Definitions
- `packages/ir/src/types/modifiers.ts`:
  - Defined explicit parameter interfaces for all 15+ standard modifier types (`TransformParams`, `ColorLutParams`, `Depth3DParams`, etc.).
  - Declared `StandardModifierNode` discriminated union and `CustomModifierNode` fallback.
- `packages/ir/src/types/VideoIR.ts`:
  - Added `SequenceType = 'video' | 'image' | 'audio' | 'text' | 'overlay'`.
  - Added `BlendMode = 'normal' | 'screen' | 'multiply' | 'overlay' | 'add' | 'color_dodge' | 'soft_light'`.
  - Added required `type: SequenceType` and optional `blendMode?: BlendMode` to `IRSequence`.
  - Added optional `modifiers?: ModifierNode[]` to `VideoIRDocument`.
  - Re-exported all modifier types from `./modifiers`.

### Component 2: JSON Schema Definitions
- `schema/modifiers.schema.json`:
  - Draft-07 decoupled modular schema with `$defs/modifierNode`, `$defs/sequenceType`, and all 15+ modifier parameter definitions.
- `schema/video-ir.schema.json`:
  - References `modifiers.schema.json#/$defs/modifierNode`.
  - Strictly requires `type` on sequences.
  - Adds optional root `modifiers` array.

### Component 3: Runtime Validator & SerDe
- `packages/ir/src/schema/VideoIRSchemaValidator.ts`:
  - Strictly requires `seq.type` and validates track containment.
  - Strictly requires `modifier.target` and enforces sequence-level and track-level domain compatibility.
  - Validates root document-level `doc.modifiers`.
  - Validates `blendMode` values.

### Component 4: Adapters & Compiler
- `packages/ir/src/adapters/StoryConfigToUniversalIRAdapter.ts` & `PipelineIRToUniversalIRAdapter.ts`:
  - Assign explicit `type` to all synthesized sequences.
  - Assign valid `target` to all synthesized modifiers.
- `packages/ir/src/compiler/RelationalDAGCompiler.ts`:
  - Propagates `type` and `blendMode` to `ResolvedSequence`.
  - Retains root `modifiers` on `ResolvedTimeline`.

### Component 5: Plugins & Master Renderer
- `packages/ir/src/plugins/ModifierPluginRegistry.ts`:
  - Added `defaultTarget` specifications to `ModifierPlugin`.
- `packages/ir/src/renderer/IRMasterRenderer.ts`:
  - Cascades `seq.blendMode || track.blendMode`.
  - Executes root `this.timeline.modifiers` in Phase 4 master composite pass.

### Component 6: Studio Integration & Fixtures
- Updated `apps/studio/src/lib/ir/defaultDemoIR.ts`, `complexSciFiDemoIR.ts`, and `stagingPresets.ts`.
- Updated `UpdateModifierCommand.ts` to support modifying targets.

### Component 8: Testing
- Added `autogenerated-tests/video_ir_spec_modernization.test.ts` (20/20 passing).
- Synchronized legacy fixtures in `autogenerated-tests/video_ir_phase1_phase2.test.ts`, `ir_schema_sync_iteration5.test.ts`, and `master-integration-iteration-1.test.ts`.
