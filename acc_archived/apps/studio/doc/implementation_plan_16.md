# Implementation Plan 16: Overlay VFX Sequences & Context-Aware Inspector

## Problem Statement
Previously, the studio inspector displayed static panels regardless of whether modifiers were attached to the selected sequence. Sequences also lacked direct timing controls (absolute frames/timecode and relational DAG links), and adding VFX effects like ambient snow, sparks, or HUD holograms required manually building sequences or modifying asset configs. Furthermore, text sequences lacked dedicated controls for dual-state base styling vs karaoke active-word glow styling.

## Architecture & Proposed Design
1. **Interactive Base Sequence Timing (`UpdateSequenceTimeCommand`)**:
   - Create `UpdateSequenceTimeCommand` supporting absolute start & duration as well as relational timing (`syncWith`, `after`, `matchLengthOf`, `paddingFrames`).
   - Wire `irState.updateSequenceTime` to push command to history and execute topological DAG recompilation.
   - Display a responsive `SequenceTime` card in `RightSidebar.tsx` with dual mode (Absolute vs Relational) and timecode/frame formatting.

2. **Context-Aware Attached-Only Modifier Inspector**:
   - In `RightSidebar.tsx`, dynamically mount modifier accordion sections only when `selectedSeq.modifiers?.some(m => m.type === key)`.
   - Provide an empty state dashed guide when no modifiers exist on the sequence.
   - Attach delete/trash action buttons strictly within `actions={<button>...}` in compliance with Rule 229 (`AccordionTrigger` action prop).

3. **Domain-Filtered "+ Add Effect" Menu**:
   - Restrict modifier dropdown additions according to `selectedTrack.type`:
     - `video`: `transform`, `relighting`, `camera`, `particles`, `hologram_hud`, `color`
     - `timed_text`: `transform`, `text/style`
     - `audio`: `audio`, `sfx/procedural`

4. **Dual-State Typography Inspector**:
   - Within `text/style` modifier panel, provide tabs or separate sub-sections for:
     - **Base Typography**: font family, size, fill color, weight, tracking, alignment.
     - **Active-Word Karaoke Highlight**: active color, text glow radius, glow color, and scale bump.

5. **Overlay VFX Staging Presets**:
   - Define canonical overlay presets (`overlay_particles_sparks`, `overlay_particles_snow`, `overlay_hologram_hud`) with `category: 'overlay'` targeting `track-overlay-vfx` (type: `video`).
   - Create sequences without `assetId` (`assetId: undefined`) with full-screen bounds, high z-depth, and particle/hologram modifiers.
