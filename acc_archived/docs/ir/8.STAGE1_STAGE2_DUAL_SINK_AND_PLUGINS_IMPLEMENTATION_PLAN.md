# Two-Stage Video Creation Pipeline: 6-Step Implementation Plan
## Stage 1: Heterogeneous Config Ingestion & Normalization to Universal Video IR
## Stage 2: Deterministic Dual-Target Execution (Headless `FFIVideoEncoder` & Interactive Preview Editor)

---

### Step 1: Stage 1 Adapter Strategy Pattern & Extensible Registry
- **Objective:** Support heterogeneous story formats (different use cases, screenplay formats, database templates) without hardcoding conditionals in the core engine (**Open-Closed Principle**).
- **Key Artifacts:**
  - `packages/ir/src/adapters/IConfigToIRAdapter.ts`: Strategy interface specifying:
    - `canAdapt(config: unknown): boolean` (format auto-detection)
    - `adapt(config: TConfig, options?: AdapterOptions): VideoIRDocument`
  - `packages/ir/src/adapters/IRConfigAdapterRegistry.ts`: Singleton registry managing all config-to-IR strategies.
  - `packages/ir/src/adapters/StoryConfigToUniversalIRAdapter.ts`: Concrete adapter implementation for legacy `story-config.json`.
  - Added CLI flag `--export-ir <path>` to allow users to dump and verify the intermediate IR document prior to rendering.

---

### Step 2: 4-Phase Lifecycle Plugin Contract (Document 7 Integration)
- **Objective:** Upgrade stub plugins to concrete, production-grade rendering and audio strategies adhering to the 4-phase lifecycle defined in `docs/ir/7.Universal_Video_IR_Comprehensive_Plugin_Implementation_Master_Plan.md`.
- **Key Artifacts:**
  - `packages/ir/src/plugins/IVideoPluginStrategy.ts`:
    - **Phase 1: Pre-flight & Relational DAG Resolution** (`preflightDAGResolution`)
    - **Phase 2: Sequence-Level Execution (Clip Space)** (`renderClipSpace`)
    - **Phase 3: Track-Level Execution (Stream Space)** (`renderStreamSpace`)
    - **Phase 4: Master Canvas Compositing & Handshake** (`renderMasterComposite`)
  - `packages/ir/src/plugins/ModifierPluginRegistry.ts`: Unified registry supporting 4-phase dispatch with defensive pass-through for unknown plugins.

---

### Step 3: Concrete Modifier Plugin Implementations
- **Objective:** Replace stub plugins with actual canvas and audio DSP operations.
- **Implementations:**
  - **3D Depth Pop-Out (`vfx/depth3d`):** [`Depth3DPlugin.ts`](packages/ir/src/plugins/vfx/Depth3DPlugin.ts)
    - Phase 2 Clip Space: Renders card boundaries (polaroid/comic) and breathing parallax zoom transformations.
  - **Editorial Crossfade (`transition/crossfade`):** [`TransitionCrossfadePlugin.ts`](packages/ir/src/plugins/editorial/TransitionCrossfadePlugin.ts)
    - Phase 2 Clip Space: Calculates linear opacity fade-in / fade-out across sequence boundaries.
  - **Procedural Particle Canvas Overlays (`overlay/canvas_particles`):** [`CanvasParticleOverlayPlugin.ts`](packages/ir/src/plugins/overlay/CanvasParticleOverlayPlugin.ts)
    - Phase 3 Stream Space: Deterministic, frame-seeded procedural rain, snow, embers, and dust.
  - **Algebraic Blend Modes (`overlay/blend_mode`):** [`BlendModePlugin.ts`](packages/ir/src/plugins/overlay/BlendModePlugin.ts)
    - Phase 4 Master Composite: Applies canvas `globalCompositeOperation` (screen, multiply, overlay, color-dodge).
  - **Dynamic Audio Ducking (`sfx/ducking`):** [`DynamicDuckingPlugin.ts`](packages/ir/src/plugins/sfx/DynamicDuckingPlugin.ts)
    - Phase 3 Audio Stream: Attenuates background music stream when foreground dialogue sequences are active.

---

### Step 4: Dual Output Sink Architecture (`IIRFrameSink`)
- **Objective:** Decouple `IRMasterRenderer` from disk I/O, allowing the identical frame loop to serve both headless compilation and interactive editor players.
- **Key Artifacts:**
  - `packages/ir/src/renderer/sink/IIRFrameSink.ts`: Abstract consumer contract with `initialize(meta)`, `consumeFrame(t, rgbaBuffer)`, and `finalize(audioResult)`.
  - `packages/ir/src/renderer/sink/FFIVideoEncoderSink.ts`:
    - Wraps `FFIVideoEncoder` (native `bun:ffi` FFmpeg).
    - Encodes RGBA frame buffers directly to `.mp4` on disk with zero intermediate PNG/JPEG disk caching.
    - Zero child processes (`Bun.spawn` / `child_process` banned).
  - `packages/ir/src/renderer/sink/PreviewCanvasSink.ts`:
    - In-memory frame sink notifying visual preview players and scrubbers per frame.
    - Sub-16ms interactive latency without disk overhead.

---

### Step 5: High-Performance Canvas Blitting in `IRMasterRenderer`
- **Objective:** Wire asset preloading, image blitting, subtitle rendering, and multi-phase plugin execution into `IRMasterRenderer` while enforcing `ZERO-ALLOC-FRAME-LOOP`.
- **Key Features:**
  - Preloads visual image assets declared in `timeline.assets` into memory.
  - Pre-allocates single native-sized RGBA buffer `new Uint8Array(width * height * 4)`.
  - Blits visual layers with automatic letterboxing/pillarboxing.
  - Renders timed-text subtitle cues.
  - Passes raw buffers directly to `options.sink` (`FFIVideoEncoderSink` or `PreviewCanvasSink`).

### Step 6: CLI Integration, Hardware Verification & End-to-End Tests
- **Objective:** Expose `--output` flag in CLI `ir-render` command and write comprehensive verification tests.
- **Key Artifacts:**

  - `apps/cli/src/index.ts`: Added `-o` / `--output` CLI argument handling.
  - `autogenerated-tests/video_ir_stage1_stage2_e2e.test.ts`:
    - **Test 1:** Validates Stage 1 config transformation via `IRConfigAdapterRegistry`.
    - **Test 2:** Validates Stage 2 `PreviewCanvasSink` interactive preview frame dispatch.
    - **Test 3:** Validates Stage 2 `FFIVideoEncoderSink` encoding a real physical `.mp4` file via `bun:ffi`.
  - Verified physical file output:
