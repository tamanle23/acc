# 303: Decompose Preview Monolith into Modular Preview Components

## Summary
Decomposed the monolithic `apps/studio/src/components/Preview.tsx` (~1,187 lines) into a suite of clean, modular, reusable components under `apps/studio/src/components/preview/`. The root `Preview.tsx` was refactored into a high-level orchestrator focused strictly on viewport state management, WebCodecs/Worker initialization, and composition.

## Architectural Changes & Extracted Components

All newly extracted components reside in `apps/studio/src/components/preview/` and are cleanly re-exported via `apps/studio/src/components/preview/index.ts`:

1. **`TransformHandles.tsx`**:
   - Encapsulates `TransformHandle` (cardinal, ordinal, rotation controls with `@dnd-kit/core` `useDraggable`) and `TransformBodyDraggable` (whole-box in-canvas translation).
2. **`InlineTextEditorModal.tsx`**:
   - Floating backdrop-blurred modal for direct in-canvas editing of active subtitles and speech text cues with keyboard shortcuts (`Enter` to commit, `Escape` to cancel).
3. **`ViewportQuickTransport.tsx`**:
   - Floating pill transport bar at the bottom center of the viewport providing Quick Rewind, Play/Pause, Step Forward, and frame-accurate SMPTE timecode readout.
4. **`VectorShapeOverlay.tsx`**:
   - Dedicated vector graphics renderer for sequence-level geometric shapes (rectangles, rounded boxes, circles, and directional arrows) with active hover indicators.
5. **`StagingDropTargetOverlay.tsx`**:
   - Floating drag-and-drop asset staging indicator badge displaying normalized canvas coordinates `(X: normX, Y: normY)` and drop prompts.
6. **`TransformGizmoOverlay.tsx`**:
   - 2D transformation bounding box overlay complete with 8 resize handles, rotation knob, rotation guide line, and `ContextualActionPill` integration.
7. **`ViewportCanvasLayer.tsx`**:
   - Dual-layer decoupled canvas element container (`#studio-canvas` for WebCodecs/Worker/fallback video frames and `#studio-overlay-canvas` for high-frequency gizmo/HUD drawing).
8. **`index.ts`**:
   - Complete barrel file exporting both pre-existing (`ViewportControlBar`, `ViewportSafeGuides`, `ContextualActionPill`, `SubtitlesOverlay`, `TelemetryCompanionCard`) and newly extracted preview components.
