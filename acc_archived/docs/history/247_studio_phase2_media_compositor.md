# 247 - Studio Phase 2: Real Visual Media Compositor (Image & Video)

## Overview
Phase 2 transforms Studio's Preview viewport into a multi-track visual media compositor. Real images and video decoding elements are cached, hardware-decoded, synchronized to the timeline playhead, and drawn into the Canvas2D context with track layer sorting and GSAP affine matrix transforms.

## Problem
Studio's `Preview.tsx` previously cleared the canvas and drew only vector gizmos, particles, and hologram rings. Video tracks defined in `VideoIR` (e.g. V1 plate, V2 3D subject) were not rendered onto the canvas, causing the preview to display an empty black box with no real visual content.

## Solution Architecture
1. **AssetTextureCache Decoder Pool (`apps/studio/src/lib/textures/AssetTextureCache.ts`)**:
   - Implemented `getVisualAsset(assetId, src, assetType, timeSec)` returning a `VisualAssetResult`.
   - Real images are fetched asynchronously with `Image` and CORS anonymous headers.
   - Video elements (`<video>`) are instantiated offscreen as hardware decoding sources with muted audio, inline playback, and throttled playhead seeking.
   - Implemented `renderMissingAssetPlaceholder(...)` rendering neutral dark video charcoal (`#151518`) cards with dashed boundary guides and type badges adhering strictly to Rule 235 isolation.
2. **Preview.tsx Multi-Track Canvas Compositing (`apps/studio/src/components/Preview.tsx`)**:
   - Queries active visual sequences at the current frame from `irState.intervalTree`.
   - Sorts sequences by track order: `V1 -> V2 -> V3 -> V4`.
   - Maps track `blendMode` to `ctx.globalCompositeOperation`.
   - Evaluates dynamic GSAP-interpolated transform matrix (`ctx.translate`, `ctx.rotate`, `ctx.scale`, `ctx.globalAlpha`).
   - Paints media directly to canvas with `ctx.drawImage()`.
3. **Quality Gates & Verification**:
   - Test suite: `autogenerated-tests/studio_phase2_media_compositor.test.ts`.
   - Full studio regression: 123 tests passing.
   - Production Vite build: passes cleanly in 3.79s (<1MB bundle).
   - Paired documentation: `apps/studio/doc/implementation_plan_12.md` and `apps/studio/doc/walkthrough_12.md`.
