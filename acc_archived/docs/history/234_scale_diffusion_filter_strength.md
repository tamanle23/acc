# 234. Scale Diffusion Filter Strength for Significant Perceptual Change

## Context & Problem
In `apps/studio/src/components/SettingsModal.tsx` and `apps/studio/src/index.css`, the "Diffusion Filter Strength" options were calibrated with closely spaced values:
- Low: `8px`
- Medium: `16px`
- High: `24px`

Because the range was narrow (8px - 24px), users could barely perceive visual differences between the blur levels across complex studio panels and layered liquid glass components.

## Implementation Details
1. **Recalibrated Blur Intensities in `apps/studio/src/index.css`**:
   - `[data-blur-intensity="low"]`: Reduced to `blur(6px)` for a crisp, transparent glass aesthetic where background elements remain distinctly readable.
   - `[data-blur-intensity="medium"]`: Tuned to `blur(18px)` as the balanced silky frosted acrylic default.
   - `[data-blur-intensity="high"]`: Expanded to `blur(40px)` for an unmistakable, deep velvet frosted glass diffusion that dissolves background details into smooth light fields.

2. **Updated Badges in `apps/studio/src/components/SettingsModal.tsx`**:
   - Updated `BLUR_INTENSITIES` pixel indicators to reflect the new dynamic values (`6px`, `18px`, `40px`).
