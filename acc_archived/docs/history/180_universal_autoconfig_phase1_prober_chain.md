# [180] Universal Auto-Config Phase 1: Headless Prober Chain & Asset Manifest

## 1. Overview & Context
Historically, `auto-config.ts` was an interactive CLI utility for Pipeline 4 that crawled local directories using basic filesystem heuristics and prompted the user for parameters to construct `story-config.json`. This tightly coupled scanning logic with terminal prompts (`@clack/prompts`), preventing headless worker tasks, autonomous Conductor agents, or multi-modal pipelines (Pipelines 1–6) from inspecting content programmatically.

In **Phase 1 of Universal Auto-Config Integration**, we decoupled media discovery into a headless, enterprise **Chain of Responsibility** prober engine inside `@acc/core` (`MediaAssetProberChain`). The prober inspects directories, extracts technical attributes, categorizes audio/visual assets, and synthesizes a structured `DiscoveredAssetManifest`.

---

## 2. Architecture & Design

### Chain of Responsibility Pattern
Each media type is inspected by an independent, single-responsibility handler extending `BaseMediaAssetProberHandler`:
```
MediaAssetProberChain
  ├── ImageProberHandler (jpg, png, webp, bmp, gif - dimensions & aspect ratio)
  ├── VideoProberHandler (mp4, mov, webm, mkv - duration, fps, resolution)
  ├── AudioProberHandler (mp3, wav, ogg, flac - channels, classification into music/voiceover/sfx/ambient)
  ├── ScriptProberHandler (txt, md, srt, vtt - lines, word counts, speech duration estimate)
  └── DataProberHandler (csv, json - row counts, headers, sample data)
```

### Manifest Synthesis
The resulting `DiscoveredAssetManifest` aggregates:
- **Visuals Array**: Formats, dimensions, native aspect ratio classification (`9:16`, `16:9`, `1:1`, `4:5`).
- **Audio Array**: Classifications (`music`, `voiceover`, `sfx`, `ambient`) using semantic file token heuristics.
- **Scripts Array**: Text lines and estimated speech duration (`wordCount * 400ms`).
- **Structured Data Array**: CSV/JSON datasets with column headers.
- **Intelligent Visual-Audio Pairings**: Resolves numeric sequence associations (e.g. `1.png` with `audio_1.mp3`).
- **Global Indicators**: `hasVoiceover`, `hasBackgroundMusic`, and `dominantVisualAspect`.

## 3. Key Implementation Details

1. **`packages/core/src/autoconfig/types.ts`**:
   - Strongly typed `DiscoveredAssetManifest`, asset models, and `IMediaAssetProberHandler`.
2. **`packages/core/src/autoconfig/probers/`**:
   - `BaseMediaAssetProberHandler`: Abstract handler with `setNext` and path normalization.
   - `ImageProberHandler`: Canvas-backed dimension and ratio resolution.
   - `VideoProberHandler`: Video container and metadata resolution.
   - `AudioProberHandler`: Voice vs BGM classification.
   - `ScriptProberHandler`: Script parsing and speech duration estimation.
   - `DataProberHandler`: Dataset row/column inspection.
3. **`packages/core/src/autoconfig/MediaAssetProberChain.ts`**:
   - Factory method `buildDefaultChain()`.
   - Recursive directory crawl with ignore filters (`node_modules`, `.git`, `dist`, etc.).
   - Natural numeric sorting for chronological file alignment.
4. **Exported via `@acc/core`**:
   - Accessible to CLI, workers, and pipelines via `import { MediaAssetProberChain } from '@acc/core'`.
