## 1. Context & Problem Statement
In previous iterations, while the card frame matched the source image aspect ratio, the backdrop canvas behind the card still used `drawImageCover` across the full output video resolution, causing the background image to be cropped/stretched to match the output canvas aspect ratio.

The user requested that the **Backdrop plate behind the card also strictly preserves 100% of the original source asset aspect ratio** (`img.width / img.height`), centered on screen with clean cinematic pillarbox/letterbox studio margins.

---

## 2. Solution & Architectural Implementation

### Exact Aspect-Ratio Contained Backdrop Plate
1. **Letterbox / Pillarbox Backdrop Computation**:
   ```typescript
   const imgRatio = img.width / img.height;
   const canvasRatio = width / height;

   let bgW = width;
   let bgH = height;
   let bgX = 0;
   let bgY = 0;

   if (imgRatio > canvasRatio) {
     bgW = width;
     bgH = width / imgRatio;
     bgY = (height - bgH) / 2;
   } else {
     bgH = height;
     bgW = height * imgRatio;
     bgX = (width - bgW) / 2;
   }
   ```
2. **Backdrop Canvas Plate Rendering**:
   - Base canvas filled with deep studio dark background (`#06060c`).
   - Uncropped source image plate drawn at `(bgX, bgY, bgW, bgH)` with 100% original aspect ratio.
   - Applied soft dark ambient scrim (`rgba(10, 10, 18, 0.65)`).
3. **Harmonized Card Sizing**:
   - Card frame bounds dynamically computed as `maxInnerW = bgW * 0.76` and `maxInnerH = bgH * 0.76`.
   - The card sits harmoniously inside the backdrop plate, retaining the exact same aspect ratio, while the character's head pops out above the card's top border.
