# 235. Isolate Studio Canvas Viewport & Subtitles from Outside Theme Styling

## Context & Problem
In `apps/studio/src/components/Preview.tsx`:
1. The `<canvas id="studio-canvas">` element had no strict CSS style isolation (`isolation: isolate`) or explicit black background color. In Light Frosted Acrylic mode, the parent container's ambient mesh (`liquid-ambient-mesh`) could bleed through transparent canvas regions or letterboxing.
2. Time-cued text, captions, and subtitles (`activeCues`) were rendered outside the canvas frame and mistakenly styled with Studio liquid glass UI tokens (`glass-panel`, `border-[var(--glass-border-highlight)]`, `text-foreground`).
   - In Light mode, `text-foreground` flipped to dark slate (`#090d16`), making subtitles dark and unreadable over dark video scenes.
   - The subtitles inherited frosted translucent bubble styling instead of authentic video subtitle typography.
3. The floating quick transport bar was nested inside the canvas div, partially obscuring the lower canvas video frame.

## Implementation Details
1. **Isolated Video Viewport Stage**:
   - Wrapped `<canvas id="studio-canvas">` and its in-canvas video overlays in a dedicated viewport stage container with `isolate` (`isolation: isolate`), `bg-black`, `rounded-xl`, `overflow-hidden`, and explicit `aspectRatio: '16/9'`.
   - Set `<canvas id="studio-canvas">` to `backgroundColor: '#000000'` with `w-full h-full object-contain block bg-black`.
   - Updated the 2D canvas context clear pass from `#020617` to `#000000`.

2. **In-Canvas Video Subtitles & Captions Styling**:
   - Moved `activeCues` inside the isolated 16:9 canvas stage at `bottom-6 left-6 right-6`.
   - Replaced all Studio UI styling (`glass-panel`, `text-foreground`) with authentic, high-contrast video subtitle styling:
     - Standard captions: `bg-black/80 border border-white/15 text-white text-base shadow-2xl drop-shadow-[0_2px_4px_rgba(0,0,0,0.95)]` with multi-layered text shadow for 100% legibility on any scene.
     - Technical / target cues: `border border-rose-500/80 bg-rose-950/85 text-rose-200 font-mono text-xs shadow-[0_0_15px_rgba(244,63,94,0.4)]`.
   - Completely immunizes video subtitles from the outer Studio UI theme (Dark Obsidian vs Light Frosted Acrylic).

3. **Separated Floating Quick Transport Bar**:
   - Positioned the quick transport bar directly below the canvas stage (`mt-3`) as an external Studio UI control (`glass-panel`), preventing any occlusion of bottom-third video frames or subtitles.

4. **Automated Verification**:
   - Extended `autogenerated-tests/studio_liquid_glass_theme.test.ts` to assert that `studio-canvas` has `isolate rounded-xl overflow-hidden` and `backgroundColor: '#000000'`, that subtitles use `bg-black/80 text-white`, and that `glass-panel` is never applied to subtitles.
   - Verified that all 68 tests across 15 suites pass cleanly (`bun test studio`).
   - Verified clean production build (`bun run studio:build`).
