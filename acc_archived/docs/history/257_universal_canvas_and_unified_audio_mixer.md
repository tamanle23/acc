# 257 - Isomorphic Canvas Provider & Unified Universal Audio Mixer

## Metadata
- **Task ID**: 257
- **Date**: 2026-10-18
- **Scope**: `packages/ir`, `packages/effect-engines`, `packages/core`, `apps/studio`
- **Status**: Completed

## Context & Objectives
1. Eliminate direct static `@napi-rs/canvas` and `fs` dependencies from visual modifier plugins (`Depth3DPlugin`, `Camera3DPlugin`, `CanvasParticleOverlayPlugin`) and `IRMasterRenderer` in favor of `UniversalCanvasProvider.createCanvas()` and `CanvasAssetLoader.loadImage()`.
2. Unify `DecoupledAudioMixer` into `UniversalAudioMixer` in `packages/ir/src/renderer/audio/UniversalAudioMixer.ts`, turning `DecoupledAudioMixer` into a backward-compatible delegation facade.
3. Eliminate any transitive Node/FFI native leakage (`@acc/core`, `child_process`, `fs`) into the `apps/studio` browser client bundle, ensuring `bun run studio:build` compiles cleanly.

## Key Changes
- **Universal Audio Mixer Master Bus**:
  - Added `mixTimeline(timeline, options)` to `UniversalAudioMixer` supporting offline timeline-level mixing, clip offset calculation, dynamic sidechain ducking, and peak normalization.
  - Implemented `UniversalAudioMixer.exportToWav(filePath, mixResult)` to encode 16-bit stereo PCM WAV files.
  - Refactored `DecoupledAudioMixer` into a facade delegating `mix()` and `exportToWav()` directly to `UniversalAudioMixer`.
- **Isomorphic Canvas Provider**:
  - Replaced `@napi-rs/canvas` instantiation in `Depth3DPlugin`, `Camera3DPlugin`, and `CanvasParticleOverlayPlugin` with `UniversalCanvasProvider.createCanvas()`.
  - Replaced `@napi-rs/canvas` and direct `fs.readFileSync` in `IRMasterRenderer` with `UniversalCanvasProvider.createCanvas()` and `CanvasAssetLoader.loadImage()`.
- **Browser-Safe Exports & Bundling**:
  - Fixed bridge `packages/effect-engines/src/audio/ProceduralAudioSynthesizer.ts` to export from `@acc/ir/client` instead of root `@acc/ir` to prevent Rollup from pulling in server entrypoints.
  - In `packages/core/src/media-engine/sinks/MediabunnyClientSink.ts`, removed static `fs` and `path` imports, guarding disk persistence under runtime Node environment checks with dynamic imports.
  - Configured `@napi-rs/canvas` as external in `apps/studio/vite.config.ts`.
