# History Record: 188 - Fix Pipeline 2 Unplayable Output (Audio & Video Exporter)

**ID**: 188  
**Date**: 2026-10-14  
**Type**: `fix(exporters)`  
**Scope**: `@acc/exporters`, `@acc/core`

## Context & Problem
When running Pipeline 2 via:
```bash
bun run cli.ts run db -c ./samples/02-db-templating/database_payload.json -o ./output/p2
```
The output media files could not be played in standard media players:
1. **Audio (`.mp3`)**: When chunks contained no spoken narration, `AudioExporter` checked `sample-story/bgm.mp3` (which was relocated to `sample-story/assets/bgm.mp3`), and fell back to dumping `Buffer.alloc(4096, 0)`. The 4096 zero bytes lacked valid MPEG audio sync frames, rendering the MP3 corrupted and rejected by all decoders (`[mp3] Failed to find two consecutive MPEG audio frames`).
2. **Video (`.mp4`)**: In `FFIVideoEncoder.ts`, video packet timestamps (PTS/DTS) were manually written linearly via `streamPts = videoPacketIndex * ticksPerFrame`, and draining remaining frames during `close()` produced non-monotonic DTS warnings (`Application provided invalid, non monotonically increasing dts to muxer in stream 0: 119 >= 118`).
3. **Director Config Propagation**: `VideoExporter.ts` did not forward `directorConfig` or `videoConfig` to `PipelineIRToUniversalIRAdapter.adapt()`, ignoring background audio and styling specifications.

## Solutions & Implementation
1. **`packages/core/src/ffmpeg-ffi/index.ts`**:
   - Added `av_packet_rescale_ts` FFI symbol binding to `avcodec`.
2. **`packages/core/src/ffmpeg-ffi/FFIVideoEncoder.ts`**:
   - Added `tbCodec` and `tbStream` timebase handles.
   - Initialized `this.tbCodec = makeAVRational(1, this.fps)` and `this.tbStream = makeAVRational(1, 90000)`.
   - Replaced manual packet timestamp override with native `FFI.avcodec.av_packet_rescale_ts(this.packet, this.tbCodec, this.tbStream)` in `encodeRgbaFrame()`, `encodeRawFrame()`, and `close()`.
3. **`packages/exporters/src/audio/AudioExporter.ts`**:
   - Added smart resolution of fallback background audio:
     - `ir.audioComposition?.backgroundMusic?.audioPath`
     - `sample-story/assets/bgm.mp3`
     - `samples/02-db-templating/assets/bgm_synth.mp3`
   - If no candidate audio file exists, uses `FFIAudioDSP.createSilentMp3Buffer()` to produce valid, standard-compliant silent MP3 sync frames.
4. **`packages/exporters/src/video/VideoExporter.ts`**:
   - Forwarded `directorConfig` and `videoConfig` from options into `PipelineIRToUniversalIRAdapter.adapt(ir, undefined, outDir, directorConfig)`.
