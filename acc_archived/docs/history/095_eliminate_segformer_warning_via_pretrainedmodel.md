# History Log 095: Eliminate Segformer Architecture Warning via PreTrainedModel

- **Task**: Eliminate the console warning `Unknown model class "SegformerForSemanticSegmentation", attempting to construct from base class` when loading `briaai/RMBG-1.4` and `BiRefNet-general` in `@huggingface/transformers`.
- **Date**: 2026-10-01
- **Status**: Completed

---

## 1. Context & Root Cause
When loading `briaai/RMBG-1.4` through `AutoModel.from_pretrained()`, the Hugging Face configuration specifies `"architectures": ["SegformerForSemanticSegmentation"]`. Because Transformers.js does not register this specific semantic segmentation class in its default auto-model lookup table, it printed an informative warning to stderr before falling back to `PreTrainedModel`.

## 2. Solution
In `RmbgStrategy.ts` and `BiRefNetStrategy.ts`, we directly instantiated models using `PreTrainedModel.from_pretrained()`:
```typescript
import { PreTrainedModel, AutoProcessor } from '@huggingface/transformers';

const [model, processor] = await Promise.all([
  PreTrainedModel.from_pretrained(this.modelId),
  AutoProcessor.from_pretrained(this.modelId)
]);
```
This directly loads the ONNX execution session without emitting unnecessary architecture fallback warnings.
