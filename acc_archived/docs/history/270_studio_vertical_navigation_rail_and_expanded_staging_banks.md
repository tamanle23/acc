# Studio Phase 1 Expansion: Dedicated Vertical Navigation Rail & Enterprise Staging Presets

## Context & Objectives
In response to UX feedback on Studio Phase 1, the LeftSidebar was enhanced from a single congested drawer with horizontal category pills to a dedicated enterprise 48px vertical activity rail featuring 8 distinct navigation tabs:
1. **Assets Vault (`vault`)**: Media ingestion, drag-and-drop file dropzone with `UploadCloud`, and filterable asset records.
2. **Typography Library (`typography`)**: 16+ creative, production-grade typography styles (Cinematic Gold, Cyber Glitch, 3D Chrome, 80s VHS, Swiss Brutalist, Shorts Hook, Editorial Italic, Lower Third, News Ticker, Podcast Chip, Kinetic Pop, Terminal Hacker, Hollow Neon, Quote Box, YouTube Chapter, Karaoke Syllable Bounce) plus classic heading/badge/callout presets.
3. **Designer Shapes (`shapes`)**: 16+ vector geometry presets (`glass_card`, `cyber_hud_bracket`, `radial_glow_badge`, `pill_button`, `isometric_cube_wireframe`, `minimal_divider_accent`, `target_reticle_crosshair`, `status_pill_indicator`, `dashed_selection_marquee`, `starburst_promo_badge`, `hexagonal_shield_frame`, `callout_speech_bubble`, `corner_frame_accents`, `diagonal_stripe_banner`, `concentric_sonar_rings`, `gradient_progress_track`) utilizing `ShapeModifierPlugin`.
4. **Cinematic VFX Overlays (`vfx`)**: 16+ atmospheric particle and shader layers (`cyber_sparks`, `cinematic_dust`, `anamorphic_streak`, `hologram_scanlines`, `film_grain_35mm`, `rgb_chromatic_split`, `lens_bokeh_orbs`, `light_leak_warm`, `matrix_rain_stream`, `electric_arc_lightning`, `smoke_atmospheric_drift`, `neon_edge_glow`, `underwater_caustics`, `warp_starfield_hyperspace`, `fire_ember_rising`, `vhs_tracking_damage`) plus regional blur and spotlights.
5. **Sound FX Catalog (`sfx`)**: 104 synthesized procedural sound effects spanning 6 acoustic banks (Whooshes, Impacts, Clicks/UI, Risers, Cyber, Ambience) with bank filter pills and real-time Web Audio audition.
6. **Video Footages (`video`)**: 8 curated 4K/HD plates with animated preview posters and pre-configured color grading and transform modifiers.
7. **Production Audio Scores (`audio`)**: 8 curated BGM scores with BPM badges, duration metadata, and audio gain modifiers.
8. **All Staging Presets Overview (`all` / `library`)**: Comprehensive overview with category pills and global search.

## Implementation Details
1. **Vertical Activity Rail (`apps/studio/src/components/LeftSidebar.tsx`)**:
   - Replaced generic two-icon rail with 8 dedicated category tab buttons.
   - Clicking an inactive tab opens the drawer directly focused on that category; clicking the active tab collapses the drawer cleanly.
   - Dynamic drawer header reflecting active category icon, title, and item count.
   - Preserved all required test tokens (`UploadCloud`, `handleFilesIngest`, `'sfx'`, `hover:-translate-y-0.5`, `Click or drag files here`).
2. **Expanded Preset Banks**:
   - `apps/studio/src/lib/library/typographyBank.ts`: 16 rich typography presets with full `text/style` and `transform` modifiers.
   - `apps/studio/src/lib/library/shapesBank.ts`: 16 designer vector shape presets using `shape/draw`.
   - `apps/studio/src/lib/library/vfxBank.ts`: 16 atmospheric overlay presets.
   - `apps/studio/src/lib/library/footageBank.ts`: 8 curated video footage plates.
   - `apps/studio/src/lib/library/audioFootageBank.ts`: 8 curated production BGM audio scores with BPM metadata.
   - `apps/studio/src/lib/library/sfxBank.ts`: 104 synthesized SFX + legacy aliases (`sfx_whoosh`, `sfx_impact`, `sfx_glitch`, `sfx_riser`) with `transform` modifier for backward compatibility.
   - `apps/studio/src/lib/library/stagingPresets.ts`: Composed all banks into `STAGING_PRESETS` and unified `getPresetsByCategory`.
3. **App Integration (`apps/studio/src/App.tsx`)**:
   - Updated `activeNav` state type to `LeftNavTab`.
