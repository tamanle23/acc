## Context & Objectives
Following the clean removal of Three.js in Phase 1, Phase 2 deepens the core capabilities of `UniversalCanvasEngine` and `CanvasTransformOverlay` in `@acc/effect-engines`:
- Build a declarative GSAP timeline compiler for deterministic frame-accurate scrubbing across sequence keyframes and modifiers.
- Upgrade Pts.js particle systems with dynamic gravitational attractors, velocity damping, and motion trails.
- Implement dual-pass 2.5D parallax relighting with Blinn-Phong specular sheen on standard 2D canvas.
- Enhance `CanvasTransformOverlay` with live floating angle and dimension badges during user drag interactions.
- Provide high-performance multi-pass partial VFX compositing (spotlights, glitches, blurs, spark emitters).

## Work Accomplished
1. **`UniversalCanvasEngine.ts`**:
