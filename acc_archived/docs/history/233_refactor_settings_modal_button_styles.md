# 233. Refactor Settings Modal Button Styles to Semantic Liquid Glass Classes

## Context & Problem
In `apps/studio/src/components/SettingsModal.tsx`, option buttons (Appearance, Optical Glass Style, Blur Intensity, Accent Color) and dialog action buttons still contained long, repetitive inline style strings with hardcoded arbitrary Tailwind classes such as `bg-[var(--accent-primary)]/15`, `border-[var(--accent-primary)]`, `ring-[var(--accent-primary)]/50`, and `bg-[var(--accent-primary)] hover:brightness-110 text-slate-950 font-semibold ...`.

This resulted in:
1. Significant code duplication across four setting option groups.
2. Fragile CSS variable opacity hacks in Tailwind (`/15`, `/50`) that rely on color-mix polyfills rather than first-class design system classes.
3. Lack of reusable button variants for accent actions and glass pills in the Studio UI component library (`apps/studio/src/components/ui/button.tsx`).

## Implementation Details
1. **Liquid Glass Utility Classes in `apps/studio/src/index.css`**:
   - Added `.glass-button-primary`: primary accent action button with `--accent-primary` background, `#0b1121` high-contrast text, smooth hover glow (`--accent-glow`), and active scale transition.
   - Added `.glass-pill`: standardized selectable pill with `--glass-border`, `--glass-bg`, and hover highlight.
   - Added `.glass-pill[data-active="true"]` & `.glass-pill.active`: active state with `--accent-primary` border, subtle accent background, glow sheen, and bold foreground text.
   - Added `.glass-badge-accent`: standardized accent badge container with dynamic border and background.

2. **Button Component Variants in `apps/studio/src/components/ui/button.tsx`**:
   - Added `variant="accent"` backed by `.glass-button-primary`.
   - Added `variant="glass"` backed by `.glass-button`.
   - Updated `outline`, `secondary`, and `ghost` variants to use semantic design tokens (`border-[var(--glass-border)]`, `bg-secondary`, `hover:bg-foreground/5`).

3. **Refactored `apps/studio/src/components/SettingsModal.tsx`**:
   - Replaced all inline button styling hacks with `.glass-pill` and `data-active={...}`.
   - Replaced the hardcoded Done button classes with `<Button variant="accent" size="sm" ...>Done</Button>`.
   - Replaced icon container and badge styling with `.glass-badge-accent`.
   - Completely eradicated all instances of `bg-[var(--accent-primary)]` and inline ring/border hacks.

4. **Automated Verification**:
   - Updated `autogenerated-tests/studio_liquid_glass_theme.test.ts` to assert that `index.css` contains `.glass-button-primary`, `.glass-pill`, and `.glass-badge-accent`, that `button.tsx` provides `accent` and `glass` variants, and that `SettingsModal.tsx` contains zero hardcoded `bg-[var(--accent-primary)]` or `ring-[var(--accent-primary)]`.
   - Verified that all 68 tests across 15 test suites in `bun test studio` pass cleanly.
   - Verified that `bun run studio:build` compiles cleanly without warnings.
