# [161] Fix Canonical IR Effect Rendering: 3D Depth, Color Grading & Procedural Overlays

- **Status:** `[x] Completed`
- **Date:** 2026-10-10
- **Scope:** `packages/ir/src/plugins/vfx/`, `packages/ir/src/renderer/`, `packages/ir/src/adapters/`

---

## 1. Context & Problem Statement
During verification of `ir-render` / Canonical IR pipeline output videos, visual effects (such as 3D depth pop-out, LUT color grading, and procedural particle overlays) were missing or not visible in the rendered video.

Investigation revealed three distinct bottlenecks:
1. **Draw Order & Overwrite**: In `IRMasterRenderer.renderCanvasFrame`, sequence modifiers (`seq.modifiers`) were invoked first, after which the default base asset (`ctx.drawImage`) was unconditionally drawn on top of the canvas, overwriting any 3D depth borders, pop-outs, or card frames.
2. **Missing `vfx/color_grading` Modifier Plugin**: `StoryConfigToUniversalIRAdapter` created `vfx/color_grading` modifiers, but no matching plugin was registered in `ModifierPluginRegistry`, causing color grading to be ignored.
3. **Missing 3D Engine Delegation in `Depth3DPlugin`**: `Depth3DPlugin` previously only stroked a placeholder rectangle instead of delegating to `Depth3DFactory` / `drawFrameBreakerFrame` from `@acc/effect-engines`.
4. **Missing Overlay Composite Mapping**: `settings.overlayComposite` in `story-config.json` was not translated into track-level `overlay/canvas_particles` modifiers.

---

## 2. Changes Made
1. **`packages/ir/src/plugins/vfx/ColorGradingPlugin.ts`**:
   - Created concrete `ColorGradingPlugin` implementing `vfx/color_grading`.
   - Connected `ColorGradingEngine.applyCanvasTransform` across Phase 2 (clip space) and Phase 4 (master composite).
2. **`packages/ir/src/plugins/index.ts`**:
   - Exported and registered `ColorGradingPlugin` into `registerCoreModifierPlugins()`.
3. **`packages/ir/src/plugins/vfx/Depth3DPlugin.ts`**:
   - Integrated `Depth3DFactory.getRenderer(mode)` and `drawFrameBreakerFrame` from `@acc/effect-engines`.
   - Renders animated card floating, pop-out subject scaling, and drop shadows in clip space.
4. **`packages/ir/src/renderer/IRMasterRenderer.ts`**:
   - Guarded base asset `ctx.drawImage`: if a sequence has a `vfx/depth3d` modifier that handles the visual composition, the default plain image draw is bypassed, preventing overwrite of the 3D depth frame.
5. **`packages/ir/src/adapters/StoryConfigToUniversalIRAdapter.ts`**:
   - Translated `settings.overlayComposite` into track-level `overlay/canvas_particles` modifiers on `track_v1_main` (`rain`, `snow`, `dust`, `embers`, `light_leak`, `vhs`).
