# 214. Master Integration Plan (Iteration 5) Phase 2: Cinematic 3D Camera Path Sequencer & Dynamic Rack Focus

## Overview & Scope
- **Task**: Implement Phase 2 of Master Integration Plan Iteration 5: Cinematic 3D Camera Path Sequencer & Dynamic Rack Focus.
- **Components Modified / Created**:
  - `@acc/effect-engines` (`packages/effect-engines/src/vision/CameraSplineInterpolator.ts`, `packages/effect-engines/src/vision/index.ts`)
  - `@acc/ir` (`packages/ir/src/plugins/vfx/Camera3DPlugin.ts`, `packages/ir/src/plugins/index.ts`)
  - `autogenerated-tests` (`autogenerated-tests/camera_spline_rack_focus.test.ts`)
- **Key Architectural Mandates Preserved**:
  - **ZERO-ALLOC-FRAME-LOOP**: Trajectory arrays and pre-blurred focal zones are pre-computed during sequence preflight (`execute()`). Per-frame evaluation uses scratch object reuse with zero nursery heap allocations.
  - **MEDIA-ENGINE-STRATEGY-ISOLATION**: Zero direct calls or imports to `bun:ffi`, `fluent-ffmpeg`, or `mediabunny`. All visual calculations use pure TypeScript and universal `CanvasRenderingContext2D` operations.
  - **DETERMINISTIC-HANDSHAKE-BACKPRESSURE**: Camera transforms are pure functions of normalized frame progress $t \in [0, 1]$.

## Changes Implemented

### 1. CameraSplineInterpolator (`@acc/effect-engines/src/vision/CameraSplineInterpolator.ts`)
- Implemented `catmullRom` and `cubicBezier` mathematical spline evaluators.
- Implemented `precomputeTrajectory`:
  - Evaluates position $\mathbf{P}(t)$, look-at target $\mathbf{T}(t)$, roll angle $\theta(t)$, $\text{FOV}(t)$, focal depth plane $Z_{\text{focal}}(t)$, and aperture into a contiguous `Float32Array` buffer.
- Implemented `readFrameState`:
  - Unpacks camera position and computes 2D/2.5D affine projection parameters (scale, translation, roll rotation) into pre-allocated scratch structures without heap churn.

### 2. Camera3DPlugin (`@acc/ir/src/plugins/vfx/Camera3DPlugin.ts`)
- Implemented `ModifierPlugin<Camera3DPluginParams>` with `type: 'vfx/camera_3d'`, `targetScope: 'sequence'`, `targetPhase: 2`.
- Preflight (`execute()`):
  - Precomputes camera trajectory matrices.
  - Pre-renders multi-tier focal zone canvases (sharp, near-blur, far-blur) using fast bilinear downsampling/upsampling.
- Runtime (`renderClipSpace()`):
  - Translates, scales, and rotates `canvasCtx` using the interpolated camera matrix.
  - Applies dynamic alpha crossfades between focal zones based on distance $|Z(t) - Z_{\text{focal}}(t)|$ and aperture.

### 3. Plugin Registration (`@acc/ir/src/plugins/index.ts`)
- Registered `Camera3DPlugin` in both singleton (`registerCoreModifierPlugins`) and isolated worker (`createIsolatedCoreModifierPlugins`) registries.

### 4. Automated Test Suite (`autogenerated-tests/camera_spline_rack_focus.test.ts`)
- Verified Catmull-Rom spline trajectory smoothness and perspective scaling.
- Verified modifier plugin registry wiring.
- Verified preflight and 30-frame zero-alloc loop execution.
