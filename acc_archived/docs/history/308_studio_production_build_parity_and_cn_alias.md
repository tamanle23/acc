# 308 — Studio Production Build Parity: Vite `cn` Alias & Radix-UI Resolution

- **Date:** 2026-10-22
- **Component:** `@acc/studio` (`apps/studio/vite.config.ts`, `autogenerated-tests/studio_build_and_module_resolution.test.ts`)
- **Status:** Completed

## Context & Problem
`bun run --cwd apps/studio build` failed at Rollup resolution time with two cascading errors:
1. `Rollup failed to resolve import "cn"` — 58+ shadcn/ui primitives in `apps/studio/src/components/ui/*.tsx` import `cn` as a bare specifier (`from "cn"`) but no package or alias existed.
2. `Rollup failed to resolve import "radix-ui"` — `radix-ui` v1.8.1 was declared in `package.json` but was not installed.

## Solution
1. Added `'cn': path.resolve(__dirname, 'src/lib/utils')` alias in `apps/studio/vite.config.ts`.
2. Ran `pnpm install radix-ui --filter @acc/studio` to install the package.

## Verification
- `bun run --cwd apps/studio build` → exits 0, `✓ built in 9.77s`, 1,657 kB bundle.
