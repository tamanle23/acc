# [297] Studio RightSidebar & Inspector Iteration 21 Improvements

- **Status**: Completed
- **Date**: 2026-10-21
- **Scope**: `apps/studio` (Inspector UX, Lock State, Cue Timeline Dialog, Relational Timing Controls)
- **Author**: Antigravity (Pair Programming)

---

## 1. Context & Objectives

Following the architectural decomposition of `RightSidebar.tsx` into modular sub-inspectors (Iteration 20 & 20ext), several UX and functional gaps remained in the inspector subsystem:
1. Subtitle cues could be added but were completely invisible in `SequenceInspector.tsx`.
2. Sequence lock was a dummy state that did not disable inputs or modifier parameters.
3. Relational timing controls lacked fields for `offsetFrames`, `overlapFrames`, and `paddingFrames`, and broke when fewer than 2 sequences existed.
4. Newly attached effects remained collapsed in the accordion.
5. The empty modifier card lacked a direct "+ Add First Effect" CTA.

---

## 2. Key Changes & Implementations

1. **Subtitle Cue Timeline Dialog (`CueTimelineDialog.tsx`)**:
   - Implemented dialog modal for editing timed text cues with millisecond accuracy.
   - Wired to `IRStateManager.getInstance().updateSequenceProps(sequenceId, { cues })`.
2. **True Full Lock State (`isLocked`) Enforcement**:
   - Disabled timing inputs, timecode indicators, action buttons, cue management, and "Add Effect".
   - Propagated `disabled={isLocked}` down through `DynamicModifierInspector` and all 11 `ModifierControlStrategies`.
3. **Relational Timing Complete Parameters & Auto-Clamp Fallback**:
   - Added numerical inputs for `offsetFrames`, `overlapFrames`, and `paddingFrames`.
   - Disabled relational mode when `otherSequenceIds.length === 0` to prevent invalid IR states.
4. **Auto-Expansion of Newly Added Modifiers**:
   - Automatically updated `openSections` state in `RightSidebar.tsx` when adding an effect.
5. **Rule 229 & Line Ceiling Preservation**:
   - Kept `RightSidebar.tsx` at 252 lines (< 350 limit).
   - Preserved `actions` prop separation on all `AccordionTrigger` components.
