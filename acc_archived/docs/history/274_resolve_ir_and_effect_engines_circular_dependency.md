# History Record [274]: Resolve Circular Dependency Between IR and Effect Engines

**Date:** 2026-10-19  
**Task:** Monorepo Architecture: Eliminate Circular Reference Between `@acc/ir` and `@acc/effect-engines`  
**Status:** Completed  

---

## 1. Context & Problem Statement
- `@acc/ir` directly imported concrete visual effect kernels, procedural simulators, color grading engines, and isomorphic canvas providers from `@acc/effect-engines`.
- Simultaneously, `@acc/effect-engines` declared `"@acc/ir": "workspace:*"` in its `package.json` due to:
  1. Backward-compatibility re-export bridges left in `packages/effect-engines/src/audio/` (`ProceduralAudioSynthesizer.ts`, `UniversalAudioMixer.ts`).
  2. Type-only imports in `packages/effect-engines/src/editing/` (`ExtendedContentChunk`, `Keyframe`).
- This created an architectural cycle: `@acc/ir` $\leftrightarrow$ `@acc/effect-engines`.
- Consequently, `@acc/ir/package.json` was forced to omit `@acc/effect-engines` to avoid Turborepo cyclic dependency errors, creating an undeclared ghost dependency that violated workspace isolation.

---

## 2. Implemented Architecture (Option 1: Unidirectional Downward)

We established a clean, linear, acyclic Turborepo dependency hierarchy:
`@acc/core` $\longrightarrow$ `@acc/effect-engines` $\longrightarrow$ `@acc/ir` $\longrightarrow$ `apps/*`

### Changes Made:
1. **Decoupled `@acc/effect-engines` from `@acc/ir`**:
   - In `apps/studio/src/components/RightSidebar.tsx`, updated the `ProceduralAudioSynthesizer` import to resolve directly from `@acc/ir/client`.
   - In `autogenerated-tests/studio_three_audio_wiring.test.ts`, updated `UniversalAudioMixer` import to resolve directly from `@acc/ir/client`.
   - Removed the obsolete re-export bridge files `packages/effect-engines/src/audio/ProceduralAudioSynthesizer.ts` and `UniversalAudioMixer.ts`.
   - Cleaned re-exports in `packages/effect-engines/src/index.ts` and `client.ts`.
   - Added canonical self-contained `Keyframe<T>` and `ExtendedContentChunk` type definitions in `packages/effect-engines/src/types.ts`.
   - Updated `ICutStrategy.ts`, `SmashCutStrategy.ts`, and `SpeedRampStrategy.ts` to import types from local `../types`.
   - Removed `"@acc/ir": "workspace:*"` from `packages/effect-engines/package.json`.

2. **Formalized `@acc/ir`'s Dependency**:
   - Added explicit, transparent `"@acc/core": "workspace:*"` and `"@acc/effect-engines": "workspace:*"` to `packages/ir/package.json`.
