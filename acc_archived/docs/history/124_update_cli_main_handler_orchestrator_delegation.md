# [124] Phase 3 Step 3.2: Update CLI Main Handler for Unified Pipeline Orchestrator Delegation

## 1. Problem Statement
Previously, `apps/cli/src/index.ts` handled the `run` command via redundant, hardcoded `if (pipelineId === ...)` branching blocks for each pipeline, manually instantiating pipeline classes and duplicating input loading / export path extraction logic instead of leveraging the central `defaultPipelineRegistry`.

## 2. Implementation Plan & Changes
1. **Unified Pipeline Input Resolver (`resolvePipelineInput`)**:
   - Created `resolvePipelineInput(pipelineId: string, options: CliOptions)` helper to resolve custom `--config` files or provide appropriate typed default datasets for all 6 pipelines.
2. **Centralized Registry Delegation**:
   - Refactored `case 'run'` in `runCli` to dispatch execution through `defaultPipelineRegistry.execute(pipelineId, input, pipelineOptions)`.
   - Unified export path extraction and return payload handling.
3. **GenerativeStoryPipeline Context Interoperability**:
   - Updated `GenerativeStoryPipeline.execute` to return `GenerativeStoryContext` conforming to `IPipeline` while preserving `toString()` and `.outputPath` properties for seamless backwards compatibility.
