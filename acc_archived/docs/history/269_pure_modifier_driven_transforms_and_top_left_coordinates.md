# History Entry 269: Pure Modifier-Driven Transforms & Universal Top-Left (0,0) Coordinates

## Metadata
- **Date**: 2026-10-18
- **Scope**: `packages/ir`
- **Issue/Goal**: Eliminate hardcoded sequence motion evaluation and viewport-center coordinate shifts from `IRCanvasCompositor`, standardize canvas coordinate space to universal top-left `(0, 0)`, and execute transformations statelessly via `TransformModifierPlugin` using target configuration (`target: 'sequence' | 'track' | 'global'`).

---

## Context & Problem
Previously:
1. `IRCanvasCompositor.ts` hardcoded an explicit call to `evaluateSequenceMotion` and shifted `canvasCtx.translate(width * 0.5, height * 0.5)` on every visual sequence, even when no `transform` modifier was present.
2. This forced the canvas origin `(0,0)` to the center of the viewport, requiring base asset blitting to draw at `-drawW * 0.5, -drawH * 0.5`.
3. Consequently, clip-space plugins (such as `Depth3DPlugin`, `CanvasParticleOverlayPlugin`, `PartialVFXPlugin`, vector shapes, and safe zones) that expected standard top-left `(0, 0)` coordinates were offset into the bottom-right quadrant or required ad-hoc coordinate compensations.

---

## Implementation Details

### 1. `packages/ir/src/types/modifiers.ts`
- Added optional `anchorPoint?: [number, number]` (default `[0.5, 0.5]` for center pivot) and `target?: 'sequence' | 'track' | 'global'` to `TransformModifierParams`.

### 2. `packages/ir/src/plugins/transform/TransformModifierPlugin.ts`
- **Stateless Anchor Pivot**:
  - Pivots rotation and scale around the configured anchor point (`anchorX = width * anchorNormX; anchorY = height * anchorNormY;`).
  - Translates `translate(anchorX + motion.x, anchorY + motion.y) -> rotate -> scale -> translate(-anchorX, -anchorY)`.
  - **Preserves Top-Left `(0, 0)` Alignment**: Because the matrix is translated back by `-anchorX, -anchorY`, the coordinate origin for all subsequent drawing commands inside the sequence remains top-left aligned.
- **Target Filtering**:
  - `renderClipSpace`: Executes for `target === 'sequence'` or unspecified.
  - `renderStreamSpace`: Executes for `target === 'track'`.
  - `renderMasterComposite`: Executes for `target === 'global'` or unspecified at timeline level.

### 3. `packages/ir/src/renderer/shared/IRCanvasCompositor.ts`
- Removed hardcoded `evaluateSequenceMotion` and canvas center translation from the sequence loop.
- All spatial transformations now execute purely through `ModifierPluginRegistry.get(mod.type).renderClipSpace()`.
- Base asset blitting updated to standard top-left centering:
  ```typescript
  const drawX = (width - drawW) * 0.5;
  const drawY = (height - drawH) * 0.5;
  canvasCtx.drawImage(asset, drawX, drawY, drawW, drawH);
  ```
- Neutral fallback placeholders draw from `(0, 0, width, height)`.
