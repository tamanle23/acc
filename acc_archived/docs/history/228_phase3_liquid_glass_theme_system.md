## Context & Objectives
Following the complete migration to `UniversalCanvasEngine` (GSAP + Pts.js) in Phase 1 and the rendering engine enhancements in Phase 2, Phase 3 modernizes the Visual Storytelling Generator Studio UI with a comprehensive **Liquid Glass Design System**:
- Implement frosted glass tokens, specular rim reflections, and multi-layer depth shadows.
- Provide dual-theme support (Dark Obsidian default and Light Frosted Acrylic) with instant DOM synchronization and `localStorage` persistence.
- Allow user customization of optical finish (`specular`, `frosted`, `cyber`), backdrop blur (`low`, `medium`, `high`), and ambient accent colors (`cyan`, `violet`, `emerald`, `amber`, `rose`).
- Upgrade Titlebar, LeftSidebar, RightSidebar, Timeline, and Preview viewport overlays to use `.glass-panel` and `.glass-card`.
- Ensure 100% test pass rate with zero regression across all Studio test suites.
