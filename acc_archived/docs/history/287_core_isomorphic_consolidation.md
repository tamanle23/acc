**Date:** 2026-10-20

**Branch:** `main`

## Context & Problem

After iteration 17 (task 286), `@acc/core-isomorphic` still re-exported from `../../core/src/isomorphic` via a barrel — creating a bidirectional relative import loop:

```
@acc/core  →  @acc/core-isomorphic  →  ../../core/src/isomorphic  →  @acc/core (loop)
```

Additionally, 3 files in `@acc/ir` and all internal `@acc/core` sub-modules (native, web, ffmpeg-ffi, autoconfig) directly imported from relative paths (`../isomorphic/canvas/…`) that pointed into the now-consolidated directory.
