## 1. Overview & Objectives

Phase 1 of **Master Integration Plan (Iteration 3)** establishes the central host control plane (`apps/ai-supervisor`) for the Automated Content Creator ecosystem. It provides:
1. **Dynamic Port Collision Handling (`portScanner.ts`)**: Resolves conflicts on ports `:50051`, `:3300`, `:11434`, and `:3333` without throwing or crashing.
2. **Global Storage Persistent Configuration (`configStore.ts`)**: Stores runtime parameters in `~/.acc/control-plane.json` per the `GLOBAL-STORAGE` rule.
3. **Windows Registry Auto-Start (`windowsStartup.ts`)**: Manages `HKCU:\Software\Microsoft\Windows\CurrentVersion\Run` with `--minimized`.
4. **Circular In-Memory Buffer & Rotating Disk Logger (`LogManager.ts`)**: Maintains 10,000 lines per service in memory with asynchronous rotation at 10MB limits (up to 3 backups).
5. **5-Tier Granular Hardware Classification (`HardwareProfiler.ts`)**:
   - Tier 1: Ultra / Workstation ($\ge$ 24GB VRAM or Mac UMA $\ge$ 36GB) — zero proactive eviction.
   - Tier 2: Pro / Mainstream (12GB–20GB VRAM or Mac UMA 16GB–32GB) — dynamic threshold.
   - Tier 3: Budget (6GB–8GB VRAM or Mac UMA 8GB) — active mutual exclusion.
   - Tier 4: Ultra-Constrained ($<$ 6GB VRAM) — CPU/GPU role splitting (Python pinned to CPU, VRAM dedicated to Ollama).
   - Tier 5: CPU-Only / Integrated Graphics.
6. **Ollama Manager & Health Probing (`OllamaManager.ts`)**: Automatic adoption of existing system Ollama on `:11434`, model listing, active VRAM inspection (`/api/ps`), and `keep_alive: 0` eviction.
7. **Multi-Daemon Hybrid Supervisor Engine (`SupervisorEngine.ts`)**: Supervises `python-backend`, `worker`, `studio`, and `ollama` with exponential backoff crash recovery, workload-aware health probing (`BUSY`), and dynamic system tray colors (`green`, `yellow`, `red`).
8. **Seamless Auto-Update with Crash Rollback (`UpdateManager.ts`)**: Periodic GitHub Releases checks, SHA-256 validation, active job gatekeeper drain, 10s boot watchdog, and automated rollback slot.
9. **Desktop Dashboard UI (`apps/ai-supervisor/src/views/index.html`)**: Real-time telemetry, service cards, live log streaming, VRAM purge, and update controls.

## 2. Key Changes & Implementation Details

- **`apps/ai-supervisor/package.json` & `electrobun.config.ts`**: Initialized `@acc/ai-supervisor` workspace package and Electrobun packaging configuration with `exitOnLastWindowClosed: false`.
- **`apps/ai-supervisor/src/bun/portScanner.ts`**: Pure `node:net` asynchronous scanner detecting port occupancy and resolving next free ports.
- **`apps/ai-supervisor/src/bun/configStore.ts`**: Global configuration loader and patcher managing `path.join(os.homedir(), '.acc', 'control-plane.json')`.
- **`apps/ai-supervisor/src/bun/windowsStartup.ts`**: Registry manager configuring automatic Windows boot with `--minimized`.
- **`apps/ai-supervisor/src/bun/LogManager.ts`**: In-memory ring buffer (10,000 lines max) with automatic 10MB file rotation (`service.log.1`, `service.log.2`, `service.log.3`).
- **`apps/ai-supervisor/src/bun/HardwareProfiler.ts`**: 5-tier VRAM profiler with Apple Silicon UMA mapping and manual profile override.
- **`apps/ai-supervisor/src/bun/OllamaManager.ts`**: REST API integration supporting `/api/tags`, `/api/ps`, `/api/generate` with `keep_alive: 0`, and `/api/pull`.
- **`apps/ai-supervisor/src/bun/UpdateManager.ts`**: Staged updater with SHA-256 validation, backup preservation, and boot crash watchdog auto-rollback.
- **`apps/ai-supervisor/src/bun/SupervisorEngine.ts`**: Master process supervisor managing 4 daemons, exponential crash backoff (1s, 2s, 4s delay), tray status aggregation, and VRAM purge coordination.
- **`apps/ai-supervisor/src/bun/index.ts`**: Control plane daemon entrypoint and embedded REST/Webview server.
- **`apps/ai-supervisor/src/views/index.html`**: Responsive Shadcn-inspired light dashboard UI.
- **`apps/ai-supervisor/src/assets/tray-*.ico`**: Generated green, yellow, and red 16x16 ICO assets for tray status display.
- **`packages/core/src/conductor`**: Restored `TaskWorkerFactory` and `IConductorTaskCommand` to maintain export integrity across the workspace.
