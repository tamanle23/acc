- **Date**: 2026-10-01

---

## 1. Context & Root Cause Analysis
1. **User Observation & Evaluation**:
   - `BiRefNet-general`: Delivered the highest visual quality and sub-pixel edge fidelity, but has high CPU inference latency (~54s).
   - `RMBG-1.4`: Delivered the best overall performance (~2.8s inference, ~44MB footprint, zero background leakage, matching BiRefNet bounding box).
   - `SAM Models (SAM 2.1 Tiny, SAM ViT-Base, SlimSAM)`: Initially showed full-screen bounding boxes during prompt evaluation.
2. **Root Cause of SAM Behavior**:
   - In Transformers.js, `post_process_masks` returns a 3D tensor of shape `[1, 3, height, width]` containing 3 candidate masks concatenated in a single flat typed array.
   - Taking `masks[0].data` directly without `.subarray(bestMaskIdx * width * height, (bestMaskIdx + 1) * width * height)` passed 3 masks concatenated to the compositing engine, distorting the bounding box calculation.
   - Slicing `subarray` for the exact `bestMaskIdx` resolved the issue completely, producing a bounding box (`{"x": 0.369, "y": 0.221, "w": 0.234, "h": 0.561}`) matching RMBG-1.4 and BiRefNet.
