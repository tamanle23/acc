# History Entry 079: Encoding Strategy Pattern Refactor for Video & RTMP Live Streams

## Problem
In log `078`, RTMP real-time streaming constraints (strict 2.0s closed GOP, `flv` container format, `zerolatency` tuning, and `Atomics.wait` clock pacing) were directly wired into `FFIVideoEncoder.ts`. This violated the **Single Responsibility Principle (SRP)** and **Open/Closed Principle (OCP)**, coupling offline high-throughput file video rendering with network socket clock-regulated RTMP live stream pumping in a single class with hardcoded conditionals.

## Plan
1. Extract video encoding behaviors into a clean **Strategy Pattern**:
   - Define canonical interface `IVideoEncodingStrategy`:
     - `mode`: `'file' | 'rtmp_live'`
     - `configureCodec(codecCtx, isNvenc, fps, crf)`
     - `allocateFormatContext(outputPath): bigint`
     - `configureFormatContext(formatCtx)`
     - `paceFrame(frameIndex, fps)`
   - Implement `FileVideoEncodingStrategy`: Offline disk render mode, maximum hardware throughput, no pacing delay.
   - Implement `RtmpLiveStreamEncodingStrategy`: RTMP/RTMPS live stream mode, YouTube-compliant 2.0s closed GOP, FLV container, zerolatency tuning, Atomics microsecond clock pacing.
2. Refactor `FFIVideoEncoder`:
   - Accept optional `strategy?: IVideoEncodingStrategy` in constructor.
   - Auto-detect default strategy by checking if `outputPath` starts with `rtmp://` or `rtmps://`.
   - Provide `getStrategy()` and `setStrategy()` for runtime flexibility and dependency injection.
   - Delegate all codec config, container allocation/configuration, and frame pacing to the active strategy.
3. Write formal unit tests in `autogenerated-tests/encoding_strategy_pattern.test.ts`.
4. Validate zero regressions across all 8 test suites and baseline `sample-story`.
