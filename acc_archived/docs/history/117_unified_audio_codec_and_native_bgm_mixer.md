# History Log 117: Unified Audio Codec Normalization & Native BGM Filtergraph Execution

- **Date:** 2026-10-02
- **Author:** Antigravity Principal Engineer
- **Component:** `@acc/core` (`FFmpegExecutor`, `FFIAudioDSP`, `FFIVideoEncoder`, `FFISceneEngine`) & `sample-story`

---

## 1. Problem Statement & Root Cause Analysis

During multi-scene rendering of `sample-story` (28 scenes):
1. **Video Scene Frame Blackout with Captions**: When enabling caption burning on video / b-roll scenes (`b-roll-nature.mp4`), the video frame initially rendered black because `ImageData` had a one-time array buffer instantiation detached from incoming frame byte writes.
2. **Missing Voiceover Audio on Mixed TTS Scenes**: `FFIConcatMuxer` performs lossless MP3 packet concatenation copying stream parameters from Scene 1 (`mp3`). When Scene 3 contained raw PCM `.wav` generated by TTS (`autogenerated/voiceovers/scene1.7a9ee590.wav`), the resulting concatenated MP4 had corrupt audio stream sync, causing silent voiceovers across downstream scenes.
3. **Silent Background Music (BGM)**: In `FFmpegExecutor.ts`, background music mixing either copied the first video segment without executing `filter_complex` or failed due to referencing non-existent properties (`inp.source` vs `inp.file`, `outputOptionsList` vs `outputOpts`) and un-split CLI option flags (`-map 0:v` passed as single token).

---

## 2. Proposed Architecture & Solution Plan

1. **Per-Frame Canvas Buffer Synchronization**:
   - In `FFISceneEngine.renderVideoScene`, allocate native RGBA `AVFrame` (`AV_PIX_FMT_RGBA`) via `FFI.avutil.av_frame_alloc` and `sws_scale`.
   - Explicitly update `ImageData.data.set(uint8Clamped)` on every decoded frame before `ctx.putImageData` and `drawCanvasCaptions`.

2. **Unified Audio Codec Normalization**:
   - Added `FFIAudioDSP.ensureMp3Audio(audioPath: string)` to inspect input audio formats and automatically convert `.wav` (or non-MP3) into standard cached `.mp3` with consistent sample rates (44.1kHz / 48kHz stereo).
   - Wired `ensureMp3Audio` directly into `FFIVideoEncoder.encodeVideoWithAudio` so every scene segment output shares identical MP3 container and codec definitions.

3. **FFmpeg BGM Filtergraph Execution**:
   - Fixed `FFmpegExecutor.run()` BGM branch to correctly read `inp.file` and `this.outputOpts`.
   - Tokenized all whitespace-separated input/output options (e.g., `-map 0:v`, `-c:a aac`) so `Bun.spawnSync` dispatches clean arguments to the FFmpeg binary.
   - Preserved sidechain compression (`sidechaincompress`), auto-ducking, volume fade (`afade`), and audio mixing (`amix`).
