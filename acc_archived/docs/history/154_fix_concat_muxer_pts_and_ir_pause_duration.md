# 154. Fix Concat Muxer PTS Runaway & Synchronize Video IR Pause Duration

## Context & Problem
1. **9-Hour Concat Duration Bug:** When rendering `sample-story` using the legacy video editing pipeline, the concatenated output video reported a metadata duration of 9 hours 7 minutes 13 seconds (`32832.9s`).
   - In `FFIConcatMuxer.ts`, packet timestamps across segments were accumulating absolute PTS values from previous segments (`streamPtsOffsets[s] += maxPtsInSeg[s] + 1n`) without normalizing each segment's PTS relative to the segment's starting timestamp (`firstPtsInSeg`).
   - In `VideoEditPipelineOrchestrator.ts`, the background music mixing FFmpeg command used `-stream_loop -1` with `amix` but lacked the `-shortest` flag in `outputOptions`, permitting looped audio to artificially inflate the container length if input video duration metadata had any timestamp offset.
2. **Pipeline Duration Mismatch (Legacy ~160s vs Video IR ~92s):**
   - The raw narration audio of `sample-story` spans 91.4 seconds across 28 scenes.
   - The legacy pipeline included `pauseBetweenScenes: 1` (+1s pause after each scene: 27 x 1s = +27s) and dialogue transition clearances (+42s), reaching ~161 seconds.
   - The Video IR pipeline adapter (`StoryConfigToUniversalIRAdapter.ts`) previously did not translate `scene.pauseAfter ?? settings.pauseBetweenScenes` into relational timeline constraints, causing it to collapse pauses down to raw narration length.

## Changes Made
1. **`packages/core/src/ffmpeg-ffi/FFIConcatMuxer.ts`:**
   - Introduced `firstPtsInSeg` array per segment to record the initial PTS/DTS per stream.
   - Normalized incoming packet timestamps: `relPts = rawPts - basePts`, `relDts = rawDts - basePts`.
   - Advanced `streamPtsOffsets[s]` by each segment's actual duration span (`maxPtsInSeg[s]`) rather than compounding raw timestamps.
2. **`apps/cli/src/pipelines/04-generative-story/VideoEditPipelineOrchestrator.ts`:**
   - Added `-shortest` to `outputOptions` in the BGM mixing step so that `-stream_loop -1` never extends container duration beyond the video stream.
3. **`packages/ir/src/compiler/RelationalDAGCompiler.ts`:**
   - Added support for `offsetFrames` on relational `after` constraints (`time.start: { after: prev_vo, offsetFrames: pauseFrames }`).
4. **`packages/ir/src/adapters/StoryConfigToUniversalIRAdapter.ts`:**
   - Injected `offsetFrames: pauseFrames` derived from `scene.pauseAfter ?? settings.pauseBetweenScenes` (30 fps * 1s = 30 frames per pause).
5. **Autogenerated Tests & Regression Suite:**
   - Updated `autogenerated-tests/video_ir_phase6_cli_scaling.test.ts` to expect 3,588 frames (119.6s) with pauses enabled.
   - Verified all 211 tests across 40 test files pass with 0 failures (`bun test autogenerated-tests/`).
