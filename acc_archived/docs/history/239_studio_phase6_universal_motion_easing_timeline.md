# 239. Studio Phase 6: Universal Motion & Easing Engine & Timeline Direct Manipulation

## Context & Problem
In an enterprise-grade NLE, motion and easing curves cannot remain an isolated static transform offset. They function as a **universal temporal modulation primitive** across:
1. **Intra-Clip Spatial Transforms**: 3-stage lifecycles (`intro` entrance, `steady` hold/drift, `outro` exit) with GSAP Bézier curves (`power2.out`, `back.out`, `elastic.out`, `bounce.out`, `expo.out`, `linear`) and underlying keyframes.
2. **Audio Dynamics & Voiceover Ducking**: Smooth sidechain envelope attenuation with analog exponential attack/release filters preventing audio clipping and pumping.
3. **Multi-Track Timeline Direct Manipulation**: Interactive left/right clip trim handles with magnetic playhead/boundary snapping, Razor split tool (`C` hotkey), and live keyboard shortcuts cheat sheet modal.

## Implementation Details

1. **Polymorphic Temporal Curve Model (`packages/ir/src/types/VideoIR.ts`)**:
   - Introduced `TemporalCurve<T>`, `TransformModifierParams`, `DynamicDuckingModifierParams`, and `TransitionModifierParams`.
   - Supported polymorphic parameters accommodating both static values and animated lifecycle configurations.

2. **Universal Canvas Motion Compiler & Zero-Re-Render Viewport (`packages/effect-engines/src/canvas/UniversalCanvasEngine.ts`)**:
   - Upgraded `syncTimeline()` to compile 3-stage lifecycles (`intro`, `steady`, `outro`) and motion presets (`pop_in`, `slide_left`, `bounce`, `overshoot`, `drift`) into the GSAP timeline.
   - Stored interpolated state objects in `interpolatedStates` map and exposed `getActiveInterpolatedTransform(seqId)`.
   - Bound in `Preview.tsx` to update canvas vector overlays and selection bounding boxes during live 60fps rAF playback without React re-render churn.

3. **Audio Dynamic Ducking Gain Curves (`packages/effect-engines/src/audio/UniversalAudioMixer.ts`)**:
   - Added `attackMs` and `releaseMs` parameters.
   - Implemented exponential analog slew rate filtering:
     `alpha = target < currentDucking ? attackAlpha : releaseAlpha`
     `currentDucking += (target - currentDucking) * alpha`.
   - Synced in `WebAudioEngine.ts` from `sfx/dynamic_ducking` modifiers.

4. **Right Sidebar Motion Inspector (`apps/studio/src/components/RightSidebar.tsx`)**:
   - Integrated motion preset quick-pickers (`Static`, `Pop In`, `Slide In`, `Bounce`, `Overshoot`, `Drift`).
   - Added dual Intro Duration and Outro Duration sliders synchronized with `EasingCurveSelector`.

5. **Timeline Direct Manipulation & Shortcuts Modal (`apps/studio/`)**:
   - In `Timeline.tsx`:
     - Implemented interactive drag trimming (`startTrim`, `cursor-col-resize`) on left/right clip handles.
     - Implemented magnetic edge snapping to neighboring sequence boundaries and playhead (12px / 3-frame threshold).
     - Added Razor Split Tool mode (`activeTool === 'razor'`, `cursor-crosshair`) enabling one-click sequence splitting.
   - Created `ShortcutsModal.tsx` and wired into `Titlebar.tsx` with hotkey listener for `?` / `Ctrl+/`.
