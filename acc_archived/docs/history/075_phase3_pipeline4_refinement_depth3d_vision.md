# History Log 075: Phase 3 Pipeline 4 Refinement (Depth Anything v2 + SAM 2 + Depth3D)

## Problem
In Master Plan v3.0, Pipeline 4 (Generative Storytelling) previously lacked automated AI subject cutout and metric depth map generation, requiring manual alpha masks or static radial fallbacks. Additionally, sound effects (`sound-effects-cli.ts`) and overlay effects (`overlay-effects-cli.ts`) were loose scripts at root rather than modular CLI commands within `apps/cli/src/commands/`.

## Plan
1. **Task 3.1**: Implement `VisionEngine` in Python backend (`apps/python-backend/src/services/vision_engine.py`) integrating Depth Anything v2 and MobileSAM with defensive edge-preserving fallbacks. Wire `VisionService` in `server.py` and `IPCFacade` (`estimateDepth`, `segmentSubject`).
2. **Task 3.2**: Connect `src/depth3d/index.ts` to `IPCFacade` for `autoSegment: true` and `autoDepth: true`. Ensure `STORY-CONFIG-8POINT-SYNC` compliance across schema, types, platforms, specs, and docs.
3. **Task 3.3**: Migrate `sound-effects-cli.ts` and `overlay-effects-cli.ts` into `apps/cli/src/commands/sfx.ts` and `apps/cli/src/commands/overlay.ts`, while maintaining backward-compatible root proxy entry points.
4. **Verification**: Execute targeted unit and integration test suite (`autogenerated-tests/phase3_depth3d_vision.test.ts`), all previous phase test suites, and sample story rendering.
