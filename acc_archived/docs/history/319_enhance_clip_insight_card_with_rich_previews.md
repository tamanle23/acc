# Task 319: Enhance ClipInsightCard with Rich Interactive Previews (Video, Audio, Image)

## 1. Overview & Context
Enhanced `ClipInsightCard.tsx` to provide rich visual and interactive previews for sequence media archetypes (Video, Image, Audio) inside the timeline clip hover HUD (`ClipHoverHUD`), adhering to the **UI/UX Design System** and **Frontend App Architect** guidelines.

## 2. Key Enhancements
- **Video Previews (`isVideo` / `track.type === 'video'` / `seq.type === 'video' | 'media'`)**:
  - Embedded inline looping `<video>` preview player.
  - Interactive play/pause toggle button with glass styling and backdrop blur.
  - External link button opening the full original video in a new browser tab.
  - Fallback error state when media stream is inaccessible or network error occurs.
- **Image Previews (`isImage` / `track.type === 'image'` / `seq.type === 'image'`)**:
  - Embedded high-fidelity image thumbnail resolving from the VideoIR asset registry (`irDoc.assets[seq.assetId]`), direct `seq.source`, or cached canvas thumbnail via `AssetTextureCache`.
  - Quick action to open an enlarged full-resolution preview modal via Radix/Shadcn `Dialog`.
  - External link button to open the original source asset directly in a new tab.
- **Audio Previews (`isAudio` / `track.type === 'audio'` / `seq.type === 'audio'`)**:
  - Embedded `<audio>` player with interactive play/pause controls.
  - Volume mute/unmute toggle.
  - Dynamic animated mini equalizer wave visualization active while playing.
  - External link button to open or download the audio stream directly.
- **Interactive UX & HoverCard Integration**:
  - Enabled `pointer-events-auto` and `select-auto` on `ClipHoverHUD.tsx` so users can seamlessly click play/pause, enlarge images, or open external tabs without the card closing.
  - Integrated full cleanup in `useEffect` when cards unmount so background audio/video playback is terminated immediately.
- **Automated Verification**:
  - Created `autogenerated-tests/timeline_clip_insight_media_previews.test.ts` verifying component exports, interactive video/audio playback hooks, image modal triggers, and HUD pointer-events.
  - All timeline tests pass (44/44 green).
  - Full monorepo production build (`turbo build`) completed cleanly with 0 errors.
