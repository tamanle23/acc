# [294] Schema-Driven Dynamic Modifier Inspector & Visual VideoIR JSON Debugger (Iteration 20)

- **Date:** 2026-10-21
- **Status:** Completed
- **Component:** `@acc/ir` (`ModifierPluginRegistry`, Plugins), `apps/studio` (`RightSidebar`, `DynamicModifierInspector`, `ModifierControlStrategies`, `VisualIRJsonDebuggerModal`, `Titlebar`, `complexSciFiDemoIR`)

---

## 1. Context & Problem

1. **Dynamic Modifier Parameter Inspector (Zero Hardcoding / Open-Closed Principle):**
   - Previously, `RightSidebar.tsx` rendered specialized panels for a fixed list of modifiers and fell back to a basic `typeof val === 'number'` slider loop (`min: 0, max: 100`) for all other plugins (`vfx/partial`, `audio/filter`, `editorial/transition_crossfade`, `editorial/split_edit`, `overlay/blend_mode`, `shape/draw`, `time_space`, etc.).
   - Complex array-based modifiers like `vfx/partial` (`regions: PartialVFXRegionConfig[]`) and enum-based modifiers (`filterType: 'lowpass' | 'highpass' | 'bandpass'`) could not be edited accurately without declarative metadata from `ModifierPluginRegistry`.
2. **Visual VideoIR JSON Editor & Live Debugger:**
   - Studio users and engineers lacked an in-app tool to inspect, search, format, validate, and live-patch the underlying `VideoIRDocument` JSON AST with real-time `VideoIRSchemaValidator` and relational DAG diagnostics.

---

## 2. Solution & Architecture

### Phase 1: Declarative Parameter Schemas on `ModifierPluginRegistry`
- Extended `packages/ir/src/plugins/ModifierPluginRegistry.ts` with `ParamFieldType`, `ParamFieldDescriptor`, `ModifierParameterSchema`, optional `readonly schema?: ModifierParameterSchema` on `ModifierPlugin`, and `getSchema(type: string)` on `ModifierPluginRegistry`.
- Attached rich declarative `schema` definitions to all core modifier plugins in `packages/ir/src/plugins/`:
  - `PartialVFXPlugin` (`regions_array` strategy), `ColorGradingPlugin`, `Depth3DPlugin`, `Camera3DPlugin`
  - `FilterModifierPlugin`, `PanModifierPlugin`, `VolumeModifierPlugin`, `PitchModifierPlugin`
  - `TransitionCrossfadePlugin`, `SplitEditPlugin`, `BlendModePlugin`, `HologramHUDPlugin`, `CanvasParticleOverlayPlugin`
  - `DynamicDuckingPlugin`, `ProceduralSFXModifierPlugin`, `TransformModifierPlugin`, `CaptionModifierPlugin`, `ShapeModifierPlugin`, `TimeSpaceModifierPlugin`

### Phase 2: Strategy Pattern Inspector (`DynamicModifierInspector`)
- Created `apps/studio/src/components/inspector/ModifierControlStrategies.tsx` implementing `ControlStrategyProps` across 6 strategies:
  - `NumberControlStrategy` (clamped slider + numeric input + unit badge + double-click reset)
  - `SwitchControlStrategy` (boolean toggle)
  - `SelectControlStrategy` (enum dropdown)
  - `ColorControlStrategy` (hex color picker + quick swatches)
  - `StringControlStrategy` (monospace text input)
  - `RegionsArrayControlStrategy` (interactive 2D normalized reticle pad + region list CRUD for `vfx/partial`)
- Created `apps/studio/src/components/inspector/DynamicModifierInspector.tsx` and wired it into `RightSidebar.tsx`, with automatic reflective fallback (`inferFieldDescriptor`) for third-party/custom plugins.

### Phase 3: Visual VideoIR JSON Editor & Live Debugger (`VisualIRJsonDebuggerModal`)
- Created `apps/studio/src/lib/commands/ReplaceDocumentCommand.ts` and `IRStateManager.applyJSONEdit(jsonString)` so live JSON edits are 100% undoable (`Ctrl+Z`) and redoable (`Ctrl+Y`).
- Built `apps/studio/src/components/debugger/VisualIRJsonDebuggerModal.tsx` featuring:
  - **Raw JSON Editor** with line numbers, Format, Minify, Copy, Reset, and live telemetry sidebar.
  - **AST Tree Navigator** with collapsible nodes, search filtering, and 1-click `Inspect Clip` selection.
  - **DAG & Schema Diagnostics** verifying JSON Schema Draft-07 compliance, relational `after`/`with` sequence anchors, asset references, and `ModifierPluginRegistry` coverage.
- Wired the `{ } Debugger` button and `Ctrl+Shift+J` global shortcut into `apps/studio/src/components/Titlebar.tsx` and `ShortcutsModal.tsx`.
