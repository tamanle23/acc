# History Log: [086] Migrate Legacy /src to @acc/effect-engines and Turborepo Monorepo Architecture

**Date**: 2026-10-01  
**Status**: [x] Completed  
**Component**: Core Architecture / Monorepo Layout (`packages/effect-engines`, `apps/cli`, `packages/core`, `src/`)

---

## 1. Problem Statement & Motivation
- The codebase was undergoing migration to a clean Turborepo monorepo architecture (`packages/` and `apps/`).
- While `packages/core`, `packages/ir`, `packages/proto`, `packages/exporters`, and `apps/cli` had been introduced, substantial core media logic (3D Depth engines, 27 canvas overlay shaders, sound effect generators, canvas subtitles, and the storytelling renderer) was still physically residing directly inside the root `src/` directory.
- The goal was to fully migrate all domain effects and story rendering logic into standard monorepo packages (`@acc/effect-engines` and `apps/cli/src/pipelines/04-generative-story`), while preserving 100% backward compatibility via zero-regression shims in root `src/`.

---

## 2. Proposed Design & Monorepo Topology
1. **`packages/effect-engines` (`@acc/effect-engines`)**:
   - `src/depth3d/`: Parallax 2.0, FrameBreaker 2.0, Sandwich 2.0, DepthMesh, Wigglegram.
   - `src/overlay-effects/`: 27 procedural shader/canvas overlay generators, registry, stacker.
   - `src/sound-effects/`: SFX registry, synthesis generators (FFmpeg, AI, generic library), audio DSP.
   - `src/subtitles/`: Frame-perfect canvas karaoke renderer (`captions-canvas.ts`) and ASS generator (`subtitles.ts`).
   - `src/styles/`: Typography presets and caption styles.
   - `src/types.ts` & `src/index.ts`: Unified effect exports.
2. **`apps/cli/src/pipelines/04-generative-story`**:
   - `StoryRenderer.ts`: Master multi-scene video orchestration engine using `FFISceneEngine` and `bun:ffi`.
   - `GenerativeStoryPipeline.ts`: Folder resolution and execution pipeline.
   - `platforms.ts`, `tts.ts`, `whisper.ts`, `upscaler.ts`, `plugins/UpscalerPlugin.ts`.
   - `index.ts`: Public pipeline exports.
3. **`packages/core` (`@acc/core`)**:
   - Added exports for `FFISceneEngine`, `FFIAudioDSP`, `SceneWorker`, `types`, and `PythonBackend`.
4. **Root `src/` (Zero-Regression Shims)**:
   - All files in `src/` (`src/renderer.ts`, `src/types.ts`, `src/platforms.ts`, `src/styles.ts`, `src/subtitles.ts`, `src/depth3d/*`, `src/overlay-effects/*`, `src/sound-effects/*`, `src/core/*`) were replaced with thin re-export shims.
