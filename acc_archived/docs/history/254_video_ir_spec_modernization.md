## 1. Context & Motivation
As the Visual Storytelling Generator expands from simple video clips into complex multi-layered scenes (vector shapes, procedural particles, 2.5D depth pop-out, overlay HUDs, active-word karaoke text, and audio ducking), the Video Intermediate Representation (IR) specification required modernization to address ambiguity in sequence semantics, domain target constraints, master post-composition passes, and decoupled schema validation.

In accordance with project rule `VIDEO-IR-SCHEMA-SYNC`, changes to the VideoIR specification must be atomically synchronized across all 8 core architectural components.

---

## 2. Key Architectural Changes

### 1. Explicit Sequence Types (`seq.type`)
- Added `SequenceType = 'video' | 'image' | 'audio' | 'text' | 'overlay'`.
- Made `type` strictly required on `IRSequence` with zero coercion/fallback.
- Enforced track-containment compatibility:
  - `video` tracks: `video`, `image`, or `overlay` sequences only.
  - `audio` tracks: `audio` sequences only.
  - `timed_text` tracks: `text` sequences only.

### 2. Global Document-Level Modifiers (`doc.modifiers`)
- Added `modifiers?: ModifierNode[]` directly at `VideoIRDocument`.
- Evaluated as a post-composition master pass on the visual canvas and master audio buffer in `IRMasterRenderer.ts`.
- Propagated to `ResolvedTimeline.modifiers` in `RelationalDAGCompiler.ts`.

### 3. Strictly Required Modifier Targets (`modifier.target`)
- Added `target: SequenceType | SequenceType[]` to `ModifierNode`.
- Runtime validator enforces:
  - Non-empty target array or single sequence type.
  - Track-level modifiers must target sequence types compatible with their track domain.
  - Sequence-level modifiers must include the parent sequence's type in their target.

### 4. Dual-Level Cascading Blend Modes (`blendMode`)
- Added `BlendMode = 'normal' | 'screen' | 'multiply' | 'overlay' | 'add' | 'color_dodge' | 'soft_light'`.
- Supported at both `IRSequence` and `IRTrack`.
- Evaluated as `seq.blendMode || track.blendMode || 'normal'`.

### 5. Decoupled Modular JSON Schemas & TypeScript Definitions
- Created `schema/modifiers.schema.json` defining strict parameter schemas, temporal easing curves, and domain targets for all 15+ standard modifiers.
- Updated `schema/video-ir.schema.json` to reference `modifiers.schema.json#/$defs/modifierNode`.
- Created `packages/ir/src/types/modifiers.ts` with discriminated union `StandardModifierNode` and fallback `CustomModifierNode`.
