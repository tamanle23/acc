# 277: Relocate MediabunnyClientSink and Client Sinks to @acc/ir/client

## Overview & Rationale
Previously, `MediabunnyClientSink` was hosted in `@acc/core` and exposed via `@acc/core/client`. However, `@acc/core` represents the native C/FFI, `FFmpegManager`, and Node batch rendering foundation of the system. Direct client consumers (such as `apps/studio` and interactive browser exporters) interact with Video IR and its frame sinks.

To establish clean architectural boundaries:
1. Re-introduced `@acc/ir/client` as the dedicated client-side frame sink and browser preview export subpath.
2. Completely removed `@acc/core/client` from `@acc/core`, removing browser client sink exports from `@acc/core/package.json`.
3. Hosted `MediabunnyClientSink` directly in `packages/ir/src/renderer/sink/MediabunnyClientSink.ts` implementing `IIRFrameSink`.
4. Exported `MediabunnyClientSink`, `PreviewCanvasSink`, `IRPreviewEngine`, and client-compatible frame sink contracts via `@acc/ir/client`.
