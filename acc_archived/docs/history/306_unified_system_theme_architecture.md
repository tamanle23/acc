# 306 — Unify Studio Application with System Theme Manager & Tailwind v4 Tokens

- **Date:** 2026-10-22
- **Component:** `@acc/studio` (`ThemeProvider`, `index.css`, Inspector, Timeline, Preview, Debugger, Sidebars)
- **Status:** Completed

## Context & Problem
While `ThemeProvider.tsx` managed user preferences for `mode` (`dark` | `light`), `glassStyle` (`specular` | `frosted` | `cyber`), `blurIntensity` (`low` | `medium` | `high`), and `accentColor` (`cyan` | `violet` | `emerald` | `amber` | `rose`), many components across `@acc/studio` still used hardcoded Tailwind palette classes (`bg-white`, `bg-slate-900`, `text-slate-600`, `bg-indigo-600`, `text-indigo-500`, `text-cyan-400`, `text-slate-950`) or invalid Tailwind opacity scale modifiers (`border-accent-theme/200`, `text-accent-theme/600`). Additionally, `[data-glass-style="cyber"]` in `index.css` contained an invalid `var(--alpha(...))` CSS expression, and `ThemeProvider` CSS variables were not fully bridged into Tailwind v4's `@theme` and `@custom-variant` directives.

## Solution & Architectural Changes
1. **Tailwind v4 `@theme` & `@custom-variant` Integration (`apps/studio/src/index.css`)**:
   - Registered `@custom-variant` definitions for `dark`, `light`, `glass-cyber`, `glass-frosted`, `glass-specular`, `blur-low`, `blur-medium`, and `blur-high`.
   - Bridged all `ThemeProvider` CSS custom properties into `@theme`:
     - `--color-accent-theme: var(--accent-primary)`
     - `--color-accent-theme-foreground: hsl(var(--primary-foreground))`
     - `--color-accent-glow: var(--accent-glow)`
     - `--color-glass-surface: var(--glass-bg)`
     - `--color-glass-border: var(--glass-border)`
     - `--color-glass-border-highlight: var(--glass-border-highlight)`
     - `--shadow-glass: var(--glass-specular), var(--glass-shadow)`
     - `--shadow-accent-glow: 0 0 15px var(--accent-glow)`
   - Fixed `[data-glass-style="cyber"]` border and shadow expressions using standards-compliant `color-mix(in srgb, var(--accent-primary) ...)`.
   - Linked `--ambient-mesh` to dynamically blend `var(--accent-primary)` in both `:root` (Light Frosted Acrylic) and `.dark` (Dark Obsidian) modes.

2. **Synchronous DOM & CSS Variable Synchronization (`apps/studio/src/lib/theme/ThemeProvider.tsx`)**:
   - Exported `applyThemeToDocument(preferences)` and `ACCENT_CONFIGS` (with `hsl`, `hex`, and `glow` properties for all 5 studio accents).
   - Applied `applyThemeToDocument` synchronously on initial state hydration as well as in `useEffect` to prevent any Flash of Unstyled Content (FOUC) and keep `--primary`, `--ring`, `--accent-primary`, `--color-brand-accent`, and `--accent-glow` in lockstep.

3. **Full Application Component Theme Unification**:
   - **App Shell & Modals**: Unified `App.tsx`, `Titlebar.tsx`, `ShortcutsModal.tsx`, `SettingsModal.tsx`, and `EasingCurveSelector.tsx` with semantic `glass-panel`, `glass-card`, `bg-accent-theme`, `text-primary-foreground`, and `border-glass-border` tokens.
   - **RightSidebar & Inspector Suite**: Eliminated all hardcoded `slate-*` and `indigo-*` classes and fixed invalid opacity classes in `RightSidebar.tsx`, `ProjectInspector.tsx`, `TrackInspector.tsx`, `SequenceInspector.tsx`, `ModifierControlStrategies.tsx`, `ParameterControls.tsx`, `DynamicModifierInspector.tsx`, and `CueTimelineDialog.tsx`.
   - **LeftSidebar & Audio Meter**: Unified `LeftSidebar.tsx` preset/drawer icons and buttons and `MasterAudioMeter.tsx` with semantic theme tokens.
   - **Preview & Timeline Suite**: Updated `ViewportControlBar.tsx`, `ViewportQuickTransport.tsx`, `TransformGizmoOverlay.tsx`, `TelemetryCompanionCard.tsx`, `ContextualActionPill.tsx`, `Timeline.tsx`, `TimelineToolbar.tsx`, `TimelineClipItem.tsx`, and `TrimHandle.tsx` to use `bg-accent-theme text-primary-foreground`, `hover:bg-foreground/10`, and `border-glass-border` for full dark/light/accent consistency while keeping the VideoIR canvas backing (`#000000`) isolated per Rule 235.
   - **Visual VideoIR JSON Editor**: Unified `VisualIRJsonDebuggerModal.tsx`, `ShikiCodeViewer.tsx`, `VisualJsonFieldEditor.tsx`, and `VisualJsonTreeNode.tsx` with semantic theme tokens.
