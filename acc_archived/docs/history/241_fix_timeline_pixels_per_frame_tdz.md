# 241. Fix Timeline PixelsPerFrame Temporal Dead Zone Reference Error

## Context & Problem
Upon loading the Studio Timeline, a runtime reference error was thrown:
`Uncaught ReferenceError: Cannot access 'pixelsPerFrame' before initialization` at `Timeline.tsx:217`.

In `apps/studio/src/components/Timeline.tsx`, `const pixelsPerFrame = Math.max(1, 4 * zoomScale);` was declared lower down in the component body (line 276). However, the trim dragging `useEffect` hook (lines 156-217) and `handleClipClick` referenced `pixelsPerFrame` in both the mouse move callback and the dependency array `[trimmingState, pixelsPerFrame, snapEnabled, tracks, currentFrame]`.
When React evaluated the component body, `pixelsPerFrame` was in the Temporal Dead Zone (TDZ) when the hook's dependency array was inspected, triggering an immediate uncaught `ReferenceError`.

## Implementation Details

1. **Reordered Variable Declarations (`apps/studio/src/components/Timeline.tsx`)**:
   - Hoisted `pixelsPerFrame` and `timelineWidth` immediately below `selectedSeqId` and `zoomScale` declarations (line 84), before any `useEffect` hooks or handlers reference them.
   - Removed the duplicate lower declarations.
