# 218: Master Plan Iteration 3 Phase 5 Ext: Studio App Three.js & Isomorphic Audio Modernization

## Overview & Context
Resolves inaudible audio playback and blank timeline/canvas clip visuals in the Visual Storytelling Studio (`apps/studio`), while creating an enterprise-grade, cross-platform 3D visual engine and isomorphic audio DSP pipeline shared between the Web client (`apps/studio`) and Node/Bun server (`@acc/effect-engines` / `packages/ir`).

Following interactive `/grill-me` alignment:
- **Visual Engine**: `pts.js` vector geometry handles procedural motion curves, orbital camera matrices, Bézier paths, and depth displacement grids without any DOM/GL dependency. `Three.js` acts as the scenegraph abstraction consuming `pts.js` matrices and Pt groups to drive `BufferGeometry` attributes and `ShaderMaterial` uniforms. Web uses hardware-accelerated `THREE.WebGLRenderer` attached to the canvas, while Node/Bun runs headless rendering via offscreen context/pixel readback for `IIRFrameSink` (`MediabunnyServerSink`).
- **Audio Engine**: An isomorphic `Float32 DSP` synthesizer and multi-track mixer generates raw Float32 PCM samples (procedural voice chatter, laser SFX, synthwave BGM) with dynamic auto-ducking. Studio plays this via `WebAudioEngine` (`AudioContext` + `AudioBufferSourceNode` + `AnalyserNode` feeding `MasterAudioMeter`), while Node/Bun feeds the PCM directly into `MediaEngineStrategy` without spawning raw ffmpeg CLI.
- **Timeline & Viewport Visuals**: `AssetTextureCache` provides real image/video frame decoding and procedural sci-fi filmstrip generation for `Timeline.tsx` and `Preview.tsx`.
- **Interactive Controls**: Viewport bounding box transform gizmo for direct clip manipulation on the canvas.
- **Master Demo IR**: Extended multi-asset Sci-Fi Space Combat Epic showcase.

## Architectural Changes & Key Implementations

1. **`@acc/effect-engines/src/three/UniversalThreeScene.ts`**:
   - Encapsulates `pts.js` (`Pt`, `Group`) vector mathematics with `three.js` scenegraph.
   - Computes orbital camera paths and 3D depth mesh displacement geometry (`THREE.PlaneGeometry`).
   - Implements custom GLSL shaders with time, depth map, and Blinn-Phong relighting normals.
   - Generates dynamic particle warp tunnel using cylindrical coordinates via `pts.js`.

2. **`@acc/effect-engines/src/audio/ProceduralAudioSynthesizer.ts` & `UniversalAudioMixer.ts`**:
   - Pure TypeScript Float32Array DSP audio generation:
     - `synthBGM`: Ambient cyberpunk drone and chord pads with analog tanh saturation.
     - `synthLaserSFX`: Frequency-swept exponential chirp + resonant decay.
     - `synthPilotVoice`: Formant-filtered vocoder speech pattern (F1=750Hz, F2=1350Hz, F3=2400Hz).
     - `synthEngineHum`: Sub-bass starship engine hum.
   - `UniversalAudioMixer`: Multi-track mixing with equal-power stereo panning and dynamic auto-ducking (voiceover smoothly attenuates BGM by 75%).

3. **`@acc/effect-engines/src/client.ts` & Subpath Export**:
   - Added `"./client"` export to `packages/effect-engines/package.json` ensuring 100% pure client safety in `@acc/studio` (zero native `.node` or `@napi-rs/canvas` dependencies in the browser bundle).

4. **`apps/studio/src/lib/audio/WebAudioEngine.ts` & `MasterAudioMeter.tsx`**:
   - Integrated `UniversalAudioMixer` with browser `AudioContext` and `AnalyserNode`.
   - Live multi-track audio playback on timeline Play/Pause.
   - Responsive scrub audio feedback (80ms actual content bursts).
   - Real-time RMS & Peak decibel level streaming to `MasterAudioMeter.tsx`.

5. **`apps/studio/src/lib/textures/AssetTextureCache.ts` & `FilmstripThumbnail.tsx`**:
   - High-performance LRU texture and thumbnail cache.
   - Procedurally synthesizes high-fidelity sci-fi filmstrip thumbnails (nebula starfields, cockpit HUD reticles, laser beams).
   - `FilmstripThumbnail.tsx` renders repeated thumbnail slices inside timeline video and overlay sequence clips in `Timeline.tsx`.

6. **`apps/studio/src/components/Preview.tsx`**:
   - WebGL 2.0 texture sampling binding active sequence textures.
   - Interactive Transform Bounding Box Gizmo with translation drag, 4 corner resize handles, top rotation stem, and real-time updates to `IRStateManager`.
