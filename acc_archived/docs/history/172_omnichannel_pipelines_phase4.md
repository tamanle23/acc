## 1. Context & Motivation

Our omnichannel generation engine supports Pipelines 1 (`01-scraper`), 2 (`02-db-templating`), and 3 (`03-repurposing`), generating both video deliverables (social alerts, bar chart race animations, 9:16 vertical repurposed shorts) and non-video assets (podcasts/MP3 voiceovers, standalone static infographics, and markdown summaries).

### The Architectural Constraint (Phase 4 / Option 3)
In earlier iterations, either pipelines bypassed the Universal Video IR engine entirely with legacy canvas encoders, or risked compiling all media types into video timelines.
We enforced the strict architectural rule:
- **Video outputs** compile directly into the declarative Universal Video IR (`VideoIRDocument`) for deterministic, multi-core accelerated rendering via `@acc/ir`.
- **Non-video outputs** (audio podcasts, static markdown/JSON, static infographics) **strictly bypass** the Video IR engine, executing pure native audio slicing, image encoding, and file dispatching without constructing unnecessary frame-rate video timelines.

## 2. Key Architecture & Implementation Changes

### 2.1 Omnichannel AST Adapter (`PipelineIRToUniversalIRAdapter`)
- **File**: `packages/ir/src/adapters/PipelineIRToUniversalIRAdapter.ts`
- Translates `PipelineIR` AST structures from Pipelines 1, 2, and 3 into canonical `VideoIRDocument` (version `1.0.0-stable`).
- Maps visual canvas assets to image tracks, extracts voiceover narrations into synchronized audio tracks with relational sequence dependencies.
- Registered in `IRConfigAdapterRegistry` and exported from `packages/ir/src/index.ts`.

### 2.2 Output-Modality Selective Dispatcher in `VideoExporter`
- **File**: `packages/exporters/src/video/VideoExporter.ts`
- Upgraded `VideoExporter` to adapt incoming `PipelineIR` via `PipelineIRToUniversalIRAdapter`, compile through `RelationalDAGCompiler`, and render natively using `IRMasterRenderer` + `FFIVideoEncoderSink`.
- Returns full video metadata including `irCumulativeHash`.
- Preserves fallback canvas encoder for maximum defensive resilience.

### 2.3 Non-Video Exporter Isolation
- `AudioExporter` (`packages/exporters/src/audio/AudioExporter.ts`): Bypasses Video IR completely; executes asynchronous audio buffer concatenation and chapter JSON emission.
- `StaticWebExporter` (`packages/exporters/src/static-web/StaticWebExporter.ts`): Bypasses Video IR completely; renders frontmatter markdown and structured JSON feeds directly.

### 2.4 Pipeline Enhancements & Verification
- **Pipeline 1 (`01-scraper`)**: Ingests event summaries, generates alert card, routes video path via Universal Video IR and podcast/static summary directly.
- **Pipeline 2 (`02-db-templating`)**: Ingests structured entity metrics, generates bar charts, compiles video via Universal Video IR, and outputs static infographic data.
- **Pipeline 3 (`03-repurposing`)**: Slices viral hooks, generates vertical short video via Universal Video IR, and emits audio podcast directly.
