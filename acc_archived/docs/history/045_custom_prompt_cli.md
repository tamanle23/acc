# [045] Sound Effects Custom Prompt CLI & Backlog

## 1. Context & Problem Statement
Previously, the Sound Effects CLI strictly required users to select a predefined `effect`, `variant`, and `sub-variant` (e.g., `foley` > `footsteps` > `sprint`). The user wanted the flexibility to bypass these presets and input raw, freeform text prompts (e.g., "Alien spaceship powering down") directly into the AI (`audioldm2`) or Library (`freesound`) engines. Additionally, future epic ideas (Spatial 3D Audio, Procedural UI Synths, and Auto-Ducking) needed to be safely stored in the project backlog.

## 2. Implementation Plan
- **Backlog Update:** Document Epic 3 (Spatial Audio), Epic 4 (Procedural Synths), and Epic 5 (Auto-Ducking) into `docs/BACKLOG.md`.
- **Interface Modification:** Expand `ISoundGenerator.generate()` to accept an optional `customPrompt` argument.
- **Generator Updates:** 
  - Modify `GenericLibrary.ts` to use `customPrompt` as the exact search query if provided.
  - Modify all `ai/` generators (like `Fallback.ts`) to use `customPrompt` as the precise text-to-audio prompt.
- **CLI Enhancement:** 
  - Add `--custom-prompt` parsing to the Headless mode of `sound-effects-cli.ts`.
  - Add a "Custom Prompt (Freeform Text)" interactive branch to the `startWizard()` flow.

## 3. Changes Made
- **[MODIFY] `docs/BACKLOG.md`:** Added Epics 3, 4, and 5.
- **[MODIFY] `src/sound-effects/core/interfaces.ts`:** Added `customPrompt?: string`.
- **[MODIFY] `src/sound-effects/engine.ts`:** Passed `customPrompt` down to `generator.generate()`.
- **[MODIFY] `src/sound-effects/generators/library/GenericLibrary.ts`:** Integrated query override logic.
- **[MODIFY] `src/sound-effects/generators/ai/*.ts`:** Bulk-updated 7 files to prioritize `customPrompt || ...`.
- **[MODIFY] `sound-effects-cli.ts`:** Completely refactored `parseArgs` and interactive choices to support the custom generation path.
