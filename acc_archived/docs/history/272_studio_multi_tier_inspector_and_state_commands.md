# 272. Studio Dynamic Multi-Tier Inspector & State Commands (Iteration 11 Phase 2)

## Overview & Scope
- **Task**: Implement Phase 2 of Master Integration Plan Iteration 11 (`apps/studio`).
- **Objective**: Introduce a full multi-tier inspection hierarchy (`[Project] > [Track] > [Sequence]`) with persistent breadcrumbs, interactive controls adhering strictly to the VideoIR V1.0 schema, and undoable state commands featuring 500ms continuous update debouncing.

## Key Deliverables & Changes

1. **State Commands**:
   - `UpdateTrackCommand.ts`: Manages undoable track modifications (`name`, `blendMode`, `style`, `routeTo`, `parentTrack`) with continuous 500ms `tryMerge`.
   - `ReorderTrackCommand.ts`: Discrete command moving tracks up or down in `doc.tracks`.
   - `UpdateSequencePropsCommand.ts`: Updates sequence-level `blendMode`, `assetId`, `activeStreams`, and inline `cues` with continuous 500ms `tryMerge`.
   - `UpdateProjectMetaCommand.ts`: Updates project-level `contentId`, `globalFps`, and `canvasSize` with continuous 500ms `tryMerge`.

2. **State Management (`irState.ts`)**:
   - Added `inspectorMode` (`sequence` | `track` | `project`) and `selectedTrackId` to `IRState`.
   - Added `setSelectedTrackId()`, `setInspectorMode()`, and helper dispatchers (`updateTrack`, `reorderTrack`, `updateSequenceProps`, `updateProjectMeta`).
   - Automatically detects parent track when selecting a sequence.

3. **Multi-Tier Breadcrumbs & Inspector Forms (`RightSidebar.tsx`)**:
   - Persistent breadcrumb navigation header: `[Project: {contentId}] > [Track: {name}] > [Sequence: {id}]`.
   - **Track Inspector Form**: Track reorder buttons (`Move Up` / `Move Down`), name editing, `blendMode` selection, opacity slider, audio bus routing (`routeTo` bus selector, volume slider, stereo pan slider), and child sequences listing.
   - **Project Inspector Form**: 1-click aspect ratio pills (`16:9`, `9:16`, `1:1`, `4:4`, `3:4`, `3:2`, `21:9`), numerical width & height inputs, framerate dropdown (`24`, `30`, `60`), and project statistics.
   - **Sequence Inspector Form**: Added sequence `blendMode` dropdown and inline timed text cues table editor (`startOffsetMs`, `endOffsetMs`, subtitle text, `+ Add Cue`, `Trash`).

4. **Context Triggers (`Timeline.tsx` & `Preview.tsx`)**:
   - Clicking track headers in `Timeline.tsx` activates track inspection.
   - Clicking the empty canvas margin in `Preview.tsx` or empty timeline lanes below tracks activates project inspection.

5. **Verification**:
   - Created `autogenerated-tests/studio_phase2_multi_tier_inspector.test.ts` with 100% pass rate.
   - Verified studio production build (`bun run --cwd apps/studio build`) passes with zero bundle errors.
