# Master Integration Plan Iteration 12: Stateless Particle Engine via Pts.js & GSAP + Centered Shape Placement

## Goal Description
1. **100% Stateless Particle Simulation Engine (`CanvasParticleOverlayPlugin`)**:
   - Refactor `CanvasParticleOverlayPlugin` so every particle's position, velocity vector, scale, and alpha is a **pure closed-form function of $(i, \text{frame}, \text{seed})$**.
   - Use **Pts.js `Noise` & `Pt`** for coherent spatial curl turbulence (giving organic fluid flow to smoke, embers, fire, dust, and water without Euler accumulator drift).
   - Use **GSAP parametric easing (`gsap.parseEase`)** for particle birth-to-death lifecycles (expansion, turbulence drift, and graceful fadeout).
   - Decommission or bypass the stateful sequential accumulator in `SIMDParticleComputeEngine`, guaranteeing that jumping or scrubbing to any arbitrary frame (forward or backward) yields 100% bit-identical visual output.
2. **Canvas-Centered Shape Placement**:
   - In `ShapeModifierPlugin.ts`, position geometries relative to the canvas/sequence center `(width * 0.5 + offsetX, height * 0.5 + offsetY)` in universal top-left `(0, 0)` space.
   - Ensure staging presets in `stagingPresets.ts` stage shapes dead-center (`normX: 0.5, normY: 0.5, x: 0, y: 0`) upon drop.

## User Review Required

> [!IMPORTANT]
> **Deterministic Random-Access Scrubbing (No Euler Accumulator Drift)**:
> - Previously, the SIMD engine updated particles sequentially (`pos += vel; vel += gravity`). Scrubbing backward did not rewind the particle simulation.
> - With Pts.js Noise and GSAP parametric easing:
>   - Each particle $i$ has a deterministic cycle: $p_i = \text{fract}\left(\frac{\text{frame} \cdot \text{speed} + \text{offset}_i}{\text{duration}_i}\right) \in [0, 1)$.
>   - Position is evaluated as:
>     $$\vec{P}(i, t) = \vec{P}_{\text{base}}(i) + \vec{V}_{\text{base}}(i) \cdot p_i + \text{Noise}(\vec{P}_{\text{base}}(i), t) \cdot \text{turbulence}$$
>   - Opacity and size are shaped by GSAP easing curves: $\alpha = \text{easeLife}(p_i)$.
>   - Scrubbing to frame 42 produces the exact same frame whether reached from 41, 100, or freshly initialized!

## Proposed Changes

### `packages/effect-engines`
#### [MODIFY] `packages/effect-engines/src/overlay-effects/simulators/DeterministicParticleField.ts` [NEW]
- Create `DeterministicParticleField` leveraging `pts` (`Noise`, `Pt`) and `gsap` easing:
  - Supports all procedural presets: `snow`, `rain`, `dust`, `embers`, `fire`, `smoke`, `fog`, `bokeh`, `digital_glitch`, `vhs`, `sci_fi_hud`.
  - Pure function `render(ctx, width, height, frame, params)`.
  - Zero heap allocation during frame loop (pre-allocated float buffers / stateless math).

### `packages/ir`
#### [MODIFY] `packages/ir/src/plugins/overlay/CanvasParticleOverlayPlugin.ts`
- Delegate rendering to `DeterministicParticleField.render(...)`.
- Retain shader post-processing (bloom, chromatic aberration, anamorphic flare) operating statelessly on the rendered frame.

#### [MODIFY] `packages/ir/src/plugins/shape/ShapeModifierPlugin.ts`
- Translate coordinate origin to canvas center:
  ```typescript
  const centerX = ctx.width * (params.normX ?? 0.5) + (params.x ?? 0);
  const centerY = ctx.height * (params.normY ?? 0.5) + (params.y ?? 0);
  canvasCtx.translate(centerX, centerY);
  ```
- Draw vector path centered around $(0, 0)$ and restore context.
