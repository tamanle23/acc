## 1. Context & Problem
For enterprise deployment (Kubernetes, distributed rendering clusters, cloud orchestrators), our engine requires production observability and zero-trust security:
1. **Missing Distributed Tracing**: Operations lack W3C Trace Context (`traceparent` header, `traceId`, `spanId`) correlating Bun tasks, FFI workers, and Python sidecars.
2. **Missing Kubernetes Health & Prometheus Metrics**: `acc serve` needs standard `/healthz/liveness`, `/healthz/readiness`, and `/metrics` exposing render throughput (`acc_render_frames_per_second`), frame latency percentiles, and memory gauges.
3. **Sensitive Data Exposure in Logs**: Authorization tokens, bearer keys, and AWS/S3 secrets risk accidental leakage into log collectors unless automatically sanitized.
4. **Dynamic Secret Governance & Auth Protection**: Services require token authentication / RBAC and dynamic secret resolution (environment / vault fallback).

---

## 2. Proposed Design
1. **W3C Distributed Tracing (`packages/core/src/telemetry/TraceContext.ts`)**:
   - Implements W3C `traceparent` (version, 16-byte traceId, 8-byte spanId, traceFlags) generation, parsing, and propagation across pipeline contexts and HTTP requests.
2. **Prometheus Metrics Registry & Collectors (`packages/core/src/telemetry/MetricsRegistry.ts`)**:
   - Real-time Counters, Gauges, and Histograms (`acc_render_frames_per_second`, `acc_render_frame_latency_ms`, `acc_memory_rss_bytes`, `acc_worker_pool_active_count`).
   - Exposes Prometheus text-format scrape string (`/metrics`).
3. **K8s Health Probes & Enhanced `acc serve` Endpoints**:
   - In `apps/cli/src/pipelines/01-scraper/ScraperEngine.ts` and `apps/cli/src/server/EnterpriseServer.ts`:
     - `/healthz/liveness` $\to$ Returns 200 OK if event loop is responsive.
     - `/healthz/readiness` $\to$ Returns 200 OK if FFmpeg FFI and memory headroom are ready.
     - `/metrics` $\to$ Serves Prometheus metrics format.
4. **Zero-Trust Security, Dynamic Secrets & Log Redaction (`packages/core/src/security/`)**:
   - `DynamicSecretsManager`: Dynamically fetches and securely masks secrets (API keys, S3 credentials, tokens).
   - `Logger` security upgrade: Automatically redacts bearer tokens, API keys, passwords, and PII from all console outputs.
