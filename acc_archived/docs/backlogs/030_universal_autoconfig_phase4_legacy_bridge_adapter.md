## Context & Problem
In Phases 1–3, we built the media prober chain (`MediaAssetProberChain`), heuristic classifiers (`PipelineClassifierRegistry`), fluent AST builder (`PipelineIRBuilder`), and fine-grained director factory (`DirectorPresetFactory`).

However, existing production rendering scripts, CI pipelines, and developers still rely heavily on `story-config.json` via commands such as `bun run cli.ts ./sample-story`. To adhere to the **ZERO-REGRESSION** and **STORY-CONFIG-8POINT-SYNC** rules, the auto-config engine must seamlessly provide an **Adapter Pattern** (`AutoConfigLegacyBridgeAdapter`) that losslessly maps new `PipelineIR` (v3.0.0) documents and `FineGrainedVideoDirectorConfig` structures back into compliant `StoryConfig` objects.

---

## Proposed Design
Implement **Phase 4 of Universal Auto-Config**:
1. **`AutoConfigLegacyBridgeAdapter` (GoF Adapter Pattern)** in `packages/core/src/autoconfig/adapters/AutoConfigLegacyBridgeAdapter.ts`:
   - `toStoryConfig(pipelineIR, directorConfig?, manifest?)`:
     - Maps `pipelineIR.metadata.title` to `storyConfig.name`.
     - Maps director canvas resolution/aspect ratio/fps to `storyConfig.settings`:
       - `9:16` -> 1080x1920 (TikTok/Reels/Shorts).
       - `16:9` -> 1920x1080 (YouTube).
       - `1:1` -> 1080x1080 (Instagram Square).
       - `4:5` -> 1080x1350 (Instagram Portrait).
     - Maps `pipelineIR.audioComposition`:
       - `backgroundMusic` -> `storyConfig.settings.bgm` (`source`, `volume`, `loop: true`, `autoDucking`).
       - `ducking` parameters forwarded to BGM.
     - Maps `directorConfig` typography / captions to `storyConfig.settings.captions`:
       - Presets: `tiktok_karaoke_glow` -> `tiktok`, `3d_sandwich` -> `cinematic`, `bold_headline` -> `bold-retro`, `minimal_editorial` -> `minimal-clean`.
     - Maps `directorConfig` 3D depth to `storyConfig.settings.depth3d` or per-scene overrides:
       - Mode: `sandwich` -> `volumetric_sandwich`, `parallax_2_5d` -> `parallax_25d`, `frame_breaker` -> `frame_breaker`.
     - Maps `pipelineIR.chunks` to `storyConfig.scenes`:
       - If visual asset is an image -> `scene.image = chunk.visualAsset.sourcePathOrBuffer`.
       - If visual asset is a video -> `scene.video = chunk.visualAsset.sourcePathOrBuffer`.
       - `audio`: `chunk.spokenAudioPath`.
       - `text`: `chunk.text`.
       - `duration`: `chunk.durationMs / 1000` (converted to seconds).
       - Transition: mapped from directorConfig roleDirectives (hook, body, outro) or segment overrides.
   - `fromStoryConfig(storyConfig, baseDir?)`:
     - Reverse bidirectional conversion if importing legacy configs into `PipelineIR`.
2. **Exports & Verification**:
   - Re-export `AutoConfigLegacyBridgeAdapter` in `packages/core/src/autoconfig/index.ts`.
   - Add unit test suite in `autogenerated-tests/autoconfig/legacy-bridge-adapter.test.ts`.
   - Verify compatibility against real `sample-story/story-config.json`.
