# 221. Refactor MediaEngineType and ContentCacheStrategyId to TypeScript Enums

## Problem Statement
To eliminate string-literal magic values and guarantee strict compile-time and runtime type safety across the monorepo, `MediaEngineType` and `ContentCacheStrategyId` required migration from string-literal unions to native TypeScript string enums. This allows callers to reference `MediaEngineType.BunFFI`, `MediaEngineType.MediabunnyClient`, and `ContentCacheStrategyId.NativeFile` with autocompletion and strong type constraints.

## Solution Plan & Implementation
1. **`MediaEngineType` Enum (`@acc/core-isomorphic/src/media-engine/types.ts`)**:
   - Converted `type MediaEngineType` to `enum MediaEngineType`:
     - `BunFFI = 'bun-ffi'`
     - `FluentFFmpeg = 'fluent-ffmpeg'`
     - `MediabunnyServer = 'mediabunny-server'`
     - `MediabunnyClient = 'mediabunny-client'`
2. **`ContentCacheStrategyId` Enum (`@acc/core-isomorphic/src/cache/types.ts`)**:
   - Introduced `enum ContentCacheStrategyId`:
     - `Memory = 'memory'`
     - `NativeFile = 'native-file'`
     - `IndexedDb = 'indexeddb'`
     - `WebCache = 'web-cache'`
   - Updated `IContentCacheStrategy.id` to `ContentCacheStrategyId | string`.
3. **Registry & Strategy Refactoring**:
   - `ContentCacheRegistry.ts`: Updated `setDefault`, `get`, `has`, and `strategies` map keys to accept `ContentCacheStrategyId | string`.
   - `MemoryCacheStrategy.ts`: `public readonly id = ContentCacheStrategyId.Memory`.
   - `IndexedDbCacheStrategy.ts`: `public readonly id = ContentCacheStrategyId.IndexedDb`.
   - `WebCacheStrategy.ts`: `public readonly id = ContentCacheStrategyId.WebCache`.
   - `NativeFileCacheStrategy.ts`: `public readonly id = ContentCacheStrategyId.NativeFile`.
   - `PlatformDetector.ts`: Updated `resolveDefaultMediaEngine()` and `resolveDefaultCacheStrategy()` to return `MediaEngineType` and `ContentCacheStrategyId` enum values.
   - `bootstrapClient()` & `bootstrapNode()`: Replaced string literals with enum values.
4. **Test Suite Verification**:
   - Updated `autogenerated-tests/platform_detector.test.ts` to assert against enum values.
