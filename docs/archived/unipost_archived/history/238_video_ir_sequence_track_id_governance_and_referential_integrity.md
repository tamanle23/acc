# 238: VideoIR Sequence & Track ID Governance, Hierarchical Authoring, and Referential Integrity

## Problem
In the Video Intermediate Representation (VideoIR) specification and Studio authoring pipeline, sequence and track identities lacked a formal distinction between system-level unique keys (`id`) and human-editable display labels (`name`). As users dragged sequences between tracks or reordered tracks, volatile track-bound identifiers (e.g. `seq_v1_1` on track 1) broke relational DAG links (`after`, `syncWith`, `matchLengthOf`, `editorial/av_link`, `transition/crossfade`) or resulted in confusing identifiers when moved. Furthermore, `VideoIRSchemaValidator` did not enforce global uniqueness of sequence IDs across all tracks or validate referential integrity against dangling or self-referential relations.

## Plan
1. Synchronize VideoIR specifications, TypeScript types (`VideoIR.ts`), and JSON Schema (`video-ir.schema.json`) with `name?: string;` on `IRSequence` and `nextSequenceIndex?: number;` on `IRMeta`.
2. Enhance `VideoIRSchemaValidator` with global sequence ID uniqueness checks and two-pass referential integrity validation for all relational pointers.
3. Build a universal, lightweight sequential authoring engine (`VideoIRAuthoringEngine`) in `packages/ir` providing track-move immune IDs (`seq_<modality>_<slug>_<globalIndex>`) backed by monotonic high-water mark counters.
4. Integrate `SplitSequenceCommand`, `DuplicateSequenceCommand`, `AddSequenceCommand`, and `AddLinkedAVSequenceCommand` with `VideoIRAuthoringEngine`.
5. Create comprehensive automated test suite and verify backwards compatibility.

  - Added `name?: string;` to `IRSequence`.
  - Added `nextSequenceIndex?: number;` to `IRMeta`.

  - Added `name` to `IRSequence` definition.
  - Added `nextSequenceIndex` to `IRMeta` definition.
- **`packages/ir/src/schema/VideoIRSchemaValidator.ts`**:
  - Added global sequence ID uniqueness tracking across all tracks.
  - Implemented Pass 2 referential integrity validation rejecting dangling references and self-referential relations.
- **`packages/ir/src/authoring/VideoIRAuthoringEngine.ts`**:
  - Created zero-allocation authoring engine with slug sanitization, monotonic ID allocation, track-move invariance, razor split lifecycle, and track ID generation.
- **`packages/ir/src/index.ts`**:
  - Exported `VideoIRAuthoringEngine` from `@acc/ir`.
- **`apps/studio/src/lib/commands/`**:
  - Updated `SplitSequenceCommand.ts`, `DuplicateSequenceCommand.ts`, `AddSequenceCommand.ts`, and `AddLinkedAVSequenceCommand.ts` to utilize `VideoIRAuthoringEngine`.
- **`docs/ir/1. video_(IR)_specification.md`**:
  - Documented `id` vs `name` semantics, track-move immunity, and referential integrity constraints.
- **`autogenerated-tests/video_ir_identity_and_referential_integrity.test.ts`**:
  - Created 17 test cases covering uniqueness, dangling relational rejection, self-reference rejection, monotonic high-water mark progression, and command lifecycle execution.
