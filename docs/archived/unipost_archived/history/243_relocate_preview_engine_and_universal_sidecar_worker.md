# 243: Relocate Preview Engine to Studio & Universal Sidecar Worker

## Problem
1. `IRPreviewEngine` in `packages/ir/src/renderer/preview/` coupled browser/client preview rendering concerns into `@acc/ir`, which is intended as an isomorphic, canonical representation and headless export engine.
2. In Iteration 36, an ad-hoc `visionWorker.ts` and `StudioVisionPipelineManager.ts` were introduced specifically for ONNX vision models, bypassing the canonical `ModifierPlugin.execute()` contract and failing to provide a generalized preflight mechanism for other modifiers.
3. Adding and removing sequences during interactive timeline editing lacked coordinated task cancellation and priority queueing.

## Plan
1. Move mathematical motion evaluators (`BezierMath`, `TemporalKeyframeEvaluator`, `DeterministicMotionEvaluator`) into `packages/ir/src/motion/`.
2. Move `IRPreviewEngine` and preview texture management into `apps/studio/src/renderer/preview/`.
3. Establish a universal `StudioSidecarWorker` (`apps/studio/src/workers/preview-sidecar.worker.ts`) and `StudioSidecarCoordinator` (`apps/studio/src/renderer/preview/sidecar/StudioSidecarCoordinator.ts`).
4. Wire sidecar preflight into `IRPreviewEngine`, providing priority-based queueing, non-blocking fallback, sequence cancellation, and reactive `onModifierWarmed` frame redraws.
5. Decommission `visionWorker.ts` and `StudioVisionPipelineManager.ts`.
6. Update all test suites and verify 100% parity and zero native import leaks.

## Changes
- **`packages/ir`**:
  - Relocated motion math to `packages/ir/src/motion/` (`BezierMath.ts`, `TemporalKeyframeEvaluator.ts`, `DeterministicMotionEvaluator.ts`, `index.ts`).
  - Removed `packages/ir/src/renderer/preview/`.
  - Re-exported motion evaluators from root `@acc/ir`.
- **`apps/studio`**:
  - Created `apps/studio/src/renderer/preview/IRPreviewEngine.ts` and `AssetTextureCache.ts`.
  - Created `apps/studio/src/renderer/preview/sidecar/SidecarTypes.ts` and `StudioSidecarCoordinator.ts`.
  - Created `apps/studio/src/workers/preview-sidecar.worker.ts`.
  - Removed `apps/studio/src/workers/visionWorker.ts` and `apps/studio/src/lib/vision/StudioVisionPipelineManager.ts`.
  - Updated `App.tsx`, `Preview.tsx`, `WebAudioEngine.ts`, `preview.worker.ts`, `package.json`, and `tsconfig.json`.
- **`autogenerated-tests`**:
  - Created `autogenerated-tests/studio_sidecar_coordinator.test.ts`.
  - Updated all test import paths to import `IRPreviewEngine` from `@acc/studio` and motion math from `@acc/ir`.
