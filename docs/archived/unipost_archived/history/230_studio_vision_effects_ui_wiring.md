# History Entry 230: Studio Vision Effects UI Wiring & Interactive Integration

## Problem
Following Iteration 27's consolidation of `VisionEngineRegistry`, the Studio UI (`apps/studio`) lacked interactive UI controls to leverage vision features:
1. No first-class Auto-Reframe modifier plugin existed in `@acc/ir` to apply `AutoReframeStrategy`.
2. `DynamicModifierInspector` rendered raw numbers rather than strategy selector controls with awareness of heuristic vs neural execution models.
3. The Transform Gizmo's `ContextualActionPill` lacked one-click 3D depth and cutout operations.
4. The Viewport Control Bar had no way to trigger depth disparity diagnostics on the canvas.
5. `IRPreviewEngine` needed to support transient diagnostic overlays without violating Node.js vs Web runtime parity or bypassing canonical modifier plugins.
