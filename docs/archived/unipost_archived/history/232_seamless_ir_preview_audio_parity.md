# Task History #232: Seamless Audio-Visual Parity (Integrating UniversalAudioMixer into IRPreviewEngine)

## Problem
`IRMasterRenderer` (the offline export renderer) seamlessly handles both visual composition and full multi-track audio mixdown via `UniversalAudioMixer`, with dynamic dialogue ducking and soft limiter compression. However, `IRPreviewEngine` in `@acc/ir` was purely visual, forcing `@acc/studio` (`WebAudioEngine.ts`) to maintain duplicate timeline parsing logic (~120 lines of redundant track/clip inspection) and manually coordinate audio with the visual preview.

## Solution & Architecture
1. **Integrated `UniversalAudioMixer` into `IRPreviewEngine`**:
   - `IRPreviewEngine` now natively manages `UniversalAudioMixer`.
   - Added `previewEngine.syncTimeline(timeline, audioSourceResolver)` and `previewEngine.renderAudioSlice(timeSec, durationSec)` alongside `renderFrame(frame, ctx)`.
   - Added `UniversalAudioMixer.syncFromTimeline(timeline, audioSourceResolver)` to automatically map tracks, volume, pan, and dynamic ducking directly from `ResolvedTimeline`.
2. **Refactored `WebAudioEngine` to Delegate to `IRPreviewEngine`**:
   - Eliminated redundant track iteration in `WebAudioEngine.syncFromIR()`.
   - `WebAudioEngine` now acts purely as the hardware audio sink and continuous multi-chunk streaming driver (`AudioBufferSourceNode -> masterGain -> analyser -> destination`).
   - Implemented lookahead replenishment in `WebAudioEngine`: checks every 1000ms and proactively schedules the next 5.0-second slice if remaining buffer is $< 2.0$s.
3. **Parity Verification**:
   - Authored `autogenerated-tests/ir_preview_master_renderer_audio_parity.test.ts` verifying identical clip extraction, synchronized state updates, and sample consistency between `IRPreviewEngine` and `IRMasterRenderer`.

## Changes
- `packages/ir/src/renderer/audio/UniversalAudioMixer.ts`: Added `syncFromTimeline` method for single-source-of-truth audio track extraction.
- `packages/ir/src/renderer/preview/IRPreviewEngine.ts`: Encapsulated `UniversalAudioMixer`, exposed `renderAudioSlice()` and `syncTimeline()`.
- `apps/studio/src/lib/audio/WebAudioEngine.ts`: Cleaned up manual track parsing, added `attachPreviewEngine()`, and implemented continuous 5.0s scheduled audio chunk streaming into the Master Bus.
- `apps/studio/src/components/Preview.tsx`: Connected `previewEngine` instance to `WebAudioEngine`.
- `autogenerated-tests/ir_preview_master_renderer_audio_parity.test.ts`: Added unit test suite for audio-visual parity between interactive preview and master renderer.
