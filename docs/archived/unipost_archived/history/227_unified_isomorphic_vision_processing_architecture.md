# Task 227: Unified Isomorphic Vision Processing Architecture

## Problem Statement
Vision capabilities across the monorepo were historically split into two packages:
- `@acc/core-isomorphic/src/vision/`: Contracts (`IDepthEstimationStrategy`, `ISubjectSegmentationStrategy`), `VisionEngineRegistry`, and pure algorithmic fallbacks (`HeuristicDepthStrategy`, `GrabCutFallbackStrategy`).
- `@acc/effect-engines/src/vision/`: Heavy neural models (`DepthAnythingV2`, `RMBG`, `BiRefNet`, `SAM2`, `Transformers.js`, `ONNX Runtime WASM/WebGPU`), context classes (`DepthEstimationContext`, `SubjectSegmentationContext`), and pure math/camera utilities (`SurfaceNormalGenerator`, `CameraSplineInterpolator`, `AutoReframeStrategy`).

This structure led to:
1. Code duplication of fallback strategies (`HeuristicDepthStrategy` and `GrabCutFallbackStrategy` existing in both packages).
2. Tight coupling of neural strategies to Node.js `Buffer` arguments, preventing clean isomorphic usage.
3. Entrapment of pure algorithmic utilities (`SurfaceNormalGenerator`, `CameraSplineInterpolator`, `AutoReframeStrategy`) in `@acc/effect-engines`, preventing lightweight web clients or web workers from using them cleanly without importing neural dependencies.
4. Divergent orchestration paths between `DepthEstimationContext` / `SubjectSegmentationContext` and `VisionEngineRegistry`.

## Plan
1. Promote pure algorithmic math and camera utilities (`SurfaceNormalGenerator`, `CameraSplineInterpolator`, `AutoReframeStrategy`) from `@acc/effect-engines/src/vision/` to `@acc/core-isomorphic/src/vision/`.
2. Provide backward-compatible re-exports with `@deprecated` docstrings in `@acc/effect-engines/src/vision/` to avoid breaking existing import paths.
3. Refactor duplicate fallback strategies (`HeuristicDepthStrategy`, `GrabCutFallbackStrategy`) in `packages/effect-engines` to wrap and re-export the `@acc/core-isomorphic` implementations, supporting both Node `Buffer` and `VisionImageInput`.
4. Standardize all neural strategies (`DepthAnythingV2BaseStrategy`, `GlpnMetricStrategy`, `DptLargeStrategy`, `BiRefNetStrategy`, `Sam2TinyStrategy`, `SamVitBaseStrategy`, `SlimSamStrategy`) to accept `Buffer | Uint8Array | VisionImageInput` with automatic defensive fallback to heuristics.
5. Unify `DepthEstimationContext` and `SubjectSegmentationContext` into facades backed by `VisionEngineRegistry`.
6. Verify monorepo boundaries via `scripts/check-native-imports.ts` and verify test suites across both packages.

## Changes
- **Core Isomorphic (`packages/core-isomorphic/src/vision/`)**:
  - Added `AutoReframeStrategy.ts`: Pure saliency and EMA crop calculation.
  - Added `CameraSplineInterpolator.ts`: Catmull-Rom & Bezier 3D camera trajectory evaluator.
  - Added `SurfaceNormalGenerator.ts`: 3x3 Sobel gradient convolution and Blinn-Phong relighting.
  - Updated `index.ts` to export the promoted utilities.
- **Effect Engines (`packages/effect-engines/src/vision/`)**:
  - `AutoReframeStrategy.ts`, `CameraSplineInterpolator.ts`, `SurfaceNormalGenerator.ts`: Replaced implementations with re-exports from `@acc/core-isomorphic`.
  - `strategies/depth/HeuristicDepthStrategy.ts`: Facade wrapping `@acc/core-isomorphic`'s `HeuristicDepthStrategy` supporting dual `Buffer` & `VisionImageInput`.
  - `strategies/segmentation/GrabCutFallbackStrategy.ts`: Facade wrapping `@acc/core-isomorphic`'s `GrabCutFallbackStrategy` supporting dual `Buffer` & `VisionImageInput`.
  - `strategies/depth/DepthAnythingV2BaseStrategy.ts`, `GlpnMetricStrategy.ts`, `DptLargeStrategy.ts`: Standardized on isomorphic inputs with defensive cascading to heuristics.
  - `strategies/segmentation/BiRefNetStrategy.ts`, `Sam2TinyStrategy.ts`, `SamVitBaseStrategy.ts`, `SlimSamStrategy.ts`: Standardized on isomorphic inputs with defensive cascading to heuristics.
  - `DepthEstimationContext.ts`, `SubjectSegmentationContext.ts`: Synced with `VisionEngineRegistry`.
- **Tests & Verification**:
  - `autogenerated-tests/transformers_js_vision.test.ts`: Initialized with `bootstrapNode()` to hook `UniversalCanvasProvider`.
