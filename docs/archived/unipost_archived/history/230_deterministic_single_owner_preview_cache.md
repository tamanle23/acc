# Task 230: Deterministic Single-Owner Cache & Post-Render Drain in Studio Preview

## Problem
In `apps/studio/src/workers/preview.worker.ts`, video rendering threw:
```
preview.worker.ts:129 [preview.worker] Render error at frame 214 InvalidStateError: Failed to execute 'drawImage' on 'OffscreenCanvasRenderingContext2D': The image source is detached
```
An initial workaround used `setTimeout(..., 50)` before `.close()`. This heuristic timer was fragile under GPU/CPU pressure and violated deterministic clean-code engineering invariants.

## Root Cause Analysis
1. **Uncoordinated Dual Ownership**: Both `MediabunnyWorkerReader.ringBuffer` and `PreviewFrameMemoryManager.frameMap` held and evicted the exact same underlying `ImageBitmap` reference.
2. **Pre-Draw Eviction Collision**: Lookahead prewarming and LRU pruning outside the playhead window (`[playhead - 2s, playhead + 3s]`) ran right before or concurrently with `engine.renderFrame()`, closing bitmaps still present in `textureCache`.

## Plan
1. Convert `MediabunnyWorkerReader` into a pure stateless decoder, removing its internal `ringBuffer` and all `.close()` calls.
2. Make `PreviewFrameMemoryManager` the single owner of decoded `ImageBitmap` lifecycle with a staged `pendingDisposal` queue.
3. Drain the disposal queue in a `finally` block in `preview.worker.ts` after each render pass, protecting actively drawn bitmaps.
4. Eliminate all `setTimeout` calls and verify with unit tests and production builds.

## Changes
- **`apps/studio/src/workers/MediabunnyWorkerReader.ts`**:
  - Removed `ringBuffer`, `ringBufferSize`, `evictFrame`, `pruneOutsideWindow`, and `getRingBufferFrames`.
  - Streamlined `requestFrame()` to decode directly and return the decoded `ImageBitmap`.
  - Retained `dispose()` for underlying `Input` and `CanvasSink` cleanup.
- **`apps/studio/src/workers/PreviewFrameMemoryManager.ts`**:
  - Removed `setTimeout(..., 50)`.
  - Added `pendingDisposal: ImageBitmap[]`.
  - Staged evicted bitmaps in `pendingDisposal`.
  - Added `drainDisposalQueue(protectedBitmaps?: Set<ImageBitmap>)`.
- **`apps/studio/src/workers/preview.worker.ts`**:
  - Wrapped `engine.renderFrame(...)` in a `try ... finally` block.
  - In `finally`, gathered all bitmaps from `textureCache` into `protectedBitmaps` and called `memoryManager.drainDisposalQueue(protectedBitmaps)`.
- **`autogenerated-tests/preview_frame_memory_manager_drain.test.ts`**:
  - Authored comprehensive test suite covering cache storage, window-pruning staging without premature close, protected bitmap preservation, and LRU disposal draining.
- **`autogenerated-tests/mediabunny_ring_buffer.test.ts`**:
  - Harmonized with stateless decoder interface.
