# Task 239: Connect Isomorphic Vision Pipeline into Studio UI (Iteration 36)

## Problem
1. **Studio Bootstrap Disconnection**: `apps/studio/src/bootstrap.ts` only initialized canvas and mediabunny, leaving `VisionEngineRegistry` and client content caches unconfigured for in-browser visual effects.
2. **Missing In-Browser Depth & Cutout Execution**: `Depth3DPlugin.ts` lacked native browser clip-space resolution and pass inspection, relying on server-only dynamic `require('@acc/effect-engines')`.
3. **Canvas Gizmo Fragmentation**: In-canvas lighting controls were missing a dedicated, isolated `@dnd-kit` overlay context, creating potential event bubbling conflicts with 2D transform handles.
4. **Lack of Viewport Pass Inspection**: No direct controls existed in `ViewportControlBar.tsx` to inspect depth buffers, surface normals, or alpha cutouts in real time.
5. **Playback Stutter**: Real-time 60 FPS playback required protective caching via `ContentCacheRegistry` and background eager warmup to eliminate neural inference UI thread blocking.

## Plan
1. **Component 1 (Client Bootstrap & Plugin Scope)**:
   - Ensure `apps/studio/src/bootstrap.ts` delegates to `@acc/core-web` `bootstrapCoreWeb()`.
   - Restrict `Depth3DPlugin` exclusively to sequence `image` types (`sequence.type === 'image'`).
   - Wire `VisionEngineRegistry` strategies directly into `Depth3DPlugin`.
2. **Component 2 (Background Vision Worker & Pipeline Manager)**:
   - Implement `apps/studio/src/workers/visionWorker.ts` for off-thread eager warmup and frame caching.
   - Implement `StudioVisionPipelineManager.ts` to observe playhead pauses and orchestrate on-demand frame vision computations.
3. **Component 3 (Plugin Parity & Catalog)**:
   - Standardize canonical auto-reframe under `vfx/auto_reframe` (`AutoReframeModifierPlugin`).
   - Add `LightVectorControlStrategy` to `ModifierControlStrategies.tsx` and register in modifier catalogs.
4. **Component 4 (Preview Canvas & Pass Inspection)**:
   - Expand `debugMode` in `ClipRenderContext`, `IRCanvasCompositor`, `IRPreviewEngine`, `PreviewWorkerBridge`, and `preview.worker.ts` to `'none' | 'depth_heatmap' | 'normals' | 'alpha'`.
   - Implement standalone `LightGizmoOverlay.tsx` with its own isolated `@dnd-kit` `DndContext`.
   - Add Vision Pass Selector (`Composite`, `Depth`, `Normals`, `Alpha`) to `ViewportControlBar.tsx` with `Shift+V` keyboard shortcut.
