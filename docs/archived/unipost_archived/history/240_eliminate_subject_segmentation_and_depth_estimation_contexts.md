# 240. Eliminate SubjectSegmentationContext and DepthEstimationContext

## Problem
In earlier iterations, `packages/effect-engines/src/vision/` contained legacy singleton contexts (`SubjectSegmentationContext` and `DepthEstimationContext`) that duplicated strategy discovery, manual conversions, and dispatching. Following the introduction of the unified isomorphic `VisionEngineRegistry` in `@acc/core-isomorphic`, these two legacy classes introduced redundant layers, dual sources of truth for strategy resolution, and lingering Node-specific `Buffer` conversions.

## Plan
1. Extend `packages/core-isomorphic/src/vision/types.ts` with missing strategy enum identifiers (`DepthStrategyId.DptLarge`, `SegmentationStrategyId.Sam2Tiny`, `SegmentationStrategyId.SamVitBase`).
2. Implement `IIsomorphicDepthStrategy` / `IIsomorphicSegmentationStrategy` on all effect-engine vision strategies so each strategy has `id`, `name`, and `isSupported = true`.
3. Migrate callers in `packages/effect-engines/src/depth3d/index.ts` from `SubjectSegmentationContext` and `DepthEstimationContext` to `VisionEngineRegistry.getSegmentationStrategy()` and `VisionEngineRegistry.getDepthStrategy()`.
4. Delete `packages/effect-engines/src/vision/SubjectSegmentationContext.ts` and `packages/effect-engines/src/vision/DepthEstimationContext.ts`, and update the barrel export in `packages/effect-engines/src/vision/index.ts`.
5. Migrate tests in `autogenerated-tests/configurable_media_engine_and_onnx.test.ts`, `autogenerated-tests/depth_strategies_benchmark.test.ts`, and `autogenerated-tests/transformers_js_vision.test.ts` to directly use `VisionEngineRegistry`.
6. Verify zero remaining references across monorepo and run native import linter guardrails.

## Changes
- **`packages/core-isomorphic/src/vision/types.ts`**: Added `DepthStrategyId.DptLarge`, `SegmentationStrategyId.Sam2Tiny`, `SegmentationStrategyId.SamVitBase`.
- **`packages/effect-engines/src/vision/strategies/`**:
  - Implemented isomorphic interfaces and explicit IDs on `DptLargeStrategy`, `DepthAnythingV2BaseStrategy`, `GlpnMetricStrategy`, `HeuristicDepthStrategy`.
  - Implemented isomorphic interfaces and explicit IDs on `Sam2TinyStrategy`, `SamVitBaseStrategy`, `BiRefNetStrategy`, `SlimSamStrategy`, `GrabCutFallbackStrategy`.
- **`packages/effect-engines/src/depth3d/index.ts`**:
  - Replaced context singletons with `VisionEngineRegistry.getSegmentationStrategy()` and `VisionEngineRegistry.getDepthStrategy()`.
  - Cleaned up auto-segmentation and depth map resolution to use isomorphic registry contracts directly.
- **`packages/effect-engines/src/vision/SubjectSegmentationContext.ts` & `DepthEstimationContext.ts`**:
  - Completely deleted obsolete context files.
- **`packages/effect-engines/src/vision/index.ts`**:
  - Removed barrel exports for the deleted contexts.
- **`autogenerated-tests/`**:
  - Updated `configurable_media_engine_and_onnx.test.ts`, `depth_strategies_benchmark.test.ts`, and `transformers_js_vision.test.ts` to target `VisionEngineRegistry`.
- **`packages/ir/src/plugins/vfx/Depth3DPlugin.ts`**:
  - Simplified cutout resolution to use imported `resolveSubjectCutout` directly.
