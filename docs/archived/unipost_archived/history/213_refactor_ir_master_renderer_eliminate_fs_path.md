# Task 213: Refactor IRMasterRenderer to Eliminate fs/path Imports Using Universal ContentCacheRegistry

## Problem
`packages/ir/src/renderer/IRMasterRenderer.ts` contained direct static imports of Node.js `fs`, `path`, and `crypto` modules (`import crypto from 'crypto'; import fs from 'fs'; import path from 'path';`). This violated the isomorphic architecture invariants of `@acc/ir`, preventing pure isomorphic execution on web/worker runtimes without polyfills, and failed to leverage the isomorphic `ContentCacheRegistry` from `@acc/core-isomorphic`.

## Plan
1. Analyze all usages of `fs`, `path`, and `crypto` in `IRMasterRenderer.ts`:
   - Path resolution in `preloadAssets` (`path.isAbsolute`, `path.resolve`, `path.extname`).
   - Temp audio output path in `render` (`path.dirname`, `path.resolve`).
   - File existence checks and asset loading (`fs.existsSync`, `fs.promises.unlink`).
   - Cryptographic hashing (`crypto.createHash('sha256')`).
2. Replace static `path` utilities with pure isomorphic path manipulation functions (`isAbsolutePath`, `resolveAssetPath`, `getFileExtension`, `getDirectoryPath`).
3. Replace static `fs` calls with isomorphic `ContentCacheRegistry.get()` checks, reads, writes, and deletes:
   - In `preloadAssets`, check `ContentCacheRegistry.get().has(resolvedPath)` and retrieve cached bytes via `get()`. Fall back to dynamic `import('fs')` guarded by `process.versions.node` only if not cached.
   - In `render`, encode mixed audio to standard 16-bit WAV bytes using `UniversalAudioMixer.encodeToWav()` and cache in `ContentCacheRegistry`. Clean up temporary audio files from cache and optional disk on completion.
4. Replace static `crypto` with `UniversalHasher` class supporting dynamic `import('crypto')` when in Node/Bun and `globalThis.crypto.subtle.digest('SHA-256')` in web/worker environments.
5. In `UniversalAudioMixer`, export pure isomorphic `encodeToWav(mixResult: DecoupledAudioMixResult): Uint8Array` using `DataView` without Node `Buffer.alloc`.
6. Add unit and integration tests in `autogenerated-tests/ir_master_renderer_cache_refactor.test.ts` verifying:
   - Asset preloading directly from `ContentCacheRegistry` without disk access.
   - Zero static imports of `fs`, `path`, or `crypto` in `IRMasterRenderer.ts`.
   - 100% bit-identical hash parity in `ir_renderer_web_server_parity.test.ts`.

## Changes
- `packages/ir/src/renderer/IRMasterRenderer.ts`:
  - Removed `import crypto from 'crypto'`, `import fs from 'fs'`, and `import path from 'path'`.
  - Added import `{ UniversalCanvasProvider, CanvasAssetLoader, ContentCacheRegistry } from '@acc/core-isomorphic'`.
  - Implemented isomorphic path helper functions (`isAbsolutePath`, `resolveAssetPath`, `getFileExtension`, `getDirectoryPath`).
  - Implemented `UniversalHasher` for zero-static-import SHA-256 hash generation.
  - Updated `preloadAssets` to check and consume `ContentCacheRegistry.get()`.
  - Updated `render` to persist audio WAV to `ContentCacheRegistry` and clean up.
- `packages/ir/src/renderer/audio/UniversalAudioMixer.ts`:
  - Implemented `encodeToWav(mixResult: DecoupledAudioMixResult): Uint8Array` using pure isomorphic `DataView` and `Uint8Array`.
  - Refactored `exportToWav` to delegate to `encodeToWav`.
- `autogenerated-tests/ir_master_renderer_cache_refactor.test.ts`:
  - Added automated test suite verifying in-memory asset preloading via `ContentCacheRegistry` and source static import validation.
