# 224: Isomorphic VisionEngineRegistry Architecture with Synchronized Bootstrap Pairing

**Target Systems:**
- `@acc/core-isomorphic` (`packages/core-isomorphic/src/vision`, `packages/core-isomorphic/src/platform`)
- `@acc/core-web` (`packages/core-web/src/index.ts`)
- `@acc/core` (`packages/core/src/bootstrap.ts`, `packages/core/package.json`)
- `@acc/effect-engines` (`packages/effect-engines/src/vision`)
- `autogenerated-tests/` (`vision_engine_registry.test.ts`, `core_web_services.test.ts`, `core_node_bootstrap.test.ts`, `depth_strategies_benchmark.test.ts`)

---

## 1. Problem Statement
1. AI vision strategies for depth estimation and subject segmentation were isolated in `@acc/effect-engines` with ad-hoc context singletons (`DepthEstimationContext`, `SubjectSegmentationContext`) and hardcoded Node `Buffer` types.
2. `bootstrapClient()` in `@acc/core-web` and `bootstrapNode()` in `@acc/core` coordinated canvas, audio/video encoding, and caching, but lacked unified vision registration and capability negotiation.
3. Neural models (`DepthAnythingV2SmallStrategy`, `RmbgStrategy`) threw unhandled fetch/file exceptions when running offline without pre-staged model weights.

---

## 2. Changes Made
1. **`VisionEngineRegistry` in `@acc/core-isomorphic`**:
   - Defined typed string enums: `VisionDomain`, `DepthStrategyId`, and `SegmentationStrategyId`.
   - Defined pure isomorphic data contracts (`VisionImageInput`, `DepthEstimationResult`, `SubjectSegmentationResult`) accepting `Uint8Array` byte data and optional `ICanvasInstance` for zero-copy passes.
   - Built singleton `VisionEngineRegistry` for managing depth and segmentation strategies with query, registration, default selection, and reset capabilities.
2. **Isomorphic Fallback Strategies**:
   - Created `HeuristicDepthStrategy` (luminance gradient + perspective falloff) and `GrabCutFallbackStrategy` (color clustering and spatial bounding box) in `@acc/core-isomorphic/src/vision/strategies/`, executing in ~1-2ms with zero external weight downloads.
3. **`PlatformDetector` Extensions**:
   - Added `resolveDefaultDepthStrategy()` and `resolveDefaultSegmentationStrategy()` resolving `heuristic`/`grabcut-fallback` on browsers and `depth-anything-v2-small`/`rmbg-1.4` on server runtimes.
4. **Synchronized Bootstrap Integration**:
   - Updated `bootstrapClient()` in `@acc/core-web/src/index.ts` to register `HeuristicDepthStrategy` and `GrabCutFallbackStrategy`.
   - Added `@acc/effect-engines` as a direct dependency in `packages/core/package.json`.
   - Updated `bootstrapNode()` in `@acc/core/src/bootstrap.ts` to register neural and fallback strategies, synchronized with `PlatformDetector`.
5. **Defensive Neural Cascading**:
   - Updated `DepthAnythingV2SmallStrategy` and `RmbgStrategy` in `@acc/effect-engines` to catch model fetch failures and transparently cascade to `HeuristicDepthStrategy` / `GrabCutFallbackStrategy`.
6. **Facade Alignment**:
   - Updated `DepthEstimationContext` and `SubjectSegmentationContext` in `@acc/effect-engines` to delegate to `VisionEngineRegistry`.
