## 1. Context & Problem
Currently, AI subject segmentation (SAM) and depth estimation (Depth Anything v2) rely on an external Python backend over gRPC or local fallback heuristics (OpenCV GrabCut / PIL Saliency). While GrabCut provides basic masking, delicate anatomical structures like sharp horns, crest spikes, and fine claws can be clipped or require manual coordinate tuning.

## 2. Proposed Design
Integrate `@huggingface/transformers` (Transformers.js v3) directly into `@acc/effect-engines` using the **Strategy Design Pattern**:
1. **Segmentation Strategy Interface (`ISegmentationStrategy`)**:
   - `SlimSamStrategy` (`Xenova/slimsam-77-uniform` - fast, 38MB, default).
   - `SamVitBaseStrategy` (`Xenova/sam-vit-base` - high-precision, 130MB).
   - `FastSamStrategy` (`Xenova/FastSAM-x` - ultra-fast).
   - `GrabCutFallbackStrategy` (defensive local fallback).
   - `SegmentationContext` / `SubjectSegmentationEngine` for seamless runtime model switching.
2. **Depth Estimation Strategy Interface (`IDepthEstimationStrategy`)**:
   - `DepthAnythingV2SmallStrategy` (`onnx-community/depth-anything-v2-small` - 95MB, default).
   - `DepthAnythingV2BaseStrategy` (`onnx-community/depth-anything-v2-base` - 380MB).
   - `HeuristicDepthStrategy` (defensive gradient/saliency fallback).
   - `DepthEstimationContext` / `NativeDepthEngine` for dynamic switching.
3. Seamless integration into `Depth3DDispatcher` and `FrameBreakerEngine` with zero Python dependency and global model caching in `~/.cache/huggingface`.
