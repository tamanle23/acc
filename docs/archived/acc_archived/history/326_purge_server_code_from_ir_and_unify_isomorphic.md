# History Entry 326: Purge Server Code from @acc/ir into Core and Unify Pure Isomorphic Video IR

**Date:** 2026-10-24
**Status:** Completed
**Author:** AI Agent (TypeScript Node Architect)

## Context & Motivation
Under Phase 5 of `docs/master_integration_plan_iteration30.md`, `@acc/ir` was configured with `./client` and `./server` subpath exports. Furthermore, server-only batch worker orchestrators (`IRChunkWorkerPool` and `FFIChunkConcatMuxer`), proxy video frame sinks (`FFIVideoEncoderSink`, `FluentPipeVideoSink`, `MediabunnyServerSink`, `MediaSinkFactory`), and direct `@acc/core` dependencies polluted `@acc/ir`, preventing it from being a 100% pure isomorphic package.

## Key Changes
1. **Relocated Server IR Workers to `@acc/core`**:
   - Transferred `IRChunkWorkerPool.ts` and `FFIChunkConcatMuxer.ts` from `packages/ir/src/workers/` to `packages/core/src/ir-server/`.
   - Exported them through `packages/core/src/ir-server/index.ts` and `packages/core/src/index.ts`.
   - Updated `IRChunkWorkerPool` to dynamically obtain sinks via `MediaEngineRegistry.get(options.engine).createVideoSink()` rather than proxy sink factories.
2. **Purged Proxy Sinks and Subpaths in `@acc/ir`**:
   - Deleted `packages/ir/src/renderer/sink/` proxy stubs (`FFIVideoEncoderSink.ts`, `FluentPipeVideoSink.ts`, `MediabunnyServerSink.ts`, `MediaSinkFactory.ts`).
   - Deleted `packages/ir/src/client.ts`, `packages/ir/src/server.ts`, and `packages/ir/src/workers/`.
   - Updated `packages/ir/package.json`: removed `./client` and `./server` from `exports` (exporting only `.` root), and completely removed `"@acc/core"` from `dependencies`.
   - Decoupled `IIRFrameSink` and `IRMasterRenderer` from `@acc/core` by importing `IMediaFrameSink` and `MediaEngineRegistry` from `@acc/core-isomorphic`.
3. **Decoupled Node.js Path Dependency from Adapters**:
   - Replaced `path.resolve` in `PipelineIRToUniversalIRAdapter` and `StoryConfigToUniversalIRAdapter` with isomorphic path resolution (`startsWith('/')`, `http(s)://`, `data:`, `blob:`, and Windows drive letter regex matching).
4. **Updated Consumers Across Apps & Exporters**:
   - Updated `apps/cli/src/commands/ir-render.ts`, `VideoEditPipelineOrchestrator.ts`, `StoryOrchestratedRenderStage.ts`, and `UIStudioPreviewEngine.ts` to import `IRChunkWorkerPool` and `FFIVideoEncoderSink` from `@acc/core`, and `IRMasterRenderer` directly from `@acc/ir`.
   - Updated `packages/exporters/src/video/VideoExporter.ts` to import `IRMasterRenderer` from `@acc/ir` and dynamic sink from `MediaEngineRegistry`.
5. **Verification**:
   - Created `autogenerated-tests/ir_isomorphic_unification.test.ts` verifying package exports, zero `@acc/core` dependency, isomorphic document validation, compilation, and adapter path resolution.
   - Verified that 26 tests across 7 test suites pass cleanly with 0 unauthorized native import leaks (`bun run scripts/check-native-imports.ts`).
