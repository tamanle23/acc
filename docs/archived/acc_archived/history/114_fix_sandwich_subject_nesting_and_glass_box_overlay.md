# 114. Fix Sandwich Subject Layer Nesting & Eliminate Glass Box Overlay

## Problem & Context
In `volumetric_sandwich` rendering:
1. A missing closing brace on the `if (subjectImg)` block in [`packages/effect-engines/src/depth3d/sandwich.ts`](packages/effect-engines/src/depth3d/sandwich.ts) caused the fallback background clipping layer (`drawImageCover(ctx, img, ...)`) to execute concurrently with the cutout subject.
2. This drew a shadowed rectangular plate over the top/middle of the frame (appearing as a "glass box / top overlay"), completely occluding the 3D banner text in midground layer 2.

## Solution & Implementation
1. **Restored Proper `if (subjectImg) ... else ...` Separation**:
   - Closed the `if (subjectImg)` block so that when a cutout subject is present (`subjectImg`), only the cutout is drawn in layer 3.
   - The fallback rectangular/center mask now runs strictly when `subjectImg` is null.
2. **Verified Bottom Banner Text Rendering**:
   - Verified that the 3D banner text at `"position": "bottom"` (Y ~ 75%) renders cleanly in the midground layer without any obscuring overlays.
3. **Automated Testing**:
   - Ran `autogenerated-tests/sandwich_positioning.test.ts` and `autogenerated-tests/phase3_depth3d_vision.test.ts` (12/12 passed).

## Changes Made
- `packages/effect-engines/src/depth3d/sandwich.ts`: Fixed conditional branching in layer 3 to cleanly separate `subjectImg` from fallback masking.
