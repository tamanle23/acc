## Key Changes
1. **Base Button Component Semantic Remap (`button.tsx`)**:
   - Remapped `variant="default"` from hardcoded `bg-indigo-600 text-white hover:bg-indigo-700` to dynamic Liquid Glass primary accent tokens:
     `bg-[var(--accent-primary)] text-slate-950 font-semibold shadow-[0_0_12px_var(--accent-glow)] hover:brightness-110 active:scale-[0.98]`.
   - Updated focus rings and links to `focus-visible:ring-[var(--accent-primary)]` and `text-[var(--accent-primary)]`.
2. **Timeline Track Headers & Controls (`Timeline.tsx`)**:
   - Replaced raw HTML `<button>` track lock and mute tags with micro `Button` components using `variant="ghost"`, `text-muted-foreground hover:text-foreground`, and active states `text-amber-400 bg-amber-500/15` (locked) and `text-rose-400 bg-rose-500/15` (muted).
   - Replaced `bg-slate-100/90 border-slate-200` track headers with `bg-[var(--glass-bg)] border-[var(--glass-border)] backdrop-blur-md` glass panels.
   - Standardized `DroppableTrackLane` backgrounds to `bg-background/25 border-[var(--glass-border)]` and active drag state `bg-[var(--accent-primary)]/10 border-[var(--accent-primary)]/40`.
   - Modernized tool selectors, transport buttons, magnetic snap toggle, and timecode badges with semantic tokens.
3. **Titlebar Semantic Token Modernization (`Titlebar.tsx`)**:
   - Remapped IR logo badge to `bg-[var(--accent-primary)] text-slate-950 shadow-[0_0_12px_var(--accent-glow)]`.
   - Standardized version badge to `bg-[var(--accent-primary)]/10 text-[var(--accent-primary)] border-[var(--accent-primary)]/30`.
   - Updated template selector dropdown to `bg-[var(--glass-bg)] border-[var(--glass-border)] text-foreground`.
   - Converted Import IR to `variant="outline"` (`border-[var(--glass-border)] text-foreground`) and Save IR to accent glass badge.
   - Converted drawer toggles, theme toggle, and shortcuts to semantic `text-muted-foreground hover:text-foreground`.
4. **Automated Testing & Production Build**:
   - Implemented `autogenerated-tests/studio_theme_tokens.test.ts` to assert zero rogue `indigo-600` or `slate-100` classes in UI components.
   - All 169 tests pass across 27 files (`bun test autogenerated-tests/studio`).
   - Production bundle built cleanly in 3.84s (`bun run studio:build`).
