## 🎯 Context & Problem Statement
To elevate `apps/studio` into an enterprise-grade NLE tool for the **Universal Video IR V1.0-Stable Schema (Strict SSOT)**, the studio required:
1. Architectural robustness via a strict **Command & Strategy Pattern** for undo/redo with slider coalescing and branching integrity.
2. Cross-platform vector math parity between browser WebGL and server FFmpeg render loops via **`pts.js`**.
3. A rich, production-grade 9-track **Sci-Fi Cyberpunk Epic Demo** covering all 17 3D depth modes, SFX dynamic ducking, spatial pans, and procedural particle VFX.
4. Professional NLE ergonomics including an interactive **Timecode Ruler**, **Stereo L/R Peak VU Audio Level Meter**, tool selectors (`V`, `C`, `H`, `Z`), and a template switcher.

---

## 🛠️ Key Implementation Changes

### 1. Command & Strategy Pattern (`apps/studio/src/lib/commands/`)
- Implemented `ICommand` (`execute()`, `undo()`, `tryMerge()`).
- Implemented `IHistoryStrategy` and `CoalescingHistoryStrategy` (maxDepth = 50, coalesceWindowMs = 500ms) to coalesce continuous slider drags into atomic undoable steps.
- Implemented `HistoryManager` maintaining encapsulated `undoStack` and `redoStack`, purging `redoStack` on new actions.
- Concrete commands: `TrimSequenceCommand`, `SplitSequenceCommand`, `UpdateModifierCommand`.

### 2. pts.js Vector Math Engine (`apps/studio/src/lib/math/DepthMathEngine.ts`)
- Integrated `pts.js` (`Pt`, `Group`) for deterministic 2.5D camera parallax drift, stereo wigglegram eye vectors, and Frame-Breaker 3D pop-out geometry calculation.

### 3. Comprehensive Sci-Fi Cyberpunk Epic Demo (`complexSciFiDemoIR.ts`)
- 9 total tracks: 4 Video (`V1 Cyberpunk Plate`, `V2 3D Depth Hologram`, `V3 Volumetric VFX`, `V4 HUD Telemetry`), 3 Audio (`A1 Pilot Dialogue`, `A2 Impact SFX`, `A3 Synthwave BGM`), 2 Timed Text (`Subtitles`, `HUD Callouts`).
- Exercises all core modifiers: `vfx/color_grading`, `vfx/depth3d`, `overlay/canvas_particles`, `sfx/dynamic_ducking`, `transition/crossfade`.

### 4. Enterprise Broadcast UI/UX Ergonomics
- **TimecodeRuler**: Built `TimecodeRuler.tsx` with major second labels and minor frame ticks.
- **MasterAudioMeter**: Built `MasterAudioMeter.tsx` displaying real-time dual-channel Stereo L/R Peak VU meter (-60dB to 0dB with clip LEDs).
- **Tool Selector**: Integrated `V` (Selection), `C` (Razor), `H` (Hand), and `Z` (Zoom-to-fit) shortcuts and buttons.
- **Template Switcher**: Added Select dropdown in `Titlebar.tsx` allowing instant switching between Sci-Fi Epic (9-track) and Default Cinematic Reel (5-track).
- **Sidebar 3D Depth Inspector**: Added dynamic sliders for `vfx/depth3d` (`popOutIntensity`).
