## 1. Context & Objectives
In Tri-Pillar Architecture ([`docs/ir/10.TRI_PILLAR_PARITY_AUDIO_PERFORMANCE_IMPLEMENTATION_PLAN.md`](../ir/10.TRI_PILLAR_PARITY_AUDIO_PERFORMANCE_IMPLEMENTATION_PLAN.md)), Pillar 1 targets closing the feature parity gap between the experimental `processAndRender` method and the production `renderStoryVideo` multi-scene rendering engine.

Key gaps resolved:
1. **Safe-Zone Margin Enforcement:** Captions and typography overlays lacked platform-specific boundary padding (`tiktok`, `youtube`).
2. **J-Cut / L-Cut Split Edit Handling:** Audio lead-in / video lag offsets (`videoOffsetMs`) were calculated in `processAndRender` but not honored in scene rendering duration or padding in `renderStoryVideo`.
3. **Canvas LUT & Color Grading:** In-memory color grading and LUT filter logic were previously isolated as FFmpeg filter strings rather than being applied natively within the zero-alloc frame loop.
4. **Configurable Audio Ducking:** BGM sidechain compression was hardcoded; now configurable via IR/BGM ducking settings.
5. **Architectural SSOT:** Extracted `VideoEditPipelineOrchestrator.prepareIR()` as a reusable AST preparation pass, while preserving full backward-compatibility for `processAndRender`.

## 2. Implementation Summary

### 2.1 Subtitle & Canvas Safe Zones
- **`packages/effect-engines/src/subtitles/subtitles.ts`:**
  - Added `safeZonePlatform` parameter to `generateAssContent(...)`.
  - Dynamically calculates ASS `marginV`, `marginL`, `marginR` scaled by canvas height and width using `SafeZoneManager.getMargins(platform)`.
- **`packages/effect-engines/src/subtitles/captions-canvas.ts`:**
  - Added `safeZonePlatform?: SafeZonePlatform` support in `drawCanvasCaptionsFromSnapshot`.
  - Calculates dynamic vertical and horizontal margins based on platform safe-zone metrics.
- **`packages/effect-engines/src/depth3d/index.ts`:**
  - Forwarded `config.settings.platform` to `drawCanvasCaptionsFromSnapshot`.

### 2.2 Native J/L-Cut Split Edit Handling
- **`apps/cli/src/pipelines/04-generative-story/VideoEditPipelineOrchestrator.ts`:**
  - In `renderStoryVideo`, added `videoOffsetMs = (scene as any).videoOffsetMs ?? 0` inspection.
  - Automatically expands `paddingTime += videoOffsetMs / 1000` to prevent truncation of audio lead-ins during scene transitions.
  - Forwarded `config.settings.platform` into `generateAssContent`.

### 2.3 Canvas LUT & In-Memory Color Grading Pass
- **`packages/core/src/ffmpeg-ffi/FFISceneEngine.ts`:**
  - Integrated `ColorGradingEngine` within `renderImageScene` and `renderVideoScene`.
  - Applies in-memory `colorEngine.applyCanvasTransform(ctx, colorGrading)` and `bgCtx` transforms before rendering frames into native `FFIVideoEncoder`.
  - Passed `platform` to `drawCanvasCaptionsFromSnapshot`.

### 2.4 Configurable Audio Ducking, `prepareIR` Extraction & `processAndRender` Decommission
- **`LegacyStoryConfigAdapter.ts`:**
  - Forwarded `videoOffsetMs` and `audioOffsetMs` from `SceneConfig` to `ExtendedContentChunk`.
- **`VideoEditPipelineOrchestrator.ts`:**
  - Extracted `public static prepareIR(storyConfig, options): ExtendedPipelineIR` to encapsulate AST normalization, safe-zone styling overrides, and `EditingOpFactory.getCutStrategy()` calculations.
  - Made BGM `sidechaincompress` options (`threshold`, `ratio`, `attack`, `release`) in `renderStoryVideo` configurable via BGM ducking settings.
  - Safely removed obsolete `processAndRender` method and dead instance fields (`videoExporter`, `colorGradingEngine`), establishing `renderStoryVideo` as the single Unified SSOT for video rendering.
