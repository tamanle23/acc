# History Log 107: Auto-Config Voiceover Synthesis and Whisper Caption Fill

- **Date**: 2026-10-01
- **Task**: Run `auto-config.ts` CLI on `sample-story` to synthesize voiceover audio for all scenes via local TTS and extract/align word-level timestamps via Whisper AI into `sample-story/story-config.json`.
- **Status**: Completed

## 1. Problem
1. In `sample-story/story-config.json`, scenes 3 through 12 had full Vietnamese narration `text` and rich 3D depth configurations, but lacked synthesized voiceover audio (`audio`) and word-level timestamp subtitles (`captions: []`).
2. Running `auto-config.ts` in merge mode previously encountered three issues:
   - `FFmpegManager.prepare()` was not awaited prior to Whisper audio loading, triggering `FFmpegManager.prepare() must be called before getBinDir()`.
   - VieNeu direct worker on Windows could raise `OSError: Could not load libtorchcodec_core4.dll`, requiring robust fallback to `defaultIPCFacade.synthesizeSpeech(...)`.
   - Repeated FFI audio decoding in `FFIAudioDSP.decodeTo16kMonoFloat32` across multiple scenes could run into resampler buffer overflow due to `swr_get_out_samples` delay.

## 2. Plan & Architecture
1. **FFmpeg Initialization**: Added `await FFmpegManager.prepare()` at the entry of `auto-config.ts` `main()`.
2. **Pure TS WAV Decoder & Safe FFI Resampler**: Added an in-memory pure TypeScript WAV reader in `packages/core/src/ffmpeg-ffi/FFIAudioDSP.ts` (`tryDecodeWav`) for fast, zero-FFI, zero-crash decoding of generated TTS WAV files, alongside a 4x expanded `outCapacity` buffer for general audio formats.
3. **Execution**: Executed `bun run auto-config.ts ./sample-story --yes` in non-interactive merge mode:
   - Generated voiceovers for scenes 3–12 into `sample-story/autogenerated/voiceovers/` via VieNeu TTS.
   - Performed script-guided Whisper alignment to calculate exact start and end timestamps for every single word.
   - Retained and merged all 12 scene configurations (frame styles, sandwich settings, depth mesh motions, parallax motions, wigglegram settings, video loop settings).
4. **Stress & Stability Verification**: Updated `autogenerated-tests/stress_render.test.ts` timeout to 180s to accommodate multi-iteration rendering of all 12 1080p scenes, and verified all tests pass.

## 3. Changes
