# [125] Phase 1: Core Orchestrator Enhancements (@acc/core)

## 1. Problem Statement
To support production-grade multimedia rendering pipelines, `@acc/core` needed advanced middleware primitives:
1. Lifecycle event hooks and in-flight inspection capabilities (`tap()`) within `PipelineRunner`.
2. Safe cancellation signal (`AbortSignal`) handling to stop long renders gracefully.
3. Concurrency gating (`BoundedExecutionMiddleware`) to prevent VRAM over-allocation during heavy parallel AI/GPU stages.
4. Pre-render AST and asset inspection (`DryRunValidatorMiddleware`) to catch missing cutouts or assets prior to FFmpeg execution.

## 2. Implementation Plan & Changes
1. **Enhanced `PipelineRunner` (`packages/core/src/PipelineRunner.ts`)**:
   - Added `PipelineRunnerHooks` (`onStageStart`, `onStageSuccess`, `onStageError`).
   - Added `tap(name, fn)` for non-intrusive middleware inspection.
   - Added `AbortSignal` cancellation checking before stage dispatch.
2. **`BoundedExecutionMiddleware` (`packages/core/src/pipeline/middlewares/BoundedExecutionMiddleware.ts`)**:
   - Implemented `createConcurrencyGate(maxConcurrent)` and `defaultGPUSemaphore`.
   - Wrapped GPU/CPU compute stages with auto-acquiring and auto-releasing semaphore slots.
3. **`DryRunValidatorMiddleware` (`packages/core/src/pipeline/middlewares/DryRunValidatorMiddleware.ts`)**:
   - Implemented pre-render verification for VFX command queues (`cmd.validate(ctx.assets)`) and `PipelineIR` chunk sanity.
   - Generated `DryRunValidationReport` in `ctx.metadata.validationReport`.
4. **Test Coverage (`autogenerated-tests/pipeline_orchestrator_core.test.ts`)**:
   - Added unit tests covering lifecycle hooks, tap, AbortSignal, concurrency gating, and dry-run validation.
