# History Entry 205: Master Integration Plan (Iteration 4) Phase 1: Media Backend Strategy Pattern (`bun:ffi` & `fluent-ffmpeg`)

## 1. Overview & Context

- **Task**: Implement Phase 1 of Master Integration Plan Iteration 4: Decouple media operations across the stack with an extensible Strategy Pattern supporting both `bun:ffi` (high-performance zero-copy shared C library) and `fluent-ffmpeg` (process-isolated CLI subprocess streaming).
- **Date**: 2026-10-16
- **Status**: Completed (`10/10` tests passing across 3 dedicated test suites)

---

## 2. Changes Implemented

### 2.1. `@acc/core` Foundation
- **`packages/core/src/media-engine/types.ts`**:
  - Defined `MediaEngineType = 'bun-ffi' | 'fluent-ffmpeg' | 'mediabunny-server' | 'mediabunny-client'`.
  - Defined contracts: `IMediaEngineStrategy`, `IChunkExecutionPolicy`, `MediaProbeResult`, `MediaEngineCapabilities`, `IMediaProbeStrategy`, `IMediaConcatStrategy`, `IAudioMuxerStrategy`, `IMediaFrameSink`, `MediaAudioMixResult`, `SinkInitMetadata`, `SinkFinalizeResult`.
  - Structured error class: `MediaEngineError` capturing exit code and stderr tail diagnostics.
- **`packages/core/src/media-engine/MediaEngineRegistry.ts`**:
  - Central singleton managing registered media engines with `bun-ffi` as default.
  - Enforces strict prerequisite validation (`strategy.validatePrerequisites()`) to fail fast when binaries/libraries are missing.
  - Supports synchronous and asynchronous lazy loading (`registerLazy`, `getAsync`).
- **`packages/core/src/media-engine/sinks/FFIVideoEncoderSink.ts`**:
  - Hardware-accelerated native C FFI encoder sink with zero heap cloning.
  - Added two-pass stream-copy audio multiplexing via `FFAudioMuxer.mux` when audio is supplied in `finalize(audioResult)`.
- **`packages/core/src/media-engine/sinks/FluentPipeVideoSink.ts`**:
  - Subprocess-isolated video sink streaming raw RGBA frames over `Bun.spawn` stdin (`pipe:0`).
  - Integrated `GPUEncoderResolver.resolveSync()` to auto-detect hardware encoders (`h264_nvenc`, QSV, VideoToolbox) with fallback to `libx264`.
  - Implements deterministic backpressure with native `FileSink.write()` and `flush()`.
  - Implements two-pass stream-copy audio muxing in `finalize(audioResult)`.
- **`packages/core/src/media-engine/strategies/BunFFIEngineStrategy.ts`**:
  - Implements `IMediaEngineStrategy` wrapping `FFIVideoEncoder`, `getMediaDurationFFI`, `FFIConcatMuxer`, and `FFAudioMuxer`.
  - Defines `FFIChunkPolicy`: Multi-session FFI encoding with zero-reencode packet copy.
- **`packages/core/src/media-engine/strategies/FluentFFmpegEngineStrategy.ts`**:
  - Implements `IMediaEngineStrategy` using native `Bun.spawn` (zero new external npm dependencies).
  - Implements `ffprobe` metadata probing, `-f concat -safe 0` lossless chunk concatenation, and stream-copy audio muxing.
  - Defines `FluentChunkPolicy`: Bounded subprocess pool $\le \min(\lfloor\text{cores}/2\rfloor, 4)$.
- **`packages/core/src/FFmpegExecutor.ts`**:
  - Refactored `FFmpegCommand.run()` to delegate CLI commands to `MediaEngineRegistry.get().executeCommand(this.buildArgs())`.
- **`packages/core/src/index.ts`**:
  - Re-exported `media-engine`.

### 2.2. `@acc/ir` Frame Sinks & Chunk Pool
- **`packages/ir/src/renderer/sink/IIRFrameSink.ts`**:
  - Extends `IMediaFrameSink` from `@acc/core` for zero-friction interoperability.
- **`packages/ir/src/renderer/sink/MediaSinkFactory.ts`**:
  - Added dynamic factory helper `MediaSinkFactory.createVideoSink(engineType, options)`.
- **`packages/ir/src/renderer/sink/FFIVideoEncoderSink.ts` & `FluentPipeVideoSink.ts`**:
  - Re-exported unified implementations from `@acc/core`.
- **`packages/ir/src/workers/IRChunkWorkerPool.ts`**:
  - Added `engine?: MediaEngineType` to `IRWorkerPoolOptions`.
  - Queries active engine's `IChunkExecutionPolicy` for concurrency tuning.
  - Instantiates worker sinks via `MediaSinkFactory.createVideoSink(options.engine)`.
  - Stitches chunk slices via `mediaEngine.getConcatStrategy().concatenate()`.

### 2.3. Exporters & CLI Integration
- **`packages/exporters/src/video/VideoExporter.ts`**:
  - Added `engine?: MediaEngineType` to `VideoExportOptions`.
  - Replaced hardcoded `new FFIVideoEncoderSink()` with `MediaSinkFactory.createVideoSink(options.engine)`.
- **`apps/cli/src/commands/ir-render.ts` & `apps/cli/src/index.ts`**:
  - Added `--engine` / `--media-engine` CLI flag (`bun-ffi` | `fluent-ffmpeg`).
  - Passed `engine` through to `IRChunkWorkerPool` and single-worker `IRMasterRenderer`.

### 2.4. Governance Rule Amendment
- **`.agents/rules/01-workspace-specific.md`**:
  - Amended `FFMPEG-MANAGER` rule to permit `fluent-ffmpeg` and `mediabunny` strictly behind `MediaEngineStrategy` implementations, maintaining the ban on rogue child processes elsewhere.
