# History Entry 074: Phase 2 - Branching Exporter Suite (Video, Audio, Social Canvas, Static Web)

## Problem Statement
The ACC system previously coupled video rendering directly to the story config ingestion loop without a generalized multi-channel export layer. To fulfill the core thesis of *"Build a unified data processing pipeline that branches out at the distribution stage"*, an independent distribution layer was needed to transform standardized `PipelineIR` into diverse media formats (H.264 MP4 videos, MP3 podcasts with chapters, multi-slide PNG carousels, Twitter/Threads markdown threads, and static web articles with JSON payloads).

## Plan
1. Create `packages/exporters` workspace package.
2. Define `BaseExporter.ts` and `IExporter` interface.
3. Implement `VideoExporter.ts` using `bun:ffi` (`FFIVideoEncoder` + `@napi-rs/canvas`) for deterministic zero-copy frame encoding.
4. Implement `AudioExporter.ts` for podcast MP3 generation and chapter metadata export.
5. Implement `SocialExporter.ts` generating 1080x1350 PNG multi-slide carousels and thread markdown.
6. Implement `StaticWebExporter.ts` producing Hugo/Astro compatible Markdown with YAML Frontmatter and JSON API representations.
7. Build `ExporterDispatcher` and `exportAll()` convenience helper.
8. Add unit test `autogenerated-tests/branching_exporters.test.ts` verifying all 4 exporters simultaneously on a mock `PipelineIR`.

## Changes Made
- `packages/exporters/`:
  - `package.json`: Configured workspace dependencies (`@acc/core`, `@acc/ir`, `@napi-rs/canvas`).
  - `src/base/BaseExporter.ts`: Defined `IExporter`, `ExportOptions`, `ExportResult`.
  - `src/video/VideoExporter.ts`: Implemented zero-copy H.264 MP4 video encoding using `@napi-rs/canvas` buffer integration (`canvas.data()`) and `FFIVideoEncoder.encodeRgbaFrame()`.
  - `src/audio/AudioExporter.ts`: Implemented podcast audio exporter generating combined MP3 audio and `_chapters.json`.
  - `src/social/SocialExporter.ts`: Implemented high-resolution (1080x1350) canvas carousel renderer producing cover slide, chunk slides, and thread markdown.
  - `src/static-web/StaticWebExporter.ts`: Implemented static website article exporter generating Frontmatter Markdown and JSON data.
  - `src/index.ts`: Built `ExporterDispatcher` facilitating fan-out to all exporters concurrently.
- `tsconfig.json`: Added path mapping for `@acc/exporters`.
- `autogenerated-tests/branching_exporters.test.ts`:
  - Verified concurrent export to Video (MP4), Audio (MP3), Social (3x PNG + Thread MD), and Static Web (MD + JSON).
