## 2. Context & Problem
`story-config.json` is officially deprecated in favor of `pipeline-ir.json` (Universal Video IR v3.0.0 AST) and `omnichannel-config.json` (Fine-Grained Video Director Directives). Previously, `AutoConfigEngineFacade.scaffoldDirectory()` always emitted a brand-new `story-config.json` for all scaffolded directories, creating legacy artifact pollution in modern projects.

---

## 3. What Was Changed & Implemented
1. **Deprecated Generation for New Directories**:
   - In [`packages/core/src/autoconfig/AutoConfigEngineFacade.ts`](file:///c:/Users/Admin/workspace/git/acc/packages/core/src/autoconfig/AutoConfigEngineFacade.ts):
     - When scaffolding a directory, the engine probes whether `story-config.json` already exists.
     - If `story-config.json` does NOT exist and `options.exportLegacyStoryConfig !== true`, the engine **omits** `story-config.json` entirely.
     - Only `pipeline-ir.json` and `omnichannel-config.json` are generated for new directories.

2. **Update / Merge Mode for Existing Legacy Projects**:
   - If `story-config.json` already exists in the target directory (e.g., legacy projects or sample story workspaces), the engine automatically enters **Update/Merge Mode**:
     - Reads the existing `story-config.json`.
     - Preserves all custom properties, author metadata, and legacy annotations.
     - Merges updated cinematography settings, resolution, and scene directives generated from the new scaffold.
     - Overwrites the existing file with the cleanly merged output.

3. **Explicit Override Support**:
   - `exportLegacyStoryConfig: true`: Explicitly forces generation of `story-config.json` even for new directories.
   - `exportLegacyStoryConfig: false`: Explicitly suppresses `story-config.json` even if it already exists.

4. **CLI User Feedback**:
   - In [`auto-config.ts`](file:///c:/Users/Admin/workspace/git/acc/auto-config.ts):
     - New projects only display `pipeline-ir.json` and `omnichannel-config.json`.
     - Existing legacy projects report: `✔ .../story-config.json (Legacy story-config.json [Merged Update])`.

5. **Test Suite Verification**:
   - Updated [`autogenerated-tests/autoconfig/facade-and-cli.test.ts`](file:///c:/Users/Admin/workspace/git/acc/autogenerated-tests/autoconfig/facade-and-cli.test.ts) to verify omission for new directories, update/merge mode when existing, and explicit boolean override behavior.
   - Updated [`autogenerated-tests/samples-scaffolding-verification.test.ts`](file:///c:/Users/Admin/workspace/git/acc/autogenerated-tests/samples-scaffolding-verification.test.ts) to reflect deprecated legacy config emission.
