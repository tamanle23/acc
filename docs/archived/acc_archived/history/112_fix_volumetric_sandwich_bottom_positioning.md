# 112. Fix Volumetric Sandwich Bottom Text Positioning & Dynamic Fallback Clipping

## Problem & Context
In 3D Depth scenes using `volumetric_sandwich` (`mode: "volumetric_sandwich"`), configuring `"position": "bottom"` was not taking effect because:
1. `sandwich.ts` had a local regression where `position` resolution logic was omitted in the rendering loop.
2. In cases where no cutout image (`subjectImg`) was provided, the fallback subject clipping layer hardcoded a full-width rectangle across the lower half (`height * 0.42` to `height * 1.0`), occluding any text positioned near the bottom of the frame.

## Proposed Plan
1. **Dynamic Position Resolution**:
   - Compute `baseY` and `baseX` at function scope supporting `"top"` (~22%), `"center"` (~48%), `"bottom"` (~75%), and numeric `positionY` / `positionX` ratio overrides.
2. **Adaptive Fallback Subject Masking**:
   - In fallback mode (when `subjectImg` is null), adjust the foreground clipping mask from full-width to an centered character region (`cx`, `cy`, `cw`, `ch`) when `"position": "bottom"` or `baseY > 60%`, allowing the background 3D text to remain visible around the subject.
3. **Automated Unit Testing**:
   - Add formal tests in `autogenerated-tests/sandwich_positioning.test.ts` verifying `"top"`, `"center"`, and `"bottom"` configurations.

## Changes Made
- `packages/effect-engines/src/depth3d/sandwich.ts`:
  - Computed `baseY` for `"bottom"` / `"bottom-center"` at `0.75 * height`.
  - Added position-aware subject fallback clipping.
- `autogenerated-tests/sandwich_positioning.test.ts`: Added unit tests for all sandwich positioning presets and custom ratios.
