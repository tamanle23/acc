# [103] Active Word Highlight Flag & Multi-Word Subtitles

## Problem
Previously, the subtitle generation pipeline coupled multi-word phrase rendering (`wordsPerPhrase > 1`) directly with the karaoke highlight mechanism. If a user did not specify `highlightPreset`, the ASS renderer defaulted `highlightPreset` to `"none"`, which caused `wordsPerPhrase` grouping to be completely bypassed and fell back to flashing single-word captions. Furthermore, users could not display multi-word static subtitles without karaoke word jumping.

## Plan
1. **Explicit Flag (`activeWordHighlight`)**:
   - Introduce `activeWordHighlight?: boolean;` (with `active-word-highlight` kebab-case alias) in `CaptionSettings` schemas and TypeScript interfaces.
   - When `activeWordHighlight: true`, karaoke active-word highlighting is enabled, and `highlightPreset` defaults to `"color"` if omitted.
   - When `activeWordHighlight: false` (or omitted), multi-word phrases (`wordsPerPhrase > 1`) render cleanly as static phrase blocks spanning the full phrase duration without word-by-word highlight jumping.
2. **Synchronize Rendering Engines**:
   - Update `packages/effect-engines/src/subtitles/subtitles.ts` to generate static multi-word dialogue events when `activeWordHighlight` is false/omitted, and sequential highlighted dialogue events when `activeWordHighlight` is true.
   - Update `packages/effect-engines/src/subtitles/captions-canvas.ts` and `packages/core/src/captions-canvas.ts` to respect `activeWordHighlight`.
3. **Sync All 8 Points**:
   - `packages/core/src/types.ts` & `packages/effect-engines/src/types.ts`
   - `schema/story-config.schema.json`
   - `docs/STORY_CONFIG_SPEC.md`
   - `auto-config.ts`
   - `sample-story/story-config.json`
   - `README.md`
4. **Verification**:
   - Add comprehensive tests in `autogenerated-tests/active-word-highlight.test.ts`.
   - Verify sample story video rendering with `bun run cli.ts ./sample-story`.

## Changes Made
- `packages/core/src/types.ts` & `packages/effect-engines/src/types.ts`:
  - Added `activeWordHighlight?: boolean;` and `'active-word-highlight'?: boolean;` to `CaptionSettings`.
- `packages/effect-engines/src/subtitles/subtitles.ts`:
  - Implemented decoupled phrase grouping and active-word highlight logic in `generateAssContent`.
- `packages/effect-engines/src/subtitles/captions-canvas.ts` & `packages/core/src/captions-canvas.ts`:
  - Resolved `highlightPreset` based on `activeWordHighlight` flag in `drawCanvasCaptions`.
- `schema/story-config.schema.json`:
  - Added `activeWordHighlight` and `active-word-highlight` properties with documentation.
- `auto-config.ts`:
  - Prompted and set `activeWordHighlight` during interactive configuration.
- `sample-story/story-config.json`:
  - Configured `"activeWordHighlight": true`.
- `docs/STORY_CONFIG_SPEC.md` & `README.md`:
  - Documented `activeWordHighlight` and decoupled multi-word phrase subtitle behavior.
