# Task 284: Studio Preview Player Performance Tuning & Reactive Decoupling

## Overview
Comprehensive performance tuning of the Studio Preview player and timeline scrubbing engine. Inspired by architectural best practices from Twick and Motion Canvas, this task decouples high-frequency frame ticks (60fps) from React virtual DOM reconciliations, introduces the Observer / Subscribable Playhead pattern, and eliminates CPU thread bottlenecks.

## Changes Implemented

### 1. Observer Pattern: `StudioPlayheadController`
- Added `apps/studio/src/lib/playhead/StudioPlayheadController.ts`:
  - **High-Frequency Stream (60fps)**: Dispatches instant frame updates directly to canvas renderers and the timeline playhead needle without triggering React reconciliations.
  - **Low-Frequency Stream (~10 Hz / on-stop)**: Throttled updates to React component state (`currentFrame` in `App.tsx`) to keep clip inspectors and titlebars in sync without causing frame drops during active playback.

### 2. Direct DOM Translation for Playhead Needle (`Timeline.tsx`)
- Replaced the per-frame React inline style recalculation with a direct `ref` subscriber.
- The needle updates its position using hardware-accelerated CSS `transform: translate3d(...)` with `will-change: transform`.
- Result: 60fps playhead motion with 0 DOM re-creations and 0 virtual DOM diffs.

### 3. Strategy Pattern: `IPreviewRenderStrategy`
- Added `apps/studio/src/lib/rendering/IPreviewRenderStrategy.ts` defining a clean contract for canvas rendering across OffscreenCanvas worker and main-thread fallback strategies.

### 4. Input Coalescing & Repeat Debouncing (`useShuttleEngine.ts`)
- Configured keyboard navigation (`ArrowLeft` / `ArrowRight`) to trigger immediate navigation on the first keypress (0ms latency), and throttled OS key-repeat events (50–100Hz) to 35ms (~28 Hz) to match display refresh timing.

### 5. Throttled Scrub Audio Feedback (`WebAudioEngine.ts`)
- Capped `playScrubFeedback()` to at most once every 70ms (~14 Hz). Rapid scrubbing or holding arrow keys no longer floods the main thread with continuous synchronous PCM stereo mixing.

### 6. Web Worker Render Frame Coalescing & Texture Sync (`preview.worker.ts`, `Preview.tsx`)
- Added `pendingRender` state machine in `preview.worker.ts` to coalesce intermediate frames arriving while the worker is actively drawing.
- Added asynchronous `ImageBitmap` transfer to `preview.worker.ts` so OffscreenCanvas can render real sequence textures off the main thread.
- Direct high-frequency subscription in `Preview.tsx` to drive worker rendering directly from the playhead controller.
