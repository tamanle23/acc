# History Entry 081: Dynamic Video Container Format Selection in Strategy Pattern

## Problem
In the initial `FileVideoEncodingStrategy` implementation, the container muxer was defaulting implicitly to MP4 without exposing explicit container configuration (`container?: 'mp4' | 'mkv' | 'mov' | 'webm'`) or container-specific parameters (such as `movflags +faststart` for streaming or `+global_header` for Matroska/WebM). When users requested non-MP4 formats (e.g. MKV or WebM), `avformat_write_header` would fail or fall back to default behavior instead of respecting user configuration.

## Plan
1. Upgrade `FileVideoEncodingStrategy`:
   - Introduce `FileVideoEncodingOptions` with `container?: string`, `fastStart?: boolean`, and `preset?: string`.
   - Resolve the target FFmpeg muxer format dynamically (`'matroska'` for MKV, `'webm'` for WebM, `'mov'` for MOV, `'mp4'` for MP4).
   - In `configureFormatContext()`, conditionally apply `movflags +faststart` for streaming formats (`mp4`, `mov`) when `fastStart` is enabled.
2. Upgrade `FFIVideoEncoder`:
   - Set `flags: +global_header` on the codec context before opening to ensure codec extradata is populated for containers like Matroska.
   - Automatically infer the container format from the output file extension (`.mkv`, `.webm`, `.mov`, `.mp4`) or explicit `fileOptions.container`.
   - Reset `codec_tag = 0` on `streamCodecpar` to allow the container muxer to select the native fourcc tag.
3. Update `VideoExporter`:
   - Support `container?: 'mp4' | 'mkv' | 'mov' | 'webm'` in `VideoExportOptions`.
   - Generate output filename matching the specified container (`${prefix}.${container}`).
   - Pass options to `FFIVideoEncoder` and populate export result metadata.
4. Update `apps/cli/src/index.ts`:
   - Add `-f, --format <fmt>` / `--container <fmt>` flags to CLI options and help guide.
5. Add comprehensive unit & integration tests in `autogenerated-tests/encoding_strategy_pattern.test.ts`, `exporters_deep_unit.test.ts`, and `phase6_unified_cli.test.ts`.

## Changes
- `packages/core/src/ffmpeg-ffi/EncodingStrategies.ts`:
  - Added `FileVideoEncodingOptions`, dynamic container resolution (`matroska`, `webm`, `mov`, `mp4`), and conditional `faststart`.
- `packages/core/src/ffmpeg-ffi/FFIVideoEncoder.ts`:
  - Added `flags +global_header`, stream timebase `1/90000`, `codec_tag = 0` reset, and auto-inference of container format.

  - Wired `options.container` / `options.format` directly to file naming, encoder strategy options, and metadata.
