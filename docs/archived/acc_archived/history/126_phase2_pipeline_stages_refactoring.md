# [126] Phase 2: Pipeline Stage Decomposition & Modular Middleware Refactoring

## 1. Problem Statement
Previously, while pipelines used `PipelineRunner`, their stage logic was defined as inline anonymous middleware blocks inside each pipeline's `buildRunner()` method. This hindered stage reusability, isolated unit testing, and modular pipeline composition.

## 2. Implementation Plan & Changes
Decomposed all 6 content pipelines into discrete, dedicated stage modules under each pipeline's `stages/` subfolder:
1. **Pipeline 1 (`01-scraper/stages/`)**:
   - `ScraperLLMSummarizeStage.ts` (LLM structured JSON news extraction).
   - `ScraperTTSSynthesisStage.ts` (Kokoro voice synthesis with audio buffer caching).
   - `ScraperCardCompositionStage.ts` (Canvas alert card rendering and `PipelineIR` assembly).
2. **Pipeline 2 (`02-db-templating/stages/`)**:
   - `DBDataNormalizationStage.ts` (Metric sorting and max metric scaling).
   - `DBBarChartCompositionStage.ts` (Infographic bar chart race slide generation).
3. **Pipeline 3 (`03-repurposing/stages/`)**:
   - `RepurposingHookExtractionStage.ts` (Viral hook sentence segmentation).
   - `RepurposingCompositionStage.ts` (Face-track bounding glow and karaoke subtitle layout).
4. **Pipeline 4 (`04-generative-story/stages/`)**:
   - `StoryFolderResolutionStage.ts` (Config parsing and asset path resolution).
   - `StoryOrchestratedRenderStage.ts` (AST transformation, safe-zones, and cut strategy rendering).
   - `StoryMetadataPersistenceStage.ts` (Output metadata JSON generation).
5. **Pipeline 5 (`05-rule-logic/stages/`)**:
   - `RuleLogicProofValidationStage.ts` (Proof step normalization).
   - `RuleLogicChalkboardCompositionStage.ts` (Chalkboard texture and LaTeX step rendering).
6. **Pipeline 6 (`06-ambient-stream/stages/`)**:
   - `AmbientParticleShaderCompositionStage.ts` (Procedural canvas particles and theme gradients).
7. **Pipeline Index Updates**:
   - Exported all stages from each pipeline's `index.ts` for full composability.
