# Master Integration Plan - Iteration 30: Unified Isomorphic Core Architecture, @acc/core-native Merger & Zero-Redundancy Refactoring

## 1. Goal Description & Executive Summary
Iteration 30 resolves architectural duplication, fragmented package boundaries, and bundler leaks across the ACC monorepo. It establishes a unified **3-Core + Isomorphic Domain Engine Architecture** with strict adherence to four architectural mandates:

1. **Pillar 1: Merge `@acc/core-native` into `@acc/core` & Decommission `core-native`**:
   - Delete `packages/core-native`.
   - Consolidate all native FFI bindings (`bun:ffi`, libav codecs, `NativeBufferPool`, `NapiCanvasAdapter`, `FFmpegManager`) directly inside `@acc/core`.
2. **Pillar 2: Single Source of Truth for `MediabunnyClientSink` in `@acc/core-web`**:
   - Relocate the canonical `MediabunnyClientSink` (with working AAC audio multiplexing and video canvas streams) into `@acc/core-web`.
   - Permanently delete duplicate copies in `@acc/core` and `@acc/ir` (no proxy re-exports).
   - `apps/studio` imports `MediabunnyClientSink` directly from `@acc/core-web`.
3. **Pillar 3: 100% Pure Isomorphic `@acc/ir`**:
   - Eliminate `@acc/ir/client` and `@acc/ir/server` subpath exports. `@acc/ir` exports exclusively from `.` (`src/index.ts`).
   - Move server-side batch worker orchestrations (`IRChunkWorkerPool`, `FFIChunkConcatMuxer`) and proxy sink files to `@acc/core`.
   - Remove `@acc/core` dependency from `packages/ir/package.json`.
4. **Pillar 4: 100% Pure Isomorphic `@acc/effect-engines`**:
   - Eliminate `@acc/effect-engines/client`. `@acc/effect-engines` exports exclusively from `.` (`src/index.ts`).
   - Move server-only FFmpeg filtergraph overlay generators (40+ generators like `rain`, `fire`, `matrix_rain`) and AI sound generators (`sound-effects/`) into `@acc/core/src/effects/`.
   - Keep 3D depth renderers, particle VFX (`DeterministicParticleField`), post-processing shaders, canvas captions, color grading, and Transformers.js vision strategies 100% pure isomorphic in `@acc/effect-engines`.
5. **Pillar 5: Isomorphic Universal Services in `@acc/core-isomorphic`**:
   - **`UniversalLogger`**: Pure isomorphic logger (ISO timestamps, log level filtering, console dispatch, zero Node/secrets dependencies). No re-export in other packages.
   - **`IContentCacheStrategy` & `ContentCacheRegistry`**: Isomorphic caching with fast 32-bit checksum math. Implemented as `NativeFileCacheStrategy` in `@acc/core` (server disk) and `IndexedDbCacheStrategy` in `@acc/core-web` (browser).
   - **Decoupled Video Encoding in `renderDepth3DScene`**: Decouple `FFIVideoEncoder` by resolving frame sinks via `MediaEngineRegistry.get().createVideoSink()`.

## 3. Package Responsibilities & Boundaries

| Package | Runtime Target | Primary Responsibilities | Strict Prohibitions |
| :--- | :--- | :--- | :--- |
| **`@acc/core-isomorphic`** | Universal | Pure contracts, `RationalTime`, `UniversalCanvasProvider`, `UniversalLogger`, `IContentCacheStrategy`, `MediaEngineRegistry`. | **Never** import Node built-ins (`fs`, `path`, etc.) or DOM globals. |
| **`@acc/effect-engines`** | Universal (100% Isomorphic) | 3D depth renderers, particle VFX (`DeterministicParticleField`), post-processing shaders, canvas captions, color grading, Transformers.js vision strategies. | **Never** import Node built-ins, native C/FFI binaries, or server pipelines. Single root export `.` only. |
| **`@acc/ir`** | Universal (100% Isomorphic) | Video IR schema/types, DAG compiler, modifiers, preview rendering engine, audio mixing math. | **Never** import Node built-ins or native binaries. Single root export `.` only. |
| **`@acc/core-web`** | Browser Client & Web Worker | `WebCanvasAdapter`, `MediabunnyClientSink` (canonical browser MP4 exporter with AAC audio), `MediabunnyClientStrategy`, `IndexedDbCacheStrategy`. | **Never** import Node built-ins or native C/FFI binaries. |
| **`@acc/core`** *(Merged Native + Server)* | Bun & Node.js Server | `bun:ffi` video decoding/encoding, `FFmpegManager`, `NativeBufferPool`, `NapiCanvasAdapter`, `NativeFileCacheStrategy`, batch render worker pools (`IRChunkWorkerPool`), FFmpeg overlay generators, AI SFX generators, stage pipelines. | **Never** imported by `apps/studio` or `@acc/core-web`. |
