# ACC (Automated Content Creator) - Hướng Dẫn Sử Dụng CLI & Kiến Trúc Monorepo Turborepo

Tài liệu hướng dẫn toàn diện về hệ thống **CLI đa Pipeline** và **Kiến trúc Monorepo Turborepo** của dự án ACC.

---

## 1. 🏗️ Tổng quan Kiến trúc Monorepo (Turborepo + Bun Workspaces)

Dự án ACC được tổ chức theo mô hình **Monorepo** chuẩn mực, chia thành các package module hóa cao (`packages/`) và các ứng dụng thực thi (`apps/`), quản lý bởi **Bun Workspaces** và điều phối cache bởi **Turborepo**:

```text
acc/
├── apps/
│   ├── cli/                   # @acc/cli: Bộ điều phối Unified CLI & 6 Orchestrator Pipelines
│   └── python-backend/        # Trạm AI Engine Python gRPC (SAM 2, Depth Anything v2, Kokoro TTS)
├── packages/
│   ├── core/                  # @acc/core: FFI FFmpeg Manager, Zero-Copy I/O, Registry, Prompts
│   ├── ir/                    # @acc/ir: Schema Timeline IR (Intermediate Representation), AST & DAG
│   ├── effect-engines/        # @acc/effect-engines: 3D Depth, Canvas VFX, Audio DSP, Transformers.js
│   ├── exporters/             # @acc/exporters: Multi-channel Exporters (Video, Audio, Social, Web)
│   └── proto/                 # @acc/proto: Protobuf & gRPC interfaces
├── autogenerated-tests/       # Bộ Unit, Stress & Regression Test Suite
├── docs/                      # Tài liệu kỹ thuật, hướng dẫn & đặc tả hệ thống
├── package.json               # Root workspace manifest & Turborepo config
└── turbo.json                 # Cấu hình dependency graph & caching của Turborepo
```

### Các lệnh Turborepo cơ bản

| Lệnh | Mô tả |
| :--- | :--- |
| `bun run test` / `turbo run test` | Chạy toàn bộ test suite của monorepo với cơ chế caching tự động |
| `turbo run build` | Build tất cả package và app theo thứ tự phụ thuộc (DAG) |

## 2. 🚀 Bộ Lệnh Unified CLI (`bun run cli.ts`)

Từ gốc dự án, bạn có thể gọi CLI thông qua `bun run cli.ts` (hoặc phím tắt `bun run cli`).

### 2.1 Cú pháp tổng quát

```bash
bun run cli.ts <command> [pipeline_id] [options]
```

### 2.2 Danh mục Lệnh (Subcommands)

| Lệnh (Subcommand) | Chức năng | Ví dụ |
| :--- | :--- | :--- |
| `list` | Liệt kê tất cả 6 Pipeline và các kênh Exporter được hỗ trợ | `bun run cli.ts list` |
| `run` | Thực thi một Pipeline với dữ liệu cấu hình hoặc thư mục đầu vào | `bun run cli.ts run story -c ./sample-story` |
| `stream` | Phát luồng trực tiếp RTMP 24/7 với GPU Zero-Copy FFI | `bun run cli.ts stream ambient --rtmp <url>` |
| `serve` | Khởi động Webhook Ingestion HTTP Daemon lắng nghe event | `bun run cli.ts serve --port 3000` |
| `overlay` | Sinh video hiệu ứng lớp phủ (Mưa, Tuyết, Khói, Lửa, Glitch...) | `bun run cli.ts overlay --effect rain --variant storm` |
| `sfx` | Sinh hiệu ứng âm thanh (Smart Router: AI/Synth/Freesound) | `bun run cli.ts sfx --custom-prompt "cinematic boom"` |
| `<story_folder>` | Chế độ rút gọn (Legacy Storyteller) render trực tiếp thư mục story | `bun run cli.ts ./sample-story` |
| `--help` / `-h` | Hiển thị bảng hướng dẫn CLI chi tiết | `bun run cli.ts --help` |

## 3. 🧩 Chi tiết 6 Pipeline Orchestrators

Hệ thống cung cấp 6 Pipeline chuyên biệt xử lý từng bài toán sản xuất nội dung tự động:

```
+-----------------------------------------------------------------------------+
|                               6 CORE PIPELINES                              |
+-------------------+--------------------+------------------------------------+
| 1. Scraper        | 2. DB Templating   | 3. Repurposing                     |
| Tin tức / Alert   | Bar Chart Race     | Video dài -> 9:16 Shorts           |
+-------------------+--------------------+------------------------------------+
| 4. Story          | 5. Rule & Math     | 6. Ambient                         |
| 3D Depth Story    | Manim Bảng đen     | Live Loop 24/7 RTMP                |
+-------------------+--------------------+------------------------------------+
```

### Pipeline 1: `scraper` (Event-Driven Scraper & Summarizer)
- **Đầu vào**: Dữ liệu sự kiện hoặc URL báo chí / công nghệ.
- **Kênh xuất (Exporters)**: `video` (Breaking Alert Card), `audio` (TTS Voiceover), `social` (Breaking Banner), `web` (Markdown summary).
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run scraper --config event.json --exporters video,audio,social,web --out ./dist/scraper
  ```

### Pipeline 2: `db` (Database & Structured Data Templating)
- **Đầu vào**: Dữ liệu bảng thống kê (Rankings, Metrics, Thời gian).
- **Kênh xuất (Exporters)**: `video` (Bar Chart Race 60 FPS), `audio`, `social` (Carousel stats), `web` (JSONB report).
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run db --config stats.json --out ./dist/db
  ```

### Pipeline 3: `repurpose` (Long-form Recycler)
- **Đầu vào**: Video ngang 16:9 gốc + Audio + Timestamps phụ đề.
- **Kênh xuất (Exporters)**: `video` (9:16 Vertical Smart-Crop + Karaoke Subtitles), `audio`.
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run repurpose --config repurpose.json --out ./dist/shorts
  ```

### Pipeline 4: `story` (Generative Storytelling)
- **Đầu vào**: Thư mục Story chứa `story-config.json`, ảnh/video B-roll và audio.
- **Tính năng**: 3D Depth Out-of-Bounds (Frame-Breaker), Drop Shadow đa tầng, Auto-Segmentation (SAM 2), XFade transitions, Whisper Timestamps, FFI NVENC zero-copy.
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run story --config ./sample-story --format mp4
  # Hoặc shorthand:
  bun run cli.ts ./sample-story
  ```

### Pipeline 5: `rule` / `math` (Rule & Math Logic Engine)
- **Đầu vào**: Bài toán hình học, giải tích, suy luận logic từng bước.
- **Kênh xuất (Exporters)**: `video` (Hiệu ứng bảng đen Manim Chalkboard vẽ từng nét), `social`, `web`.
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run math --config theorem.json --out ./dist/math
  ```

### Pipeline 6: `ambient` (Procedural Ambient Loop & Live Stream)
- **Đầu vào**: Cấu hình chủ đề vũ trụ, hạt không gian (Deep Space, Cyber Grid, Aurora).
- **Kênh xuất (Exporters)**: `video` (Render file), `live-stream` (Đẩy luồng trực tiếp RTMP lên YouTube/Twitch).
- **Lệnh chạy render file**:
  ```bash
  bun run cli.ts run ambient --duration 10 --out ./dist/ambient
  ```
- **Lệnh phát sóng Live Stream RTMP**:
  ```bash
  bun run cli.ts stream ambient --rtmp "rtmp://a.rtmp.youtube.com/live2/YOUR_STREAM_KEY" --duration 3600
  ```

## 4. 🛠️ Các Bộ Tool CLI Chuyên Biệt

### 4.1 Wizard Tự Động Sinh Cấu Hình Story (`auto-config.ts`)
Interactive Wizard hỗ trợ nhận diện asset, chọn Preset nền tảng (TikTok, YouTube, FB), Preset phụ đề, và tự động gọi Whisper AI trích xuất timestamps tiếng Việt chính xác 100%.

```bash
bun run auto-config.ts ./sample-story
```

### 4.2 Sinh Hiệu Ứng Lớp Phủ Overlay (`overlay`)
Render các vòng lặp seamless loop hạt mưa, tuyết, khói, lửa, VHS, glitch bằng `@napi-rs/canvas` và mã hóa FFI trực tiếp:

- **Chế độ Wizard tương tác**:
  ```bash
  bun run cli.ts overlay
  ```
- **Chế độ dòng lệnh Headless**:
  ```bash
  bun run cli.ts overlay --effect rain --variant storm --duration 4 --width 1920 --height 1080 --fps 30
  bun run cli.ts overlay --composite retro_glitch_vhs
  ```

### 4.3 Sinh Hiệu Ứng Âm Thanh SFX (`sfx`)
Hỗ trợ Smart Routing tự động chọn giữa Procedural UI Synth, AudioLDM2 AI và Freesound:

- **Chế độ Wizard tương tác**:
  ```bash
  bun run cli.ts sfx
  ```
- **Chế độ Prompt AI Headless**:
  ```bash
  bun run cli.ts sfx --custom-prompt "heavy thunder and lightning crash" --duration 3.5
  ```
- **Chế độ Composite / Preset Headless**:
  ```bash
  bun run cli.ts sfx --composite cyberpunk_ui
  bun run cli.ts sfx --effect ui --variant click --sub-variant subtle
  ```

## 5. 📋 Bảng Tham Số (Flags Reference)

| Flag | Tên đầy đủ | Phạm vi áp dụng | Mô tả |
| :--- | :--- | :--- | :--- |
| `-c` | `--config <file\|dir>` | `run`, `stream` | Đường dẫn file JSON cấu hình hoặc thư mục story |
| `-e` | `--exporters <list>` | `run` | Danh sách kênh xuất cách nhau bởi dấu phẩy: `video,audio,social,web` |
| `-o` | `--out <dir>` | `run` | Thư mục lưu trữ kết quả xuất |
| `-f` | `--format <fmt>` | `run` | Định dạng container video: `mp4`, `mkv`, `mov`, `webm` (Mặc định: `mp4`) |
| `-r` | `--rtmp <url>` | `stream` | Endpoint URL RTMP/RTMPS máy chủ tiếp nhận luồng (YouTube/Twitch) |
| `-p` | `--port <port>` | `serve` | Cổng lắng nghe Webhook HTTP (Mặc định: `3000`) |
| `-d` | `--duration <sec>` | `stream`, `run` | Giới hạn thời lượng luồng phát hoặc vòng lặp (giây) |
| `-h` | `--help` | Toàn cục | Hiển thị hướng dẫn sử dụng CLI |

## 6. 💡 Bảng Tổng Hợp Lệnh Nhanh (Cheatsheet)

```bash
# 1. Kiểm tra danh sách Pipelines & Channels
bun run cli.ts list

# 2. Tạo cấu hình Story mới với Wizard & Whisper AI
bun run auto-config.ts ./my-story

# 3. Render Story Video chuẩn 3D Depth
bun run cli.ts ./my-story
# hoặc:
bun run cli.ts run story -c ./my-story -f mp4

# 4. Chạy Webhook Daemon đón sự kiện Scraper
bun run cli.ts serve --port 3000

# 5. Phát trực tiếp 24/7 RTMP Ambient Stream
bun run cli.ts stream ambient --rtmp "rtmp://..." --duration 7200

# 6. Sinh lớp phủ Overlay Mưa Bão Full HD
bun run cli.ts overlay -e rain -v storm -d 3

# 7. Sinh âm thanh SFX qua Prompt AI
bun run cli.ts sfx -p "futuristic sci-fi portal open" -d 4.0

# 8. Chạy toàn bộ Test Suite của Monorepo
bun run test
```
