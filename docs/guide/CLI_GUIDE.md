# ACC (Automated Content Creator) - Hướng Dẫn Sử Dụng CLI & Kiến Trúc Monorepo Turborepo

Tài liệu hướng dẫn toàn diện về hệ thống **Unified CLI**, **Universal Auto-Config Engine (v3.0)** và **Kiến trúc Monorepo Turborepo** của dự án ACC.

---

## 1. 🏗️ Tổng quan Kiến trúc Monorepo (Turborepo + Bun Workspaces)

Dự án ACC được tổ chức theo mô hình **Monorepo** chuẩn mực, chia thành các package module hóa cao (`packages/`) và các ứng dụng thực thi (`apps/`), quản lý bởi **Bun Workspaces** và điều phối cache bởi **Turborepo**:

```text
acc/
├── apps/
│   ├── cli/                   # @acc/cli: Bộ điều phối Unified CLI & 6 Orchestrator Pipelines
│   └── python-backend/        # Trạm AI Engine Python gRPC (SAM 2, Depth Anything v2, Kokoro TTS)
├── packages/
│   ├── core/                  # @acc/core: FFI FFmpeg Manager, Zero-Copy I/O, Autoconfig, Registry
│   ├── ir/                    # @acc/ir: Universal Video IR, Timeline IR (v3.0.0), DAG AST Schemas
│   ├── effect-engines/        # @acc/effect-engines: 3D Depth, Canvas VFX, Audio DSP, Transformers.js
│   ├── exporters/             # @acc/exporters: Multi-channel Exporters (Video, Audio, Social, Web)
│   └── proto/                 # @acc/proto: Protobuf & gRPC interfaces
├── autogenerated-tests/       # Bộ Unit, Stress & Regression Test Suite
├── docs/                      # Tài liệu kỹ thuật, hướng dẫn & đặc tả hệ thống
│   ├── guide/
│   │   ├── CLI_GUIDE.md       # Sách hướng dẫn toàn diện Unified CLI & Monorepo
│   │   ├── AUTO_CONFIG_ASSET_STAGING_GUIDE.md # Hướng dẫn chuẩn bị Asset & Narrative Frameworks
│   │   ├── SOUND_EFFECTS_CLI_GUIDE.md
│   │   └── OVERLAY_EFFECTS_CLI.md
│   ├── SYSTEM_ARCHITECTURE_DOCUMENT.md
│   ├── STORY_CONFIG_SPEC.md
│   └── AUTO_CONFIG_UNIVERSAL_PIPELINE_IR_INTEGRATION_SPEC.md
├── package.json               # Root workspace manifest & Turborepo config
└── turbo.json                 # Cấu hình dependency graph & caching của Turborepo
```

### Các lệnh Turborepo cơ bản

| Lệnh | Mô tả |
| :--- | :--- |
| `bun run test` / `turbo run test` | Chạy toàn bộ test suite của monorepo với cơ chế caching tự động |
| `turbo run build` | Build tất cả package và app theo thứ tự phụ thuộc (DAG) |

## 2. 🚀 Bộ Lệnh Unified CLI (`bun run cli.ts`)

Từ gốc dự án, bạn có thể gọi CLI thông qua `bun run cli.ts` (hoặc lệnh nhị phân `bun run acc`).

### 2.1 Cú pháp tổng quát

```bash
bun run cli.ts <command> [pipeline_id] [options]
```

### 2.2 Danh mục Lệnh (Subcommands)

| Lệnh (Subcommand) | Chức năng | Ví dụ cú pháp |
| :--- | :--- | :--- |
| `list` | Liệt kê tất cả 6 Pipeline và các kênh Exporter được hỗ trợ | `bun run cli.ts list` |
| `run` | Thực thi một Pipeline với dữ liệu cấu hình hoặc thư mục đầu vào | `bun run cli.ts run story -c ./sample-story` |
| `ir-render` | Render trực tiếp qua Canonical Universal Video IR Engine (Parallel Chunking, NVENC FFI) | `bun run cli.ts ir-render -c ./sample-story/story-config.json -j 4` |
| `stream` | Phát luồng trực tiếp RTMP 24/7 với GPU Zero-Copy FFI | `bun run cli.ts stream ambient --rtmp <url>` |
| `serve` | Khởi động Webhook Ingestion HTTP Daemon lắng nghe event | `bun run cli.ts serve --port 3000` |
| `worker` | Khởi động Conductor Polling Worker daemon thực thi task đa kênh | `bun run cli.ts worker --conductor-url http://localhost:8080/api --sandbox` |
| `overlay` | Sinh video hiệu ứng lớp phủ (Mưa, Tuyết, Khói, Lửa, VHS, Glitch...) | `bun run cli.ts overlay --effect rain --variant storm` |
| `sfx` | Sinh hiệu ứng âm thanh (Smart Router: AI/Synth/Freesound) | `bun run cli.ts sfx --custom-prompt "cinematic boom"` |
| `<story_folder>` | Chế độ rút gọn (Legacy Storyteller) render trực tiếp thư mục story | `bun run cli.ts ./sample-story` |
| `--help` / `-h` | Hiển thị bảng hướng dẫn CLI chi tiết | `bun run cli.ts --help` |

## 3. 🧩 Chi tiết 6 Pipeline Orchestrators

Hệ thống cung cấp 6 Pipeline chuyên biệt xử lý từng bài toán sản xuất nội dung tự động:

```
+-----------------------------------------------------------------------------+
|                               6 CORE PIPELINES                              |
+-------------------+--------------------+------------------------------------+
| 1. Scraper        | 2. DB Templating   | 3. Repurposing                     |
| Tin tức / Alert   | Bar Chart Race     | Video dài -> 9:16 Shorts           |
+-------------------+--------------------+------------------------------------+
| 4. Story          | 5. Rule & Math     | 6. Ambient                         |
| 3D Depth Story    | Manim Bảng đen     | Live Loop 24/7 RTMP                |
+-------------------+--------------------+------------------------------------+
```

### Pipeline 1: `scraper` (Event-Driven Scraper & Summarizer)
- **Đầu vào**: Dữ liệu sự kiện hoặc URL báo chí / công nghệ.
- **Kênh xuất (Exporters)**: `video` (Breaking Alert Card), `audio` (TTS Voiceover), `social` (Breaking Banner), `web` (Markdown summary).
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run scraper --config event.json --exporters video,audio,social,web --out ./dist/scraper
  ```

### Pipeline 2: `db` (Database & Structured Data Templating)
- **Đầu vào**: Dữ liệu bảng thống kê (Rankings, Metrics, Thời gian).
- **Kênh xuất (Exporters)**: `video` (Bar Chart Race 60 FPS), `audio`, `social` (Carousel stats), `web` (JSONB report).
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run db --config stats.json --out ./dist/db
  ```

### Pipeline 3: `repurpose` (Long-form Recycler)
- **Đầu vào**: Video ngang 16:9 gốc + Audio + Timestamps phụ đề.
- **Kênh xuất (Exporters)**: `video` (9:16 Vertical Smart-Crop + Karaoke Subtitles), `audio`.
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run repurpose --config repurpose.json --out ./dist/shorts
  ```

### Pipeline 4: `story` (Generative Storytelling)
- **Đầu vào**: Thư mục Story chứa `story-config.json` hoặc `pipeline-ir.json`, ảnh/video B-roll và audio.
- **Tính năng**: 3D Depth Out-of-Bounds (Frame-Breaker, Volumetric Sandwich), Drop Shadow đa tầng, Auto-Segmentation (SAM 2), XFade transitions, Whisper Timestamps, FFI NVENC zero-copy.
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run story --config ./sample-story --format mp4
  # Hoặc shorthand:
  bun run cli.ts ./sample-story
  ```

### Pipeline 5: `rule` / `math` (Rule & Math Logic Engine)
- **Đầu vào**: Bài toán hình học, giải tích, suy luận logic từng bước.
- **Kênh xuất (Exporters)**: `video` (Hiệu ứng bảng đen Manim Chalkboard vẽ từng nét), `social`, `web`.
- **Lệnh chạy**:
  ```bash
  bun run cli.ts run math --config theorem.json --out ./dist/math
  ```

### Pipeline 6: `ambient` (Procedural Ambient Loop & Live Stream)
- **Đầu vào**: Cấu hình chủ đề vũ trụ, hạt không gian (Deep Space, Cyber Grid, Aurora).
- **Kênh xuất (Exporters)**: `video` (Render file), `live-stream` (Đẩy luồng trực tiếp RTMP lên YouTube/Twitch).
- **Lệnh chạy render file**:
  ```bash
  bun run cli.ts run ambient --duration 10 --out ./dist/ambient
  ```
- **Lệnh phát sóng Live Stream RTMP**:
  ```bash
  bun run cli.ts stream ambient --rtmp "rtmp://a.rtmp.youtube.com/live2/YOUR_STREAM_KEY" --duration 3600
  ```

## 4. 🛠️ Bộ Công Cụ CLI Chuyên Biệt

### 4.1 Universal Auto-Config Engine (`auto-config.ts`)

Được tái cấu trúc hoàn toàn trên kiến trúc **Universal Auto-Config Engine (v3.0)** với 6 Enterprise GoF Design Patterns (`MediaAssetProberChain`, `PipelineClassifierRegistry`, `PipelineIRBuilder`, `DirectorPresetFactory`, `AutoConfigLegacyBridgeAdapter`, `AutoConfigEngineFacade`).

#### Tính năng chính:
- **Heuristic Pipeline Classification**: Tự động nhận diện thư mục thuộc Pipeline nào (Pipelines 1–6) dựa trên cấu trúc media và hiển thị điểm tin cậy (Confidence %).
- **Fine-Grained Video Director Synthesis**: Tự động tạo cấu hình đạo diễn điện ảnh 3-Tier (Canvas LUT, Audio Staging BGM/SFX, Depth3D Sandwich/Parallax, Chuyển cảnh).
- **Dual-Emission Guarantee**: Sinh đồng thời 3 files cấu hình cho dự án:
  1. `pipeline-ir.json`: Canonical PipelineIR (v3.0.0) DAG AST cho kết xuất đa kênh.
  2. `omnichannel-config.json`: Cấu hình phân phối nội dung đa kênh (Video, Social, Audio, Web, Interactive).
  3. `story-config.json`: File cấu hình Legacy Bridge đảm bảo tương thích ngược 100% với các công cụ cũ.

#### Cách sử dụng:

```bash
# 1. Chế độ Wizard tương tác thông minh (@clack/prompts):
bun run auto-config.ts ./sample-story

# 2. Chế độ tự động hoàn toàn không tương tác (Headless CI/CD):
bun run auto-config.ts ./sample-story --yes

# 3. Chỉ định tham số trực tiếp (Command Flags):
bun run auto-config.ts ./my-project --pipeline 4 --aspect 9:16 --fps 30 --depth --transitions

# 4. Thử nghiệm xem trước không ghi file (Dry Run):
bun run auto-config.ts ./my-project --dry-run
```

| Flag | Mô tả | Giá trị hỗ trợ |
| :--- | :--- | :--- |
| `-y`, `--yes` | Bỏ qua toàn bộ câu hỏi tương tác, tự động áp dụng lựa chọn tối ưu | Boolean |
| `-n`, `--dry-run` | Kiểm tra media và tính toán phân loại mà không tạo/ghi file | Boolean |
| `--pipeline <id>` | Ép kiểu Pipeline cụ thể | `1`, `2`, `3`, `4`, `5`, `6` |
| `--aspect <ratio>` | Thiết lập tỷ lệ khung hình video | `9:16`, `16:9`, `1:1`, `4:5` |
| `--fps <number>` | Thiết lập tốc độ khung hình | `24`, `30`, `60` |
| `--depth` / `--no-depth` | Bật hoặc tắt hiệu ứng không gian 3D Depth | Boolean |
| `--transitions` / `--no-transitions` | Bật hoặc tắt hiệu ứng chuyển cảnh | Boolean |

### 4.2 Sinh Hiệu Ứng Lớp Phủ Overlay (`overlay`)
Render các vòng lặp seamless loop hạt mưa, tuyết, khói, lửa, VHS, glitch bằng `@napi-rs/canvas` và mã hóa FFI trực tiếp:

- **Chế độ Wizard tương tác**:
  ```bash
  bun run cli.ts overlay
  ```
- **Chế độ dòng lệnh Headless**:
  ```bash
  bun run cli.ts overlay --effect rain --variant storm --duration 4 --width 1920 --height 1080 --fps 30
  bun run cli.ts overlay --composite retro_glitch_vhs
  ```

### 4.3 Sinh Hiệu Ứng Âm Thanh SFX (`sfx`)
Hỗ trợ Smart Routing tự động chọn giữa Procedural UI Synth, AudioLDM2 AI và Freesound:

- **Chế độ Wizard tương tác**:
  ```bash
  bun run cli.ts sfx
  ```
- **Chế độ Prompt AI Headless**:
  ```bash
  bun run cli.ts sfx --custom-prompt "heavy thunder and lightning crash" --duration 3.5
  ```
- **Chế độ Composite / Preset Headless**:
  ```bash
  bun run cli.ts sfx --composite cyberpunk_ui
  bun run cli.ts sfx --effect ui --variant click --sub-variant subtle
  ```

## 5. 📋 Bảng Tham Số Toàn Diện (Flags Reference)

| Flag | Tên đầy đủ | Phạm vi áp dụng | Mô tả chức năng |
| :--- | :--- | :--- | :--- |
| `-c`, `-i` | `--config`, `--input <path>` | `run`, `stream`, `ir-render` | Đường dẫn file JSON cấu hình hoặc thư mục story |
| `-e` | `--exporters <list>` | `run` | Danh sách kênh xuất cách nhau bởi dấu phẩy: `video,audio,social,web` |
| `-o` | `--out`, `--output <dir>` | `run`, `ir-render` | Thư mục lưu trữ kết quả render |
| `-f` | `--format`, `--container <fmt>` | `run`, `ir-render` | Định dạng video: `mp4`, `mkv`, `mov`, `webm` (Mặc định: `mp4`) |
| `-j` | `--concurrency <num>` | `ir-render`, `run` | Số worker threads render song song các lát cắt thời gian (IDR temporal chunks) |
| `--chunk-start` | `--chunk-start <frame>` | `ir-render` | Frame bắt đầu cho cụm render phân tán |
| `--chunk-end` | `--chunk-end <frame>` | `ir-render` | Frame kết thúc cho cụm render phân tán |
| `--export-ir` | `--export-ir <file.json>` | `run`, `ir-render` | Xuất tài liệu Video IR JSON đã biên dịch ra đĩa để phân tích hoặc debug |
| `-r` | `--rtmp <url>` | `stream` | Endpoint URL RTMP/RTMPS máy chủ tiếp nhận luồng (YouTube/Twitch) |
| `-p` | `--port <port>` | `serve` | Cổng HTTP lắng nghe Webhook (Mặc định: `3000`) |
| `-w` | `--conductor-url <url>` | `worker` | Địa chỉ máy chủ Netflix Conductor OSS API |
| `-s` | `--sandbox` | `worker` | Chế độ chạy thử nghiệm sandbox mô phỏng task không cần Conductor server |
| `-d` | `--duration <sec>` | `stream`, `run` | Giới hạn thời lượng luồng phát hoặc vòng lặp (giây) |
| `-n` | `--dry-run` | `run`, `auto-config` | Kiểm tra tính hợp lệ của AST & Media mà không mã hóa video |
| `-h` | `--help` | Toàn cục | Hiển thị hướng dẫn sử dụng CLI |

## 6. 💡 Bảng Tổng Hợp Lệnh Nhanh (Cheatsheet)

```bash
# 1. Khởi tạo & Tự động quét cấu hình dự án với Auto-Config Engine v3.0
bun run auto-config.ts ./my-story

# 2. Tự động hóa tạo cấu hình không cần bấm phím (CI/CD)
bun run auto-config.ts ./my-story --yes --aspect 9:16 --fps 30

# 3. Chạy thử nghiệm các mẫu chuẩn trong ./samples/ (Đầy đủ SFX, VFX Overlays & 3D Depth)
bun run cli.ts run scraper -c ./samples/01-scraper-summarizer/source_feed.json -n
bun run cli.ts run db -c ./samples/02-db-templating/database_payload.json -n
bun run cli.ts run repurposing -c ./samples/03-repurposing-recycler/repurpose_transcript.json -n
bun run cli.ts ./samples/04-generative-storytelling -n
bun run cli.ts run rule -c ./samples/05-rule-logic/proof_problem.json -n
bun run cli.ts run ambient -c ./samples/06-ambient-loops/ambient_config.json -n

# 4. Render Story Video theo chuẩn Legacy Shorthand
bun run cli.ts ./my-story

# 5. Render trực tiếp qua Canonical Universal Video IR Engine (4 threads song song)
bun run cli.ts ir-render -c ./my-story/story-config.json -j 4 --format mp4

# 6. Xuất đồng thời 4 kênh phân phối (Omnichannel Video, Audio, Social, Web)
bun run cli.ts run scraper -c ./event.json -e video,audio,social,web -o ./dist

# 7. Chạy Webhook Daemon đón sự kiện tự động
bun run cli.ts serve --port 3000

# 8. Khởi động Conductor Worker Daemon
bun run cli.ts worker --conductor-url http://localhost:8080/api

# 9. Phát trực tiếp 24/7 RTMP Ambient Stream
bun run cli.ts stream ambient --rtmp "rtmp://..." --duration 7200

# 10. Sinh lớp phủ Overlay Mưa Bão Full HD
bun run cli.ts overlay -e rain -v storm -d 3

# 11. Sinh âm thanh SFX qua Prompt AI
bun run cli.ts sfx -p "futuristic sci-fi portal open" -d 4.0

# 12. Chạy toàn bộ Test Suite của Monorepo
bun run test
```
