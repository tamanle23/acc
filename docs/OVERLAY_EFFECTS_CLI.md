# Hướng dẫn sử dụng Overlay Effects CLI

Công cụ `overlay-effects-cli.ts` là một công cụ mạnh mẽ dùng để tạo ra các video chứa hiệu ứng lớp phủ (overlay effects) dạng vòng lặp liền mạch (seamless loop). Công cụ sử dụng HTML5 Canvas (thông qua `@napi-rs/canvas`) để tính toán đồ họa hạt (particles) trực tiếp trong bộ nhớ (Zero-Disk) và nén thành video siêu nhẹ qua FFmpeg.

> 📖 **Xem thêm:** Tài liệu đặc tả toán học và cơ chế hòa trộn chi tiết tại [`OVERLAY_METHODS_SPEC.md`](./OVERLAY_METHODS_SPEC.md).

---

## 🚀 Cách sử dụng

```bash
bun run overlay-effects-cli.ts --effect <tên_hiệu_ứng> [các_tùy_chọn]
```

**Ví dụ thực tế:**
```bash
# Tạo bão tuyết dài 5 giây, độ phân giải Full HD (Nền đen MP4)
bun run overlay-effects-cli.ts --effect snow --variant blizzard --duration 5 --width 1920 --height 1080

# Tạo lá phong rơi trong suốt (Nền trong suốt WebM VP9)
bun run overlay-effects-cli.ts --effect leaves --variant sakura_petals --bg-transparent
```

### ⚙️ Danh sách tham số (Options)

| Tham số | Viết tắt | Mặc định | Ý nghĩa |
| :--- | :--- | :--- | :--- |
| `--effect` | `-e` | *(Bắt buộc)* | Tên nhóm hiệu ứng (VD: `rain`, `snow`, `dust`). Xem bảng Catalog bên dưới. |
| `--variant` | `-v` | `default` | Biến thể của hiệu ứng (VD: `drizzle`, `storm`). |
| `--duration` | `-d` | `3.0` | Độ dài của vòng lặp (giây). *Mẹo: Dùng số nguyên tố (3, 5, 7) để kết hợp vòng lặp Polyrhythmic dài hạn.* |
| `--fps` | `-f` | `30` | Tốc độ khung hình (Frames Per Second). |
| `--width` | `-w` | `1920` | Chiều rộng video (pixel). |
| `--height` | `-h` | `1080` | Chiều cao video (pixel). |
| `--bg-transparent` | `-t` | `false` | Bật chế độ nền trong suốt. Video xuất ra dạng `.webm` (VP9). Nếu tắt (mặc định), video sẽ có nền đen `.mp4` (dùng cho blend mode `screen`). |
| `--output` | `-o` | *(Tự động)* | Đường dẫn file xuất ra. Mặc định lưu vào `./autogenerated/overlay-effects/`. |
| `--canvas-engine` | `-c` | `napi-rs` | Lõi xử lý Canvas. |

## 📁 Cấu trúc thư mục đầu ra

Khi chạy lệnh hoàn tất, hệ thống sẽ tự động xuất ra 2 tệp tại thư mục `./autogenerated/overlay-effects/`:

1. **Tệp Video:** `[effect]_[variant]_[duration]s.mp4` (hoặc `.webm`)
2. **Tệp JSON (Metadata):** Chứa thông tin về hiệu ứng để hệ thống biết nó cần áp dụng Blend Mode gì (`screen` hay `overlay`).

```json
{
  "effect": "rain",
  "variant": "storm",
  "resolution": {
    "width": 1920,
    "height": 1080
  },
  "fps": 30,
  "duration": 5,
  "background": {
    "type": "solid",
    "color": "#000000",
    "recommended_blend_mode": "screen"
  },
  "file": "rain_storm_5s.mp4"
}
```

## 🧠 Kiến trúc Cốt lõi (Dành cho Developer)

- **Memory-Efficient Data Pipeline (Zero-Disk):** Không tạo ra file PNG/JPG rác. Hình ảnh Canvas được trích xuất thành raw buffer RGBA và Pipe trực tiếp vào FFmpeg.
- **Seamless Looping:** Nội suy vòng lặp (Frame cuối khớp frame đầu) tạo cảm giác vô tận mượt mà.
- **Polyrhythmic Looping:** Khả năng kết hợp các độ dài nguyên tố để tạo sự ngẫu nhiên trong thời gian dài (tránh quy luật thị giác trùng lặp).
