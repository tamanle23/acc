## 1. Executive Summary & Aligned Decisions

Following the interactive `/grill-me` alignment, the architectural decisions and parity guarantees are solidified:
1. **Canonical Modifier / Plugin Wrapping Invariant**: All visual transformations and diagnostic projections remain strictly wrapped in canonical `ModifierPlugin` implementations in `@acc/ir`. Zero ad-hoc drawing bypasses in `preview.worker.ts` or Studio UI components.
2. **Web & Node Dual-Runtime Parity via `IRPreviewEngine`**:
   - `IRPreviewEngine` in `@acc/ir/src/renderer/preview/IRPreviewEngine.ts` is the single source of truth across both runtimes.
   - It delegates to `IRCanvasCompositor.renderFrame()` using `UniversalCanvasProvider`, executing bit-identically in browser Web Workers (`WebCanvasAdapter`) and Node.js CLI / tests (`NapiCanvasAdapter`).
3. **Transient Viewport Diagnostic State**:
   - The Depth Heatmap button in the Viewport Control Bar passes transient `{ debugMode: 'depth_heatmap' }` options to `IRPreviewEngine.renderFrame()`.
   - `IRCanvasCompositor` passes this to `Depth3DPlugin.renderClipSpace()`, which blits the depth disparity map directly without polluting or mutating the saved Video IR document.
4. **Auto-Reframe Integration**: Implemented as a first-class sequence modifier (`vfx/auto_reframe`) in `@acc/ir` leveraging [`AutoReframeStrategy`](file:///c:/Users/Admin/workspace/git/acc/packages/core-isomorphic/src/vision/AutoReframeStrategy.ts) from `@acc/core-isomorphic`, supporting target aspect ratios (`9:16`, `1:1`, `4:5`, `16:9`), EMA smoothing (`0.1`–`0.9`), and interactive crop guide overlays.
5. **Gizmo Contextual Action UX**: The Preview Gizmo [`ContextualActionPill`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/preview/ContextualActionPill.tsx) presents a lightweight Liquid Glass popover menu for 3D Pop-Out, allowing users to pick depth modes:
   - **Parallax 2.5D**: Adds `vfx/depth3d` with `mode: 'parallax_25d'`
   - **Pop-Out (Frame Breaker)**: Adds `vfx/depth3d` with `mode: 'frame_breaker'`
   - **Rim Light Cutout**: Adds `vfx/depth3d` with `mode: 'silhouette_rim_light'`
6. **Strategy Resolution in Inspector**: Zero-latency Heuristic algorithms (`DepthStrategyId.Heuristic`, `SegmentationStrategyId.GrabCutFallback`) remain the default for instant 60fps responsiveness; neural models (`Depth-Anything-V2`, `BiRefNet`) are selectable via a stylized badge dropdown in the Inspector when weights/hardware are ready.

## 3. Detailed Implementation Steps

### Phase 1: `AutoReframeModifierPlugin` in `@acc/ir`
1. Create `packages/ir/src/plugins/vfx/AutoReframeModifierPlugin.ts`:
   - Extends `ModifierPlugin<AutoReframePluginParams>`.
   - Supports parameters: `targetAspectRatio` (`'9:16' | '1:1' | '4:5' | '16:9'`), `smoothingFactor` (`number`), `motionDamping` (`boolean`), `visualGuide` (`boolean`), `strategyId` (`string`).
   - Uses `AutoReframeStrategy` to calculate smooth window translations and scale adjustments per frame without heap allocations.
2. Register in `packages/ir/src/plugins/index.ts` via `registerCoreModifierPlugins()`.
3. Add automated tests in `autogenerated-tests/auto_reframe_modifier_plugin.test.ts`.

### Phase 2: Depth Diagnostic Mode in `Depth3DPlugin`, `IRCanvasCompositor`, and `IRPreviewEngine`
1. Update `packages/ir/src/renderer/shared/IRCanvasCompositor.ts`:
   - Add `debugMode?: 'depth_heatmap' | 'none'` to `CanvasCompositorOptions`.
   - In `renderFrame()`, pass `debugMode` into `ClipRenderContext`.
2. Update `packages/ir/src/plugins/vfx/Depth3DPlugin.ts`:
   - In `renderClipSpace()`, if `ctx.debugMode === 'depth_heatmap'`, blit the pre-computed grayscale or false-color depth disparity map with overlay opacity directly onto the canvas.
3. Update `packages/ir/src/renderer/preview/IRPreviewEngine.ts`:
   - Accept `debugMode?: 'depth_heatmap' | 'none'` in `PreviewRenderOptions` and forward to `IRCanvasCompositor`.

### Phase 3: DynamicModifierInspector Vision Strategy Controls
1. In `apps/studio/src/components/inspector/ModifierControlStrategies.tsx`:
   - Implement `VisionStrategyControlStrategy` supporting `vision_depth_strategy` and `vision_segmentation_strategy` types.
   - Dynamically load registered options from `VisionEngineRegistry`.
   - Render performance badges (`⚡ Instant / Heuristic` vs `🧠 Neural AI`).
2. Update `Depth3DPlugin.ts` and `AutoReframeModifierPlugin.ts` schemas to declare strategy field types.

### Phase 4: Preview Gizmo ContextualActionPill 3D Popover
1. In `apps/studio/src/components/preview/ContextualActionPill.tsx`:
   - Add a 3D Depth button with icon `Box` / `Sparkles`.
   - Open a sleek Liquid Glass popover menu offering:
     - **2.5D Parallax Plane**
     - **Frame Breaker Pop-Out**
     - **Subject Rim Light Cutout**
     - **Auto-Reframe (9:16 Mobile)**
   - When clicked, dispatches `IRStateManager.addModifier` or `updateModifier`.

### Phase 5: ViewportControlBar Depth Heatmap Diagnostic Mode
1. In `apps/studio/src/components/preview/ViewportControlBar.tsx`:
   - Add `showDepthHeatmap: boolean` state and `onToggleDepthHeatmap: () => void`.
   - Render `ScanEye` button with active glowing styling.
2. In `apps/studio/src/components/Preview.tsx`:
   - Forward `showDepthHeatmap` state to `PreviewWorkerBridge`.
3. In `apps/studio/src/lib/worker/PreviewWorkerBridge.ts` and `apps/studio/src/workers/preview.worker.ts`:
   - Add handler for message `SET_DEPTH_DEBUG_MODE`.
   - Pass `debugMode: 'depth_heatmap'` to `engine.renderFrame(...)`.

### Phase 6: VFX Preset Bank Expansion
1. In `apps/studio/src/lib/library/vfxBank.ts`:
   - Add presets:
     - `vfx_parallax_zoom_3d`: 2.5D parallax plane with gentle forward push.
     - `vfx_auto_reframe_mobile`: 9:16 smart subject tracking crop.
     - `vfx_cinematic_rack_focus`: Foreground to background focal rack.
