## 1. Executive Summary & Architectural Paradigm

### 1.1 The ACC Human Interaction Interface Strategy
The ACC (Automated Content Creator) application runs as a high-throughput, headless, stateless execution pool orchestrated by **Netflix Conductor OSS**. While 56.4% of content generation is hands-free after initial configuration, **35.2% of content creation workflows (`In the Middle` stage) require mid-flight human review and intervention gates**, and **56.4% require precise pre-execution seeding (`Before` stage)**.

The **ACC Liquid Glass Control Plane** provides a real-time visual cockpit for human operators to:
1. **Trigger & Seed (`Before` Stage):** Curate inputs, setup RSS whitelists, inject database spec matrices, train character LoRAs, configure math solvers, and set ambient stream seeds.
2. **Intervene & Refine (`In the Middle` Stage):** Pause at Conductor `HUMAN_REVIEW` task gates to perform zero-copy video frame trimming, AI script tone editing, character consistency checks, audio sidechain ducking, and interactive HTML5 node reachability verification.
3. **Audit & Health Monitor (`After` Stage):** Monitor live RTMP streams, verify real-time price spike tickers, audit auto-reply bot logs, and track 1-to-N omnichannel fan-out metrics.

## 3. Frontend System Architecture & Design Patterns Mapping

To support 250 content variations without code duplication, the Control Plane frontend is built using **7 Core Software Design Patterns**:

```text
                                DESIGN PATTERNS IN FRONTEND
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ 1. Strategy Pattern: Component Strategy Registry maps content types to Intervention UIs   │
│ 2. Command Pattern: User edits (script tweaks, video trims) encapsulated in Undo/Redo Cmds │
│ 3. State Machine Pattern: Manages Conductor task states (POLL, PAUSED, EDITING, RESUMED) │
│ 4. Observer Pattern: Reactive WebSocket updates for live FFmpeg progress & Conductor logs │
│ 5. Composite Pattern: Nested timeline tracks & scene layers in Video/Audio Workspaces    │
│ 6. Decorator Pattern: Overlays live safe zones, waveform histograms & brand safe guards  │
│ 7. Flyweight Pattern: Shared Canvas/WebGL contexts and video scrub buffer instances       │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 Component Strategy Registry (`InterventionStrategyRegistry`)

```typescript
// apps/control-plane-ui/src/strategies/InterventionStrategyRegistry.ts
import { ComponentType } from 'react';

export interface InterventionProps<TInput = any, TOutput = any> {
  taskId: string;
  workflowInstanceId: string;
  contentTypeId: string;
  pipelineId: string;
  inputData: TInput;
  onSubmit: (updatedOutputData: TOutput) => Promise<void>;
  onReject: (reason: string) => Promise<void>;
}

export class InterventionStrategyRegistry {
  private static registry = new Map<string, ComponentType<InterventionProps>>();

  public static register(contentTypeId: string, component: ComponentType<InterventionProps>): void {
    this.registry.set(contentTypeId, component);
  }

  public static getStrategy(contentTypeId: string, pipelineId: string): ComponentType<InterventionProps> {
    const custom = this.registry.get(contentTypeId);
    if (custom) return custom;

    // Fallback to Canonical Pipeline Strategy
    const pipelineFallback = this.registry.get(`pipeline_${pipelineId}`);
    if (pipelineFallback) return pipelineFallback;

    throw new Error(`[InterventionRegistry] No strategy found for ContentType: ${contentTypeId}`);
  }
}
```

## 4. State Machine & Netflix Conductor OSS Integration

The UI acts as the client to Netflix Conductor's `/tasks` REST/WebSocket API. When a workflow hits a `HUMAN_REVIEW` task node, Conductor pauses execution and sets task status to `IN_PROGRESS` or `PAUSED`.

```text
               CONDUCTOR TASK STATE MACHINE IN CONTROL PLANE
  ┌──────────────┐
  │  POLLING     │ ◄── UI listens to Conductor Task Queue via WebSockets
  └──────┬───────┘
         │ Task received (status: IN_PROGRESS / taskType: HUMAN)
         ▼
  ┌──────────────┐
  │  INSPECTING  │ ◄── Liquid Glass UI renders specific Intervention Strategy Workspace
  └──────┬───────┘
         │ User modifies parameters (script, video cuts, audio levels)
         ▼
  ┌──────────────┐
  │  VALIDATING  │ ◄── Automated brand safety, KaTeX math checks, safe zone checks
  └──────┬───────┘
         │ User clicks "Approve & Resume Workflow"
         ▼
  ┌──────────────┐
  │  SUBMITTING  │ ◄── POST to Conductor `/tasks` with updated payload -> Workflow Resumes
  └──────────────┘
```

## 5. Universal Pipeline Trigger UIs (`Before` Stage - Pre-Execution Setup)

The **Trigger UI Workspace** allows content creators and team leads to launch new creation pipelines or configure automated schedule triggers.

### 5.1 Pipeline 1: Event-Driven Scraper & Summarizer Trigger Studio
* **Target Content Types:** Items 1–10 (Industry Digest, Market Recap, Crypto Alerts, Tech Repos)
* **Liquid Glass Components:**
  * **Translucent Source Feed Matrix:** Interactive glass cards listing Whitelisted RSS Feeds, API Webhooks, and GitHub GraphQL endpoints with real-time health indicator lights.
  * **DOM Selector & Grammar Rule Builder:** Code Editor with JSON Schema validation and vLLM Qwen2.5 grammar rules.
  * **Threshold Sliders:** Translucent sliders for volatility triggers (e.g., "Trigger alert when BTC swings > 3.5% in 15 mins").

### 5.2 Pipeline 2: Database Injection & Programmatic Templating Studio
* **Target Content Types:** Items 11–20, 61–70, 111 (Product VS Comparisons, Top 10 Lists, Quote Cards, Bar Chart Races)
* **Liquid Glass Components:**
  * **Spec Database Query Builder:** Visual PostgreSQL JSONB / Airtable field mapping grid with real-time preview.
  * **Canvas Typography & Layout Inspector:** Drag-and-drop glass panel adjusting canvas padding, font hierarchy, and color palettes rendered via `@napi-rs/canvas`.

### 5.3 Pipeline 3: Asset Repurposing & Transcript Studio
* **Target Content Types:** Items 40–43, 51–55, 101, 143, 146 (Podcast Transcripts, YouTube-to-Blog, Creepypasta Shorts, Webinar Cuts)
* **Liquid Glass Components:**
  * **Drag-and-Drop Glass Ingestion Dropzone:** Upload multi-gigabyte MP4/WAV files or paste YouTube URLs.
  * **Whisper Word-Level Alignment Configurator:** Model selector (Whisper.cpp small vs large-v3), speaker diarization threshold tuning, and language selector.

### 5.4 Pipeline 4: Autonomous Generative Storytelling Studio
* **Target Content Types:** Items 46, 102–103, 121–130, 173–176, 201–207 (AI Short Films, Creepypasta, Horror Stories, Choose Your Own Adventure)
* **Liquid Glass Components:**
  * **Character Consistency LoRA Selector:** Glass grid of trained character LoRAs with face lock preview nodes.
  * **Story AST Prompt Matrix:** Input seed fields for narrative genre, pacing (seconds per shot), depth-3D pop-out intensity, and emotional tone.

### 5.5 Pipeline 5: Rule-Based & Math Logic Studio
* **Target Content Types:** Items 22, 24–26, 112–113, 117, 221–225 (Math Solvers, Manim Physics, Code Tutorials, Financial Calculators)
* **Liquid Glass Components:**
  * **Live KaTeX / LaTeX Equation Canvas:** Real-time mathematical equation visualizer with bound check warnings.
  * **Matter.js / Manim Simulation Controls:** Gravity, friction, and vector speed sliders with instant WebGL simulation preview.

### 5.6 Pipeline 6: Infinite Ambient & Procedural Loop Studio
* **Target Content Types:** Items 110, 127, 141, 150, 161–166, 195 (24/7 Lofi, Binaural Beats, WebGL Shaders, White Noise)
* **Liquid Glass Components:**
  * **WebGL Shader Seed Explorer:** Live canvas node for tuning GLSL fragment shader parameters (frequency, color warp, flow speed).
  * **Audio DSP Frequency Shaping Visualizer:** Multi-band EQ curve with high-pass 30Hz anti-rumble filter toggle.

## 6. Mid-Execution Human Intervention UIs (`In the Middle` Gate Action Workspaces)

### 6.1 Workspace 1: Format 1 & 2 (Static Web & Social Network Intervention Workspace)
* **Handles Content Types:** Items 1–100 (ELI5 Explainers, Book Summary Threads, Quote Cards, Infographics)
* **Liquid Glass Interventions:**
  * **Side-by-Side Split View:** Left pane displays source ingested JSON/Markdown; right pane displays rendered Liquid Glass card or social thread preview.
  * **AI Hook & Brevity Refactor Controls:** Quick-action buttons (`Make More Punchy`, `Simplify to ELI5`, `Check Brand Safety`).
  * **Typography Overflow Guard Indicator:** Real-time badge alerting if text exceeds card padding or tweet character counts.

### 6.2 Workspace 2: Format 3 (Shorts, Reels & Long-Form Video Intervention Workspace)
* **Handles Content Types:** Items 101–150 (Reddit Creepypasta, AI Short Films, Bar Chart Races, Web Walkthroughs)
* **Liquid Glass Interventions:**
  * **Zero-Copy Frame Preview Canvas:** Canvas frame player powered by WebCodecs API streaming uncompressed frames directly from ACC scratch space.
  * **Platform Safe Zone Overlay Decorator:** Toggleable translucent mesh overlays for TikTok UI buttons, Instagram Reels caption bounds, and YouTube Shorts overlays.
  * **Depth3D & Parallax Tuning Controls:** Interactive spatial sliders adjusting foreground cutout z-distance, focal length, and dynamic camera speed.
  * **Multi-Track Editing Controls:** Trim clip boundaries, swap visual stock assets, and re-generate AI voiceovers.

### 6.3 Workspace 3: Format 4 (Audio, Podcasts & SFX Intervention Workspace)
* **Handles Content Types:** Items 151–200 (2-Host Podcasts, Audiobooks, Binaural Beats, Guided Meditations)
* **Liquid Glass Interventions:**
  * **Multitrack Waveform Visualizer:** Translucent glass audio tracks displaying Host 1, Host 2, BGM, and Foley SFX.
  * **Dynamic Sidechain Ducking Inspector:** Visual ducking curve graph allowing human operators to adjust voiceover compression threshold (-18dB) and release times.
  * **Phonetic Pronunciation Dictionary Fixer:** Inline editor for fixing mispronounced jargon (e.g. converting "API" to `ey-pee-ahy`).

### 6.4 Workspace 4: Format 5 (Interactive HTML5, WebGL & CYOA Games Workspace)
* **Handles Content Types:** Items 201–250 (Choose Your Own Adventure, Scrollytelling, Calculators, Tinder Swipers)
* **Liquid Glass Interventions:**
  * **Choice Graph Reachability Inspector:** D3.js interactive node-link graph mapping all narrative branches in CYOA games, identifying dead-end nodes or orphan choices.
  * **Live Embedded Web Sandbox:** Sandboxed `<iframe>` executing generated React/Vue/D3 components with touch event emulation.
  * **Monte Carlo Game Balance Tester:** Button to run 1,000 automated playthroughs on card battlers/calculators to flag overpowered stats.
