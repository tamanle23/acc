## 1. Executive Summary & Core Architectural Paradigm

### 1.1 Stateless Engine Workers x Netflix Conductor OSS
The ACC (Automated Content Creator) engine operates as a pool of high-performance, stateless Conductor OSS Task Workers. The ACC application core contains **ZERO business logic** (no user billing, no human review state persistence). Instead, **Netflix Conductor OSS owns all workflow state machine execution, retries, exponential backoffs, and human task gates (`HUMAN_REVIEW` / `WAIT_FOR_SIGNAL`)**.

When human intervention is required (`Before`, `In the Middle`, or `After`), Conductor pauses the workflow DAG. The **ACC Control Plane UI** provides a real-time cockpit for human operators to inspect content payloads, tweak AI scripts, adjust zero-copy video cuts, Duck audio tracks, and validate interactive node graphs. Upon approval, the UI posts updated JSON parameters to Conductor's `/tasks` API, resuming downstream ACC task workers seamlessly.

## 2. Mandatory UI/UX Directives & Inclusive Design Principles

When generating or evaluating UI designs for all 250 content type workflows, the ACC Control Plane strictly enforces 12 foundational design directives:

### 2.1 Visual Design Directives
1. **Visual Hierarchy:** Critical CTAs (e.g. `Approve & Resume Workflow`) feature prominent size, high-contrast primary colors (Emerald `#059669` / Cyan `#0284c7`), and ample whitespace to distinguish core actions from secondary options.
2. **Clarity:** Explicit text labels are mandated over ambiguous standalone icons (e.g. `Edit Script Narrative` rather than a pencil icon). Interactive elements feature predictable hover and click affordances.
3. **Consistency:** Unified component library (`LiquidGlassPanel`, `LiquidGlassModal`), strict W3C W3C W3C Design Tokens, and uniform typography scales across all screens.
4. **System Feedback:** Instant visual confirmation for user actions via hover state glows, active press scales, loading spinners, and toast notifications.
5. **Forgiveness:** Frictionless "Undo" / "Redo" command stacks for all user edits, paired with plain-language, actionable error messages (e.g., *"Script exceeds Twitter 280-character limit by 14 characters. Click 'Auto-Summarize' to fix."*).
6. **Accessibility (WCAG 2.1 AA Compliance):** Minimum 4.5:1 contrast ratio for all text elements against light glass backgrounds, and minimum **44x44px touch targets** for all mobile and tablet touch interfaces.

### 2.2 User Experience (UX) Flow Directives
7. **User-Centricity:** Mapped directly to human operator goals across the 3 lifecycle stages (`Before`, `In the Middle`, `After`).
8. **Friction Reduction:** Smart defaults, automatic PII redaction blur boxes, and automated grammar validation to minimize cognitive load.
9. **Information Architecture:** Progressive disclosure reveals advanced controls (e.g. Depth3D focal lengths, sidechain ratio curves) only when requested by the operator.
10. **Context Awareness:** Accounts for operator device constraints (desktop multi-monitor vs tablet mobile touch) with fluid responsive grid layouts.
11. **Data-Driven Iteration:** Integrated telemetry tracking operator intervention durations to optimize automation thresholds over time.
12. **Inclusive Design:** Full keyboard navigation support (`Tab`, `Enter`, `Escape`), screen reader ARIA labels, and high-contrast light mode default theme.

1. **Pipeline 1 (Event Scraper & Summarizer):** RSS Feed Whitelist matrix, API Rate-Limit sliders, and vLLM Qwen2.5 JSON Grammar Schema editor.

3. **Pipeline 3 (Repurposing & Media Ingestion):** Drag-and-drop media ingestion dropzone with Whisper.cpp word-level alignment & speaker diarization controls.
4. **Pipeline 4 (Generative Storytelling):** Character LoRA face-lock selector grid, Depth3D pop-out intensity seed, and narrative pacing AST controls.
5. **Pipeline 5 (Rule Logic & Math Engines):** Live KaTeX / LaTeX equation math previewer and Matter.js / Manim physics simulation sliders.
6. **Pipeline 6 (Infinite Ambient Loops):** WebGL GLSL shader parameter explorer and Audio DSP 30Hz anti-rumble high-pass filter toggle.

### 5.1 Format 1 & 2 (Static Web & Social Network Intervene Workspace)
* **Handles Content Types:** Items 1–100 (ELI5 Explainers, Book Summary Threads, Quote Cards, Infographics)
* **Liquid Glass Interventions:** Side-by-Side Split View displaying raw ingested source on the left and rendered social quote card on the right; AI refactoring controls (`Make Punchier`, `Simplify to ELI5`); Real-time character count overflow guard badges.

### 5.2 Format 3 (Shorts, Reels & Long-Form Video Intervene Workspace)
* **Handles Content Types:** Items 101–150 (Reddit Creepypasta, AI Short Films, Bar Chart Races, Web Walkthroughs)
* **Liquid Glass Interventions:** WebCodecs zero-copy frame player streaming directly from FFmpeg scratch space; TikTok/Reels platform safe zone mesh overlays; Interactive Depth3D parallax sliders; Multi-track clip trimming.

### 5.3 Format 4 (Audio, Podcasts & SFX Intervene Workspace)
* **Handles Content Types:** Items 151–200 (2-Host Podcasts, Audiobooks, Binaural Beats, Guided Meditations)
* **Liquid Glass Interventions:** Multitrack waveform visualizer (Host A, Host B, BGM, Foley SFX); Dynamic sidechain ducking curve inspector (-18dB attenuation curve); Inline phonetic pronunciation fixer.

### 5.4 Format 5 (Interactive HTML5, WebGL & CYOA Games Intervene Workspace)
* **Handles Content Types:** Items 201–250 (Choose Your Own Adventure, Scrollytelling, Calculators, Tinder Swipers)
* **Liquid Glass Interventions:** D3.js choice reachability node graph detecting unreachable narrative branches or orphan choice nodes; Sandboxed embedded `<iframe>` runtime player; Monte Carlo 1,000-playthrough game balance tester.
