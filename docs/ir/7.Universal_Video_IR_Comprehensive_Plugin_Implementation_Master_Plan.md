# Universal Video IR: Comprehensive Plugin Implementation Master Plan
## Architecture: Extensible Entity-Component Ecosystem (V1.0-Stable)

This document outlines the systematic implementation blueprint for the Video IR Plugin Ecosystem. It codifies procedural physics, 3D metric depth, mathematical blend modes, acoustic synchronization, intelligent sound effect routing, and canvas-based overlay generation into deterministic, phase-isolated plugins.

---

## 1. Architectural Foundations

The Universal Video IR engine enforces a strict **Open-Closed Principle**:
*   **The Core (Closed):** The root schema (Assets, Tracks, Sequences, and Relational DAG Timing) is permanently locked and strictly handles *What* and *When*.
*   **The Ecosystem (Open):** All advanced behaviors (rendering, compositing, spatial logic, audio DSP) are delegated to the `modifiers` array, evaluated by the backend Strategy Pattern interfaces.
*   **Absolute Determinism:** Wall-clock time is eliminated. All mathematical integrations, particle solvers, and physics constraints are locked to absolute integer frame ticks (`currentFrame`) and seeded PRNG hashes.

---

## 2. Phase-Isolated Execution Pipeline

Plugins must register to execute in one or more of the following deterministic phases:

### Phase 1: Probing & Relational DAG Resolution
*   **Goal:** Pre-flight calculation of all dynamic constraints into absolute integers.
*   **Plugin Targets:** `ai/auto_reframe` (Bounding box analysis), `render/acoustic_karaoke_subtitles` (HarfBuzz text shaping & phonetic syllable weighting), `procedural/voronoi_fracture` (Delaunay seed triangulation), `sfx/library_fetch` (Freesound API asset resolution), `sfx/audioldm_gen` (Local AI text-to-audio inference).

### Phase 2: Sequence-Level Execution (Clip Space)
*   **Goal:** Modifiers bound to individual asset lifespans ($t_{rel} \in [0, duration]$), rendered into isolated offscreen buffers.
*   **Plugin Targets:** `depth3d/frame_breaker` (SAM2 cutouts), `composite/homography_pin` (Screen replacements), `transition/speed_ramp` (Bezier time warp), `overlay/alpha_particle_canvas` (Zero-disk VP9 transparent overlays).

### Phase 3: Track-Level Execution (Stream Space)
*   **Goal:** Modifiers applied to continuous concatenated stream buffers across the timeline.
*   **Plugin Targets:** `procedural/swarm_boids`, `procedural/particle_emitter`, `vfx/vignette_tunnel`, `color/lut_3d`, `overlay/luma_particle_canvas` (Zero-disk H.264 screen blending overlays), `audio/composite_auto_ducking` (Foreground/Background SFX mixing).

### Phase 4: Master Canvas Compositing & Handshake
*   **Goal:** Multi-track layering, blend modes, and backpressure-synchronized export to FFmpeg (`bun:ffi`).
*   **Plugin Targets:** `composite/blend_transfer`, `depth3d/typographic_sandwich`, `vfx/macro_bokeh`, `audio/ebu_r128_normalizer`, `layout/safe_zone_guard`.

## 3. The Plugin Taxonomy & Implementation Specs

### 3.1 Spatial 3D & Depth Pop-Out (`depth3d/*`)
Requires SAM2 alpha mattes and Depth Anything v2 metric maps.
*   **`depth3d/frame_breaker`:** (Phase 2) Computes pixel depth ($z_{thresh}$). Pixels exceeding threshold bypass the inner card stencil mask, simulating 3D out-of-bounds extrusion.
*   **`depth3d/typographic_sandwich`:** (Phase 4) Adjusts Z-index compositor stack: `[Plate] -> [Text Track] -> [Subject Alpha Matte]`.
*   **`depth3d/cast_shadow_across_planes`:** (Phase 2) Affine skew projection of subject alpha contours with Gaussian blur.
*   **`depth3d/gyro_focal_tilt`:** (Phase 2) Procedural matrix rotation applying pitch/yaw offset to virtual $2.5D$ camera.

### 3.2 Procedural Physics, Particles & Swarm (`procedural/*`)
Requires seeded pseudo-random number generators (PRNG) and semi-implicit Euler integration.
*   **`procedural/particle_emitter`:** (Phase 3) Computes step-wise kinematics: $P_x(t) = P_{x0} + v_x t + \text{CurlNoise}_x(P, \text{seed}, t)$.
*   **`procedural/swarm_boids`:** (Phase 3) Applies Craig Reynolds' separation, alignment, and cohesion vector weights.
*   **`procedural/voronoi_fracture`:** (Phase 1 & 2) Phase 1 fragments the mesh. Phase 2 breaks structural glue constraints via threshold physics.

### 3.3 Generative Canvas Overlays (`overlay/*`)
Utilizes `@napi-rs/canvas` for zero-disk memory processing of particle graphics into FFmpeg pipes. Enforces seamless or polyrhythmic looping based on prime number durations.
*   **`overlay/luma_particle_canvas`:** (Phase 3) Generates H.264 compatible additive overlays on a solid `#000000` black background for screen blending. Supports variants like `rain/storm`, `dust/ambient_dust`, `embers/campfire_sparks`, `vhs/tracking_snow`, and `glitch/datamosh`.
*   **`overlay/alpha_particle_canvas`:** (Phase 2) Generates VP9 compatible overlays retaining a fully transparent alpha channel (`#00000000`). Supports variants like `leaves/sakura_petals`, `confetti/party_confetti`, `camera_ui/cctv_security`, and `audio_spectrum/circular_eq`.

### 3.4 Overlay Systems & Mathematical Blending (`composite/*`)
Maps to FFmpeg `blend` filters and Skia `SkBlendMode`.
*   **`composite/blend_transfer`:** (Phase 4) Mathematical pixel blending. E.g., `screen` ($C_{out} = 1 - (1 - C_{bg})(1 - C_{fg})$) over a solid `#000000` plate.
*   **`composite/homography_pin`:** (Phase 2) Calculates $3 \times 3$ perspective transformation matrix from source corners to destination coordinates.

### 3.5 Typography & Kinetic Motion (`render/*`, `animation/*`)
*   **`render/acoustic_karaoke_subtitles`:** (Phase 1 & 3) Syllable-weighted timestamp alignment. Enforces strict acoustic bounds (50ms lead-in, 40ms decay) and immediate de-illumination on $>60ms$ inter-word pauses.
*   **`render/lower_third`:** (Phase 2) Draws glassmorphic UI slates with eased matrix entry/exit transitions.
*   **`animation/spring_callout`:** (Phase 2) Evaluates damped harmonic oscillator equations ($F = -kx - cv$) for tracking callouts.

### 3.6 Atmosphere & Canvas Shaders (`vfx/*`, `color/*`)
*   **`color/lut_3d`:** (Phase 3) Tetrahedral interpolation against `.cube` color space maps.
*   **`vfx/macro_bokeh`:** (Phase 4) Evaluates large-radius separated Gaussian blurs and thresholded luma scaling on peripheral regions.
*   **`vfx/vignette_tunnel`:** (Phase 3) Radial smoothstep anamorphic gradient overlay.

### 3.7 Editorial Rhythm & Audio DSP (`editorial/*`, `audio/*`)
*   **`editorial/smash_cut`:** (Phase 1) Triggers instantaneous $+12\text{dB}$ audio delta and visual flash frame on specific boundary markers.
*   **`transition/speed_ramp`:** (Phase 2) Cubic Bezier interpolation of presentation timestamps ($pts$) avoiding audio pitch shift (via optical flow/resampling).
*   **`audio/sidechain_ducking`:** (Phase 3) Sidechain compressor router. Music volume attenuates when Voiceover track amplitude exceeds noise floor.
*   **`audio/ebu_r128_normalizer`:** (Phase 4) Two-pass integration enforcing $-14.0\text{ LUFS}$ target and $-1.0\text{ dBFS}$ true-peak limits.

### 3.8 Sound Effects Smart Routing & Generation (`sfx/*`)
A smart router taxonomy that abstracts audio generation technologies to supply the multi-track timeline (e.g., `scenes[].sfx` or `settings.sfx`).
*   **`sfx/procedural_synth`:** (Phase 2) Generates highly optimized, pure mathematical audio via FFmpeg for UI clicks, hovers, success chimes, and retro 8-bit effects.
*   **`sfx/library_fetch`:** (Phase 1) Queries the Freesound API to source photorealistic diegetic fauna and foley sounds.
*   **`sfx/audioldm_gen`:** (Phase 1) Triggers local AI Text-to-Audio (AudioLDM2) generation for freeform custom prompts, cinematic impacts, and sci-fi lasers.
*   **`audio/composite_auto_ducking`:** (Phase 3) A multi-layer mixer that assigns `foreground` and `background` roles to synthesized audio, automatically applying sidechain compression to duck background ambient layers when foreground layers trigger.

## 4. Backend TypeScript Interface Contracts

To integrate plugins into the core engine, the backend implements the Strategy Pattern.

```typescript
export interface IVideoPluginStrategy<TParams TState="any" any,> {
  readonly pluginId: string;
  readonly targetPhase: 1 | 2 | 3 | 4;

  /**
   * PHASE 1: Pre-flight. Resolve expressions, bounding boxes, or physics setups.
   * Returns an immutable state object passed to rendering phases.
   */
  preflight(params: TParams, dagContext: DAGResolutionContext): TState;

  /**
   * PHASE 2: Local Clip Space. Render into the isolated sequence surface buffer.
   */
  renderClipSpace?(ctx: SkiaCanvasContext, frame: number, state: TState): void;

  /**
   * PHASE 3: Stream Space. Render across the concatenated track buffer.
   */
  renderStreamSpace?(ctx: SkiaCanvasContext, frame: number, state: TState): void;

  /**
   * PHASE 4: Master Composite. Modify the final outgoing multi-track mix.
   */
  renderMasterComposite?(masterCtx: SkiaCanvasContext, frame: number, state: TState): void;
}
