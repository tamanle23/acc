# History 345: Inverted Telemetry Ingestion Architecture & Ark UI Fleet Observability

## Task Overview
Execute [Iteration 37 Master Plan](file:///Users/anle/workspace/acc/docs/master_implementation_plan_iteration37.md) end-to-end:
1. Correct the SSE telemetry misconception by implementing an **Inverted Telemetry Ingestion Model**:
   - Supervised sidecars stream/emit outbound metrics to AI-Supervisor.
   - Python AI backend provides gRPC Server Streaming (`rpc StreamTelemetry(TelemetryStreamRequest) returns (stream TelemetryEvent)`) on port 50051.
   - Worker daemon provides standard HTTP Server-Sent Events (`GET /api/worker/telemetry/stream` on port 4000).
   - AI-Supervisor control plane implements client stream consumers (`PythonGrpcStreamConsumer` and `WorkerSseStreamConsumer`) with exponential backoff auto-reconnect (`1s -> 2s -> 5s -> 10s`).
2. Dual Persistence:
   - In-memory sliding ring-buffer (last 200 events) for real-time SolidJS UI filtering.
   - Append-only forensic file `~/.acc/supervisor/audit_events.jsonl` for post-mortem analysis across restarts.
3. SolidJS Dashboard Reactive Refactor:
   - Deleted 3 legacy `setInterval` HTTP polling loops in `supervisorStore.ts`.
   - Wired native browser `EventSource('/api/telemetry/stream')`.
4. Ark UI Primitives Expansion:
   - `@ark-ui/solid` Drawer: `AuditDrawer.tsx` rendering model lifecycle transitions, loaded models, evictions, and OOM circuit breaker alerts with 5-state matrix and tabs.
   - `@ark-ui/solid` Dialog and Slider: `TtsPlaygroundModal.tsx` for real-time speech verification across Kokoro 82M, VieNeu-v3-Turbo, and Cadence fallback with RTF benchmarking.
5. Studio Boundary Isolation:
   - Kept Studio's `TelemetryCompanionCard.tsx` and `DiagnosticTelemetryCard.tsx` decoupled from sidecar fleet management.
