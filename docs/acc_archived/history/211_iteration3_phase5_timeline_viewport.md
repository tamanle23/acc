## 🎯 Context & Problem Statement
Following the Option A decoupling of `apps/studio` into a pure 100% client-side React 19 SPA, the studio required transformation into a true non-linear video editing (NLE) environment. The fundamental mandate was establishing the **Universal Video IR V1.0-Stable Schema as the single source of truth (SSOT)**:
1. The primary purpose of Studio is visually authoring and inspecting Video IR documents.
2. The input to Studio is a valid `VideoIRDocument` JSON file, and the output is the modified `VideoIRDocument` JSON file with 100% round-trip fidelity.
3. Every timeline action (clip trimming, playhead splitting, modifier tweaking) directly mutates the Video IR document.
4. The viewport must deliver real-time calibrated WebGL 2.0 fragment shader rendering with zero server footprint at 0 FPS idle.
5. Audio scrubbing must provide immediate tactile feedback via pure browser Web Audio API.

---

## 🛠️ Key Implementation Changes

### 1. Universal Video IR Client Exports (`packages/ir`)
- **Isomorphic Browser Prober Interface**: Extracted `IAssetMetadataProber` in `packages/ir/src/prober/AssetMetadataProber.ts` and enabled polymorphic probers in `RelationalDAGCompiler`.
- **Pure Client Subpath Export (`@acc/ir/client`)**: Exported clean browser-compatible contracts (`VideoIR`, `RelationalDAGCompiler`, `IntervalTreeIndex`, `VideoIRSchemaValidator`) in `packages/ir/package.json` without native Node or C-binding dependencies.

### 2. Browser Asset Metadata Prober (`apps/studio/src/lib/ir/`)
- Implemented `BrowserAssetMetadataProber` using browser-native HTML5 `Audio`, `Image`, and `Video` elements to asynchronously probe durations and aspect ratios without Node `fs` or `child_process`.
- Implemented `defaultDemoIR` featuring 2 video tracks (with `vfx/color_grading` and `overlay/canvas_particles`), 2 audio tracks (with `sfx/dynamic_ducking`), 1 timed text subtitle track, and relational timings (`after`, `matchLengthOf`).

### 3. Reactive Video IR State Store (`IRStateManager`)
- Built `IRStateManager` as a singleton reactive store:
  - Manages `VideoIRDocument` as the SSOT with an immutable undo/redo history stack (up to 50 states).
  - Automatically compiles relational timelines via Kahn's algorithm and builds an `IntervalTreeIndex` for $O(\log N)$ frame intersection queries.
  - Implemented `trimSequence` (handles both absolute numeric frames and relational `offsetFrames` / `paddingFrames`).
  - Implemented `splitSequence` (splits sequences at the playhead and establishes `after` relational chaining).
  - Implemented `updateModifier` and `removeModifier` (real-time parameter mutations with schema validation).
  - Implemented `loadFromJSON` and `exportJSON`.

### 4. Calibrated WebGL 2.0 Fragment Shader Viewport (`Preview.tsx`)
- Upgraded the preview viewport from static 2D canvas to a hardware-accelerated **WebGL 2.0 GLSL shader pipeline**:
  - Fullscreen quad vertex shader with inverted screen-space texture coordinates.
  - Procedural fragment shader implementing exposure compensation, contrast adjustment, saturation grading, and vignette attenuation directly from active sequence `vfx/color_grading` modifiers.
  - Dynamic subtitle text overlay rendered over active `TimedTextCue` cues.
  - Event-driven execution (0 FPS idle): only redraws on playhead motion or modifier value adjustment.

### 5. Multi-Track VideoFlow NLE Timeline (`Timeline.tsx`)
- Replaced boilerplate lane display with interactive multi-track editing:
  - **Dynamic Zoom & Pan**: Slider-driven zoom ratio ($0.4\times$ to $3.0\times$) with horizontal scroll.
  - **Trimming Handles**: Drag-to-trim start and end handles on sequences.
  - **Razor / Split Tool (`Scissors`)**: Instant sequence splitting at the current frame (`C` hotkey).
  - **Magnetic Snapping (`Magnet`)**: Snaps playhead and clip boundaries.
  - **Track Controls**: Mute, solo, and lock toggles per track.
  - **Keyboard Transport**: `Space` (Play/Pause), `ArrowLeft` / `ArrowRight` (Frame step / 1s jump with `Shift`), `Home` (Rewind).

### 6. Client Web Audio Engine & Canvas Waveforms (`WebAudioEngine.ts` & `AudioWaveform.tsx`)
- Pure browser Web Audio API (`AudioContext`, `OscillatorNode`, `GainNode`) providing tactile micro-pitch scrub sound feedback as the playhead moves.
- Waveform peak decimation algorithm rendering responsive canvas audio waveforms under audio track sequences.

### 7. Titlebar & Sidebar Integration (`Titlebar.tsx` & `Sidebar.tsx`)
- **Titlebar**: Added "Import Video IR", "Save Video IR", "Undo" (`Ctrl+Z`), and "Redo" (`Ctrl+Y`) controls alongside WebCodecs MP4 export.
- **Sidebar**:
  - **IR Assets Tab**: Dynamic searchable catalog of all assets registered in `doc.assets`.
  - **Inspector Tab**: Real-time slider controls for `vfx/color_grading` (Contrast, Saturation, Exposure) and `sfx/dynamic_ducking` (Duck Volume) on selected sequences.
