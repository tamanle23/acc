# 305: Liquid Glass Design Theme Polish for Visual VideoIR JSON Debugger

## Summary
Audited and upgraded all UI elements in `apps/studio/src/components/debugger/VisualIRJsonDebuggerModal.tsx` and its extracted submodules to fully harmonize with the studio's system **Liquid Glass Design System** (`[data-glass-style]`, `--glass-bg`, `--glass-border`, `--glass-border-highlight`, `glass-panel`, `glass-card`, `glass-pill`, `glass-button-primary`):

1. **Modal Container & Header**:
   - Upgraded `DialogContent` to full specular liquid glass panel (`border-t-[var(--glass-border-highlight)]`, `glass-panel`, `shadow-2xl`).
   - Modal header styled with frosted acrylic backdrop blur (`bg-[var(--glass-bg)]/80 backdrop-blur-md`).
   - App logo container given dynamic accent glow (`shadow-[0_0_12px_var(--accent-glow)]`).
2. **View Mode Switcher Toolbar**:
   - Replaced default buttons with semantic `glass-pill` and active `glass-button-primary` pills with specular borders and hover states.
3. **Interactive Visual Tree Editor**:
   - Upgraded search toolbar and path breadcrumbs to semi-transparent glass surfaces with `backdrop-blur-xs`.
   - Node badges and sequence indicators styled with semantic theme variables (`--accent-primary`, `--accent-glow`).
   - Context action buttons styled with `glass-card` and subtle frosted hover states.
   - Field editors (dropdowns, inputs, boolean switches) styled with `var(--glass-bg)`, `var(--glass-border)`, and dynamic focus glow rings.
4. **Shiki Code Viewer & Code Toolbar**:
   - Code toolbar upgraded to liquid glass surface with specular buttons.
   - Editor gutter numbers and error markers styled with liquid glass borders and semi-transparent rose alerts.
5. **Diagnostics Telemetry & Footer**:
   - Upgraded telemetry cards to responsive `glass-card` surfaces.
   - Modal footer styled with `bg-[var(--glass-bg)]/80 backdrop-blur-md` and `glass-button-primary` for the "Apply to Studio" CTA.
