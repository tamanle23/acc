## Changes Implemented

### 1. SIMDParticleComputeEngine (`@acc/effect-engines/src/overlay-effects/simulators/SIMDParticleComputeEngine.ts`)
- Implemented high-throughput vectorized particle engine:
  - Particle buffer stride (11 floats): $[x, y, z, v_x, v_y, v_z, \text{life}, \text{maxLife}, \text{size}, \text{opacity}, \text{colorIndex}]$.
  - Vectorized update loop with gravity, drag, velocity integration, and lifetime fade.
  - Tail swap dead-particle removal avoiding array splicing or garbage collection churn.
  - Batch spawning and direct canvas blitting for rain, snow, embers, dust, fire, and sparks.

### 2. PostProcessingShaders (`@acc/effect-engines/src/overlay-effects/simulators/PostProcessingShaders.ts`)
- Implemented zero-allocation post-processing shader kernels:
  - `applyChromaticAberration`: Fast horizontal RGB channel shift using scanline caching to prevent in-place overwrite.
  - `applyBloom`: High-pass thresholding ($>0.7$) with downsampled blur and additive screen compositing.
  - `applyAnamorphicFlare`: Optical horizontal streak lines with customizable tint.

### 3. CanvasAdapterFactory Enhancement (`@acc/effect-engines/src/overlay-effects/canvas-strategies/factory.ts`)
- Dynamic engine resolution supporting `'gpu' | 'napi-rs' | 'auto'`.
- Detects display availability and headless environments (`DISPLAY`, OS platform) to ensure zero crashes in Linux/CI/CD headless containers.

### 4. CanvasParticleOverlayPlugin Modernization (`@acc/ir/src/plugins/overlay/CanvasParticleOverlayPlugin.ts`)
- Extended `CanvasParticleOverlayParams` with `useSIMD?: boolean` and `shaders?: PostProcessingShaderParams`.
- Pre-warms `SIMDParticleComputeEngine` and pre-allocates scratch compositing canvases during `execute()`.
- Steps simulation and applies post-processing passes during `renderStreamSpace()`.

### 5. Automated Test Suite (`autogenerated-tests/particle_simd_vfx.test.ts`)
- Verified 10,000+ particle continuous buffer management.
- Verified headless adapter resolution.
- Verified chromatic aberration channel displacement math.
- Verified bloom & anamorphic flare execution.
- Verified `CanvasParticleOverlayPlugin` 10-frame stream rendering.
