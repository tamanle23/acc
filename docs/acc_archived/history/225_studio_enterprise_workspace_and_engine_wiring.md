## 1. Context & Objectives
Prior to this task, `apps/studio` placed the Library, Assets Vault, and Inspector together in a single right sidebar tabs component. Drag-and-drop was implemented via legacy HTML5 Drag and Drop events (which suffered from OS ghosting glitches and poor pointer separation), and the Viewport canvas used a standalone WebGL2 shader rather than directly mounting the isomorphic `UniversalThreeScene` and syncing `UniversalAudioMixer` dynamic ducking modifiers.

The objectives of this milestone were:
1. Move Library and Assets Vault to a dedicated **Far-Left 48px Enterprise Activity Rail + 300px Slide-out Drawer** (`LeftSidebar.tsx`).
2. Retain the **Right Sidebar strictly for property inspection** (`RightSidebar.tsx`) with an NLE Action Bar (Duplicate Sequence, Delete Sequence with 100% undo recovery, Lock/Bypass toggle) and Project & Canvas Settings fallback when no sequence is selected.
3. Replace HTML5 drag-and-drop with `@dnd-kit/core` and `@dnd-kit/utilities` with a 6px `PointerSensor` constraint and floating `<DragOverlay>`.
4. Deeply wire `UniversalThreeScene` (with `THREE.WebGLRenderer`) onto the canvas and sync `UniversalAudioMixer` dynamic ducking modifiers (`sfx/dynamic_ducking`) in `WebAudioEngine.ts`.
5. Support workspace hotkeys `[` (left drawer), `]` (right inspector), and `\` (Zen / full canvas mode).

## 2. Key Architecture & Deliverables

### 2.1 Commands & State Management
- `apps/studio/src/lib/commands/DuplicateSequenceCommand.ts`:
  - Clones sequence on its track, generates a unique ID (`${id}_copy_${hash}`), shifts start frame, and maintains DAG integrity.
  - Full undo/redo support.
- `apps/studio/src/lib/commands/DeleteSequenceCommand.ts`:
  - Removes sequence from its track while preserving original position for exact restoration on undo.
- `apps/studio/src/lib/ir/irState.ts`:
  - Added `duplicateSequence(sequenceId)` and `deleteSequence(sequenceId)` public methods.

### 2.2 Enterprise Dual-Sidebar Architecture
- `apps/studio/src/components/LeftSidebar.tsx`:
  - 48px Activity Rail with high-contrast active tab indicators and drawer collapse toggle.
  - 300px Slide-out Drawer:
    - Library view: 12 categorized staging presets with `useDraggable`, search filter, category pills, and `+ Insert` center button.
    - Assets Vault: Media assets with `useDraggable`, type filter pills (`All`, `Video`, `Audio`, `Image`), and duration metadata.
- `apps/studio/src/components/RightSidebar.tsx`:
  - Dedicated 336px Property Inspector.
  - Active sequence: Sequence metadata, Copy ID button, NLE Action Bar (Duplicate, Delete, Lock), Add Modifier dropdown, and deep collapsible accordions (Transform, 3D Relighting, 3D Camera, Particle VFX, Typography, Audio Ducking).
  - Fallback state: Project & Canvas Settings (Resolution, FPS, Color Space, Duration, Track count, Timeline Engine info).
- `apps/studio/src/components/Titlebar.tsx`:
  - Added Left Drawer toggle and Right Inspector toggle buttons with tooltip hotkey hints.

### 2.3 `@dnd-kit` Pointer Drag Pipeline
- `apps/studio/src/App.tsx`:
  - Wrapped middle workspace in `<DndContext>` using `pointerWithin` collision and `PointerSensor` (`activationConstraint: { distance: 6 }`).
  - Added hardware-accelerated `<DragOverlay>` with `DragOverlayPreview`.
  - Added global keydown listener for `[`, `]`, `\`.
- `apps/studio/src/components/Preview.tsx`:
  - Integrated `useDroppable({ id: 'canvas-viewport-drop-zone' })` with responsive drop zone highlight aura.

### 2.4 Deep Visual & Audio Engine Wiring
- `apps/studio/src/components/Preview.tsx`:
  - Mounted `UniversalThreeScene` with Three.js `WebGLRenderer` directly on the canvas.
  - Synchronizes 3D depth relief mesh, holographic HUD, 1500-particle warp tunnel, partial VFX regions (spotlights, blurs, glitches, spark emitters), and vector transform overlay into a single depth-tested pass.
- `apps/studio/src/lib/audio/WebAudioEngine.ts`:
  - Dynamically extracts `sfx/dynamic_ducking` modifiers (`duckVolume`, `attackMs`, `releaseMs`, `stereoPan`) from `IRStateManager` to set `UniversalAudioMixer.duckingFactor` and clip parameters.
