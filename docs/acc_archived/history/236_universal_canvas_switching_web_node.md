# 236. Universal Canvas Abstraction Layer (Isomorphic Web & Node Environment Switching)

## Context & Problem
In the Visual Storytelling Generator architecture, 2D canvas drawing, offscreen rasterization, pixel extraction, and overlay shader effects must execute in two radically distinct environments:
1. **Node.js / Bun Server Runtime**: Headless rendering pipeline, FFmpeg CLI overlays, video export, where native C++ libraries (`@napi-rs/canvas`) provide high-speed Skia-backed canvas and raw image pixel access.
2. **Browser / WebGL Runtime (`apps/studio`)**: Interactive Studio editor, timeline preview, and real-time canvas overlays, where standard HTML5 `<canvas>` and `OffscreenCanvas` are supported, but importing `@napi-rs/canvas` or native `.node` binaries causes fatal Vite compilation failures (`Unexpected character '\0'`).

Prior to this phase, `@acc/effect-engines` suffered from environment coupling: server-side canvas strategies directly imported `@napi-rs/canvas`, and client code risked importing native-dependent modules. Furthermore, there was no uniform isomorphic API for loading images or extracting raw RGBA `Uint8Array` pixel buffers across browser and Node.

## Implementation Details

1. **Normalized Canvas Abstraction Interfaces (`packages/effect-engines/src/canvas/types.ts`)**:
   - Defined `CanvasEnvironment`: `'web' | 'node' | 'worker' | 'unknown'`.
   - Defined `CanvasInstance`: Polymorphic union wrapping `HTMLCanvasElement`, `OffscreenCanvas`, or `@napi-rs/canvas Canvas`.
   - Standardized `CanvasAdapter` contract:
     - `create(width, height): CanvasInstance`
     - `getContext(canvas): CanvasContext2D | null`
     - `toBuffer(canvas, mimeType): Promise<Buffer | Uint8Array>`
     - `toDataURL(canvas, type, quality): string`
     - `toBlob(canvas, type, quality): Promise<Blob>`
     - `isSupported(): boolean`
     - `getEnvironment(): CanvasEnvironment`

2. **WebCanvasAdapter (`packages/effect-engines/src/canvas/adapters/WebCanvasAdapter.ts`)**:
   - Zero native C++ / Node dependencies.
   - Leverages `OffscreenCanvas` when available in browser main thread or Web Workers, falling back seamlessly to `document.createElement('canvas')`.
   - Supports raw RGBA pixel extraction via `toBuffer(canvas, 'raw')` using `getImageData().data`.

3. **NodeCanvasAdapter (`packages/effect-engines/src/canvas/adapters/NodeCanvasAdapter.ts`)**:
   - Dynamically requires `@napi-rs/canvas` at runtime using lazy factory loaders.
   - Automatically normalizes MIME formats (e.g. `'png'` -> `'image/png'`) required by `@napi-rs/canvas`.
   - Supports raw RGBA buffer extraction via `canvas.toBuffer('raw')`.
   - Strictly isolated from Vite browser client bundle.

4. **UniversalCanvasProvider (`packages/effect-engines/src/canvas/UniversalCanvasProvider.ts`)**:
   - Unified singleton & static facade providing:
     - Runtime environment detection (`detectEnvironment()`).
     - Dynamic engine switching (`setEngine('auto' | 'web' | 'node')`).
     - Adapter resolution (`getAdapter()`).
     - Convenience canvas instantiation (`createCanvas(w, h)`).

5. **Isomorphic CanvasAssetLoader (`packages/effect-engines/src/canvas/CanvasAssetLoader.ts`)**:
   - Cross-environment image loading:
     - Server / Node: loads image from file path or Buffer via `@napi-rs/canvas` `loadImage`.
     - Browser / Web: loads image from URL or Blob via native `Image` element or `createImageBitmap`.
   - Standardized `extractRawPixels(canvas, x, y, w, h)` returning pure `Uint8Array` RGBA buffer regardless of runtime engine.

6. **CanvasAdapterFactory Backward Compatibility (`packages/effect-engines/src/overlay-effects/canvas-strategies/factory.ts`)**:
   - Refactored `CanvasAdapterFactory.getAdapter()` to route seamlessly through `UniversalCanvasProvider.getAdapter()`, preserving complete backward compatibility with all legacy overlay shaders.

7. **Client Entrypoint Isolation (`packages/effect-engines/src/client.ts` & `apps/studio`)**:
   - Exported only browser-safe modules (`UniversalCanvasProvider`, `WebCanvasAdapter`, `CanvasAssetLoader`, `UniversalCanvasEngine`, `CanvasTransformOverlay`) from `@acc/effect-engines/client`.
   - Corrected `apps/studio/src/components/Preview.tsx` to import strictly from `@acc/effect-engines/client`, eliminating Vite bundling of native `.node` binaries.

8. **Automated Test Suite (`autogenerated-tests/universal_canvas_switching.test.ts`)**:
   - Created 10 comprehensive tests covering:
     - Node/Bun environment detection and default adapter resolution.
     - Runtime engine switching between `'node'`, `'web'`, and `'auto'`.
     - 2D drawing, raw RGBA pixel extraction, and data URL generation.
     - `WebCanvasAdapter` support status and `OffscreenCanvas` simulation.
     - `CanvasAssetLoader` buffer image loading and pixel extraction.
     - `CanvasAdapterFactory` backward compatibility routing.
