# 207. Relocate Python Backend to `apps/ai-supervisor/python-backend`

- **Task ID**: 207
- **Date**: 2026-10-16
- **Status**: Completed
- **Author**: Antigravity

## Context & Motivation
Previously, the Python gRPC AI Subsystem resided in `apps/python-backend`. Because `apps/ai-supervisor` is the unified desktop control plane and supervisor orchestrating the local Python daemon, having the Python subsystem isolated under `apps/ai-supervisor/python-backend` co-locates the daemon lifecycle with its supervisor while maintaining clean, self-contained `uv` virtual environment encapsulation.

## Key Changes
1. **Directory Relocation (`git mv`)**:
   - Moved `apps/python-backend` to `apps/ai-supervisor/python-backend`.
   - Preserved `.venv`, `src/server.py`, `src/services/` (TTS, Vision, LLM), and `pyproject.toml` / `uv.lock`.
2. **Workspace Isolation**:
   - Removed orphaned `@acc/python-backend` `package.json` to keep `python-backend` as a pure, self-contained Python / `uv` project without extraneous Bun workspace registration.
   - Ran `bun install` to prune `@acc/python-backend` from `bun.lock`.
3. **Supervisor Spawn Path Updates**:
   - Updated `apps/ai-supervisor/src/bun/SupervisorEngine.ts` (`startPythonBackend()`):
     - Resolves `pythonBackendCwd` to `path.resolve(this.repoRoot, "apps", "ai-supervisor", "python-backend")`.
     - Spawns `server.py` with `cwd: pythonBackendCwd`.
4. **IPCFacade Auto-Bootstrap Path Updates**:
   - Updated `packages/core/src/ipc/IPCFacade.ts` (`GRPCAIStrategy.bootstrapLock`):
     - Resolves `pythonBackendDir` to `path.resolve(__dirname, '../../../../apps/ai-supervisor/python-backend')`.
5. **Architecture Documentation**:
   - Updated Section 4.5 of `docs/SYSTEM_ARCHITECTURE_DOCUMENT.md` to document the new `apps/ai-supervisor/python-backend` layout.
