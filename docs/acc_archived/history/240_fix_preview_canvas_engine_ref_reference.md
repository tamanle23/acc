# 240. Fix Preview Canvas Engine Ref Reference Error

## Context & Problem
During Phase 6 testing and runtime execution in `apps/studio/src/components/Preview.tsx`, selecting a sequence while playback or transformation occurred triggered an uncaught runtime exception:
`Uncaught ReferenceError: canvasEngineRef is not defined`

In `Preview.tsx`, the canvas engine reference was instantiated as `const engineRef = useRef<UniversalCanvasEngine | null>(null);`. During the addition of real-time GSAP interpolated transform bindings for the active selection bounding box, `canvasEngineRef.current?.getActiveInterpolatedTransform(selectedSeqId)` was referenced instead of `engineRef.current?.getActiveInterpolatedTransform(selectedSeqId)`.

## Implementation Details

1. **Reference Correction & Clean Inline Evaluation (`apps/studio/src/components/Preview.tsx`)**:
   - Replaced incorrect `canvasEngineRef` symbol references with `engineRef`.
   - Refactored the bounding box `style` attribute calculation into a concise IIFE:
     ```tsx
     style={(() => {
       const interp =
         !isDragging && selectedSeqId && engineRef.current
           ? engineRef.current.getActiveInterpolatedTransform(selectedSeqId)
           : null;
       const curX = interp ? interp.x : transform.x;
       const curY = interp ? interp.y : transform.y;
       const curScale = interp ? interp.scale : transform.scale;
       const curRot = interp ? interp.rotation : transform.rotation;
       const curOpacity = interp ? interp.opacity : 1.0;

       return {
         transform: `translate(${curX}px, ${curY}px) scale(${curScale}) rotate(${curRot}deg)`,
         opacity: curOpacity,
         width: '50%',
         height: '50%',
       };
     })()}
     ```
   - Eliminated redundant `getActiveInterpolatedTransform` lookups across each CSS transform dimension while avoiding runtime crashes.
