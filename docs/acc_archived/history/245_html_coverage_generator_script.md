## Context & Objectives
The repository previously output terminal text coverage when invoking Bun's built-in coverage runner (`bun test --coverage`), but lacked a visual, interactive HTML coverage dashboard analogous to JaCoCo's HTML report in JVM projects or Istanbul/c8 in Node ecosystems.

The objective was to set up a zero-external-dependency, high-speed HTML coverage generator in the repository that:
1. Parses standard LCOV coverage data generated by Bun (`--coverage-reporter=lcov`).
2. Generates an interactive master dashboard (`coverage/html/index.html`) with:
   - High-level metric cards for Line, Function, and Branch coverage.
   - Real-time client-side search filtering by file path.
   - Severity filter pills (`All`, `>= 80%`, `50%-79%`, `< 50%`).
   - Interactive column sorting across file names, coverage percentages, and missed lines.
3. Generates per-file source code views (`coverage/html/files/<filename>.html`) with:
   - Line-by-line hit count badges (`12x`, `0x`).
   - Color-coded line highlighting (green for hit, red for missed, neutral for comments/imports).
   - "Show Missed Lines Only" toggle to immediately highlight untested branches.
   - Clickable `#L123` line anchors and breadcrumbs navigation.
4. Integrates seamlessly into `package.json` with `bun run coverage`, `bun run coverage:studio`, and `bun run coverage:html`.

## Key Changes
1. **`scripts/generate-coverage-html.ts`**:
   - Implemented `parseLcov()` with normalization of Windows and POSIX path separators.
   - Implemented `calculateSummary()` for aggregate monorepo metrics.

   - Implemented `generateFileHtml()` with line-by-line syntax highlighting and missed-line filter.

2. **`package.json`**:
   - Added `coverage` script running full suite coverage and generating HTML.
   - Added `coverage:studio` script targeting the Studio test suite and generating HTML.
   - Added `coverage:html` script to re-generate HTML from an existing `coverage/lcov.info`.
3. **`apps/studio/src/components/Preview.tsx`**:
   - Polished standalone `if (isLocked) return;` guard in `handleTransformDragStart` to maintain 100% test pass rate.
4. **`autogenerated-tests/coverage_html_generator.test.ts`**:
   - Comprehensive test suite with 13 tests covering parsing, summaries, HTML generation, and CLI runner.
