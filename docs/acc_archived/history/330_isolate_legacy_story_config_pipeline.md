## 1. Context & Problem Statement
`story-config.json` was the original format used to describe multi-scene video edits before the introduction of Universal Video IR v3.0.0 (`pipeline-ir.json`). 

Previously, `apps/cli/src/pipelines/04-generative-story/VideoEditPipelineOrchestrator.ts` spanned 770+ lines of monolithic code intertwining:
1. Modern Canonical Video IR engine delegation (`StoryConfigToUniversalIRAdapter` -> `IRMasterRenderer` / `IRChunkWorkerPool`).
2. Deprecated multi-pass disk rendering logic: multi-process `SceneWorkerPool`, intermediate disk-based `.mp4` and `.ass` files, raw `FFmpegFilterGraph` transitions (`settb`, `aresample`, `xfade`), fallback image/audio generation, and legacy BGM/SFX mixing.

This monolithic coupling created high cognitive load, risked regressions in the modern IR pipeline, and obscured the system's true architectural boundaries.

---

## 2. Key Architecture & Implementation Changes

### 2.1 Quarantined Legacy Submodule (`apps/cli/src/pipelines/04-generative-story/legacy/`)
- **`LegacyDiskStoryRenderer.ts`**: Encapsulated the complete 500+ line disk-based multi-pass scene renderer, worker pool lifecycle, dynamic RAM throttling, fallback audio/image assets, and complex FFmpeg filtergraph stitch routines.
- **`LegacyIRPreparationAdapter.ts`**: Extracted legacy AST enrichment, safe-zone validation, and NLE cut calculation (`prepareIR()`).
- **`index.ts`**: Cleanly exported the quarantined module.

### 2.2 Lightweight Facade in `VideoEditPipelineOrchestrator.ts`
- Reduced `VideoEditPipelineOrchestrator.ts` from 770+ lines to ~80 lines.
- Established strict separation:
  - Canonical IR rendering (`StoryConfigToUniversalIRAdapter` -> `RelationalDAGCompiler` -> `IRChunkWorkerPool` / `IRMasterRenderer`) is the primary zero-copy rendering path.
  - On unrecoverable IR error, gracefully delegates to `LegacyDiskStoryRenderer.render()`.
  - Static helper `prepareIR()` delegates cleanly to `LegacyIRPreparationAdapter.prepareIR()`.
- Maintained 100% backward compatibility for all external callers and existing tests.

### 2.3 Formal Deprecation Annotations in `@acc/ir`
- Annotated `LegacyStoryConfigAdapter` and `StoryConfigToUniversalIRAdapter` with `@deprecated` JSDoc tags directing developers toward `PipelineIRToUniversalIRAdapter` and `pipeline-ir.json`.

### 2.4 Test Suite Import Fixes
- Updated `autogenerated-tests/systematic_editing_engine.test.ts` to reflect the pure isomorphic relocation of editing compositors and sound effect factories to `@acc/core`.
