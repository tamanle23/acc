1. **Universal Video IR Schema** (`schema/video-ir.schema.json`):
   - Standard JSON Schema (draft-07) defining `VideoIRDocument` V1.0-Stable entity-component architecture.

2. **Universal Pipeline IR Schema** (`schema/pipeline-ir.schema.json`):

   - Standard JSON Schema defining `omnichannel-config.json` used by `AutoConfigEngineFacade` and 1-to-N fan-out conductor strategies.
   - Comprehensive model for the 3-Tier Fine-Grained Video Director control (`CanvasDirectorConfig`, `AudioStagingDirectorConfig`, `TypographyDirectorConfig`, `ArchetypeVisualDirectives`, `SegmentDirectorOverride`, `roleDirectives`, `depth3d`, `overlayComposite`, and `sfx`).

   - Synced missing `UpscaleModel` enum values (`realesr-animevideov3`) and `ratio` attribute to match `packages/core/src/types.ts`.

5. **VSCode Integration** (`.vscode/settings.json`):
   - Registered pattern mappings for `story-config.json`, `omnichannel-config.json`, `pipeline-ir.json`, and `video-ir.json` pointing to their respective schema definitions in `./schema/`.
