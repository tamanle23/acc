# History Entry 325: Purify Isomorphic Effect Engines and Relocate Server Generators to Core

**Date:** 2026-10-24
**Status:** Completed
**Author:** AI Agent (TypeScript Node Architect)

## Context & Motivation
Following Phase 4 of `docs/master_integration_plan_iteration30.md`, `@acc/effect-engines` contained mixed concerns: pure isomorphic canvas effect renderers and client plugins, side-by-side with server-only FFmpeg overlay command generators, Python/FFmpeg sound effect synthesis scripts, and a hardcoded dependency on server `FFIVideoEncoder` in `renderDepth3DScene`.

This phase purifies `@acc/effect-engines` into a 100% isomorphic package exposing only `.` (eliminating `./client`), relocates server overlay and sound-effect generators to `@acc/core`, and updates CLI and IR consumers to import from the appropriate canonical boundaries.

## Key Changes
1. **Server Effects Relocation to `@acc/core`**:
   - Moved 40+ FFmpeg overlay generators, pipelines, registries, stackers, editing decorators/compositors, and sound effect synthesizers into `packages/core/src/effects/` and `packages/core/src/editing/`.
   - Exported these through `packages/core/src/effects/index.ts` and `packages/core/src/index.ts`.
   - Updated CLI commands (`apps/cli/src/commands/overlay.ts`, `sfx.ts`, `VideoEditPipelineOrchestrator.ts`) to import from `@acc/core`.
2. **Pure Isomorphic `@acc/effect-engines`**:
   - Rewrote `packages/effect-engines/src/depth3d/index.ts` using `UniversalCanvasProvider`, `fastChecksum`, `ContentCacheRegistry`, and dynamic video sink creation via `MediaEngineRegistry.get().createVideoSink()`.
   - Replaced server `Logger` in `DepthEstimationContext.ts` and `SubjectSegmentationContext.ts` with `UniversalLogger` from `@acc/core-isomorphic`.
   - Deleted `packages/effect-engines/src/client.ts` and removed `./client` from `package.json` `exports`.
   - Purged `@acc/core`, `@acc/core-native`, and `@acc/core-web` from `packages/effect-engines/package.json` dependencies.
3. **Consumer Imports Updated**:
   - Updated `apps/studio/src/components/Preview.tsx` and all plugins in `packages/ir/src/plugins/` to import directly from `@acc/effect-engines`.
4. **Verification**:
   - Added `autogenerated-tests/effect_engines_isomorphic.test.ts` covering safe zones, captions, color grading, deterministic particle fields, and isomorphic depth3d rendering.
   - All tests pass cleanly (`bun test`).
