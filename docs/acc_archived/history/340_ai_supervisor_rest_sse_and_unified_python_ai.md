# Task History: 340 - AI-Supervisor REST+SSE Control Plane, Unified Python AI Inference & Studio IR Preview Sync (Iteration 35)

## 1. Context & Motivation
Following the process isolation and strategy refactoring in Iteration 34, Iteration 35 completed the transformation of `@acc/ai-supervisor` and `@acc/studio` preview synchronization:
1. **Ollama Decommissioning**: The external Ollama sidecar was dropped completely. All local AI inference (TTS and LLM structured prompt generation) is unified into the Python AI backend (`apps/ai-supervisor/python-backend`).
2. **Python Backend Specialization**:
   - **Stripped off Vision**: Removed `VisionService` and `VisionEngine` from the Python backend; visual segmentation and depth estimation remain cleanly decoupled inside the monorepo's isomorphic ONNX runtime (`UniversalOnnxRuntimeProvider`).
   - **Strategy Pattern for TTS**: Refactored `tts_engine.py` into `ITTSSynthesisStrategy` supporting **Kokoro** (multilingual/English), **VieNeu-v3-Turbo** (high-speed Vietnamese tonal neural synthesis), and deterministic cadence tone fallback.
3. **REST + Server-Sent Events (SSE) Control Plane**:
   - Implemented `TelemetryEventBroker` to broadcast real-time events (`telemetry`, `service-state`, `alert`) over standard HTTP `text/event-stream` (`GET /api/telemetry/stream`).
   - Implemented `OSProcessSampler` using `IProcessRunner` to sample OS-level metrics (`cpuPercent`, `memoryRssMb`) across all active services (`python-backend`, `worker`, `studio`).
   - Implemented `DomainTelemetryPoller` to query Python AI VRAM & loaded models via gRPC `AdminService.GetVRAMStatus`.
   - Implemented `POST /api/worker/heartbeat` for worker domain telemetry ingestion.
4. **Studio Preview Telemetry & Engine Sync**:
   - Updated `TelemetryCompanionCard.tsx` to subscribe to the live SSE stream via native browser `EventSource` with the 5-state component matrix (Connected, Syncing, Empty, Error, Disabled).
   - Confirmed direct reuse of `@acc/ir`'s `IRPreviewEngine` in `apps/studio/src/workers/preview.worker.ts`.

## 2. Key Changes Across Components

### A. Python AI Backend (`apps/ai-supervisor/python-backend`)
- **`src/services/tts_engine.py`**:
  - Implemented `ITTSSynthesisStrategy` abstract base class.
  - Implemented `KokoroTTSStrategy` for English/multilingual speech synthesis.
  - Implemented `VieNeuV3TurboTTSStrategy` for high-throughput Vietnamese tonal speech synthesis.
  - Implemented `CadenceToneFallbackTTSStrategy` for deterministic non-blocking fallback.
  - Updated `TTSEngine` facade to dynamically route synthesis requests via `model_strategy`.
- **`src/server.py`**:
  - Removed `VisionService` and imports; decoupled from visual pipelines.
  - Retained consolidated `TTSService`, `LLMService`, and `AdminService`.

### B. AI-Supervisor Bun Backend (`apps/ai-supervisor/src/bun/`)
- **`telemetry/TelemetryEventBroker.ts`**: In-memory event bus and rolling 60s ring buffer with `createEventStream(signal)` SSE generator.
- **`telemetry/OSProcessSampler.ts`**: Subprocess PID sampler querying `ps` (macOS/Linux) or PowerShell (Windows) via `IProcessRunner`.
- **`telemetry/DomainTelemetryPoller.ts`**: Queries Python gRPC port 50051 for model VRAM status.
- **`SupervisorEngine.ts`**:
  - Purged Ollama service registration and reduced fleet to 3 core services: `python-backend`, `worker`, and `studio`.
  - Added exponential backoff crash recovery: $t = \min(1000 \times 2^{\text{crashCount}}, 30000)\text{ ms}$.
- **`index.ts`**: Added REST endpoints (`POST /api/worker/heartbeat`, `GET /api/telemetry/snapshot`) and SSE stream (`GET /api/telemetry/stream`).
- **`configStore.ts`**: Dropped Ollama configuration fields.

### C. SolidJS Desktop UI (`apps/ai-supervisor/src/ui/`)
- **`components/FleetGrid.tsx`**: Replaced Ollama card with unified 3-column fleet layout (`python-backend`, `worker`, `studio`).
- **`components/ConsoleSection.tsx`**: Removed Ollama log tab.
- **`types.ts`**: Removed Ollama configuration types.
- Rebuilt production UI bundle via `scripts/build-ui.ts`.

### D. Studio NLE Telemetry Integration (`apps/studio/src/components/preview/`)
- **`TelemetryCompanionCard.tsx`**: Connected live browser `EventSource('/api/telemetry/stream')` with real-time hardware tier, AI VRAM, worker render FPS, and WCAG 2.1 AA focus rings.
