# 238. Studio Phase 5: GSAP Easing Inspector & Left Sidebar Enhancements

## Context & Problem
In **Iteration 7 (Phase 5)** of the Studio Modernization roadmap, motion and asset workflows required enterprise refinements:
1. **Interactive GSAP Easing Inspector**:
   - Editors previously lacked visual feedback when tuning motion dynamics on transform and motion modifiers.
   - Requirement: An interactive SVG Bézier curve easing selector with hover animations, traveling dot previews, and two-way synchronization with `params.ease` on the transform modifier in `IRStateManager`.
2. **Dual SFX Strategy**:
   - Pre-generated staging presets in the Left Sidebar for instant drag-and-drop into the audio track.
   - An on-the-fly Procedural Audio Synthesizer in the Right Sidebar with parameterized synthesis, live Web Audio API auditioning, and timeline insertion.
3. **Left Sidebar Discovery & Assets Vault Dropzone**:
   - Rapid asset and preset discovery via search queries and category filter pills (`All`, `Typography`, `Shapes`, `VFX`, `SFX`).
   - Delicate, non-intrusive card micro-animations (subtle lift, glow, quick '+' action button).
   - Direct file drag-and-drop upload dropzone in the Assets Vault generating client-side blob URLs and registering metadata in `doc.assets` via `IRStateManager.addAsset`.

## Implementation Details

1. **Visual GSAP Easing Inspector (`apps/studio/src/components/EasingCurveSelector.tsx`)**:
   - Defined 7 standard GSAP easing curves: `power2.out`, `power2.inOut`, `back.out`, `elastic.out`, `bounce.out`, `expo.out`, and `linear`.
   - Rendered interactive Bézier curve tiles using SVG paths with a animated traveling marker dot driven by `@keyframes travelCurve` in `apps/studio/src/index.css`.
   - Integrated into `RightSidebar.tsx` inside the `transform` accordion with immediate synchronization to `params.ease`.

2. **Procedural Audio Synthesizer DSP & Staging Presets**:
   - Extended `packages/effect-engines/src/audio/ProceduralAudioSynthesizer.ts` with pure DSP algorithms:
     - `synthWhoosh`: Swept bandpass filtered noise with a gaussian envelope.
     - `synthImpact`: Exponential sub-bass sine drop with punchy attack transient.
     - `synthGlitch`: Ring-modulated digital stutter burst with sample-and-hold step quantization.
     - `synthRiser`: Exponential pitch climb with accelerating tremolo pulse and volume swell.
   - Added 4 SFX staging presets in `apps/studio/src/lib/library/stagingPresets.ts` targeting `track-audio` with `sfx/procedural` and `transform` modifiers.
   - Implemented Procedural SFX synthesizer controls in `RightSidebar.tsx` with Web Audio API live auditioning and one-click timeline insertion.

3. **Left Sidebar Discovery & Drag-and-Drop Ingestion (`apps/studio/src/components/LeftSidebar.tsx`)**:
   - Added category filter pills: `All`, `Typography`, `Shapes`, `VFX`, `SFX`.
   - Enhanced `DraggablePresetCard` with delicate, non-intrusive micro-animations (`hover:-translate-y-0.5`, subtle border glow, icon pulse, and quick '+' insertion).
   - Implemented drag-and-drop upload dropzone in Assets Vault calling `handleFilesIngest` to generate `URL.createObjectURL` references and registering metadata in `IRStateManager.addAsset`.

4. **Automated Verification**:
   - Created `autogenerated-tests/studio_phase5_easing_sidebar.test.ts` covering GSAP easing presets, pure DSP synthesis, SFX staging presets, IRStateManager asset additions, and component integration.
   - Verified that all 88 studio tests across 17 test suites pass cleanly (`bun test studio`).
   - Verified clean production build via Vite (`bun run studio:build`).
