# [164] Incorporate AI Segmentation & Depth Anything Models into Canonical IR Pipeline

- **Status:** `[x] Completed`
- **Date:** 2026-10-10
- **Scope:** `packages/effect-engines/src/depth3d/`, `packages/ir/src/adapters/`, `packages/ir/src/plugins/vfx/`

---

## 1. Context & Problem Statement
While `renderStoryVideo` leverages AI subject segmentation (`SubjectSegmentationContext` using SAM 2 / BiRefNet / RMBG-1.4) and depth estimation (`DepthEstimationContext` using Depth Anything v2 / DPT) when cache misses occur or when rendering depth meshes (`depth_map_3d`, `mesh_displacement`), the canonical IR pipeline (`ir-render`) lacked the invocation bridges:
1. `resolveSubjectCutout` only performed file reads without executing `segContext.segment(imgBuffer)` when a cutout was missing.
2. `Depth3DPlugin` did not compute or pass `srcCanvas` and multi-plane `depthLayers` (`mgCanvas`, `fgCanvas`), rendering depth mesh and volumetric modes as empty or flat.
3. `StoryConfigToUniversalIRAdapter` mapped relative image strings (`assets/scene1.jpg`) instead of resolved paths (`scene.resolvedImage`), which caused file lookup failures during pipeline execution.

---

## 2. Changes Made
1. **Live AI Segmentation Fallback (`packages/effect-engines/src/depth3d/index.ts`)**:
   - In `resolveSubjectCutout`, if no cached subject cutout is found on disk and `depthConfig.autoSegment !== false`, the engine invokes `segContext.segment(imgBuffer)` in-process and caches the resulting mask buffer and bounding box metadata into `autogenerated/depth-3d`.
2. **Depth Anything Multi-Plane Depth Estimation (`packages/effect-engines/src/depth3d/index.ts`)**:
   - Implemented and exported `resolveDepthMapData(imagePath, width, height, depthConfig)`:
     - Checks cache for Depth Anything 16-bit depth maps.
     - Runs `depthContext.estimateDepth(imgBuffer)` using Depth Anything v2 if not cached.
     - Builds continuous multi-plane depth layers (`srcCanvas`, `mgCanvas`, `fgCanvas`) without grid tearing.
3. **Bridge into `Depth3DPlugin` (`packages/ir/src/plugins/vfx/Depth3DPlugin.ts`)**:
   - During `execute()`, pre-resolves both the AI cutout and `resolveDepthMapData`.
   - In `renderClipSpace()`, passes `srcCanvas` and `depthLayers` directly into `Depth3DFactory.getRenderer(mode).renderFrame(...)`, ensuring `DepthMeshRenderer` and all 17 3D depth engines have full access to Depth Anything layers.
4. **Resolved Asset Forwarding in `StoryConfigToUniversalIRAdapter`**:
   - Updated `visualSrc` and `audioSrc` to prefer `scene.resolvedImage` / `scene.resolvedVideo` and `scene.resolvedAudio`, guaranteeing valid absolute paths.
