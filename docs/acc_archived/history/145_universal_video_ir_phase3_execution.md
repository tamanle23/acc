## 1. Problem Statement
The Universal Video IR Rendering Engine required an Open-Closed Principle (OCP) modifier processing pipeline. The engine must decouple "How" media is transformed from "When" it plays, allowing effects (VFX, SFX, editorial cuts, compositing) to be dynamically registered without altering the core compiler or runtime logic. Furthermore, operations must be dry-runnable and inspectable via the Command Pattern.

---

## 2. Plan of Action
1. **Modifier Plugin Registry:**
   - Define `ModifierContext` and `ModifierPlugin<TParams>` interfaces.
   - Implement `ModifierPluginRegistry` with registration, type lookup, and defensive execution (graceful degradation on unknown modifiers).
2. **Core Story Engine Bridges:**
   - `Depth3DPlugin` (`vfx/depth3d`): Bridges existing 3D depth renderers (frame-breaker, volumetric sandwich, parallax).
   - `DynamicDuckingPlugin` (`sfx/dynamic_ducking`): Bridges sidechain audio ducking DSP.
   - `SplitEditPlugin` (`editorial/split_edit`): Bridges cinematic J-cuts and L-cuts.
   - `TransitionCrossfadePlugin` (`transition/crossfade`): Bridges scene crossfade settings.
   - `BlendModePlugin` (`overlay/blend_mode`): Bridges algebraic compositing blend modes.
3. **Command Pattern:**
   - Implement `RenderCommand` and `MacroRenderCommand` for dry-runnable, inspectable, and atomic media execution steps.
4. **Verification:**
   - Author formal tests in `autogenerated-tests/video_ir_phase3_plugins.test.ts`.
