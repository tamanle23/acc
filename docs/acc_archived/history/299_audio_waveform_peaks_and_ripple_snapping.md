## 1. Context & Motivation

Following the completion of Pillar 1 (Dedicated Transition System & Universal Transition Plugin), Pillar 2 addresses core NLE timeline productivity and performance requirements:
1. **Audio Waveform Peak Decimation**: Offloading PCM min/max decimation and multi-resolution LOD sampling from the main render thread to avoid jank when zooming/scrubbing large audio tracks.
2. **Track-Scoped Ripple Editing**: Enabling seamless ripple trims and gap-closing ripple deletes without disturbing independent tracks or breaking undo/redo history.
3. **Abutting Magnetic Snapping & HUD Confirmation**: Offering magnetic snapping to adjoining sequence seams within 4 frames, complete with emerald visual indicators and HUD status badges.

---

## 2. Key Architecture & Implemented Features

### 2.1 Audio Waveform Web Worker (`audioWaveform.worker.ts` & `WebAudioEngine.ts`)
- **`apps/studio/src/workers/audioWaveform.worker.ts`**:
  - Implemented `computePeaksFromPcm`: decimated min/max amplitude sampling from `Float32Array` channels.
  - Implemented `generateProceduralEnvelope`: deterministic procedural audio cadence fallback when assets are loading or synthesized offline.
  - Zero-copy IPC transfer using `postMessage(response, [peaks.buffer])`.
- **`apps/studio/src/lib/audio/WebAudioEngine.ts`**:
  - Wired worker background dispatch into `getWaveformPeaks()`.
  - Main thread provides instant procedural/cached peaks and updates asynchronously when worker results return.

### 2.2 Track-Scoped Undoable Ripple Editing Suite
- **`RippleTrimSequenceCommand.ts`**:
  - Implements track-scoped downstream sequence shifting ($dStart + dDur$).
  - Full undo/redo reversibility, supporting command merging for interactive drag operations.
- **`RippleDeleteSequenceCommand.ts`**:
  - Closes timeline gaps on deletion by shifting downstream sequences on the active track backward by the deleted clip's duration.
  - Full undo restoration preserving original track positioning.
- **`IRStateManager.ts`**:
  - Wired `rippleTrimSequence(sequenceId, deltaStart, deltaDuration)` and `rippleDeleteSequence(sequenceId)`.
- **`Timeline.tsx`**:
  - Added toolbar toggle (`ArrowRightLeft` icon) with active accent theme token for Ripple Edit Mode.
  - In Ripple Mode, trimming start/end boundaries dispatches `rippleTrimSequence`.
- **`SequenceInspector.tsx`**:
  - Added `Ripple Del` action button alongside standard clip deletion.

### 2.3 Abutting Magnetic Snapping & HUD Confirmation
- **`Timeline.tsx`**:
  - Extended snap candidate points to tag adjoining clip boundaries with `isAbut: true` and label `Abut {seq.id}`.
  - Rendered emerald guideline (`#10b981`), emerald glow, and HUD pill indicator (`activeSnapGuideline.isAbut ? 'text-emerald-300 bg-emerald-950/90 border-emerald-500/60' : ...`).
