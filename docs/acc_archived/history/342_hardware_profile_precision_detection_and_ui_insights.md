# Task History: 342 - Hardware Profile Precision Detection & Insightful UI Card Modernization

## 1. Context & Motivation
Under `/goal`, `/ui-ux-design-principles`, and `/enterprise-clean-coder`, this task elevates the hardware profile detection and UI telemetry insights of the AI-Supervisor desktop control plane:
1. **Accurate Hardware Acceleration Detection**: Previously, `HardwareProfiler` only checked `nvidia-smi` and Apple Silicon `sysctl` (`arm64`), leaving macOS Intel/AMD systems and other platforms falling back to a generic `CPU (Software Fallback)` and `tier5`.
2. **Polyglot Display Probing (`queryMacDisplays`)**: Added non-blocking JSON probing via `system_profiler SPDisplaysDataType -json`, correctly detecting discrete PCIe graphics cards (e.g. `Radeon Pro 555X` with 4 GB VRAM, Metal 2 support, and AMD vendor tag), classifying the hardware into `Tier 4` with CPU/GPU role splitting.
3. **High-Density Insightful Hardware UI Cards**: Enhanced [`TelemetryGrid.tsx`](../../apps/ai-supervisor/src/ui/components/TelemetryGrid.tsx) with semantic tokens, exact dedicated VRAM badges, hardware compute tier pills, GPU vendor and Metal API badges, and specific CPU model branding (`Intel(R) Core(TM) i7-9750H @ 2.60GHz`).

---

## 2. Key Architecture & Code Modifications

### A. HardwareProfiler & Multi-GPU Detection Strategy
- **File**: `apps/ai-supervisor/src/bun/HardwareProfiler.ts`
- **CPU & GPU Contracts**:
  - Expanded `HardwareProfile` with `CpuInfo` (`model`, `cores`, `speedMhz`).
  - Added `queryMacDisplays(runner)`: Queries macOS display data via `system_profiler` JSON output, prioritizes discrete PCIe GPUs (`sppci_pcie_device`) over integrated ones, and extracts VRAM (`4 GB` / `4294967296 bytes`), vendor, and Metal support.
  - Automatically classifies systems into their true capability tier (e.g. 4GB discrete GPU correctly classifies into `tier4` with safe headroom of 1.0 GB).

### B. UI/UX Card Refinement (`TelemetryGrid.tsx`)
- **File**: `apps/ai-supervisor/src/ui/components/TelemetryGrid.tsx`
- **Hardware Accelerator Card**:
  - Displays real accelerator name (`Radeon Pro 555X`) with a badge showing dedicated VRAM (`4GB VRAM`).
  - Active compute tier pill (`TIER4`) and execution device target (`CPU`).
  - GPU vendor descriptor (`Vendor: AMD` or `UMA Shared`) and graphics API tag (`METAL2`).
- **CPU Activity & Render Pipeline Card**:
  - Displays clean processor branding (`i7-9750H`) instead of generic text.
  - Dynamic worker state badge displaying real-time job IDs, frame progress, or `Idle / Ready`.

### C. Type Declarations
- **File**: `apps/ai-supervisor/src/ui/types.ts`
- Synchronized `HardwareProfile`, `HardwareGpuInfo`, and `HardwareCpuInfo` with strict typing (`readonly`, zero `any`).
