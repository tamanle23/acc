# Specification: Content-Dependent & Configurable Omnichannel Fan-Out Architecture

## 1. Overview & Architectural Principles
The ACC Multi-Pipeline Engine does **not** treat content generation as either a rigid 1-to-1 mapping (topic locked to single format) or an indiscriminate 1-to-all broadcast (blindly attempting to render formats that make no sense for the content).

Instead, each content type defines a **semantic capability envelope** (`supportedModalities`), a canonical default (`defaultModality`), and supports **fine-grained execution-time configuration** across any eligible format.

```
                    [ Ingestion Source / Task Input ]
                                    │
                                    │ (e.g. Crypto Recap, Mortgage Calc, Lo-Fi Beat)
                                    ▼
                     [ IContentTaskStrategy ]
                       ├── supportedModalities: ContentModality[]
                       ├── defaultModality: ContentModality
                       └── Compatibility Validation Guard
                                    │
                         ┌──────────┴──────────┐
                         │ Validated           │ Incompatible
                         ▼                     ▼
                [ PipelineIR AST ]         Throws 400 Bad Request
                         │                 e.g. Audio podcast for
                         │                 DOM Mortgage Calculator
                         ▼
        [ Selective & Configured Modality Exporters ]
        ├── videoConfig        ──> VideoExporter (Universal Video IR)
        ├── audioConfig        ──> AudioExporter (EBU R128 Loudness DSP)
        ├── socialConfig       ──> SocialExporter (Threads / Carousel)
        ├── staticWebConfig    ──> StaticWebExporter (SSG / Markdown)
        └── interactiveConfig  ──> WidgetExporter (HTML5 / D3 / Three.js)
```

## 2. Content Capability Matrix Archetypes

| Content Archetype | Example Content Types | Supported Modalities | Incompatible Modalities & Rationale |
| :--- | :--- | :--- | :--- |
| **Financial & Market Aggregation** | Crypto Recap (`item_002`), Stock Breakouts (`item_084`), Earnings (`item_156`) | `['social', 'video', 'audio', 'static-web', 'interactive-web']` | Fully omnichannel: can produce charts, tweets, video reels, and audio briefs. |
| **Interactive Logic & Calculators** | Mortgage Calculator (`item_223`), Regex Sandbox (`item_241`), Tax Estimator (`item_224`) | `['interactive-web', 'static-web']` | **Incompatible with `audio` & `video`**: A user needs interactive DOM sliders and mathematical tables; a spoken podcast reciting DOM input fields is nonsensical. |
| **Ambient Procedural Audio** | Lo-Fi Beat (`item_161`), White Noise (`item_195`), Rain Sounds (`item_166`) | `['audio', 'video']` | **Incompatible with `interactive-web` & `static-web`**: Purely sensory audio-visual loops with no textual narrative or data tables. |
| **Visual Stories & Shorts** | Reddit Creepypasta (`item_101`), 3D Parallax Story (`item_121`) | `['video', 'audio', 'social']` | **Incompatible with `interactive-web`**: Linear narrative fiction suited for streaming video and social teasers. |

## 3. Configuration Contract Specification

### 3.1 Task Input Payload
```typescript
export interface ContentTaskInputPayload {
  contentTypeId: string;
  title?: string;
  summary?: string;
  
  // 1. Explicit Modality Selection (Optional: defaults to defaultModality)
  modalities?: Array<'static-web' | 'social' | 'video' | 'audio' | 'interactive-web'>;
  
  // 2. Fine-Grained Modality Configuration Blocks
  videoConfig?: {
    aspectRatio?: '9:16' | '16:9';
    fps?: number;
    durationMs?: number;
    theme?: string;
  };
  audioConfig?: {
    format?: 'mp3' | 'wav' | 'flac' | 'aac';
    targetLoudnessLufs?: number; // e.g. -14.0 LUFS
    duckingDb?: number;
    voiceId?: string;
  };
  socialConfig?: {
    platforms?: Array<'twitter' | 'linkedin' | 'instagram'>;
    customHashtags?: string[];
  };
  staticWebConfig?: {
    format?: 'markdown' | 'html' | 'both';
    slug?: string;
  };
  interactiveWebConfig?: {
    initialState?: Record<string, unknown>;
    theme?: 'dark' | 'light';
  };
}
```

### 3.2 Compatibility Enforcement
If a caller requests a modality outside `strategy.supportedModalities`, `BaseContentTaskStrategy` immediately aborts before any asset or AI generation occurs:
```typescript
for (const mod of requestedModalities) {
  if (!this.supportedModalities.includes(mod)) {
    throw new Error(
      `[${this.contentTypeId}] Modality '${mod}' is incompatible with this content type. Supported modalities: ${this.supportedModalities.join(', ')}`
    );
  }
}
```

## 4. Verification & Testing
Validated in `autogenerated-tests/strategies/strategies_omnichannel_fanout.test.ts`:
- Full 5-modality fanout for multi-modal topics.
- Rejection of incompatible formats (`item_223_mortgage_calculators` rejecting `audio`).
- Application of fine-grained configuration parameters (`videoConfig.fps: 60`, `audioConfig.format: 'wav'`).
