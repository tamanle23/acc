# Hướng dẫn Sử dụng: Sound Effects CLI (V2.0)

Hệ thống Sound Effects CLI là một công cụ độc lập, mạnh mẽ giúp bạn tạo, tổng hợp và xử lý mọi loại hiệu ứng âm thanh (SFX) cho dự án Visual Storytelling.

## 🌟 1. Công nghệ Định tuyến Thông minh (Smart Router)

Bạn **không cần** phải biết âm thanh được tạo ra bằng Công nghệ nào. Hệ thống sở hữu một "Bộ não định tuyến" tự động chuyển hướng yêu cầu của bạn tới động cơ tốt nhất:

| Thể loại (Category) | Engine Tự động | Ưu điểm & Đặc tả |
| :--- | :--- | :--- |
| **`ui`**, `click`, `hover`, `success` | 🧮 **FFmpeg (Procedural)** | Sinh âm thanh bằng các phương trình toán học thuần túy. Siêu nhẹ (vài KB), trong vắt, tốc độ tạo 0.1s. Hỗ trợ âm thanh Modern (chime) và Retro 8-bit. |
| **`fauna`**, `diegetic`, `foley` | 🎧 **Library (Freesound)** | Sử dụng API tìm kiếm âm thanh vật lý/sinh học từ đời thực. Đảm bảo độ chân thực tuyệt đối cho tiếng động vật, tiếng mưa, không gian. |
| **`scifi`**, `cinematic`, `custom` | 🤖 **AI (AudioLDM2)** | Sử dụng Local AI để tổng hợp các âm thanh kỹ xảo, cháy nổ, điện ảnh dồn dập hoặc sinh âm thanh từ văn bản tự do (Text-to-Audio). |

Tất cả các âm thanh sau khi tạo đều đi qua **AudioNormalizer DSP** để chuẩn hóa âm lượng (EBU R128) và cắt gọt (Fade-out/Seamless Loop) một cách tự động.

## 💻 2. Chế độ Tương tác (Interactive Wizard)

Nếu bạn không muốn nhớ các câu lệnh, chỉ cần chạy:
```bash
bun run sound-effects-cli.ts
```
Giao diện Console sẽ hiện ra và đưa ra 3 lựa chọn cho bạn:
1. **Single Sound Effect:** Dùng menu thả xuống chọn các loại SFX có sẵn (Foley, Fauna, UI, v.v...).
2. **Composite Sound (Multi-layer Mix):** Tạo các bản Mix phức tạp trộn nhiều âm thanh (Xem phần 4).
3. **Custom Prompt (Freeform Text):** Tự do gõ văn bản tiếng Anh để AI tạo ra âm thanh bạn muốn.

---

## ⚡ 3. Chế độ Gõ Lệnh (Headless CLI)

Dành cho các Automation Scripts hoặc Batch Generation.

**Tạo một hiệu ứng có sẵn:**
```bash
bun run sound-effects-cli.ts --effect ui --variant pickup --sub-variant coin --duration 1.0
```

**Tạo âm thanh bằng Custom Prompt tự do:**
```bash
bun run sound-effects-cli.ts --custom-prompt "A heavy cinematic sub bass impact with deep reverb" --duration 3.0
```
*(Kết quả sẽ được xuất vào thư mục: `autogenerated/sound-effects/mixed/`)*

---

## 💡 4. Mẹo viết Custom Prompt (Cho hệ thống AI)

Để có kết quả Text-to-Audio tốt nhất, hãy tuân thủ các quy tắc mô tả Âm thanh học:
*   ✅ **NÊN dùng tính từ miêu tả tính chất:** *"Cinematic heavy sub bass impact, deep reverb, dramatic"*.
*   ✅ **NÊN chỉ rõ nguồn phát và tần số:** *"Sci-fi alien laser gun, high pitch energy blast, crisp"*.
*   ❌ **KHÔNG NÊN dùng 1 từ chung chung:** *"Explosion"*, *"Sound"*, *"Music"*. AI sẽ không có đủ bối cảnh để tạo ra chất liệu tốt.

## 🎛️ 5. Auto-Ducking Composites (Kỹ xảo Nén âm nền)

**Composite** là bản Mix hòa trộn nhiều lớp âm thanh lại với nhau (Ví dụ: `stormy_night`, `cinematic_trailer_hit`).
Đặc biệt, hệ thống được trang bị công nghệ **Sidechain Compression (Auto-Ducking)** chuẩn Studio.

Trong File Cấu hình Registry (`src/sound-effects/core/Registry.ts`), mỗi lớp âm thanh (Layer) được gán một vai trò:
*   `role: 'background'` (Âm nền: Tiếng mưa, Quán cafe).
*   `role: 'foreground'` (Âm chính: Tiếng sấm sét, Tiếng chuông UI).

Khi render Composite:
```bash
bun run sound-effects-cli.ts --composite stormy_night
```
Hệ thống sẽ **tự động ép giảm âm lượng của các lớp Background xuống** mỗi khi lớp Foreground phát ra tiếng, giúp bản Mix của bạn cực kỳ trong trẻo, không bị "đục" hay tranh chấp tần số. Kỹ thuật này cũng được áp dụng tự động cho Nhạc nền (BGM) trên Main Video của bạn!

## 🎬 6. Tích hợp Sound Effects & Master Voiceover vào `story-config.json`

Hệ thống cho phép gắn SFX trực tiếp vào từng phân cảnh hoặc toàn bộ video theo kiến trúc Multi-Track Timeline:

### A. Gắn SFX vào từng Scene (`scenes[].sfx`)
```json
{
  "scenes": [
    {
      "image": "scene1.jpg",
      "audio": "voiceover1.mp3",
      "sfx": [
        {
          "source": "sfx/whoosh.wav",
          "time": 0.0,
          "duration": 0.5,
          "volume": 0.8,
          "duckBgm": true
        }
      ]
    }
  ]
}
```

### B. Chế độ Master Voiceover Timeline (`settings.audioTrack`)
Khi toàn bộ video sử dụng 1 file voiceover duy nhất làm trục thời gian chính:
```json
{
  "settings": {
    "audioTrack": {
      "source": "voiceover/master.mp3",
      "volume": 1.0
    },
    "sfx": [
      {
        "source": "sfx/cinematic_boom.mp3",
        "time": 4.5,
        "volume": 0.9,
        "duckBgm": true
      }
    ]
  },
  "scenes": [
    { "image": "scene1.jpg", "duration": 4.5 },
    { "image": "scene2.jpg", "duration": 5.5 }
  ],
  "captions": [
    { "text": "Lời", "start": 0.2, "end": 0.6 },
    { "text": "thoại...", "start": 0.7, "end": 1.2 }
  ]
}
```
