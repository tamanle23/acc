## 1. Context & Problem Statement
`VideoEditPipelineOrchestrator.processAndRender` (IR-based, `LegacyStoryConfig` -> `ExtendedPipelineIR`) is not used by any production code path; only `autogenerated-tests/systematic_editing_engine.test.ts` calls it. The production path is the static `renderStoryVideo(ResolvedStoryConfig)`. The two diverged after history 128/129.

### Feature gap analysis
Features present in `processAndRender` that are absent from `renderStoryVideo` (verified by grep inside `VideoEditPipelineOrchestrator.ts`):

| Feature | In `processAndRender` | In `renderStoryVideo` | Notes |
|---|---|---|---|
| Color grading / LUT (`ColorGradingEngine`, `options.lutPath`, contrast/saturation) | Yes (filter string only, never applied) | **Missing** | No LUT or grade stage in the multi-scene render |
| Safe-zone enforcement (`SafeZoneManager.getMargins`) | Partial: margins computed but unused | **Missing** | Only TikTok caption `stylePreset` override takes effect |
| Platform-aware typography overlay presets (`typographyOverlays`) | Yes | **Missing** | Captions use `config.settings.captions` instead |
| NLE cut strategies / J-L cuts (`EditingOpFactory`, `videoOffsetMs`, `calculateCut`) | Yes (stored in `chunk.metadata.calculatedCut`, unused) | **Missing** | `renderStoryVideo` has only dialogue-clearance padding for crossfade (history 136) |
| Configurable sidechain ducking (`AudioDuckingDSP`, attenuation/attack/release from IR) | Yes (filter string only, never applied) | **Partial** | Inline `sidechaincompress` for BGM only (`bgm.autoDucking`); not configurable via IR |
| IR normalization (`LegacyStoryConfigAdapter`) | Yes | Partial | Adapter runs in stages to fill `ctx.ir`, but render ignores the IR |
| `VideoExporter` zero-copy export | Yes | **Missing** | `renderStoryVideo` uses worker pool + FFI concat muxer |
| Structured return (`ir`, `exportResult`, `filterGraphString`) | Yes | No (`void`) | Useful for timeline editor / dry-run |

Features only in `renderStoryVideo` (absent from `processAndRender`): worker pool, 3D depth, xfade transitions, master voiceover remux, multi-track SFX, overlay composite, BGM looping, upscaler plugin, AI pre-warm, fallback assets.

## 2. Proposed Design
1. Split `processAndRender` into `prepareIR()` (adapt, safe zones, cut calc) and export.
2. Feed `prepareIR()` output into `renderStoryVideo` incrementally: safe zones and cuts first (lowest risk), then LUT grading, then configurable ducking.
3. Apply `colorFilter` and `duckingFilter` in the real graphs (use unique stream labels per STREAM-LABELS rule).
4. Guard every step behind options so default output stays identical (ZERO-REGRESSION); add golden tests.
5. Decide later whether `renderStoryVideo` becomes a thin wrapper over the IR path (tied to the timeline editor, see `docs/brainstorming/VIDEO_EDIT_PIPELINE_ORCHESTRATOR_DETERMINISM_AND_REMOTION_FEASIBILITY.md`).
6. If still unused after parity work, delete `processAndRender`.

## 3. Acceptance Criteria
- [ ] Safe-zone margins applied to captions/overlays in `renderStoryVideo`
- [ ] J/L cut calculations consumed by scene timing
- [ ] LUT / color grading applied via `ColorGradingEngine`
- [ ] IR-configured ducking replaces/augments inline BGM sidechain
- [ ] `processAndRender` either has a production caller or is removed
- [ ] Golden-output regression tests in `autogenerated-tests/`; `bun run cli.ts ./sample-story` unchanged
- [ ] `docs/SYSTEM_ARCHITECTURE_DOCUMENT.md` updated if data flow changes
