## Context & Problem
In Phase 1 and Phase 2, `auto-config` gained the capability to crawl media directories via `MediaAssetProberChain` and heuristically identify the best matching Canonical Pipeline (1 through 6) via `PipelineClassifierRegistry`.

However, the auto-config system currently lacks:
1. A **Builder Pattern** (`PipelineIRBuilder`) to synthesize compliant, validated `PipelineIR` v3.0.0 documents from the discovered assets (pairing visual layers, voiceover timings, BGM audio composition, ducking envelopes, and distribution hints).
2. A **Factory Pattern** (`DirectorPresetFactory`) to generate production-grade `FineGrainedVideoDirectorConfig` structures with 3-tier cinematography controls (Canvas & LUT color grading, BGM & SFX audio staging, 3D depth, Ken Burns motions, and domain archetype directives) tailored to each pipeline.

---

## Proposed Design
Implement **Phase 3 of Universal Auto-Config**:
1. **`PipelineIRBuilder` (Builder Pattern)** in `packages/core/src/autoconfig/builders/PipelineIRBuilder.ts`:
   - Fluent API for building `PipelineIR` (v3.0.0).
   - Methods: `setTitle(title)`, `setPipelineId(id)`, `addChunk(chunk)`, `setChunks(chunks)`, `setAudioComposition(composition)`, `setDistributionHints(hints)`, `setStructuredData(data)`, `populateFromManifest(manifest, archetypeDefaults)`.
   - Automated asset pairing: Pairs sequential visual files (e.g. `1.png`, `2.png`) with discovered audio files (or estimated durations if audio is missing).
   - Audio ducking & composition setup: BGM assignment, auto-ducking (-14dB), volume balance.
   - Validation on `.build()` guaranteeing required fields and non-negative chunk durations.
2. **`DirectorPresetFactory` (Factory Pattern)** in `packages/core/src/autoconfig/factories/DirectorPresetFactory.ts`:
   - Factory generating production-grade `FineGrainedVideoDirectorConfig` envelopes for each of the 6 canonical archetypes:
     - Pipeline 1 (Scraper & Summarizer): Clean tech LUT, minimal typography, subtle Ken Burns.
     - Pipeline 2 (DB-Templating): Chart visuals, cubic-bezier animation curves, glowing UI accents.
     - Pipeline 3 (Repurposing Recycler): Talking head auto-reframe, kinetic captions, emphasis punch-ins.
     - Pipeline 4 (Generative Storytelling): 3D parallax / frame-breaker sandwich, teal-orange LUT, cinematic transitions, ambient dust.
     - Pipeline 5 (Rule-Logic): Interactive decision branching, neon pill callouts.
     - Pipeline 6 (Ambient Loops): Looping music staging, particle visuals, crossfades.
   - Preserves user overrides (`aspectRatio`, `fps`, `enableDepth3D`, `enableTransitions`, etc.).
3. **Exports & Testing**:
   - Re-export `PipelineIRBuilder` and `DirectorPresetFactory` in `packages/core/src/autoconfig/index.ts`.
   - Comprehensive unit test suite in `autogenerated-tests/autoconfig/builder-preset-factory.test.ts`.
