# History Entry 498: Fix Canvas2D Multiple Readback and WAI-ARIA Hidden Console Warnings

## Problem
When interacting with the IR Plugin Visual Playground and Inspector form, three distinct console warnings and performance violations appeared:
1. **`Canvas2D: Multiple readback operations using getImageData are faster with the willReadFrequently attribute set to true`**:
   - `usePlaygroundEngine.ts`, `BentoCurveVisualizer.tsx`, and modifier plugins (`ColorGradingPlugin`, `Depth3DPlugin`, `Camera3DPlugin`, `CanvasParticleOverlayPlugin`) created 2D canvas contexts without `{ willReadFrequently: true }`.
   - Subsequent calls to `ctx.getImageData(...)` during modifier processing (e.g. 3D LUTs, tetrahedral interpolation, depth normal mapping, bloom) triggered synchronous CPU-GPU memory readbacks, causing pipeline stalls.
2. **`Blocked aria-hidden on an element because its descendant retained focus... Element with focus: <div ... #popover-cl-114-content>`**:
   - `SelectContent` in `select.tsx` and `Popover` in `popover.tsx` were wrapped in `<PopoverPrimitive.Root>` which defaulted to `modal={true}` in `@kobalte/core`.
   - When opened inside the `IrPluginPlaygroundModal` (which is itself a modal `Dialog`), Kobalte's modal manager applied `aria-hidden="true"` to outside nodes in `document.body` while focus remained within the portaled popover content, triggering a WAI-ARIA accessibility violation.
3. **`[Violation] Handling of 'wheel' input event was delayed for 114 ms due to main thread being busy`**:
   - Synchronous GPU readbacks from `getImageData` without `willReadFrequently` stalled the JavaScript main thread for over 100ms during parameter scrubbing, delaying native wheel event dispatching.

## Plan
1. **Canvas2D Performance & Readback Optimization**:
   - Add `{ willReadFrequently: true }` to `canvas.getContext('2d', { willReadFrequently: true })` in `usePlaygroundEngine.ts` (both main rendering pass and `renderKeyframeToCanvas`).
   - Add `{ willReadFrequently: true }` across all plugin offscreen canvases that perform pixel-level traversal (`ColorGradingPlugin`, `Camera3DPlugin`, `Depth3DPlugin`, `CanvasParticleOverlayPlugin`).
2. **WAI-ARIA Popover Non-Modal Configuration**:
   - Configure `modal={props.modal ?? false}` on `PopoverPrimitive.Root` in `apps/studio/src/components/ui/select.tsx` and `apps/studio/src/components/ui/popover.tsx`.
   - Add `onFocusOutside` handling to prevent focus escape and avoid ancestor `aria-hidden` attribute injection.
3. **Automated Verification**:
   - Add regression tests in `autogenerated-tests/ir_playground_bento_features.test.ts` validating `willReadFrequently: true` options and `modal: false` defaults.
   - Run full Bun test suite and Vite production build.
