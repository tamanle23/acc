# Task 495: IR Plugin & Modifier Visual Playground Modal

## Problem Statement
The Universal Video-IR subsystem (`packages/ir`) features an extensive modifier and plugin architecture comprising 50+ modular plugins across VFX, 3D depth, procedural time-space generators, kinetic typography, motion curves, overlays, transitions, and audio DSP. While `IrVisualEditorModal.tsx` enabled low-level AST tree editing and JSON schema validation, there was no interactive visual workbench for creators or engineers to isolate, preview, benchmark, and tweak modifier plugins in real time at 60 FPS before applying them to Studio timeline sequences.

## Architecture & Implementation Plan
1. **Engine Core & Presets (`apps/studio/src/components/debugger/playground/`)**:
   - `playgroundPresets.ts`: Curated production presets for core complex plugins (`overlay/canvas_particles`, `time_space/strange_attractor`, `time_space/relativistic_blackhole`, `vfx/color_grading`, `time_space/callout_leader`, etc.) with fallback synthesis using `extractSchemaDefaults`.
   - `usePlaygroundEngine.ts`: Decoupled RAF loop running at 60 FPS, high-DPI Retina buffer scaling, polymorphic 4-phase execution router (Phase 2 Clip space, Phase 3 Stream space, Phase 4 Master composite, synthetic audio waveform visualizer), state stack delta auditor (`save`/`restore` balance), and `IRStateManager` sequence bridge.
2. **Interactive UI Viewport & Panels**:
   - `PlaygroundViewport.tsx`: High-DPI canvas preview, SMPTE testcard, obsidian dark, studio white, and checkerboard backdrops, interactive scrubber, timecode readout, speed multipliers (0.25x-2x), aspect ratios (16:9, 9:16, 1:1), and floating telemetry badges.
   - `PlaygroundCatalog.tsx`: Real-time search filter and category pills across 8 functional families (VFX, Overlays, TimeSpace, Motion, Text, Shapes, Editorial, Audio).
   - `PlaygroundInspector.tsx`: Dynamic form generator supporting all 15 `ParamFieldType` types (sliders, switches, text, selects, color pickers, easing curves, light vectors, shader groups, and JSON fallbacks), Shiki JSON code viewer, and diagnostics panel.
   - `IrPluginPlaygroundModal.tsx`: Liquid Glass modal layout with multi-view switcher (`Trio`, `Focus`, `Code Split`) powered by `@corvu/resizable` (`ResizablePanelGroup`).
3. **Studio Shell Wiring**:
   - `Titlebar.tsx`: Lazy-loaded modal mount with `Ctrl+Shift+P` global keyboard shortcut, Titlebar LOD button, and More Menu integration.

## Key Changes
- `apps/studio/src/components/debugger/playground/playgroundPresets.ts`: Presets catalog and schema defaults extractor.
- `apps/studio/src/components/debugger/playground/usePlaygroundEngine.ts`: Reactive engine hook for RAF playback, zero-alloc render context, and telemetry.
- `apps/studio/src/components/debugger/playground/PlaygroundViewport.tsx`: High-DPI canvas viewport and transport controls.
- `apps/studio/src/components/debugger/playground/PlaygroundCatalog.tsx`: Searchable category catalog for 50+ plugins.
- `apps/studio/src/components/debugger/playground/PlaygroundInspector.tsx`: Dynamic schema form controls and Shiki code viewer.
- `apps/studio/src/components/debugger/IrPluginPlaygroundModal.tsx`: Resizable 3-column Liquid Glass modal assembly.
- `apps/studio/src/components/Titlebar.tsx`: `Ctrl+Shift+P` shortcut, Titlebar LOD button, More Menu trigger, and lazy component mount.
- `autogenerated-tests/ir_plugin_playground_modal.test.ts`: Automated test suite covering plugin discovery, schema generation, stateless execution, stack delta parity, and `ModifierNode` contracts.
