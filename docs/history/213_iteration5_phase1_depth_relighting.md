# 213. Master Integration Plan (Iteration 5) Phase 1: Depth-Aware Dynamic Relighting & Normal Map Shading

## Overview & Scope
- **Task**: Implement Phase 1 of Master Integration Plan Iteration 5: Depth-Aware Dynamic Relighting & Normal Map Shading.
- **Components Modified**:
  - `@acc/effect-engines` (`packages/effect-engines/src/vision/SurfaceNormalGenerator.ts`, `packages/effect-engines/src/vision/index.ts`)
  - `@acc/ir` (`packages/ir/src/plugins/vfx/Depth3DPlugin.ts`)
  - `autogenerated-tests` (`autogenerated-tests/depth_relighting.test.ts`)
- **Key Architectural Mandates Preserved**:
  - **ZERO-ALLOC-FRAME-LOOP**: Normal maps ($N_x, N_y, N_z$) and relighting scratch canvases are computed/allocated strictly once during preflight (`execute()`) and reused across all subsequent frames.
  - **MEDIA-ENGINE-STRATEGY-ISOLATION**: No direct imports or bindings to `bun:ffi`, `fluent-ffmpeg`, or `mediabunny`.
  - **SPECULAR-BLEED-PREVENTION**: Alpha mask gating ($A / 255$) prevents specular highlights from bleeding onto transparent background pixels.
  - **DETERMINISTIC-HANDSHAKE-BACKPRESSURE**: Relighting uses pure frame progress math without wall-clock drift.

---

## Changes Implemented

### 1. SurfaceNormalGenerator (`@acc/effect-engines/src/vision/SurfaceNormalGenerator.ts`)
- Implemented `generateFromDepth`:
  - 3x3 Sobel spatial gradient convolution with edge boundary clamping on normalized scalar depth maps.
  - Unit normal derivation: $\mathbf{N} = \text{normalize}([-G_x, -G_y, 1.0 / \text{strength}])$ stored in contiguous `Float32Array` buffers.
- Implemented `applyRelightingToRgba`:
  - Blinn-Phong lighting evaluation kernel with diffuse ($N \cdot L$), specular $((N \cdot H)^\alpha)$, ambient, and soft rim feathering $(1 - |N_z|)$.
  - Gated by subject alpha $(A / 255)$.
  - Direct zero-allocation in-place buffer modulation.
- Implemented `parseColor`:
  - Parser for CSS hex (`#fff`, `#ffffff`) and `rgb(...)` color strings.

### 2. Depth3DPlugin Extension (`@acc/ir/src/plugins/vfx/Depth3DPlugin.ts`)
- Extended `Depth3DPluginParams` with optional `relighting?: RelightingParams`.
- Added preflight caching in `execute()`:
  - Generates and caches `SurfaceNormalMap` in `normalMapCache`.
  - Pre-allocates compositing scratch canvas in `relightCanvasCache`.
- Added dynamic relighting pass in `renderClipSpace()`:
  - Evaluates Blinn-Phong lighting on the scratch canvas snapshot.
  - Blends non-destructively onto the main canvas context via `globalCompositeOperation = 'screen'`.

### 3. Automated Test Suite (`autogenerated-tests/depth_relighting.test.ts`)
- Synthetic depth gradient test verifying Sobel convolution vector directions and unit length ($\|\mathbf{N}\| \approx 1.0$).
- Alpha gating test asserting that transparent pixels receive zero specular bleed.
- Color parser accuracy test across hex, rgb, and numeric tuples.
- Deterministic rendering and zero-alloc frame loop test with `Depth3DPlugin`.
