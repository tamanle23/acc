# History Record 402: Fix Demo Schema Errors & Expand Multi-Domain Use-Case Demos

## 1. Problem
Following the strict enforcement of the single-source generator invariant (`targetScope === 'standalone'`), two issues surfaced:
1. **Self-Referential Validator Rejection**: In `VideoIRSchemaValidator.ts`, `hasStandaloneGenerator` was computed across the sequence and passed as `true` during the per-modifier audit. When evaluating the sequence's own primary standalone generator, `isModifierAllowedOnEntity` rejected it with:
   `Sequence already contains a standalone generator. A sequence cannot host multiple standalone generators.`
2. **Compound Standalone Generators in Demos**: Several pre-existing demo projects (`complexSciFiDemoIR`, `defaultDemoIR`, `astroTelemetryDemoIR`, `quantumPhysicsDemoIR`) had combined multiple standalone generators (e.g. particles + HUD reticle, or field generator + callout leader) onto single sequences, violating the newly enforced NLE clip single-source invariant.
3. **Demo Scope Gaps**: Additional domains such as timeline-level master optical post-processing, kinetic typography, multi-target telemetry, and spatial procedural audio sound design lacked dedicated studio demo templates.

## 2. Plan
1. **Validator Remediation**:
   - In `VideoIRSchemaValidator.ts`, evaluate modifier compatibility against the sequence's *other* modifiers (`modifierTypes.filter((_, idx) => idx !== i)`), ensuring a primary standalone generator does not falsely self-conflict.
   - Enforce instance policy in `ModifierPluginRegistry.ts` (`instancePolicy: 'single'`).
2. **Demo Invariant Conformance**:
   - Refactor `complexSciFiDemoIR.ts`, `defaultDemoIR.ts`, `astroTelemetryDemoIR.ts`, and `quantumPhysicsDemoIR.ts` to separate multiple generators across distinct tracks or sequential clips.
3. **New Multi-Domain Demo Templates**:
   - Create `apps/studio/src/lib/ir/kineticTypographyDemoIR.ts` (Kinetic titles, multi-target callouts, neural network plexus, glitch datastreams, superformula geometry).
   - Create `apps/studio/src/lib/ir/cinemaMasteringDemoIR.ts` (Timeline-level photometric bloom, anamorphic glare, crossfades, multi-camera A-roll, voiceover ducking).
   - Create `apps/studio/src/lib/ir/spatialAudioDemoIR.ts` (Spatial stereo panning, frequency filters, pitch modulation, sidechain ducking, audio visualizers).
4. **Studio UI & Store Integration**:
   - Register the 3 new templates in `apps/studio/src/lib/ir/irState.ts` (`switchTemplate`) and `apps/studio/src/components/Titlebar.tsx` (`Select` dropdown).
5. **Formal Automated Verification**:
   - Author `autogenerated-tests/demos_schema_and_generator_coverage.test.ts` validating that all 9 demo projects pass `VideoIRSchemaValidator.validate()` with 0 errors.

## 3. Changes
- **`packages/ir/src/schema/VideoIRSchemaValidator.ts`**: Computed `hasOtherStandalone` and `otherModifierTypes` excluding index `i` during sequence modifier validation.

- **`apps/studio/src/lib/ir/complexSciFiDemoIR.ts`**: Preserved `overlay/hologram_hud` on `seq-hud-tactical`; moved `overlay/canvas_particles` (`sci_fi_hud`) to sequential clip on Track V6.
- **`apps/studio/src/lib/ir/defaultDemoIR.ts`**: Split `seq-particle-overlay` into `seq-particle-overlay` and `seq-callout-overlay`.
- **`apps/studio/src/lib/ir/astroTelemetryDemoIR.ts`**: Decomposed Track V2 into Track V2 (Field Generators) and Track V3 (Astrometric Telemetry & Annotations).

## 4. Verification
1. All 9 demos pass `VideoIRSchemaValidator.validate()` with 0 errors.
2. Every sequence across all 9 demos hosts at most one primary standalone generator.
3. Standalone generator sequences only host universal modifiers (`transform`, `motion/gsap`, `overlay/blend_mode`, `transition/*`).
4. Full coverage across timeline-scope, track-scope, sequence VFX, procedural audio/SFX, and all time-space generators.
