# 420: Standalone Text Overlay Modifier & Typography Bank Migration

## Problem
In the VideoIR architecture, graphic text overlay objects (such as title cards, lower thirds, chapter pills, and kinetic titles) were historically staged using `type: 'text'` sequences and `timed_text/style` modifiers with synthetic 1-element `cues` arrays. This overloaded the subtitles/captions subsystem, caused acoustic safe zone constraints and track-level migrations in `irState.ts` to interfere with standalone overlay graphics, and broke single-source-of-truth expectations for text authoring.

## Plan
1. **Schema & Types**: Add `TextDrawModifierParams` to `schema/modifiers.schema.json`, register `"text/draw"` and `"text/overlay"` in `ModifierTypeEnum`, and regenerate types with zero drift.
2. **Core Plugin**: Implement `TextModifierPlugin` with `targetScope: 'standalone'` and Phase 2 Clip-Space rendering, 1080p reference scaling, multi-line wrapping, kerning, strokes, neon glow, and background badges.
3. **Inspector & In-Canvas Editing**: Register `text/draw` in `modifierCatalog.ts`, provide multi-line `<Textarea>` for `text` in `PrimitiveControlStrategies.tsx`, and wire double-click inline text editing in `Preview.tsx`, `UniversalCanvasHitOverlay.tsx`, and `TransformGizmoOverlay.tsx`.
4. **Preset Migration**: Migrate all 16 presets in `typographyBank.ts` to `type: 'overlay'`, `targetTrackType: 'video'`, attaching `transform` and `text/draw` modifiers, removing `cues`.
5. **Testing & Verification**: Create `autogenerated-tests/text_draw_modifier_plugin.test.ts`, verify schema sync with `--check`, and run full Vite production build.
