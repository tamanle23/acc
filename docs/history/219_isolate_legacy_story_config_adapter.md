# 219. Isolate LegacyStoryConfigAdapter into Legacy Story Renderer

## Problem Statement
Following the migration of `StoryConfigToUniversalIRAdapter.ts` to `apps/legacy-story-renderer` in task 218, `packages/ir/src/LegacyStoryConfigAdapter.ts` remained inside `packages/ir`. This legacy adapter converts `LegacyStoryConfig` into `ExtendedPipelineIR` (AST v3.1) and is strictly needed only for legacy story rendering pipelines and compatibility test suites. Keeping legacy story adapters in the core `@acc/ir` package polluted the canonical Universal Video IR boundary and prevented complete isolation of legacy story configuration processing.

## Solution Plan & Implementation
1. **Relocate File**: Moved `packages/ir/src/LegacyStoryConfigAdapter.ts` to `apps/legacy-story-renderer/src/LegacyStoryConfigAdapter.ts` via `git mv`.
2. **Decouple `@acc/ir`**: Removed `export * from './LegacyStoryConfigAdapter';` from `packages/ir/src/index.ts`.
3. **Consolidate Exports in `@acc/legacy-story-renderer`**: Exported `LegacyStoryConfigAdapter` and its legacy types (`LegacyStoryConfig`, `LegacySceneConfig`, `LegacyStorySettings`, `LegacySceneTransition`, `LegacySceneCaption`, `LegacyCaptionSettings`) from `apps/legacy-story-renderer/src/index.ts`.
4. **Update Consumers**:
   - `apps/cli/src/pipelines/04-generative-story/stages/StoryFolderResolutionStage.ts`: Updated import to `@acc/legacy-story-renderer`.
   - `apps/cli/src/pipelines/04-generative-story/VideoEditPipelineOrchestrator.ts`: Updated legacy type import to `@acc/legacy-story-renderer`.
   - `apps/legacy-story-renderer/src/LegacyIRPreparationAdapter.ts`: Switched import to local `./LegacyStoryConfigAdapter`.
   - `apps/legacy-story-renderer/src/StoryConfigToUniversalIRAdapter.ts`: Switched import to local `./LegacyStoryConfigAdapter`.
   - `autogenerated-tests/`: Updated 12 test suites to import `LegacyStoryConfigAdapter`, `StoryConfigToUniversalIRAdapter`, and `LegacyStoryConfig` from `@acc/legacy-story-renderer`.
