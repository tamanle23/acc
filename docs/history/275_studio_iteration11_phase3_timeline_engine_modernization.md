## 🎯 Context & Objective
In Phase 3 of Iteration 11, the Studio Timeline required complete engine modernization to deliver an intuitive, high-performance Non-Linear Editor (NLE) experience:
1. **TotalFrames Unification:** Eliminate divergent `totalDurationFrames` properties across `App.tsx`, `Preview.tsx`, `Timeline.tsx`, `RightSidebar.tsx`, and `WebAudioEngine.ts` to strictly adhere to canonical `totalFrames`.
2. **Sticky Split-View Timeline Layout:** Separate track headers and timeline lanes into a fixed left column (~192px / `w-48`) for track controls and headers, and a horizontally scrollable right viewport container holding the `TimecodeRuler` and sequence lanes.
3. **Track Reordering UI:** Add interactive `ChevronUp`, `ChevronDown`, and `GripVertical` controls to track headers connected directly to `IRStateManager.reorderTrack(trackId, 'up' | 'down')` with complete undo/redo support.
4. **Enhanced Magnetic Snapping & Guideline:** Extend snap targets during clip dragging and trimming to sequence boundaries, the current playhead frame, and 1-second grid ticks (`k * fps`). Render an active vertical neon cyan guideline with a frame tooltip badge when snapping occurs within a 4-frame threshold.
5. **Hand Pan Tool (`H`):** Provide smooth timeline canvas click-and-drag panning when `activeTool === 'hand'`.

## 🛠️ Changes Implemented

### 1. Unified `totalFrames`
- Replaced all legacy references to `totalDurationFrames` with canonical `totalFrames` across:
  - `apps/studio/src/App.tsx`
  - `apps/studio/src/components/Preview.tsx`
  - `apps/studio/src/lib/audio/WebAudioEngine.ts`
  - `apps/studio/src/components/RightSidebar.tsx`
  - `apps/studio/src/components/Timeline.tsx`

### 2. Sticky Split-View Layout (`apps/studio/src/components/Timeline.tsx`)
- Refactored the timeline body into a two-column split layout:
  - **Left Header Column (`w-48 shrink-0`):** Fixed position displaying the Track Headers label header row, individual track header cards, track reorder buttons, mute/lock toggles, and a dashed Project Settings button for easy access.
  - **Right Viewport (`flex-1 overflow-x-auto`):** Contains the interactive `TimecodeRuler`, playhead needle, cyan snap guideline, and droppable clip lanes sized according to `timelineWidth`.

### 3. Track Reorder Controls & Hand Tool Panning
- Added `ChevronUp` and `ChevronDown` buttons on each track header card calling `IRStateManager.getInstance().reorderTrack(track.id, 'up' | 'down')`.
- Dynamically disabled the Up button on the topmost track and the Down button on the bottommost track.
- Added mouse event listeners (`onMouseDown`, `onMouseMove`, `onMouseUp`) and a `scrollContainerRef` for seamless drag panning when the Hand tool (`H`) is active.

### 4. Comprehensive Magnetic Snapping with Visual Guideline
- Upgraded `handleDragMove` during clip movement and trimming to collect snap targets:
  - Active playhead frame (`currentFrame`).
  - Sequence start and end frames across all tracks.
  - 1-second grid intervals (`sec * fps`).
- Added state `activeSnapGuideline: number | null` which renders an absolute cyan vertical guide (`shadow-[0_0_8px_#22d3ee]`) with an attached frame badge tooltip when snapping is within 4 frames.
- Cleared the guideline automatically upon drag completion in `handleDragEnd`.

### 5. Automated Testing & Verification
- Created `autogenerated-tests/studio_phase3_timeline_enhancements.test.ts` verifying:
  - `totalFrames` resolution and integrity.
  - Magnetic snap calculation and threshold matching.
  - Track reordering dispatch, state updates, and undo/redo reversibility.
- Validated existing test suite `autogenerated-tests/studio_phase2_multi_tier_inspector.test.ts` (10/10 passing).
- Verified production build via `bun run build` in `apps/studio` with 0 errors.
