# 373: Headless Scoped Resource Engine & Unified Compositor RAII Parity

## Problem
Following Iteration 45's resolution of live playback memory leaks in `@acc/studio`, headless exports via `IRMasterRenderer` and `IRChunkWorkerPool` as well as the shared `IRCanvasCompositor` still exhibited three architectural gaps:
1. **Unmanaged Static Scratch Singleton in `IRCanvasCompositor`**: `IRCanvasCompositor.ts` held a static `scratchCanvasInstance` outside `FrameResourceScope`, risking cross-worker context collisions during concurrent chunk rendering.
2. **Lack of Sliding Sequence Eviction in `IRMasterRenderer`**: Completed sequences retained their pre-baked neural textures (`SequenceResourceScope`) and cached assets until the entire export finished, causing linear memory growth on multi-clip timelines.
3. **Rigid Memory Ceiling & Shared Singleton in `IRChunkWorkerPool`**: 4K exports needed a higher native budget than 1080p, and concurrent chunk workers lacked isolated `NativeResourceManager` instances.

## Plan
1. Add `NativeResourceManager.createIsolated(maxGpuBytes)` and `NativeResourceManager.computeResolutionBudgetBytes(width, height, customMaxMemoryMb)` in `@acc/core-isomorphic`.
2. Add LIFO `onExit(callback)` stack unwinding to `FrameResourceScope` and native backing release to `CanvasScratchPool`.
3. Refactor `IRCanvasCompositor.renderFrame()` to acquire scratch canvases through `FrameResourceScope` and wire `FrameResourceScope` into both `IRPreviewEngine.renderFrame()` and `IRMasterRenderer.renderCanvasFrame()`.
4. Implement JIT sequence preflight and sliding hybrid lookahead eviction (`computeAssetLifespans` + `evictExpiredSequences`) in `IRMasterRenderer`.
5. Isolate per-worker `NativeResourceManager` instances in `IRChunkWorkerPool`.

## Changes
- `packages/core-isomorphic/src/resource/NativeResourceManager.ts`: Added `createIsolated`, `computeResolutionBudgetBytes`, `hasSequenceScope`, and `disposeAllSequenceScopes`.
- `packages/core-isomorphic/src/resource/NativeResourceScope.ts`: Added `onExit(callback)` LIFO cleanup hooks to `FrameResourceScope`.
- `packages/core-isomorphic/src/canvas/CanvasScratchPool.ts`: Added `destroyCanvasBacking` on pool overflow and `clear()`.
- `packages/ir/src/renderer/shared/IRCanvasCompositor.ts`: Replaced static `scratchCanvasInstance` with frame-scoped RAII scratch context.
- `apps/studio/src/renderer/IRPreviewEngine.ts`: Wired `FrameResourceScope` into `renderFrame()`.
- `packages/ir/src/renderer/IRMasterRenderer.ts`: Implemented resolution-aware budgeting, JIT sequence preflight, sliding hybrid lookahead eviction, and `Disposable` interface.
- `packages/ir/src/server/IRChunkWorkerPool.ts` & `packages/core/src/ir-server/IRChunkWorkerPool.ts`: Added isolated per-worker `NativeResourceManager` instances and deterministic `finally` cleanup.
- `autogenerated-tests/headless_scoped_resource_engine.test.ts`: Added formal verification suite covering 1,000-frame soak, hybrid lookahead eviction, resolution scaling, and worker isolation.
