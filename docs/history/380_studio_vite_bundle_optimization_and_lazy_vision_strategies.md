# 380. Studio Vite Bundle Optimization and Lazy Vision Strategies

### Problem
1. **Monolithic Bundle Bloat**: `@acc/studio` bundled `@huggingface/transformers` and `onnxruntime-web` directly into the main `index.js` chunk (>2.15 MB minified), slowing down initial application load.
2. **Vite Dynamic/Static Import Conflict Warning**: `@huggingface/transformers` was dynamically imported in `UniversalOnnxRuntimeProvider.ts` but statically imported at the top of 9 vision strategy files in `packages/effect-engines`, causing Vite/Rollup to emit warnings and cancel lazy chunk splitting.

### Plan
1. Configure Vite `manualChunks` in `apps/studio/vite.config.ts` to separate:
   - `vendor-transformers` for `@huggingface/transformers`
   - `vendor-onnx` for `onnxruntime-web` and `onnxruntime-common`
2. Migrate all 9 vision strategies in `packages/effect-engines` to lazy dynamic resolution via `await UniversalOnnxRuntimeProvider.getTransformers()` inside `init()`.
3. Verify with `transformers_js_vision.test.ts` and ensure production build completes with zero import conflict warnings.

### Changes
- `apps/studio/vite.config.ts`: Configured `vendor-transformers` and `vendor-onnx` manual chunks.
- `packages/effect-engines/src/vision/strategies/`:
  - `depth/DepthAnythingV2SmallStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.
  - `depth/DepthAnythingV2BaseStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.
  - `depth/DptLargeStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.
  - `depth/GlpnMetricStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.
  - `segmentation/BiRefNetStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.
  - `segmentation/RmbgStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.
  - `segmentation/Sam2TinyStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.

  - `segmentation/SlimSamStrategy.ts`: Replaced static `@huggingface/transformers` import with `UniversalOnnxRuntimeProvider.getTransformers()`.
