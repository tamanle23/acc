# 384. TimeSpaceModifierPlugin Refinement & Demo Showcase

## Problem
1. **Method Signature Mismatch in Compositor**: In `packages/ir/src/plugins/TimeSpaceModifierPlugin.ts`, the sequence render method was named `renderClip(...)` instead of `renderClipSpace(...)`. Because `IRCanvasCompositor.renderFrame` specifically checks `if (plugin.renderClipSpace)`, `TimeSpaceModifierPlugin` was completely bypassed during sequence clip rendering and never drawn onto the canvas.
2. **Cache Key Invalidation Bug**: In `getOrCreateMachine`, the plugin cached `_timeSpaceMachine` on `targetHolder` without checking if `templateId` had changed, preventing switching between different templates on the same sequence.
3. **Studio Modifier Catalog Misalignment**: In `apps/studio/src/components/inspector/modifierCatalog.ts`, `time_space` was mislabeled as "Time-Space Speed Ramp" with audio speed ramp params instead of "Time-Space Motion Graphic" with procedural template parameters (`templateId`, `boundary`, `seed`, `params`).
4. **Missing Demo Showcase**: Neither `defaultDemoIR` nor `complexSciFiDemoIR` included the `time_space` modifier, preventing users from seeing `TimeSpaceStateMachine` in action in the Studio workspace.

## Plan
1. Fix `TimeSpaceModifierPlugin.ts`:
   - Rename `renderClip` to `renderClipSpace` (with `renderClip` retained as a backward-compatible alias).
   - Invalidate and recreate `_timeSpaceMachine` if `targetHolder._timeSpaceTemplateId !== templateId`.
   - Read dynamic sequence frame rate (`(ctx.sequence as any)?.fps || 30`).
2. Align `modifierCatalog.ts`:
   - Change catalog definition to "Time-Space Motion Graphic", supported on `['video', 'overlay', 'image']`.
   - Provide default template parameters: `templateId: 'callout_leader'`, `boundary: 'loop'`, `seed: 1337`, `params: { text: 'TARGET ACQUIRED', ... }`.
3. Update Demo IR Documents:
   - Add a `time_space` tracking callout modifier to `seq-lower-third-callout` in `complexSciFiDemoIR.ts` (`SECTOR 7-G LOCK`).
   - Add a `time_space` tracking callout modifier to `seq-particle-overlay` in `defaultDemoIR.ts` (`NATURE RESERVE`).
4. Verify all tests pass and `@acc/studio` builds with 0 errors.
