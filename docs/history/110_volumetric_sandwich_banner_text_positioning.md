# 110. Volumetric Sandwich Banner Text Positioning & Typography Customization

## Problem & Context
In 3D Depth scenes using the `volumetric_sandwich` effect (`mode: "volumetric_sandwich"`), the banner text (`bannerText`) rendered behind the foreground subject had a fixed default vertical anchor (`height * 0.38`), fixed font size (`width * 0.065`), and fixed gradient styling. Users needed fine-grained control to adjust the vertical position (`top`, `center`, `bottom`, or custom ratios / pixel coordinates), horizontal alignment, custom font size, text color, and floating animation motion.

## Proposed Plan
1. **Types & Schema Update**:
   - Extend `SandwichVolumetricSettings` in `packages/effect-engines/src/types.ts` and `packages/core/src/types.ts` with `position?: 'top' | 'center' | 'bottom'`, `positionY?: number`, `positionX?: number`, `fontSize?: number`, `textColor?: string`, and `floatMotion?: boolean`.
   - Update `schema/story-config.schema.json` with corresponding definitions and descriptions.
2. **Volumetric Sandwich Rendering**:
   - In `packages/effect-engines/src/depth3d/sandwich.ts`, compute `fontSize`, `baseY` (supporting preset and numeric ratios/pixels), `baseX`, `floatOffset`, and `textColor` dynamically from `sandwichSettings`.
3. **Documentation & Specification**:
   - Update `docs/STORY_CONFIG_SPEC.md` with positioning guidance and copy-pasteable JSON examples.
4. **Sample Story & Regression Verification**:
   - Update `sample-story/story-config.json` scene 4 to showcase the new properties (`position`, `positionY`, `fontSize`, `floatMotion`).
   - Run benchmark and test suites.

## Changes Made
- `packages/effect-engines/src/types.ts` & `packages/core/src/types.ts`: Added `position`, `positionY`, `positionX`, `fontSize`, `floatMotion` to `SandwichVolumetricSettings`.
- `packages/effect-engines/src/depth3d/sandwich.ts`: Implemented dynamic positioning resolution (ratios `0.0 - 1.0` or pixel coordinates, `position` presets, custom font sizing, and custom text coloring).
- `schema/story-config.schema.json`: Added validation schema for all new sandwich properties.
- `docs/STORY_CONFIG_SPEC.md`: Added detailed explanation of sandwich text positioning properties.
- `sample-story/story-config.json`: Added `position: "top"`, `positionY: 0.28`, `fontSize: 0.075`, `floatMotion: true` to scene 4.

## Verification
- Ran multi-strategy depth benchmark (`bun test autogenerated-tests/depth_strategies_benchmark.test.ts`): All 5 tests passed with 0 failures.
- Verified schema and backward compatibility: Scenes without explicit positioning default smoothly to 38% height.
