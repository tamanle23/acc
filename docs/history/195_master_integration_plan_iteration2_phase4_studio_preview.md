## 2. Context & Problem
While headless rendering pipelines (`IRMasterRenderer`, `IRChunkWorkerPool`) provide high-throughput, deterministic batch exports, developers and content creators require an interactive preview mechanism to scrub the playhead, inspect typography and procedural visual shaders in real-time, toggle VFX modifiers (e.g., `depth_3d`, `canvas_particle_overlay`), and dispatch deterministic renders directly from the interface without restarting CLI workflows.

## 3. What Was Built
1. **Core Types & RFC 6902 JSON-Patch Specification**:
   - Location: [`apps/cli/src/studio/types.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/cli/src/studio/types.ts)
   - Implements `JsonPatchOperation` (`add`, `remove`, `replace`, `move`, `copy`, `test`), `TimelinePlayheadState`, `ActiveClipInfo`, `ResolvedFramePreview`, and `StudioRenderOptions`.

2. **Immutable State & Playhead Manager (`StudioTimelineState.ts`)**:
   - Location: [`apps/cli/src/studio/StudioTimelineState.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/cli/src/studio/StudioTimelineState.ts)
   - Pure immutable state manager wrapping `VideoIRDocument`.
   - Bidirectional RFC 6902 JSON-Patch executor with automatic inverse patch creation, undo stack, and redo stack.
   - Real-time playhead scrubbing (`seek`, `step`, `play`, `pause`) with frame/time code resolution.
   - Active clip resolution: dynamically resolves active clips, local frame offsets, active text cues, and modifiers at arbitrary frame indices.
   - High-level semantic mutation helpers: `updateSequenceTime`, `updateTextCue`, `toggleModifier`, `updateTrackStyle`.

3. **Hybrid Dual-Pipeline Preview (`UIStudioPreviewEngine.ts`)**:
   - Location: [`apps/cli/src/studio/UIStudioPreviewEngine.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/cli/src/studio/UIStudioPreviewEngine.ts)
   - Frontend Preview: Resolves lightweight compositing frames (canvas size, active text cues, modifier flags) instantly without allocating FFI encoder locks.
   - Backend Dispatch: Dispatches headless deterministic export via `IRMasterRenderer` using the patched AST, adhering strictly to **ZERO-ALLOC-FRAME-LOOP** and monotonic timestamp bitstream integrity.

4. **Native Bun HTTP Server & Interactive Canvas Editor (`StudioServer.ts`)**:
   - Location: [`apps/cli/src/studio/StudioServer.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/cli/src/studio/StudioServer.ts)
   - Serves local HTTP studio preview server (port `3300` default) via `Bun.serve`.
   - REST API endpoints:
     - `GET /api/health`: Health status and port info.
     - `GET /api/timeline`: Complete document, playhead state, and active clips.
     - `POST /api/patch`: Applies RFC 6902 patches and recompiles the DAG.
     - `POST /api/undo` & `POST /api/redo`: Full undo/redo history.
     - `POST /api/scrub`: Updates playhead frame/time.
     - `POST /api/render`: Triggers backend deterministic export.
     - `GET /`: Embedded responsive dark-theme HTML5 Studio Editor with canvas viewport, timecode display, draggable scrubber slider, clips/text editor, VFX toggles, and live JSON-patch audit log.
