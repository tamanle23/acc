# History Entry 072: Phase 0 - Turborepo Monorepo & Workspace Scaffolding (Zero-Regression)

## Problem Statement
The ACC (Automated Content Creator) codebase was monolithic and tightly coupled to the single visual storytelling pipeline (Pipeline 4). To support all 6 core content pipelines and decouple the Python AI backend via gRPC as outlined in `docs/MASTER_IMPLEMENTATION_PLAN_V3.md`, the repository needed to transition into a modular Turborepo monorepo powered by Bun workspaces. Crucially, this structural transition had to guarantee **100% Zero-Regression** on existing workflows, test suites, and CLI entry points.

## Plan
1. Configure `turbo.json` with Turborepo task pipeline definitions (`build`, `test`, `dev`).
2. Update root `package.json` to configure Bun workspaces (`packages/*`, `apps/*`) and add `turbo` dev dependency.
3. Configure `tsconfig.json` path mappings (`@acc/core`, `@acc/ir`) to enable instant TypeScript resolution without intermediate compilation steps.
4. Establish `packages/ir` containing the canonical `PipelineIR` contracts.
5. Establish `packages/core` containing shared native media engines (`FFmpegManager`, `bun:ffi` zero-copy bindings, `AssetContext`, `logger`, `AudioNormalizer`).
6. Establish `apps/cli` with `GenerativeStoryPipeline.ts` encapsulating visual storytelling execution.
7. Maintain backward-compatible shims in `src/` and keep root `cli.ts` proxying transparently to ensure `bun run cli.ts ./sample-story` and `bun run render` continue to function without any breaking changes.
8. Verify zero regression using `bun test autogenerated-tests` and rendering `./sample-story`.
