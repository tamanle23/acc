# Milestone 390: Studio Iteration 51 Adaptive Audit & Defect Gap Remediation

## 1. Problem Statement
Following the baseline execution of Master Plan Iteration 51, a deep `/adaptive-skill-researcher` and `/code-reviewing` verification was conducted across all 18 defect matrices (L-1 to L-5, R-1 to R-4, T-1 to T-5, P-1 to P-5). While the core structural scaffolding was established, several subtle gaps, stubs, and mismatches were uncovered:
1. **Left Sidebar Vault Ingestion (`LeftSidebar.tsx`)**:
   - `handleInsertAsset` was implemented, but was omitted from `<DraggableAssetCard assetId={asset.id} asset={asset} />`, leaving the "Insert to Timeline" button hidden on vault cards (Defect L-4).
2. **Footage & Audio Presets (`footageBank.ts` & `audioFootageBank.ts`)**:
   - `footage_cyber_city` and `footage_deep_space` presets retained `type: 'image'` in `createSequence` instead of standard `type: 'video'` (Defect L-2).
   - Presets lacked root `type` and `assetId` tags expected by unit test schema suites.
   - Named exports `FOOTAGE_PRESETS` and `AUDIO_PRESETS` were missing as aliases for `VIDEO_FOOTAGE_PRESETS` and `AUDIO_FOOTAGE_PRESETS`.
3. **Live Ephemeral Canvas Rendering (`IRCanvasCompositor.ts` & `IRPreviewEngine.ts`)**:
   - `IRPreviewEngine.setEphemeralTransformOverride` stored ephemeral transforms during gizmo drags, but `IRCanvasCompositor.renderFrame` had no mechanism to read or composite them into visual sequences and timed-text captions during active pointer drags.
   - Pointer move and release in `useGizmoTransform.ts` did not trigger immediate canvas re-blitting (`onRenderFrame`).
4. **Hit-Testing Subtitle Coordinate Drift (`CanvasHitTester.ts`)**:
   - Subtitle hit testing hardcoded `normX: 0.5`, ignoring spatial transform offsets (`x / 1920`, `y / 1080`, `scale`) and detaching selection boxes from dragged subtitles.
5. **VFX Ambiance Stub (`Preview.tsx`)**:
   - `showVfxAmbiance` state toggle had no effect on the canvas wrapper because the liquid ambient mesh overlay was statically rendered.

---

## 2. Architecture & Design Plan
1. **Live Ephemeral Canvas Blitting Loop**:
   - Add `transformOverrides?: Map<string, any>` to `CanvasCompositorOptions` and `renderTrackSequences` in `IRCanvasCompositor.ts`.
   - Dynamically inject active sequence transform overrides into modifier params during both visual sequence compositing and timed-text post-processing.
   - Connect `onRenderFrame` callback in `useGizmoTransform.ts` to `renderStrategy.renderFrame(currentFrame)` for smooth 60 FPS viewport re-blitting during dragging.
2. **Hit-Testing Subtitle Alignment**:
   - Update `CanvasHitTester.resolveSequenceRegion` for text and subtitle sequences to incorporate `transMod.params.x / 1920`, `transMod.params.y / 1080`, and `transMod.params.scale`.
3. **Preset Schema Parity & Alias Exports**:
   - Expand `StagingPreset` interface with optional `type?: SequenceType` and `assetId?: string`.
   - Align all video presets in `footageBank.ts` to `type: 'video'`.
   - Export `FOOTAGE_PRESETS` and `AUDIO_PRESETS` aliases.
4. **Left Sidebar Vault Ingestion**:
   - Pass `onInsert={handleInsertAsset}` to `<DraggableAssetCard>` in `LeftSidebar.tsx`.
5. **VFX Ambiance Dynamic Overlay**:
   - Conditionally render the liquid ambient mesh based on `showVfxAmbiance` in `Preview.tsx`.

## 4. Verification Matrix
- **L-1 (DnD Context)**: Single root `DndContext` verified; inner context eliminated.
- **L-2 (Presets & Assets)**: All video presets use `type: 'video'` and valid asset IDs; all audio presets use `audio/volume`.
- **L-3 (Shapes & Partial VFX)**: Geometry and cornerRadius mapped; fallback normalization in `PartialVFXPlugin`.
- **L-4 (Vault Ingestion)**: Metadata duration probing, search by `name`, and "Insert" button on `DraggableAssetCard` verified.
- **L-5 (AudioContext Cleanup)**: `AudioContext.close()` on ended with timeout fallbacks verified across sidebar and inspector.
- **R-1 (Inspector Accordion)**: Unique `modKey` per modifier prevents Radix collisions.
- **R-2 (Modifier Target Schema)**: Modifiers inherit sequence domain target (`seq.type`).
- **R-3 (Track Styling Bus)**: Track volume, pan, and mute gating applied in `UniversalAudioMixer` and `IRCanvasCompositor`.
- **R-4 (Virtualizer Pruning)**: Single-item virtualizer removed; replaced by natural `overflow-y-auto`.
- **T-1 (Track Semantics)**: `track.muted`, `visible`, `locked` saved to `VideoIR`; keyboard hotkeys guarded against locked tracks.
- **T-2 (DnD Frame Drop)**: Drop calculation incorporates `timelineScrollLeft` and `pixelsPerFrame = max(0.2, 1.5 * zoomScale)`.
- **T-3 (Relational Timing)**: `SplitSequenceCommand` and `RippleMoveSequenceCommand` resolve start frames and string durations from `CompiledTimeline`.
- **T-4 (Waveforms)**: Standardized on clip-scoped `WaveSurferWaveform`; redundant track virtual canvas eliminated.
- **T-5 (HUD & Ruler)**: Timecode ruler pointer capture scrub active; razor hover HUD responsive.
- **P-1 (Gizmo Math)**: Canvas coordinates projected to responsive DOM container percentages `(muX + curX / 1920) * 100%`.
- **P-2 (Live Gizmo Drag)**: Ephemeral transform overrides streamed to `IRCanvasCompositor` at 60 FPS with immediate canvas blit.
- **P-3 (Captions Transform)**: `transform` modifiers and `textColor` dynamically rendered for subtitles in `IRCanvasCompositor`.
- **P-4 (Video Audio Preload)**: Video assets preloaded in `WebAudioEngine.syncFromIR`.
- **P-5 (Drop & Ambiance)**: Canvas drop zone normalized coordinates wired; `showVfxAmbiance` toggle functional.
