# Implementation History: 273 - Studio RightSidebar Add Effect & Controlled Accordion Expansion

## Problem Statement
In `apps/studio/src/components/RightSidebar.tsx`, when users selected an effect from the "Add Effect" dropdown menu on a sequence, nothing visually changed in the Inspector panel:
1. The Accordion was using an uncontrolled `defaultValue` array (`['transform', 'relighting', 'camera', 'particles', 'hologram_hud', 'typography', 'audio']`). Radix Accordion only reads `defaultValue` on initial mount; adding a new effect to an already mounted component did not open the accordion item for that effect.
2. Several modifier types like `'vfx/color_grading'` (`value="color"`) and `'sfx/procedural'` (`value="procedural_sfx"`) were missing from `defaultValue`.
3. DropdownMenuItem was using `onClick` without `onSelect`, which could be dropped or bypassed when Radix closed the popover menu.
4. For modifiers without dedicated hardcoded sections (such as custom or additional plugins), there was no dynamic fallback accordion inspector card rendered.

## Solution & Architecture
1. **Section ID Mapping Helper (`getSectionIdForModifierType`)**:
   - Maps modifier types (`transform`, `vfx/depth_relighting`, `camera/3d`, `vfx/color_grading`, `sfx/procedural`, etc.) to their respective accordion value keys (`transform`, `relighting`, `camera`, `color`, `procedural_sfx`, etc.).
   - Provides safe namespaced IDs for custom plugins: `generic_${type}`.
2. **Controlled Accordion (`openSections` State)**:
   - Replaced static `defaultValue` with controlled `value={openSections}` and `onValueChange={setOpenSections}`.
   - When an effect is chosen via `handleAddEffect(mod)`, the target section ID is automatically appended to `openSections` and `updateModifierParams(mod.type, mod.defaultParams)` is dispatched.
3. **Dual Event Handlers on DropdownMenuItem**:
   - Added both `onSelect` and `onClick` on each `DropdownMenuItem` to ensure cross-browser click and keyboard selection trigger reliably.
4. **Fallback Modifier Section**:
   - Added a fallback dynamic accordion item for any attached modifiers not explicitly handled by dedicated forms, rendering numeric sliders, boolean switches, and text inputs for their parameters.
5. **Automated Unit Tests**:
   - Added tests in `autogenerated-tests/studio_phase2_multi_tier_inspector.test.ts` verifying section mapping and modifier attachment via `UpdateModifierCommand`.
