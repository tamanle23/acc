# Walkthrough: Dual-Profile Multi-Track Blending & Layer Isolation Architecture

## Changes Made
Implemented and verified the **Dual-Profile Multi-Track Blending & Layer Isolation Architecture** across the core IR intermediate representation, canonical canvas compositor, and Studio preview subsystems.

### 1. Intermediate Representation Core & Schema Sync
- **Schema & Type Expansion (`packages/ir/src/types/VideoIR.ts`, `schema/video-ir.schema.json`, `packages/ir/src/schema/VideoIRSchemaValidator.ts`):**
  - Expanded `BlendMode` union to support all 11 canonical composite operations: `normal`, `screen`, `multiply`, `overlay`, `add`, `color_dodge`, `soft_light`, `lighten`, `darken`, `difference`, `exclusion`.
  - Added `blendMode?: BlendMode` and `opacity?: number` to `ResolvedTrack`.
  - Synchronized JSON Schema Draft-07 enum definitions.
- **Compiler Topology Propagation (`packages/ir/src/compiler/RelationalDAGCompiler.ts`):**
  - Compiler now propagates `track.blendMode` and `track.opacity` (or `track.style.opacity`) into the compiled `trackMap`.

### 2. Canonical Canvas Compositor (`packages/ir/src/renderer/shared/IRCanvasCompositor.ts`)
- **Blend Mode Standardizer:** Introduced `mapBlendModeToCanvasCompositeOperation()` mapping all 11 Video IR modes to standard W3C Canvas 2D `globalCompositeOperation` strings (e.g. `add` $\rightarrow$ `lighter`, `color_dodge` $\rightarrow$ `color-dodge`, `soft_light` $\rightarrow$ `soft-light`).
- **Zero-Allocation Singleton Scratch Surface:** Reusable scratch canvas instance and context dynamically resized to viewport dimensions, completely preventing GC nursery heap churn in the frame loop.
- **Dual-Profile Stacking Engine:**
  - **Preview Profile (`preview`):** Fast-path direct blit for clean standard tracks (`blendMode === 'normal'`, `opacity === 1.0`, zero modifiers); isolated scratch pass only for tracks requiring isolation (non-normal blend modes, opacity $< 1.0$, or track-level stream modifiers).
  - **Master Profile (`master`):** Strict layer isolation across all visual tracks, preventing stream modifier bleed (e.g. blurs or color grades) into underlying tracks.
- **Transparent / Checkerboard Viewport Support:** Respects `options.clearColor === 'transparent'` via `clearRect`, preserving alpha channel for overlays and viewport checkerboard display.
- **NLE Bottom-to-Top Stacking Order:** Visual tracks render sequentially from Track 0 (V1, bottom) to Track $N$ (top), with timed-text captions strictly rendered over all visual layers.

### 3. Studio Preview & Web Worker Integration
- **`PreviewWorkerBridge.ts` & `preview.worker.ts`:**
  - Extended bridge and worker messages with `clearColor`.
  - OffscreenCanvas worker clears with `clearRect` when checkerboard is active, and forwards `clearColor` to `IRPreviewEngine`.
- **`Preview.tsx`:**
  - Passes `clearColor: showCheckerboard ? 'transparent' : '#000000'` through both main-thread fallback and OffscreenCanvas worker bridge.
