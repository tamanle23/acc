# History Entry 381: Console Dead Code Elimination & Shared Data-Table Consolidation (Iteration 50 Phase 3)

## Problem & Context
During Iteration 50 architecture review, several violations of monorepo invariants were identified in `apps/console`:
1. `apps/console/src/features/users/components/RegisterUserForm.tsx` and `apps/console/src/features/users/api/useRegisterUserFacade.ts` were orphaned dead code calling an unauthenticated, non-existent `/api/v2/users/register` via raw `fetch()`. They violated `NO-ORPHANED-CODE`.
2. Both `features/users` and `features/workflow-executions` had local files named `data-table-bulk-actions.tsx` defining components named `DataTableBulkActions`, which shadowed the canonical shared primitive in `@/components/data-table/bulk-actions.tsx`.

## Plan
1. Delete `RegisterUserForm.tsx` and `useRegisterUserFacade.ts`. Ensure no remaining references exist.
2. Disambiguate local bulk actions files:
   - Rename to `users-bulk-actions.tsx` exporting `UsersBulkActions`.
   - Rename to `workflow-executions-bulk-actions.tsx` exporting `WorkflowExecutionsBulkActions`.
3. Update table consumers (`users-table.tsx` and `workflow-executions-table.tsx`).
4. Implement formal automated verification suite in `autogenerated-tests/console_dead_code_and_primitives.test.ts`.

## Changes Completed
- Deleted:
  - `apps/console/src/features/users/components/RegisterUserForm.tsx`
  - `apps/console/src/features/users/api/useRegisterUserFacade.ts`
- Renamed & Refactored:
  - `apps/console/src/features/users/components/users-bulk-actions.tsx`: Exporting `UsersBulkActions`, composing `@/components/data-table` primitives.
  - `apps/console/src/features/workflow-executions/components/workflow-executions-bulk-actions.tsx`: Exporting `WorkflowExecutionsBulkActions`, composing `@/components/data-table` primitives.
- Updated Consumers:
  - `apps/console/src/features/users/components/users-table.tsx` -> consumes `UsersBulkActions` and `DataTablePagination`.
  - `apps/console/src/features/workflow-executions/components/workflow-executions-table.tsx` -> consumes `WorkflowExecutionsBulkActions` and `DataTablePagination`.
- Formal Verification:

- Documentation:
