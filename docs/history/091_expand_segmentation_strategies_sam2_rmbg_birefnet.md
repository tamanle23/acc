## 1. Context & Overview
To evaluate subject segmentation quality and boundary precision beyond `SlimSamStrategy` (~38MB) and `SamVitBaseStrategy` (~130MB), we integrated 3 state-of-the-art vision models in ONNX format via `@huggingface/transformers`:
1. **`Sam2TinyStrategy` (`onnx-community/sam2.1-hiera-tiny-ONNX`, ~39MB)**: Meta's SAM 2.1 architecture with Hiera-Tiny backbone, providing superior boundary detail for anatomical features (horns, claws, teeth) with zero background leakage.
2. **`RmbgStrategy` (`briaai/RMBG-1.4`, ~44MB)**: 1-Click prompt-free background removal network with smooth feathered alpha edges and ultra-fast inference (~3s).
3. **`BiRefNetStrategy` (`onnx-community/BiRefNet-general-ONNX`, ~120MB)**: High-resolution bilateral reference network for deep dichotomous subject extraction.
