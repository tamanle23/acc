# 222. Eliminate Legacy canvas-strategies and Migrate to UniversalCanvasProvider

## Problem Statement
The codebase contained redundant legacy canvas wrappers in `packages/core/src/effects/overlay-effects/canvas-strategies` and `packages/effect-engines/src/overlay-effects/canvas-strategies`. These directories contained `CanvasAdapterFactory`, `NapiRsCanvasAdapter`, and duplicate type interfaces (`CanvasContext2D`, `CanvasInstance`, `CanvasAdapter`). On every frame, `NapiRsCanvasAdapter` created wrapper objects tracked in a WeakMap, causing unnecessary heap allocations and bypassing `UniversalCanvasProvider` and `PlatformDetector`.

## Solution Plan & Implementation
1. **Directory Elimination**:
   - Completely deleted `packages/core/src/effects/overlay-effects/canvas-strategies/` (`base.ts`, `factory.ts`, `index.ts`, `napi-rs.ts`).
   - Completely deleted `packages/effect-engines/src/overlay-effects/canvas-strategies/` (`base.ts`, `factory.ts`, `index.ts`, `napi-rs.ts`).
   - Removed `export * from './canvas-strategies'` from `packages/effect-engines/src/overlay-effects/index.ts`.
2. **Overlay Effect Generators Migration (27 Generators)**:
   - Migrated all 27 effect generators (`audio_spectrum.ts`, `bokeh.ts`, `bubbles.ts`, `camera_ui.ts`, `confetti.ts`, `digital_glitch.ts`, `dust.ts`, `embers.ts`, `film_damage.ts`, `fire.ts`, `floating_hearts.ts`, `fog.ts`, `god_rays.ts`, `grunge_texture.ts`, `leaves.ts`, `lens_flare.ts`, `light_leak.ts`, `lightning.ts`, `matrix_rain.ts`, `rain.ts`, `rain_on_glass.ts`, `sci_fi_hud.ts`, `smoke.ts`, `snow.ts`, `speed_lines.ts`, `starfield.ts`, `vhs.ts`) in `packages/core/src/effects/overlay-effects/generators/`.
   - Replaced `CanvasAdapterFactory.getAdapter('napi-rs')` with direct zero-allocation calls:
     ```ts
     const canvas = UniversalCanvasProvider.createCanvas(this.width, this.height);
     ```
   - In `fire.ts`, utilized `UniversalCanvasProvider.acquireScratchCanvas(this.width, this.height)` and `UniversalCanvasProvider.releaseScratchCanvas(tempCanvas)`.
3. **Internal Export Alignment**:
   - Re-exported isomorphic types in `packages/core/src/media-engine/types.ts` to cleanly decouple submodules.
   - Fixed `packages/core/src/native/index.ts` to import `MediaEngineRegistry` from `@acc/core-isomorphic`.
4. **Test Suite Modernization**:
   - `autogenerated-tests/universal_canvas_switching.test.ts`: Migrated away from `CanvasAdapterFactory` and `NodeCanvasAdapter`, using `bootstrapNode()`, `UniversalCanvasProvider`, and `NapiCanvasAdapter` directly.
   - `autogenerated-tests/particle_simd_vfx.test.ts`: Migrated away from `CanvasAdapterFactory`, testing `UniversalCanvasProvider` directly.
