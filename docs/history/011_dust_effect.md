# [011] Implement Dust Overlay Effect

**1. Context & Problem Statement**:
The user requested the implementation of the `dust` effect from the `Atmosphere` group defined in `.agents/rules/overlay-effects-architecture.md`. The effect needs to support two variants: `ambient_dust` (slow-moving, random spread) and `sunshaft_dust` (denser, diagonal drift simulating a light beam). The particles should also fade in and out to simulate low opacity and twinkling.

**2. Implementation Plan**:
- Create `src/overlay-effects/generators/dust.ts`.
- Implement math for slow 2D drift (speedX and speedY).
- Implement seamless fading: Use a sine wave mapped to the `timeSec` and a `pulseFrequency`. The frequency is calculated as an integer multiple of `(2 * Math.PI) / duration` so the pulsing completes full cycles and perfectly links the last frame to the first frame without snapping.
- Modulo math is used to keep dust particles wrapping seamlessly across the screen edges.
