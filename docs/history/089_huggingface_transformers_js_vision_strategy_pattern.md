# History Log 089: Native In-Process Vision Strategy Pattern via @huggingface/transformers

- **Task**: Integrate `@huggingface/transformers` (Transformers.js v3) for native, in-process AI subject segmentation (SAM) and depth estimation (Depth Anything v2) using the Strategy Design Pattern with 0% external Python dependency.
- **Date**: 2026-10-01
- **Status**: Completed

---

## 1. Context & Problem
Previously, subject segmentation and depth estimation relied on an external Python backend over gRPC or fallback canvas heuristics (GrabCut / perspective luminance gradients). While functional, having Python daemon dependencies added setup friction, and fallback heuristics required manual coordinate tuning to prevent clipping fine details (e.g. dinosaur horn crests, sharp claws, facial features).

## 2. Proposed Architecture & Strategy Pattern
We implemented native, in-process ONNX neural vision pipelines directly in TypeScript/Bun using `@huggingface/transformers` (v3) structured around the **Strategy Design Pattern**:
1. **Segmentation Strategy Contract (`ISegmentationStrategy`)**:
   - `SlimSamStrategy`: Fast ~38MB ONNX model (`Xenova/slimsam-77-uniform`), perfect for instant local rendering.
   - `SamVitBaseStrategy`: High-precision 130MB ONNX model (`Xenova/sam-vit-base`) for ultra-fine anatomical contours.
   - `GrabCutFallbackStrategy`: Zero-network canvas-based fallback ensuring 100% crash-proof defensive execution.
   - `SubjectSegmentationContext`: Singleton manager enabling dynamic runtime strategy switching (`useStrategy`, `setStrategy`) with automatic `try/catch` fallback.
2. **Depth Estimation Strategy Contract (`IDepthEstimationStrategy`)**:
   - `DepthAnythingV2SmallStrategy`: Native ONNX Depth Anything v2 (`onnx-community/depth-anything-v2-small`, 95MB).
   - `HeuristicDepthStrategy`: In-memory luminance/perspective depth gradient fallback.
   - `DepthEstimationContext`: Dynamic depth context with automatic fallback.
3. **Integration & Storage**:
   - Models are cached globally in `path.join(os.homedir(), '.cache', 'huggingface')` per `GLOBAL-STORAGE` rule.
   - Wires directly into `renderDepth3DScene` in `packages/effect-engines/src/depth3d/index.ts`.
   - Zero temporary disk I/O: raw frame buffers stream directly in memory (`Buffer` / `Uint8Array`).

## 5. Walkthrough
Developers or users can switch or inject segmentation and depth models at runtime:
```typescript
import { SubjectSegmentationContext, DepthEstimationContext } from '@acc/effect-engines';

// Switch segmentation model dynamically:
const segContext = SubjectSegmentationContext.getInstance();
segContext.useStrategy('slimsam'); // or 'sam-vit-base', 'grabcut'
const segResult = await segContext.segment(imageBuffer);

// Switch depth estimation model dynamically:
const depthContext = DepthEstimationContext.getInstance();
depthContext.useStrategy('depth-anything-v2-small'); // or 'heuristic'
const depthResult = await depthContext.estimateDepth(imageBuffer);
```
