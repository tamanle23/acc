# 492: IR and Effect-Engines Remediation, WinterTC Conformance & Zero-Alloc Hardening

## Problem
A comprehensive architectural code review of `@acc/ir` and `@acc/effect-engines` under `/code-reviewing`, `/wintertc-web-api`, and `/enterprise-clean-coder` identified critical bugs and anti-patterns:
1. **Catastrophic Hot Loop Allocations**: `PostProcessingShaders.applyChromaticAberration` allocated two new `Uint8Array`s (`lineRed`, `lineBlue`) on every single scanline of every frame (2,160 allocations/frame at 1080p, 129,600 allocations/sec at 60 FPS), triggering severe GC pauses.
2. **Canvas Transform Stack Corruption**: In `IRCanvasCompositor.renderFrame`, `canvasCtx.save()` was called at the root, but `canvasCtx.restore()` was omitted on asynchronous rejections, leaking transform states.
3. **Scratch Canvas Resource Leaks**: Scratch canvases acquired from `UniversalCanvasProvider` in `CanvasParticleOverlayPlugin`, `depth3d/index.ts`, and `vision/utils.ts` were released outside `try...finally` blocks, causing permanent canvas leaks when shaders or sinks threw errors.
4. **Silent Video Decode Failures**: `IRMasterRenderer` silently caught video frame decode errors with empty `catch { }`, causing dropped video frames with zero logging or diagnostics.
5. **Keyframe Curve Outro Incompleteness**: `TemporalKeyframeEvaluator.evaluateNumeric` extracted `outro` from `TemporalCurve` but never evaluated it because `durationSec` was not passed.
6. **Domain Entity Monkey-Patching & Re-instantiation Storm**: `BaseTimeSpacePlugin` mutated `ctx.sequence` with `_timeSpaceMachine` properties, and when `ctx.sequence` was absent, instantiated a brand new `TimeSpaceStateMachine` every frame (60 instantiations/sec).
7. **$O(N^2)$ Kahn's Topological Sort Traversal**: `RelationalDAGCompiler` performed linear `standardItems.find(...)` scans inside Kahn's algorithm queue loops instead of $O(1)$ Map lookups.
8. **WinterTC Node Buffer Coupling**: `AssetMetadataProber` used `Buffer.alloc(44)` instead of universal `Uint8Array` and `DataView`.

## Plan
1. Refactor `PostProcessingShaders.applyChromaticAberration` to use pre-allocated static scanline buffers (`scanlineRed`, `scanlineBlue`).
2. Implement idempotent `restoreRootContext()` in `IRCanvasCompositor.renderFrame` to guarantee exact 1:1 `save()` / `restore()` balance across all synchronous, asynchronous, and error execution paths.
3. Wrap all `acquireScratchCanvas` calls in `CanvasParticleOverlayPlugin`, `renderDepth3DScene`, and `createCutoutRgba` in strict `try...finally` blocks.
4. Add `UniversalLogger.warn` for decoder failures in `IRMasterRenderer.ts`.
5. Support `durationSec` and calculate `outro` easing windows in `TemporalKeyframeEvaluator` and `DeterministicMotionEvaluator`.
6. Replace domain monkey-patching in `BaseTimeSpacePlugin` with an internal `WeakMap`, and defend against undefined `ctx.ctx`.
7. Index sequences by ID in `RelationalDAGCompiler` to ensure true $O(V + E)$ Kahn topological sorting.
8. Modernize `AssetMetadataProber.probeWavHeaderSync` to use `new Uint8Array(44)` and `DataView.getUint32(..., true)`.
9. Add comprehensive test suite in `autogenerated-tests/ir_effect_engines_remediation.test.ts`.

## Changes
- `packages/effect-engines/src/overlay-effects/simulators/PostProcessingShaders.ts`: Added reusable scanline buffers with dynamic growth.
- `packages/ir/src/renderer/shared/IRCanvasCompositor.ts`: Added `restoreRootContext()` guaranteed in `.catch()` and `.finally()`.
- `packages/ir/src/plugins/overlay/CanvasParticleOverlayPlugin.ts`: Wrapped bloom scratch canvas in `try...finally`.
- `packages/effect-engines/src/vision/utils.ts`: Wrapped cutout and mask scratch canvases in `try...finally`.
- `packages/effect-engines/src/depth3d/index.ts`: Pre-resolved 3D renderer outside loop and wrapped scratch canvases in `try...finally`.
- `packages/ir/src/renderer/IRMasterRenderer.ts`: Added explicit `UniversalLogger.warn` on frame decode errors.
- `packages/ir/src/motion/TemporalKeyframeEvaluator.ts`: Added `durationSec` parameter, `outro` window evaluation, and `steady` pulse handling.
- `packages/ir/src/motion/DeterministicMotionEvaluator.ts`: Passed `durationSec` and checked `isTemporalCurve` across all properties.
- `packages/ir/src/plugins/time-space/BaseTimeSpacePlugin.ts`: Integrated `WeakMap` machine cache, added `getActiveMachine()`, guarded `ctx.ctx.save`.
- `packages/core-isomorphic/src/math/time-space/TimeSpaceStateMachine.ts`: Added polymorphic `seek(timeSec, viewport)` overload and `timeSec` alias on snapshot.
- `packages/ir/src/compiler/RelationalDAGCompiler.ts`: Converted Kahn's algorithm lookup from $O(N)$ linear scans to $O(1)$ Map indexing.
- `packages/ir/src/prober/AssetMetadataProber.ts`: Replaced Node `Buffer` with standard `Uint8Array` and `DataView`.
- `autogenerated-tests/ir_effect_engines_remediation.test.ts`: Created new test suite with 7 assertions covering all remediation points.
