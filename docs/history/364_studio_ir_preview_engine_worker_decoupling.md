# History Entry 364: Studio IRPreviewEngine & Sidecar Worker Permanent Decoupling

## Problem
In Apps/Studio, `IRPreviewEngine.worker.ts` was loaded twice whenever the viewport was initialized using `WorkerRenderStrategy`.
The root cause was architectural:
`IRPreviewEngine` constructor contained a hidden ambient fallback:
`this.sidecarCoordinator = options?.sidecarCoordinator ?? PreviewWorkerCoordinator.getInstance();`.
When `preview.worker.ts` (the dedicated viewport rendering worker) instantiated `new IRPreviewEngine(timeline)`, it executed in an isolated worker thread where `PreviewWorkerCoordinator.instance` was `null`. Because `preview.worker.ts` polyfilled `(self as any).window = self`, the environment check passed and spawned a second, nested worker instance whose modifier preflights were completely unobserved.

## Plan
1. Convert `IRPreviewEngine` from runtime value import to type-only import (`import type { PreviewWorkerCoordinator }`).
2. Adopt pure dependency injection: default `sidecarCoordinator` to `null` and `autoPreflight` to `false`.
3. In `MainThreadRenderStrategy`, explicitly inject `PreviewWorkerCoordinator.getInstance()` from the composition root.
4. In `preview.worker.ts`, pass explicit `{ sidecarCoordinator: null, autoPreflight: false }`.
5. Guard `PreviewWorkerCoordinator.getInstance()` against execution in Web Worker realms (`WorkerGlobalScope` / `importScripts`).
6. Create formal unit tests in `autogenerated-tests/studio_preview_engine_worker_decoupling.test.ts`.

## Changes
- `apps/studio/src/renderer/IRPreviewEngine.ts`: Type-only import of `PreviewWorkerCoordinator`; default `sidecarCoordinator` to `null`.
- `apps/studio/src/renderer/PreviewWorkerCoordinator.ts`: Added worker realm guards to `getInstance()` and `initWorker()`.
- `apps/studio/src/renderer/strategies/MainThreadRenderStrategy.ts`: Explicit coordinator injection on the main UI thread.
- `apps/studio/src/renderer/workers/preview.worker.ts`: Explicit `{ sidecarCoordinator: null, autoPreflight: false }`.
- `autogenerated-tests/studio_preview_engine_worker_decoupling.test.ts`: Added 6-assertion unit test suite.
- `apps/studio/doc/implementation_plan_39.md` & `apps/studio/doc/walkthrough_39.md`.
