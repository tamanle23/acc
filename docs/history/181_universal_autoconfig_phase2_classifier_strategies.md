## 1. Context & Motivation
Following Phase 1 (`MediaAssetProberChain`), raw workspace folders are probed into structured `DiscoveredAssetManifest` metadata. However, the system previously had no autonomous mechanism to classify which of the 6 canonical pipelines (Scraper/Summarizer, DB-Templating, Repurposing, Generative Storytelling, Rule-Logic, Ambient Loops) should be scaffolded based on discovered assets.

## 2. Technical Implementation
1. **Classifier Contract & Scaffolding Types (`packages/core/src/autoconfig/types.ts`)**:
   - `IPipelineClassifierStrategy`: Defines `pipelineId`, `canonicalName`, `description`, `calculateConfidence(manifest)`, and `generateArchetypeDefaults(manifest)`.
   - `ArchetypeScaffoldConfig`: Encapsulates pipeline defaults, recommended output modalities, resolution/FPS presets, and timing rules.
   - `PipelineResolutionResult`: Delivers chosen strategy, confidence score, ranked alternatives, and suggested scaffolding.
2. **6 Canonical Classifier Strategies (`packages/core/src/autoconfig/classifiers/`)**:
   - `ScraperSummarizerClassifierStrategy` (Pipeline 1): Matches script/article heavy workspaces without long videos.
   - `DbTemplatingClassifierStrategy` (Pipeline 2): Matches tabular CSV or records-array JSON datasets.
   - `RepurposingClassifierStrategy` (Pipeline 3): Detects raw long-form footage (> 15s) while ignoring previous render outputs (`final.mp4`, `.temp_*.mp4`).
   - `GenerativeStoryClassifierStrategy` (Pipeline 4): Detects sequential image scenes, voiceovers, or legacy `story-config.json` (assigned confidence 1.0).
   - `RuleLogicClassifierStrategy` (Pipeline 5): Matches interactive branching/quiz/decision trees in script bodies.
   - `AmbientLoopClassifierStrategy` (Pipeline 6): Matches long background music stems without voiceovers.
3. **Central Strategy Registry (`packages/core/src/autoconfig/PipelineClassifierRegistry.ts`)**:
   - Singleton registry with all 6 canonical strategies auto-registered.
   - Extensible registration via `register(strategy)`.
   - `resolvePipeline(manifest, explicitPipelineId?)`: Performs heuristic scoring, sorts by confidence descending, supports manual override, and provides a safe fallback to Pipeline 4 when confidence is low.
4. **Data Prober Refinement (`packages/core/src/autoconfig/probers/DataProberHandler.ts`)**:
   - Refined JSON dataset discovery to ignore schema definitions (`*.schema.json`), transformed ASTs, and non-array configuration dictionaries.
