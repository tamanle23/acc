# History Entry 496: IR Plugin Visual Playground Bento Grid Upgrade

## Problem
The previous 3-column split layout for the IR Modifier Playground provided basic testing but lacked the creative depth, visual polish, and advanced look-dev capabilities expected in modern creative suites:
1. No side-by-side or split wipe comparison between raw unprocessed video frames and rendered modifier output.
2. Modifiers could only be tested in isolation; there was no interactive multi-modifier chaining pipeline (Stack Mode) to preview composite passes.
3. Presets were tucked away inside a simple dropdown rather than displayed as interactive, visually stimulating preset cards.
4. No temporal keyframe storyboard strip to inspect modifier progress across $0\%, 25\%, 50\%, 75\%, 100\%$ intervals without manually scrubbing.
5. No visual easing curve graph to inspect and evaluate temporal motion interpolation in real-time.

## Plan
1. **Engine Extensions (`usePlaygroundEngine.ts`)**:
   - Add zero-alloc A/B comparison split wipe using `ctx.save()`, `ctx.beginPath()`, `ctx.rect(splitX, 0, width - splitX, height)`, `ctx.clip()`, and `ctx.restore()`.
   - Add multi-modifier chaining pipeline (`modifierStack`, `addModifierToStack`, `toggleModifierEnabled`, `reorderModifier`, `removeModifierFromStack`, `setStackItemParam`).
   - Add `renderKeyframeToCanvas(canvas, frame)` for direct mini-canvas sampling without base64 string allocations.
   - Batch sequence timeline commitment for modifier stacks via `IRStateManager`.
2. **Modular Bento Tiles (`apps/studio/src/components/debugger/playground/bento/`)**:
   - `BentoHeroViewport.tsx`: High-DPI canvas, interactive pointer-drag split slider, floating HUD telemetry, aspect ratio switcher, full-width transport bar.
   - `BentoPresetShowcase.tsx`: Visual preset cards with color gradient badges, descriptions, fast search, and 1-click loading.
   - `BentoModifierStack.tsx`: Layer manager with eye bypass toggles, layer reordering, parameter editing, and "+ Add Effect" picker.
   - `BentoStoryboardFilmstrip.tsx`: 5-frame miniature canvas thumbnail strip ($160\times 90$) with click-to-seek and snapshot PNG export.
   - `BentoCurveVisualizer.tsx`: Interactive cubic bezier easing graph with real-time rolling playhead ball synchronized to RAF time.
   - `BentoCatalogAndJson.tsx`: Filterable 50+ plugin directory paired with live Shiki JSON syntax highlighting and timeline bridge.
3. **Responsive Bento Grid Container & Modal Integration**:
   - `PlaygroundBentoLayout.tsx`: 12-column responsive Bento Grid assembling all 6 tiles with Liquid Glass UI styling tokens.
   - Wire `IrPluginPlaygroundModal.tsx` to set `bento` as default view mode with toolbar toggle button and `0`/`b` keyboard shortcuts.
4. **Automated Testing & Build Verification**:
   - Create `autogenerated-tests/ir_playground_bento_features.test.ts`.
   - Build `@acc/studio` with Vite and execute tests with Bun.

## Walkthrough
1. Press `Ctrl+Shift+P` (or click "Playground" in Studio titlebar) to open the modal.
2. The modal launches directly into the **Bento Grid View**:
   - **Hero Viewport** (top left): 60 FPS animated preview with transport scrubber, speed chips, aspect ratio switcher, and telemetry HUD.
   - **A/B Compare**: Click "A/B Compare" and drag the cyan divider handle across the canvas to compare raw background plates against processed modifier output with zero memory allocations.
   - **Modifier Stack** (top right): Add multiple plugins sequentially (e.g. `transform` $\to$ `overlay/canvas_particles` $\to$ `timeline/photometric_bloom`). Click the eye icon to bypass individual layers or reorder them.
   - **Presets Showcase** (middle right): Click visual preset cards to apply curated looks.
   - **Precision Inspector** (bottom left): Fine-tune parameters with sliders, switches, color pickers, and accordion groups.
   - **Motion Curve Visualizer** (bottom center): Switch easing curves (`easeOutCubic`, `easeInOutBack`, `equal_power`) and observe the rolling playhead ball track the timeline in real-time.
   - **Catalog & JSON** (bottom right): Search 50+ plugins, view live Shiki VideoIR JSON, or commit single/stacked modifiers to the active sequence.
   - **Storyboard Filmstrip** (bottom 12 cols): 5 mini-canvases capture keyframes across $0\% \to 100\%$. Click any thumbnail to jump the playhead, or click "Snapshot PNG" to download.
