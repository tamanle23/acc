# 355: Fix useShuttleEngine Indefinite Playback Boundary Condition

## Problem
In `apps/studio/src/lib/shuttle/useShuttleEngine.ts`, when toggling play on the timeline, playback ran indefinitely upon reaching the end instead of stopping.

## Root Cause
- `DeterministicTimelineClock.tick(...)` deterministically clamps `targetFrame` to `Math.min(this.totalFrames - 1, targetFrame)`.
- `useShuttleEngine` checked `if (targetFrame >= total)` where `total = totalFramesRef.current`. Because `targetFrame` is clamped to `total - 1`, the condition was never true.
- `requestAnimationFrame(tick)` stayed scheduled indefinitely, and forward play restart checks (`currentFrameRef.current >= totalFramesRef.current`) failed to wrap to 0.

## Plan & Changes
1. Update `apps/studio/src/lib/shuttle/useShuttleEngine.ts`:
   - Set end-of-timeline condition to `targetFrame >= endFrame && currentSpeed > 0` with `endFrame = Math.max(0, total - 1)`.
   - Update forward restart condition in `setSpeed` to wrap to frame 0 when `currentFrameRef.current >= Math.max(0, totalFramesRef.current - 1)`.
2. Document in `apps/studio/doc/implementation_plan_36.md` and `apps/studio/doc/walkthrough_36.md`.
3. Verify test suite and studio production build.
