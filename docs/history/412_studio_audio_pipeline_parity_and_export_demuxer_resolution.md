# 412 — Studio Audio Pipeline Parity & Export Demuxer Resolution

## 1. Problem
1. **No Audio in Exported MP4 (`export.worker.ts`)**:
   - `export.worker.ts` executes in a Web Worker environment where `OfflineAudioContext` is absent or restricted.
   - `MediabunnyClientStrategy.createAudioDecoder()` attempts to use `OfflineAudioContext` for audio files, fails/skips, and its `UrlSource` fallback without protocol resolution returns `null`.
   - `UniversalAudioMixer.decodeAsset()` receives `null` and yields an all-zero or empty buffer (`totalSamples: 0`).
   - `MediabunnyClientSink.finalize(audioResult)` checks `if (audioResult.totalSamples > 0)`. Because it is 0, zero audio samples are appended to `AudioSampleSource`, creating an MP4 with an empty/silent audio track.
   - In `ClientExportOrchestrator.ts`, the in-process fallback path instantiates `new IRMasterRenderer(irState.timeline, 42)` without the 5th strategy argument, disabling media engine capabilities.

2. **Inconsistent Preview Audio Between Playings**:
   - **`AudioAssetCache` Async Decode Race**: On initial playback, `getAudioChannels()` returns `null` while initiating a background fetch/decode. `UniversalAudioMixer.sampleClipAudio()` immediately falls back to procedural synth tones (beeps/rain noise). On subsequent play, the real PCM is ready and plays the actual asset.
   - **Clip-Local Time vs. Timeline Global Time in `sampleClipAudio`**: `UniversalAudioMixer.sampleClipAudio` passes global timeline time `sliceStart` (e.g. 5.0s) into `DecodedPcmSource.sample()` instead of the clip-relative offset (`sliceStart - clip.startTimeSec`). As a result, clips starting after `t = 0` sample beyond the source buffer length and output complete silence.
   - **Dual Playback Transport Conflict**: `WebAudioEngine` concurrently pushed chunks to `streamWorklet` while scheduling `AudioBufferSourceNode` instances, risking double audio or click/gap artifacts during 1000ms refill intervals.

## 2. Plan
1. **Fix Clip-Relative Time & Clamping in `UniversalAudioMixer` & `DecodedPcmSource`**:
   - Compute clip-relative offset `Math.max(0, sliceStart - clip.startTimeSec)` in `UniversalAudioMixer.sampleClipAudio`.
   - In `DecodedPcmSource.sample()`, sample from `clipRelativeOffsetSec + trimStartSec` and clamp to asset end (output 0.0 silence past asset duration).
   - In `UniversalAudioMixer.sampleClipAudio()`, output silence for unready asset clips unless an explicit `sfx/procedural` modifier is attached.
2. **Implement Mediabunny Demuxer Audio Decoder Fallback**:
   - In `MediabunnyClientStrategy.createAudioDecoder()`, when `OfflineAudioContext` is unavailable (e.g. in Web Workers), decode audio `ArrayBuffer` directly via Mediabunny `Input({ formats: ALL_FORMATS, source: new BlobSource(...) })` + `AudioSampleSink(audioTrack)`.
3. **Inject Strategy in `ClientExportOrchestrator` Fallback**:
   - Pass `MediaEngineRegistry.get('mediabunny-client')` as 5th argument to `IRMasterRenderer`.
4. **Harden `WebAudioEngine` Transport**:
   - Unify playback strictly through `AudioBufferSourceNode` lookahead scheduling; prevent race conditions with uninitialized worklet.
5. **Formal Automated Verification**:
   - Write comprehensive unit tests in `autogenerated-tests/audio_pipeline_export_parity.test.ts`.
   - Verify with `bun test`.
   - Build studio app with `pnpm --filter studio exec vite build`.
