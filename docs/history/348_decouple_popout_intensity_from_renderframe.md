# 348: Decouple popOutIntensity from renderFrame to Sequence Modifier Dynamic Resolution

## Problem
`popOutIntensity` was historically passed as a top-level parameter to `renderFrame` and merged into modifier params as `{ ...mod.params, popOutIntensity }` in `IRCanvasCompositor`. This caused two critical architectural defects:
1. It overwrote each sequence modifier's own configured `mod.params.popOutIntensity` with a global default or caller-provided fallback (e.g. `IRMasterRenderer` didn't pass it, causing it to fall back to `1.0` during export and stomping on custom clip intensities).
2. `Preview.tsx` and `App.tsx` were forced to execute brittle timeline loops scanning all tracks and sequences looking for the last depth modifier just to supply a global `popOutIntensity` argument on every frame tick.

## Plan
1. In `IRCanvasCompositor.ts`, merge parameters as `{ ...(popOutIntensity !== undefined ? { popOutIntensity } : {}), ...mod.params }` so that sequence modifiers dynamically resolve their own `mod.params.popOutIntensity` as the primary source of truth.
2. In `IRPreviewEngine.ts` and `PreviewWorkerBridge.ts`, make `popOutIntensity` strictly optional without coercing a forced default `1.0`.
3. In `preview.worker.ts`, pass `data.popOutIntensity` directly without overwriting with `?? 1.0`.
4. In `Preview.tsx` and `App.tsx`, remove the brittle timeline loops and let each sequence modifier dynamically resolve its own parameters.
5. Verify with automated unit and parity tests.

## Changes
- `packages/ir/src/renderer/shared/IRCanvasCompositor.ts`: Inverted parameter precedence so `mod.params` takes priority over global option.
- `apps/studio/src/renderer/IRPreviewEngine.ts`: Made `popOutIntensity` optional in `renderFrame`.
- `apps/studio/src/lib/worker/PreviewWorkerBridge.ts`: Made `popOutIntensity` optional.
- `apps/studio/src/lib/worker/preview.worker.ts`: Forwarded `data.popOutIntensity` directly.
- `apps/studio/src/components/Preview.tsx`: Removed brute-force timeline modifier scanning loop and global parameter passing.
- `apps/studio/src/App.tsx`: Removed brute-force timeline modifier scanning loop from export loop.
- `autogenerated-tests/depth3d_inference_resolution.test.ts`: Added test asserting each sequence modifier's `popOutIntensity` is preserved without global overwrite.
