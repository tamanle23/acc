# 464. Fix Preview Playback Lag & Optimize Sequential Video Reader

## Problem
Following the elimination of black frame flashing, preview playback in `@acc/studio` exhibited noticeable lag and stuttering across different timeline frame rates. A rigorous code review identified two critical bottlenecks:
1. **False Texture Blit Blocking on Non-Video Timeline Sequences**:
   - In `preview.worker.ts`, the front-buffer blit guard `hasMissingActiveTexture` checked all sequences returned by `engine.seek(frame).activeSequences`.
   - Any non-video sequence (audio tracks, background music, sound effects, subtitles, overlay graphics) has an `assetId` but no corresponding entry in `videoReaders` or `textureCache`.
   - Consequently, `!textureCache.has(assetId)` evaluated to `true` on almost every frame when an audio track was present, blocking `ctx.drawImage(backCanvas!, 0, 0)`. The onscreen canvas was skipped or updated sporadically, appearing as severe stutter and dropped frames.
2. **Head-Of-Line Blocking & Double-Decode Queue Latency in `SequentialVideoReader`**:
   - `SequentialVideoReader` relied on an unbounded FIFO promise queue (`decodeQueue`) for all `canvasSink.getCanvas()` calls.
   - When the playhead advanced or skipped a frame (e.g. 60 Hz RAF loop, 24/25/50 FPS timeline cadence, or jump seeks), `paintSlot` was queued behind the in-flight background `preloadNext` promise.
   - The reader was forced to wait for an unneeded frame to decode before starting the target frame's decode, doubling decode latency (25ms + 25ms = 50ms) and collapsing playback below 20 FPS.
   - Furthermore, `this.preloadedFrame` was not cleared upon swapping, allowing stale state to persist across ticks.

## Plan
1. **Filter Active Asset Inspection to Registered Video Readers Only**:
   - In `preview.worker.ts`, populate `activeVideoAssetIds` strictly from active sequences where `seq.assetId && videoReaders.has(seq.assetId)`.
   - Ensure audio tracks, overlay shapes, captions, and non-video assets never trigger `hasMissingActiveTexture`.
   - Pass `activeVideoAssetIds` to `decoderPool.updatePriorities` for hardware decoder prioritization.
2. **Eliminate Head-of-Line Blocking in `SequentialVideoReader`**:
   - Replace unbounded FIFO `decodeQueue` chaining with a clean single-flight re-entrant mutex lock (`acquireDecodeLock`).
   - Coordinate directly through `this.preloadPromise`:
     - If `preloadedFrame === frame`: swap immediately (0ms hit), reset `preloadedFrame = -1`, launch `preloadNext(frame + 1, fps)`, and return active canvas.
     - If `preloadingFrame === frame`: await `preloadPromise`, swap immediately on success, and launch next preload.
     - If `preloadPromise` is in flight for a different frame: await `preloadPromise` to ensure `CanvasSink` is idle, then decode the target frame directly without queue lag.
     - Maintain pristine hold-on-miss guarantee: return active slot on decode delays or dropped frames.
3. **Automate Comprehensive Verification**:
   - Expand `autogenerated-tests/studio_preview_playback_cadence.test.ts` to test frame skips and variable frame rates (24, 30, 60 FPS).
   - Verify `autogenerated-tests/studio_offscreen_worker_parity.test.ts` passes with strict serialization.
   - Verify `@acc/studio` production bundle builds cleanly.

## Changes

### `apps/studio/src/renderer/workers/preview.worker.ts`
- Restricted `activeVideoAssetIds` to sequences matching `seq.assetId && videoReaders.has(seq.assetId)`.
- Updated `hasMissingActiveTexture` check to evaluate only `activeVideoAssetIds`, allowing unhindered 60 FPS front-buffer blitting for timelines with audio or overlay tracks.
- Aligned `decoderPool.updatePriorities` to target `activeVideoAssetIds`.

### `apps/studio/src/renderer/workers/SequentialVideoReader.ts`
- Replaced FIFO `decodeQueue` with an async single-flight mutex `acquireDecodeLock()`.
- Added immediate 0ms cache-hit return when `preloadedFrame === frame` and reset `preloadedFrame = -1` on swap.
- Implemented direct awaiting of `preloadPromise` when `preloadingFrame === frame`, avoiding duplicate decodes.
- Added graceful clearing of in-flight preloads when playhead skips or seeks.

### `autogenerated-tests/studio_preview_playback_cadence.test.ts`
- Added test verifying seamless frame skips without queue pileup or stalls.
- Added test validating 0ms slot swaps on preloaded sequential frames across 24, 30, and 60 FPS.

### `autogenerated-tests/studio_playback_transport.test.ts`
- Replaced direct JSX import with source inspection to maintain SolidJS 1.9 compatibility in Bun test runner.
