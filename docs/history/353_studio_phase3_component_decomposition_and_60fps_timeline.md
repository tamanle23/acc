# 353: Studio Phase 3 — Component Decomposition & 60 FPS Timeline Virtualization

## 1. Problem Statement
1. **Monolithic God Components**:
   - `apps/studio/src/App.tsx` (692 lines) coupled top-level workspace layout, keyboard shortcuts, `@dnd-kit` drag-and-drop ingestion (with linked A/V splitting), and a synchronous frame-by-frame MP4 export loop (`MediabunnyClientSink` + `UniversalAudioMixer`) that blocked the main thread during rendering.
   - `apps/studio/src/components/LeftSidebar.tsx` (1,190 lines) bundled SVG vector shape specimen thumbnails, typography preview renderers, draggable preset/asset cards, drag overlay previews, activity rail navigation, and virtualized drawer lists in a single file.
   - `apps/studio/src/components/inspector/ModifierControlStrategies.tsx` (1,130 lines) housed all 13 UI control strategy implementations in a single file.
2. **60Hz Timeline Drag Re-Render Cascade**:
   - In `TimelineDom.tsx`, `activeDragState` was passed as an object prop directly to every `ClipItem`. Whenever a user dragged or trimmed a single clip at 60 FPS, `activeDragState` mutated on every animation frame, forcing **every stationary clip across every track** to re-render unnecessarily.

## 2. Plan
1. **Decompose `App.tsx` (< 300 lines)**:
   - Extract `ClientExportOrchestrator` (`apps/studio/src/lib/export/ClientExportOrchestrator.ts`) with cooperative main-thread yielding (`yieldToMainThread()` via `scheduler.yield` / `requestAnimationFrame`) and `AbortSignal` cancellation so the UI and Cancel Export button remain responsive at 60 FPS during MP4 encoding.
   - Extract `useWorkspaceDnd` (`apps/studio/src/lib/dnd/useWorkspaceDnd.ts`) encapsulating `@dnd-kit` sensors and canvas/timeline drop handlers.
   - Extract `ExportProgressModal` (`apps/studio/src/components/ExportProgressModal.tsx`).
2. **60 FPS Timeline Virtualization & `ClipItem` Memoization**:
   - Wrap `ClipItem` in `React.memo`.
   - Pass scoped primitive drag props (`isBeingDragged`, `isPairedDrag`, `dragType`, `trimHandle`, `trimDeltaFrames`, `isAnyDragActive`) from `TimelineDom.tsx` to `ClipItem.tsx`, and stabilize `handleClipClick`, `getTrackBadgeStyle`, and `handleClipHover` with `useCallback`.
3. **Modularize `LeftSidebar.tsx` (< 420 lines)**:
   - Extract `PresetThumbnails.tsx`, `SidebarCards.tsx`, and `SidebarActivityRail.tsx` into `apps/studio/src/components/sidebar/` and re-export all public symbols from `LeftSidebar.tsx`.
4. **Modularize `ModifierControlStrategies.tsx` (< 300 lines)**:
   - Extract `PrimitiveControlStrategies.tsx`, `RegionsArrayControlStrategy.tsx`, and `CompositeGroupControlStrategies.tsx` into `apps/studio/src/components/inspector/strategies/` and re-export all strategies from `ModifierControlStrategies.tsx`.

## 5. Walkthrough
- When a user drags or trims a sequence on the timeline, `TimelineDom` computes primitive boolean/number props for each `ClipItem`. Stationary clips receive identical primitive values and stable `useCallback` handlers, allowing `React.memo(ClipItem)` to skip re-rendering all stationary clips at 60Hz.
- When exporting to MP4, `ClientExportOrchestrator.exportToMp4` yields to the browser main thread every 3 frames (`yieldToMainThread()`) and checks `AbortSignal.aborted`, ensuring smooth progress bar updates and instantaneous cancellation via `AbortController`.
