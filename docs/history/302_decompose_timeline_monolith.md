# Task 302: Decompose Timeline Monolith into Modular Timeline Components

## Context & Objectives
`apps/studio/src/components/Timeline.tsx` was a monolith component (~1,561 lines) responsible for transport tooling, playhead controls, scrubbing, track headers, clip rendering, drag-and-drop state, snapping lines, razor hover guides, floating timecode HUD, audio meter, and canvas fallback.

In accordance with `/ui-ux-design-system`, `/frontend-app-architect`, and single-responsibility principles, this task decomposed the monolith into focused, reusable components housed under `apps/studio/src/components/timeline/`.

## Architecture & Modular Breakdown

The following modular components were extracted and created:

1. **`TrimHandle.tsx`** (`TrimHandle`, `TrimHandleProps`):
   - Encapsulates `@dnd-kit/core` `useDraggable` logic for clip trimming (`start` and `end` handles).
   - Prevents click bubbling to parent clip.
   - Provides resize cursor and accessible snap-enabled tooltip.

2. **`DroppableTrackLane.tsx`** (`DroppableTrackLane`, `DroppableTrackLaneProps`):
   - Implements `@dnd-kit/core` `useDroppable` track target container.
   - Handles drop-hover highlight styling and track locked state styling.

3. **`TimelineClipItem.tsx`** (`TimelineClipItem`, `TimelineClipItemProps`):
   - Full clip rendering component with 4-tier adaptive Level of Detail (LOD: Micro, Compact, Standard, Expanded).
   - High-contrast archetype indicators (Video, Audio, Subtitle/Text, VFX).
   - In-line script/subtitle cue snippet text previews.
   - Filmstrip thumbnail and audio waveform canvas backgrounds.
   - Transition block overlay integration.
   - Direct interactive audio-video linked toggle button (`Link2`/`Unlink`).

4. **`TrackHeaderCard.tsx`** (`TrackHeaderCard`, `TrackHeaderCardProps`):
   - Sticky track header card with track type and identifier.
   - Track reordering controls (Up / Down) connected to `IRStateManager.reorderTrack`.
   - Independent track Lock/Unlock toggle.
   - Independent track Mute/Unmute toggle.

5. **`TimelineToolbar.tsx`** (`TimelineToolbar`, `TimelineToolbarProps`):
   - Complete top transport and utility bar.
   - Tool selector (Select `V`, Razor `C`, Hand `H`).
   - Transport buttons (Rewind, Shuttle Reverse `J`, Play/Pause `K`/`Space`, Shuttle Forward `L`).
   - Magnetic Snapping (`Snap`) and Ripple Editing (`Ripple`) mode toggles.
   - DOM vs Canvas engine strategy switch.
   - Zoom out, slider, zoom in, and fit buttons.
   - Master audio VU meter and SMPTE / Frame timecode readouts.

6. **`TimelineOverlayHUD.tsx`** (`TimelineOverlayHUD`, `TimelineOverlayHUDProps`):
   - Magnetic snapping vertical needle (Cyan for grid/playhead, Emerald for abutting clip seams).
   - Razor tool cut guide with frame indicator badge.
   - Floating timecode delta HUD during clip dragging and trimming.

7. **`apps/studio/src/components/timeline/index.ts`**:
   - Clean export barrel file for timeline components.

8. **`apps/studio/src/components/Timeline.tsx`**:
   - Refactored orchestrator component composing `TimelineToolbar`, `TimecodeRuler`, `TimelineOverlayHUD`, `TrackHeaderCard`, `DroppableTrackLane`, and `TimelineClipItem`.
   - Reduced file size from ~1,561 lines to ~915 lines with zero regression to virtualization, web worker sync, or dragging/trimming state machines.
