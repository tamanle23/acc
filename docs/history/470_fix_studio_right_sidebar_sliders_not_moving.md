# 470. Fix Studio RightSidebar Sliders Not Moving

## Problem
In `apps/studio/src/components/RightSidebar.tsx` and across child inspectors (`DynamicModifierInspector.tsx`, `SequenceInspector.tsx`, `TrackInspector.tsx`, `ParameterControls.tsx`), numeric sliders did not move when users clicked or dragged them.

### Root Cause
1. **Kobalte Synchronous Memo Inversion**:
   In `@kobalte/core/slider`'s `SliderPrimitive.Root`, `onSlideMove` invoked `state.setThumbPercent` (which dispatches `onChange` with the new value), and immediately on the subsequent line executed `local.onChange?.(state.values())`. Because `state.values()` is backed by an internal `createMemo` tracking `props.value`, and SolidJS signals do not flush synchronously in the middle of a running event listener call stack, `state.values()` returned the stale pre-drag value. Kobalte's second call immediately reverted the property, snapping the slider thumb back to its starting position and preventing visual movement.
2. **Referential Array Wrapping**:
   In `PrimitiveControlStrategies.tsx` and `ParameterControls.tsx`, passing `value={[numericVal()]}` created a new array reference on every render, triggering internal Kobalte state resets.

## Plan
1. **Replace Kobalte Slider Primitive**:
   - Implement an enterprise-grade, native SolidJS `Slider` component in `apps/studio/src/components/ui/slider.tsx`.
   - Implement dual-layer pointer tracking via `setPointerCapture` and fallback window event listeners.
   - Implement optimistic `dragValue` visual state to ensure thumb tracks the cursor instantaneously at 60/120fps without snapping back.
   - Implement precision step arithmetic (`clampAndStep`) eliminating floating-point rounding errors.
   - Add keyboard accessibility (`ArrowRight`, `ArrowLeft`, `PageUp`, `PageDown`, `Home`, `End`) and ARIA slider semantics (`role="slider"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`).
2. **Update Inspector Control Strategies**:
   - Update `PrimitiveControlStrategies.tsx` (`NumberControlStrategy`) to provide `defaultValue={defaultVal()}` and pass `value={numericVal()}` directly.
   - Update `ParameterControls.tsx` (`ParameterSlider`) to provide `defaultValue={props.defaultValue}` and pass `value={props.value}` directly.
3. **Formal Verification**:
   - Write comprehensive test suite in `autogenerated-tests/studio_slider_properties_interaction.test.ts`.
   - Verify zero regressions with existing studio tests.
   - Execute production build with `pnpm --filter @acc/studio build`.
