# History Record 401: Standalone Generator Invariants, Universal Transform Whitelist & Declarative Plugin Manifest

## 1. Problem
As the modifier ecosystem expanded across timeline, track, and sequence scopes, several architectural ambiguities and schema integrity gaps arose:
1. **Modifier Over-Application on Procedural Sequences**: Sequences hosting standalone procedural generators (`targetScope === 'standalone'`, such as `generator/radial_burst`) were permitting the attachment of footage-bound VFX modifiers (`vfx/depth3d`, `vfx/camera_3d`, `vfx/color_grading`, `vfx/partial`). Because standalone procedural clips do not decode raster video frames or generate depth maps, attaching these effects resulted in runtime execution failures and nonsensical composition states.
2. **Multiple Standalone Generator Ambiguity**: Schema validation lacked an invariant preventing multiple standalone source providers on a single sequence, violating the single-source principle.
3. **Absence of Declarative Plugin Capabilities (SSOT)**: Plugin capabilities (universal applicability, supported track types, instance policies) were dispersed or hardcoded across inspector UI dropdown filters instead of being declared on the plugins themselves.
4. **Compositor Matrix Order**: The 2D canvas context transformation matrix in `IRCanvasCompositor` must be positioned and transformed before drawing clip contents, ensuring that universal spatial modifiers (`transform`, `motion/gsap`) seamlessly translate, rotate, and scale procedural visual generators.

## 2. Plan
1. **Core Types & Dynamic Registry Invariants**:
   - Add `isUniversal?: boolean`, `supportedTrackTypes?: readonly TrackType[]`, and `instancePolicy?: 'single' | 'multiple'` to `ModifierPlugin`.
   - Export `STANDALONE_SEQUENCE_ALLOWED_MODIFIERS: ReadonlySet<string>` in `ModifierPluginRegistry`.
   - Implement `ModifierPluginRegistry.getCapabilityMatrix()` to compile and expose the capability matrix from the plugins themselves.
   - Refactor `ModifierPluginRegistry.isModifierAllowedOnEntity` to enforce:
     - Standalone single-source invariant: Reject a second standalone generator if one already exists.
     - Universal modifier whitelist: On standalone sequences, allow only universal modifiers (`transform`, `motion/gsap`, `overlay/blend_mode`, `transition/*`).
2. **Schema Validator Hardening**:
   - Update `VideoIRSchemaValidator.validateSequence` to enforce `count(targetScope === 'standalone') <= 1`.
   - Pass `hasStandaloneGenerator` and `existingModifierTypes` into `isModifierAllowedOnEntity`.
3. **Declarative Plugin Manifests**:
   - Update `TransformModifierPlugin`, `GSAPMotionPlugin`, `BlendModePlugin`, `UniversalTransitionPlugin`, and `TransitionCrossfadePlugin` to declare `isUniversal: true`, `supportedTrackTypes`, and `instancePolicy`.
4. **Compositor Transformation Matrix Ordering**:
   - In `IRCanvasCompositor.processClipSpaceModifiers`, ensure spatial `transform` and `motion/gsap` apply to the canvas context matrix before base assets or procedural generators are drawn.
5. **Studio UI & State Safeguards**:
   - Update `RightSidebar.tsx` to pass sequence standalone state into `isModifierAllowedOnEntity`.
   - Add `Standalone Generator` Liquid Glass badge in `SequenceInspector.tsx`.
   - Add defensive deduplication in `irState.ts` `migrateLegacyModifiers`.
6. **Formal Test Authoring**:
   - Author `autogenerated-tests/modifier_plugin_contract_audit.test.ts` and `autogenerated-tests/standalone_generator_hierarchy_and_whitelist.test.ts`.

## 3. Changes
- **`packages/ir/src/types/modifiers.ts`**: Added `EntityModifierContext` and `EntityModifierCheckResult` supporting `hasStandaloneGenerator` and `existingModifierTypes`.
- **`packages/ir/src/plugins/ModifierPluginRegistry.ts`**: Added `isUniversal`, `supportedTrackTypes`, and `instancePolicy` to `ModifierPlugin`; added `STANDALONE_SEQUENCE_ALLOWED_MODIFIERS`; implemented `getCapabilityMatrix()`; enforced standalone invariants in `isModifierAllowedOnEntity`.
- **`packages/ir/src/schema/VideoIRSchemaValidator.ts`**: Enforced single standalone generator per sequence and verified modifier entity constraints with standalone context.
- **`packages/ir/src/plugins/transform/TransformModifierPlugin.ts`**: Declared `isUniversal = true`, `supportedTrackTypes = ['video', 'timed_text']`, `instancePolicy = 'single'`.
- **`packages/ir/src/plugins/motion/GSAPMotionPlugin.ts`**: Declared `isUniversal = true`, `supportedTrackTypes = ['video', 'timed_text']`, `instancePolicy = 'single'`.
- **`packages/ir/src/plugins/overlay/BlendModePlugin.ts`**: Declared `isUniversal = true`, `supportedTrackTypes = ['video']`, `instancePolicy = 'single'`.
- **`packages/ir/src/plugins/editorial/UniversalTransitionPlugin.ts` & `TransitionCrossfadePlugin.ts`**: Declared `isUniversal = true`, `supportedTrackTypes = ['video', 'audio']`, `instancePolicy = 'multiple'`.
- **`packages/ir/src/renderer/shared/IRCanvasCompositor.ts`**: Ensured clip-space spatial modifiers are applied prior to drawing contents.
- **`apps/studio/src/components/RightSidebar.tsx`**: Dynamically passed `hasStandaloneGenerator` and `existingModifierTypes` to filter dropdown modifier choices.
- **`apps/studio/src/components/inspector/SequenceInspector.tsx`**: Rendered Liquid Glass badge indicator for standalone generator sequences.
- **`apps/studio/src/lib/ir/irState.ts`**: Added defensive standalone generator deduplication in `migrateLegacyModifiers`.
- **`autogenerated-tests/modifier_plugin_contract_audit.test.ts`**: Contract audit test for all modifier plugins and dynamic capability matrix.
- **`autogenerated-tests/standalone_generator_hierarchy_and_whitelist.test.ts`**: Unit test suite for schema rejection, whitelist enforcement, dynamic entity check, and defensive migration.

## 4. Verification
1. **Plugin Contract Completeness**: All registered plugins in `ModifierPluginRegistry` declare valid targets, and `getCapabilityMatrix()` successfully compiles all entries.
2. **Schema Invariant Enforcement**:
   - Single standalone generator validation passes for valid standalone sequences.
   - Rejecting duplicate standalone generators on the same sequence with diagnostic error.
   - Prohibiting footage VFX (`vfx/depth3d`, `vfx/partial`, etc.) on standalone sequences.
   - Allowing universal modifiers (`transform`, `motion/gsap`, `overlay/blend_mode`, `transition/*`) on standalone sequences.
3. **Inspector & State Parity**:
   - Studio inspector filters out non-whitelisted modifiers on standalone clips.
   - `migrateLegacyModifiers` strips secondary standalone generators from legacy project states.
