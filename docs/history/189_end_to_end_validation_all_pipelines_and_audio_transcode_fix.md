## 1. Overview & Context
Following task [`188`](188_fix_pipeline_2_unplayable_audio_and_video.md) which resolved video DTS/PTS strictly monotonic pacing in `FFIVideoEncoder` and audio synthesis in `AudioExporter` for Pipeline 2 (`p2`), a comprehensive end-to-end execution of all remaining pipelines (`p1`, `p3`, `p4`, `p5`, `p6`) was conducted to guarantee that all generated media files play seamlessly across standard video/audio decoders without errors.

## 2. Issues Encountered & Root Cause

### Pipeline 4 (`p4` - Generative Storytelling) MP4 Decoding Error
When executing `bun run cli.ts run story -c ./samples/04-generative-storytelling -o ./output/p4`:
- Output file `04_generative_storytelling_1.mp4` failed to decode with:
  `[mov,mp4,m4a,3gp,3g2,mj2] type:'stsd' parent:'stbl' sz: 0 8 52 -> invalid size 0 in stsd`.
- **Root Cause**:
  `StoryOrchestratedRenderStage` utilizes `IRChunkWorkerPool` for parallel temporal slice rendering. `IRChunkWorkerPool` stitches video chunks using `FFIChunkConcatMuxer.concatenate()` and then calls `FFAudioMuxer.mux(tempVideoOnlyPath, masterAudioWavPath, outPath)`.
  `FFAudioMuxer.mux()` previously copied codec parameters directly via `avcodec_parameters_copy`. Because `masterAudioWavPath` is raw uncompressed PCM (`pcm_s16le`, codec id 65536) generated by `DecoupledAudioMixer.exportToWav()`, the MP4 muxer rejected raw PCM audio (`Tag [1][0][0][0] incompatible with output codec id '65536'`), causing `avformat_write_header` to fail and leaving the MP4 header `stsd` atom corrupted (size 0).

## 3. Implementation Details

### Pure FFI In-Memory Audio Transcoder in `FFAudioMuxer.ts`
- Detected when the target container is an MP4/MOV format (`.mp4`, `.mov`, `.m4v`) and the input audio is uncompressed PCM (`inCodecId >= 65536 && inCodecId < 69632`).
- Integrated an in-memory FFI decoding and AAC encoding pipeline:
  1. Opens audio decoder for `inCodecId` via `avcodec_find_decoder` and `avcodec_open2`.
  2. Allocates AAC stereo encoder (`avcodec_find_encoder_by_name("aac")`, 48000 Hz, stereo FLTP, 192 kbps, `+global_header`).
  3. Resamples audio frames on the fly using `swresample` (`swr_alloc_set_opts2`, `swr_convert`) to 48000 Hz Float Stereo.
  4. Encodes planar float frames to AAC packets (`avcodec_send_frame`, `avcodec_receive_packet`), setting stream index to 1 and writing interleaved frames with zero memory leaks.
