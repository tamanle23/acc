# 234: NLE Clip Drag Architecture & Timeline Canvas Elimination

## Problem Statement
In previous iterations, clip dragging inside the Studio timeline exhibited two severe usability and architectural defects:
1. **Pointer Desynchronization**: Clip dragging did not maintain pointer grab offset or track alignment. In-track dragging was fighting with TanStack Virtualizer dynamic DOM unmounting, causing `@dnd-kit` collision detection to return `null` or miscalculate coordinates during rapid horizontal or vertical track crossing.
2. **Dual-Mode Maintenance Overhead**: Maintaining parallel DOM (`TimelineDom.tsx`) and Canvas (`TimelineCanvas.tsx`) renderers created architectural fragmentation, dead code paths, and state synchronization friction.
3. **Jittery Magnetic Snapping**: Snapping continuously to arbitrary 1-second grid intervals interfered with smooth editing workflows, lacking the magnetic threshold and hysteresis standard in NLEs (DaVinci Resolve, Premiere Pro).

## Proposed Architecture & Plan
1. **Total Elimination of `TimelineCanvas`**:
   - Delete `apps/studio/src/components/timeline/TimelineCanvas.tsx`.
   - Remove `timelineMode` toggles from `Toolbar.tsx`, `Timeline.tsx`, `OverlayHUD.tsx`, `RazorGuideline.tsx`, and `TimecodeBadge.tsx`. Standardize exclusively on `TimelineDom`.
2. **TanStack Virtualizer Decoupling & CSS Containment**:
   - Eliminate `useVirtualizer` from track rows in `TimelineDom.tsx` to prevent `@dnd-kit` droppable nodes from unmounting during drag gestures.
   - Utilize native CSS `content-visibility: auto` paired with `contain-intrinsic-size: 1000px 40px` on track lanes to preserve native browser C++ layout/rendering skipping without DOM node destruction.
3. **Elevated Drag Layer via `<DragOverlay>`**:
   - Keep stationary 35% opacity anchor ghost in the origin track.
   - Render unconstrained, elevated `<ClipDragProxy>` in `@dnd-kit`'s portal `<DragOverlay>`.
   - Follow pointer sub-pixel coordinates smoothly with grab offset preservation, delta frame counters (`±X frames`), and magnetic snap guidelines.
4. **Deterministic Snap Engine with Hysteresis**:
   - Implement `TimelineSnapCalculator` with an 8px snap radius and a 6px breakaway threshold. Snap exclusively to meaningful editorial boundaries (clip head, clip tail, and playhead).
5. **Cross-Track Media Compatibility & Ripple Displacement**:
   - Reject audio clips on video tracks and video clips on audio tracks with red visual cues.
   - Dispatch `RippleMoveSequenceCommand` and `rippleMoveSequence` on drop for automatic collision-free displacement.

## Key Changes
- **`apps/studio/src/components/timeline/TimelineCanvas.tsx`**: Completely deleted.
- **`apps/studio/src/components/timeline/index.ts`**: Removed `TimelineCanvas` export.
- **`apps/studio/src/components/timeline/Toolbar.tsx`**: Removed `timelineMode`, `onSetTimelineMode`, and DOM/Canvas toggle UI.
- **`apps/studio/src/components/timeline/OverlayHUD.tsx`**, **`RazorGuideline.tsx`**, **`TimecodeBadge.tsx`**: Removed `timelineMode` prop and canvas branches.
- **`apps/studio/src/components/Timeline.tsx`**: Streamlined directly to `<TimelineDom />`, eliminating mode state.
- **`apps/studio/src/lib/timeline/interaction/TimelineSnapCalculator.ts`**: Created standalone pure magnetic snap engine with hysteresis.
- **`apps/studio/src/components/timeline/ClipDragProxy.tsx`**: Created high-performance elevated drag proxy component with status badges and delta counters.
- **`apps/studio/src/components/timeline/DroppableTrackLane.tsx`**: Enforced CSS `content-visibility: auto` and `contain-intrinsic-size: 1000px 40px`.
- **`apps/studio/src/components/timeline/ClipItem.tsx`**: Added anchor ghost state (35% opacity, dashed border) and suppressed hover HUD during dragging.
- **`apps/studio/src/components/timeline/ClipHoverHUD.tsx`**: Added `disabled` prop support.
- **`apps/studio/src/components/timeline/TimelineDom.tsx`**: Removed TanStack Virtualizer row virtualizer, wired `<DragOverlay>`, snap calculation, and ripple move dispatch.
