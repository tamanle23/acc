# 372: Iteration 45 Architecture Compliance Audit & Code Cleanup

## Problem
Following the initial delivery and black-screen hotfixes of Iteration 45, an exhaustive architecture compliance audit was conducted against `docs/iterations/master_implementation_plan_iteration_45.md` to identify gaps between the plan and the implementation, and to enforce `enterprise-clean-coder` and `typescript-coding` principles across all 4 architectural pillars:
1. **Ad-hoc Coupling in Worker Orchestrator**: In `preview.worker.ts`, lines 420-426 directly imported and called `Depth3DPlugin.cleanupSequence(seq.id)` and `Camera3DPlugin.cleanupSequence(seq.id)`. This violated the Open-Closed Principle (OCP) and Single Responsibility Principle (SRP) by tightly coupling a generic worker orchestrator to specific modifier plugin implementations.
2. **Global Native Resource ID Collisions**: In `packages/core-isomorphic/src/resource/NativeResourceManager.ts`, resources were registered under raw IDs (e.g., `'cutout'`, `'depth_src'`). When multiple sequences were present on the timeline, later sequences overwrote existing entries in the global `resources` map, breaking isolation and causing premature evictions or lost handles.
3. **Inaccurate Canvas Byte Size Deduction**: In `packages/core-isomorphic/src/resource/NativeResourceScope.ts`, `NativeResourceWrapper` attempted to deduce dimensions from `raw.width` and `raw.height`. When wrapping a universal canvas facade, the underlying native canvas was nested under `raw.getRawCanvas()`, resulting in incorrect or fallback byte calculations.
4. **Missing Explicit Resource Management Protocol**: In `apps/studio/src/renderer/workers/SequentialVideoReader.ts`, the class implemented a manual `dispose()` method but did not implement the TypeScript standard `Disposable` interface (`[Symbol.dispose]()`), preventing modern RAII `using` blocks.

## Plan
1. Eliminate all ad-hoc plugin imports from `preview.worker.ts` by replacing specific plugin calls with polymorphic sequence scope disposal: `NativeResourceManager.getInstance().disposeSequenceScope(seq.id)`.
2. Add `disposeSequenceScope(sequenceId: string)` to `NativeResourceManager` so any sequence's resources are closed cleanly without the worker knowing about individual plugins.
3. Namespace global resource registrations in `NativeResourceManager` as `${options.scope.id}:${id}` when a scope is provided, ensuring sequence isolation.
4. Enhance `NativeResourceWrapper` byte size deduction to unwrap universal canvas facades (`raw.getRawCanvas()`).
5. Implement `Disposable` and `[Symbol.dispose]()` on `SequentialVideoReader`.
6. Audit all 4 pillars of Iteration 45 for full compliance, verification, and code cleanliness.

## Changes
- `apps/studio/src/renderer/workers/preview.worker.ts`: Removed static imports of `Depth3DPlugin` and `Camera3DPlugin`. Replaced ad-hoc cleanup with `NativeResourceManager.getInstance().disposeSequenceScope(seq.id)`.
- `packages/core-isomorphic/src/resource/NativeResourceManager.ts`:
  - Added `disposeSequenceScope(sequenceId: string): void`.
  - Scoped resource registration keys (`scopedKey = options.scope ? \`${options.scope.id}:\${id}\` : id`) and closed duplicate keys prior to replacement.
- `packages/core-isomorphic/src/resource/NativeResourceScope.ts`: Updated `NativeResourceWrapper` to unpack underlying canvases from canvas facades before computing byte size.
- `apps/studio/src/renderer/workers/SequentialVideoReader.ts`: Implemented `Disposable` and added `public [Symbol.dispose](): void`.
- `packages/ir/src/plugins/vfx/Depth3DPlugin.ts`: Added synchronous recovery of `cutout` from `seqScope.get('cutout')?.getRaw()` to eliminate redundant re-decodes.
