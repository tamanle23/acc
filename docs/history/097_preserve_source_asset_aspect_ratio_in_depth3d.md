# 097 - Preserve Source Asset Aspect Ratio in 3D Depth & Frame Breaker Engines

## 1. Context & Problem Statement
Previously, the `frame_breaker` engine calculated card frame dimensions (`baseFrameW`, `baseFrameH`) based on the output canvas dimensions (`width * 0.72`, `height * 0.72`). When the source image asset had an aspect ratio different from the output video resolution (e.g., a 16:9 landscape photo in a 9:16 vertical video, or a 4:3 photo in a 16:9 canvas), the inner image inside the card frame was cropped and forced into the canvas's aspect ratio.

The user clarified that the **original aspect ratio of the input scene asset (`img.width / img.height`)** must be preserved 100% without arbitrary cropping, while keeping the entire effect safely contained within the canvas boundaries.

---

## 2. Solution & Architectural Implementation

### Exact Source Aspect Ratio Preservation for `frame_breaker`
1. **Dynamic Frame Dimension Calculation**:
   - Calculated `imgRatio = img.width / img.height`.
   - Constrained the inner photo area within bounding box limits (`maxInnerW`, `maxInnerH`):
     ```typescript
     let targetInnerW = maxInnerW;
     let targetInnerH = maxInnerW / imgRatio;
     if (targetInnerH > maxInnerH) {
       targetInnerH = maxInnerH;
       targetInnerW = maxInnerH * imgRatio;
     }
     ```
   - Computed frame outer dimensions:
     ```typescript
     const baseFrameW = targetInnerW + borderWidth * 2;
     const baseFrameH = targetInnerH + borderWidth * 2 + bottomExtraPadding;
     ```
2. **Zero-Crop Inner Photo Rendering**:
   - `sw = img.width`, `sh = img.height`, `sx = 0`, `sy = 0`.
   - 100% of the original photo is rendered inside the frame with its exact native aspect ratio.
3. **Pixel-Perfect Pop-Out Subject Alignment**:
   - Subject cutout scale matches `scale = innerW / img.width`.
   - `offsetX = innerX`, `offsetY = innerY`.
   - Head and upper body project out of the frame border with sub-pixel alignment to the inner photo.
