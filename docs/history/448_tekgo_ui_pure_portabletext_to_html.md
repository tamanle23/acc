# History Log 448: tekgo-ui Pure PortableText to HTML Migration

## Problem
In the previous migration of `apps/tekgo-ui` to Astro 5 and Preact, `@portabletext/react` v8 was retained on the server to avoid rewriting custom rich-text serializers. However, `@portabletext/react` v8 was compiled upstream using the React 19 Compiler, injecting `import { c } from "react/compiler-runtime"`. This caused Vite dependency pre-bundling to fail because Preact does not implement a `preact/compat/compiler-runtime` module. While an artificial shim (`src/shims/react-compiler-runtime.ts`) and Vite alias hack unblocked development, using `@portabletext/react` introduced unnecessary React VDOM overhead on the server, forced `preact({ compat: true })` path aliases, and retained a fragile shim.

## Plan
1. Replace `@portabletext/react` with `@portabletext/to-html` (pure framework-agnostic JavaScript) in `apps/tekgo-ui/package.json`.
2. Implement `renderPortableTextToHtml` in `apps/tekgo-ui/src/lib/portabletext.ts` with custom serializers:
   - Syntax highlighting via `refractor` with HAST-to-HTML formatting.
   - Heading anchor slugging via `GithubSlugger`.
   - Math blocks, responsive images, videos, blockquotes, lists, and links.
3. Convert `PortableTextRenderer.tsx` into a pure Astro component (`PortableTextRenderer.astro`) utilizing `<Fragment set:html={html} />`.
4. Delete `apps/tekgo-ui/src/shims/react-compiler-runtime.ts` and clean up `apps/tekgo-ui/astro.config.mjs` aliases.
5. Update consumer pages (`src/pages/about/index.astro`, `src/pages/blog/[...slug].astro`) to import `PortableTextRenderer.astro`.
6. Add unit tests in `autogenerated-tests/tekgo_ui_astro5_migration.test.ts` to verify serialization of paragraphs, links, headings, refractor code highlighting, math, and empty values.
7. Verify with `astro check`, `astro build`, and `bun test`.
