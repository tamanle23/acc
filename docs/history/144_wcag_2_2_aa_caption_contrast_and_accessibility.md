# [144] WCAG 2.2 AA Caption Contrast & Design Token Accessibility Hardening

## Problem
In visual caption presets (`PRESETS` in `@acc/effect-engines`), certain preset combinations (such as `bold-retro` with bright orange `#FF7700` primary text and `#FFFFFF` white outline) exhibited text-to-outline contrast ratios as low as 2.65:1, failing W3C WCAG 2.2 Level AA accessibility standards which mandate a minimum contrast ratio of ≥ 4.5:1. Furthermore, there were no built-in sRGB luminance or contrast calculation utilities to programmatically audit caption presets and design tokens.

## Plan
1. Calibrate `bold-retro` outline color in `packages/effect-engines/src/styles/styles.ts` from `#FFFFFF` to `#000000`, raising contrast to 7.9:1.
2. Implement `getLuminance` and `calculateContrastRatio` helper functions compliant with W3C WCAG 2.2 formulas.
3. Create automated unit test suite `autogenerated-tests/wcag_accessibility_contrast.test.ts` to audit all 10 caption presets (`tiktok`, `classic`, `cinematic`, `vlog`, `neon-glow`, `bold-retro`, `minimal-clean`, `karaoke`, `news-banner`, `retro-typewriter`).

## Changes
- `packages/effect-engines/src/styles/styles.ts`:
  - Added `getLuminance(hex: string): number` for sRGB relative luminance calculation.
  - Added `calculateContrastRatio(hex1: string, hex2: string): number` for WCAG 2.2 contrast ratio computation.
  - Updated `PRESETS['bold-retro'].outlineColor` to `#000000`.
- `autogenerated-tests/wcag_accessibility_contrast.test.ts`:
  - Created new unit test suite checking luminance, contrast ratios, and verifying all 10 caption presets meet WCAG 2.2 Level AA (≥ 4.5:1).

## Verification
