# 354: Studio Phase 4 — Enterprise UX, Resizable Layout, Sonner Toasts & Specs Sync

## 1. Problem Statement
1. **Missing Mandatory Specs (`DESIGN.md` & `ROUTE.md`)**:
   - Monorepo rules in `.agents/rules/01-workspace-specific.md` mandate that every frontend app maintain synchronized `DESIGN.md` (tokens, typography, Liquid Glass) and `ROUTE.md` (screens, blueprints, keyboard flows). Neither existed for `apps/studio`.
2. **Rigid Viewport / Timeline Layout**:
   - `apps/studio/src/App.tsx` used fixed-dimension flexbox containers for the Preview canvas stage vs. the Timeline scrubber and tracks. Video editors could not dynamically resize the viewport relative to the audio/video tracks.
3. **Blocking Native Alerts**:
   - Export completion and export failures in `App.tsx` triggered synchronous, blocking browser `window.alert(...)` modals, interrupting user workflows.
4. **WCAG 2.2 AA Accessibility & Aria Gaps**:
   - Interactive swatches in `SettingsModal.tsx`, track toggles in `TrackHeaderCard.tsx`, transport buttons in `Toolbar.tsx`, and viewport controls in `ViewportControlBar.tsx` lacked `aria-pressed`, explicit `aria-label` screen reader tags, and keyboard focus rings.

## 2. Plan
1. **Author `apps/studio/DESIGN.md`**:
   - Document Liquid Glass tokens (`--glass-bg`, `--glass-border`, `--glass-specular`), color palette, typography scales, and archetype track invariants (Audio = Emerald, Video = Indigo, VFX/Depth = Amber, Text/Subtitles = Violet).
2. **Author `apps/studio/ROUTE.md`**:
   - Document the responsive NLE topology, resizable split-pane layout, modal dialog hierarchy (Export, Settings, Shortcuts, Visual IR Debugger, Cue Editor), and complete keyboard shortcut matrix.
3. **Implement Resizable Split Layout & Sonner Toasts in `App.tsx`**:
   - Integrate `ResizablePanelGroup`, `ResizablePanel`, and `ResizableHandle` with keyboard-accessible vertical splitters.
   - Replace `alert(...)` with rich non-blocking `sonner` toasts (`toast.success` with "Download Again" action; `toast.error` with error recovery descriptions) and mount `<Toaster />`.
4. **Enforce WCAG 2.2 AA Accessibility Across Studio**:
   - Add `aria-pressed`, `aria-label`, and `focus-visible:ring-2 focus-visible:ring-accent-theme` across `SettingsModal.tsx`, `TrackHeaderCard.tsx`, `Toolbar.tsx`, and `ViewportControlBar.tsx`.
5. **Verification & Git Archival**:
   - Create unit test suite `autogenerated-tests/studio_phase4_ux_resizable_specs.test.ts`.
   - Run all 8 Studio test suites with `bun test` and build with `pnpm --filter @acc/studio build`.
