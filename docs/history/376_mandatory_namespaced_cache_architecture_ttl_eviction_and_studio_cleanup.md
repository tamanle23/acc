# Task History 376: Mandatory Namespaced Cache Architecture with TTL, LRU/Size Eviction & Studio Codebase Optimization

## Problem
1. **Unpartitioned Content Cache**: `ContentCacheRegistry` operated as a single flat key-value namespace, mixing assets, audio, textures, and models without partition directories or logical isolation.
2. **Missing Expiry & Eviction**: No first-class TTL expiration (`expiresAt`) or LRU / byte-quota eviction policies existed to clean up transient blobs.
3. **Studio Code Health**: `apps/studio` had duplicate barrel exports in `src/components/index.ts` with colliding casing (`./Preview` vs `./preview`, `./Timeline` vs `./timeline`), unoptimized bundle chunks (>2.5 MB), and OPFS debugger resolution issues when inspecting subdirectories.

## Plan
- Modernize `ContentCacheRegistry` to require explicit namespaces (`CacheNamespace`) with dedicated subdirectories.
- Introduce `expiresAt` TTL tracking and `evict({ maxEntries, maxSizeBytes, strategy: 'lru' })`.
- Remove all backward-compatibility stubs and migrate all monorepo consumers across `@acc/core-isomorphic`, `@acc/core-web`, `@acc/core`, `@acc/effect-engines`, `@acc/ir`, and `@acc/studio`.
- Normalize component index barrel exports in `@acc/studio` and add Rollup vendor chunking in `vite.config.ts`.
- Fix hierarchical path navigation in `OpfsCacheStrategy` and `OpfsDebuggerModal`.

## Changes Made
1. **`packages/core-isomorphic/src/cache/`**:
   - `types.ts`: Defined `CacheNamespace`, `INamespacedCache`, `CacheSetOptions`, `EvictionPolicyOptions`, and updated `CacheEntryMetadata`.
   - `ContentCacheRegistry.ts`: Implemented `NamespacedCacheAdapter` with path-based directory prefixes (`${namespace}/${key}`), dynamic TTL expiration checks, and LRU/byte quota eviction. Replaced `get()` with mandatory `namespace(ns, strategyId)`.
2. **`packages/core/src/cache/NativeFileCacheStrategy.ts`**:
   - Added automatic subdirectory creation and recursive key enumeration for path-based keys (`${namespace}/${key}`).
3. **`packages/core-web/src/cache/OpfsCacheStrategy.ts`**:
   - Added `resolveTargetDirectory` to traverse and create nested OPFS directory handles for namespaced items.
   - Updated `readEntryBlob` and `removeCustomEntry` to support nested path traversal.
4. **Bootstraps & Consumers**:
   - Migrated all call sites in `core-web/src/index.ts`, `core/src/bootstrap.ts`, `OnnxModelManager.ts`, `AssetProtocolRegistry.ts`, `depth3d/index.ts`, `Camera3DPlugin.ts`, `Depth3DPlugin.ts`, `IRMasterRenderer.ts`, `UniversalAudioMixer.ts`, and `IRChunkWorkerPool.ts`.
5. **`apps/studio/`**:
   - Normalized barrel exports in `src/components/index.ts`.
   - Configured `manualChunks` in `vite.config.ts` for `vendor-shiki` and `vendor-ui-primitives`.
   - Updated `OpfsDebuggerModal.tsx` to read entries using full node path.
6. **Tests**:
