# 360. OPFS Cache Strategy Files & Folders Debugger UI

## Problem
In client browser and Web Worker environments, [`OpfsCacheStrategy`](file:///c:/Users/Admin/workspace/git/acc/packages/core-web/src/cache/OpfsCacheStrategy.ts) manages zero-heap, disk-backed media assets and cached blobs directly in the browser's Origin Private File System (OPFS). Because OPFS is invisible to standard DevTools (lacking built-in file tree visualizers or blob hex inspectors), developers, architects, and QA engineers had zero visual debugging capability to inspect cached video frames, audio PCM chunks, companion `.meta.json` descriptors, storage quota usage, or file hierarchies.

## Plan
1. **Core-Web OPFS Inspection API**:
   - Enhance [`OpfsCacheStrategy`](file:///c:/Users/Admin/workspace/git/acc/packages/core-web/src/cache/OpfsCacheStrategy.ts) with enterprise inspection and file-system manipulation methods:
     - `getStorageEstimate()`: returns exact bytes used, available quota, and usage percent via `navigator.storage.estimate()`.
     - `inspectTree()`: recursively enumerates directories and files, pairing content files with companion `.meta.json` metadata, computing recursive sizes and timestamps.
     - `inspectEntries(includeMeta?)`: returns flattened entry records with decoded cache keys.
     - `readEntryBlob()` / `readEntryText()`: reads raw files or UTF-8 text directly.
     - `writeCustomFile()`: writes blobs/text to OPFS supporting standard `WritableStream` and fallback handles.
     - `removeCustomEntry()`: deletes files, companion metadata, or directories.
     - `formatOpfsBytes()`: utility for human-readable bytes formatting (`B`, `KB`, `MB`, `GB`, `TB`).
2. **Modular shadcn/ui + Tailwind Liquid Glass Debugger UI**:
   - Create `apps/studio/src/components/debugger/opfs/`:
     - `types.ts`: TypeScript contracts for view modes, filter categories, file details, and storage state.
     - `OpfsHexViewer.tsx`: Zero-dependency, paginated hex + ASCII dump viewer for binary buffers/blobs.
     - `OpfsFilePreview.tsx`: Multi-format previewer for images (`<img>`), audio (`<audio>`), video (`<video>`), JSON/text, and hex dumps, plus metadata inspection and one-click file downloads.
     - `OpfsTreeExplorer.tsx`: Collapsible folder tree, search bar with debounce, category filter chips (All, Media, JSON, Meta, Other), sort controls, and deletion actions.
     - `OpfsDebuggerModal.tsx`: Master dialog featuring Liquid Glass styling, storage quota progress meter, live refresh, test file creation, and cache purging.
3. **Studio Integration**:
   - Wire `OpfsDebuggerModal` into [`Titlebar.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/Titlebar.tsx) with a dedicated `OPFS Cache` button and keyboard shortcut `Ctrl+Shift+O`.
   - Wire an "Inspect Files" action into [`SettingsModal.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/SettingsModal.tsx) under "Storage & Media Cache".
4. **Verification**:
   - Write comprehensive unit tests in `autogenerated-tests/opfs_cache_strategy_inspector.test.ts` covering directory tree recursion, companion metadata mapping, quota estimation, file I/O, and byte formatting.
   - Run full production Vite build (`pnpm --filter @acc/studio build`).
