# 307 — Studio Theme Styling Guide & Regression Guardrails

- **Date:** 2026-10-22
- **Component:** `@acc/studio` (`docs/studio_theme_styling_guide.md`, `ViewportSafeGuides.tsx`, `studio_theme_unification.test.ts`)
- **Status:** Completed

## Context & Problem
Following the full unification of `@acc/studio` with `ThemeProvider.tsx` and Tailwind v4 `@theme` tokens in Task 306, the repository needed a comprehensive, canonical reference guide documenting how developers and AI agents should author theme-compliant components, custom variants, and CSS styles, along with automated CI regression guardrails across all 30+ Studio components.

## Solution & Architectural Changes
1. **Comprehensive Studio Theme Styling Guide (`docs/studio_theme_styling_guide.md`)**:
   - Documented the end-to-end mental model (`ThemeProvider` -> `applyThemeToDocument()` -> `<html class/data-*/style>` -> `index.css` -> Tailwind v4 `@theme` utilities).
   - Provided a token cheat sheet for Surfaces & Text (`bg-background`, `text-foreground`, `text-muted-foreground`, `bg-muted`), Liquid Glass (`bg-glass-surface`, `border-glass-border`, `border-glass-border-highlight`, `shadow-glass`, `shadow-accent-glow`), Accent tokens (`text-accent-theme`, `bg-accent-theme`, `text-primary-foreground`), and prebuilt classes (`glass-panel`, `glass-card`, `glass-pill`, `glass-button`, `glass-button-primary`, `glass-badge-accent`).
   - Added copy-pasteable recipes for panels, toggles, inputs, semantic status colors, custom variants (`glass-cyber:`, `glass-frosted:`, `glass-specular:`, `blur-*`), raw CSS (`color-mix`), and Canvas/SVG integration.
   - Documented Do/Don't patterns, intentional exceptions (video canvas backing `#000000`, in-canvas subtitles, semantic track-type colors), and step-by-step instructions for adding new accent colors or tokens.

2. **Viewport Safe Guides Polish (`apps/studio/src/components/preview/ViewportSafeGuides.tsx`)**:
   - Updated the 16:9 Action Safe (93%) boundary, badge, and center crosshair to use `border-accent-theme/60`, `glass-badge-accent`, `bg-accent-theme/80`, and `shadow-accent-glow`.

3. **Expanded CI Guardrails (`autogenerated-tests/studio_theme_unification.test.ts`)**:
   - Expanded static token hygiene checks to cover 30 Studio component files across `inspector/`, `timeline/`, `preview/`, `debugger/`, `audio/`, and root modals, plus verification of `docs/studio_theme_styling_guide.md` (5 test suites, 1,230 `expect()` assertions passing).
