## 1. Problem & Context
Trước đây, để chuẩn hóa codec audio trước khi nạp vào encoder hoặc ghép các phân cảnh (scene), hệ thống sử dụng phương thức chuyển đổi trung gian lưu ra đĩa (Disk-based `.mp3` cache qua `FFIAudioDSP.ensureMp3Audio`).
Điều này dẫn đến:
- Phát sinh I/O đĩa không cần thiết với hàng chục file `.mp3` tạm trong thư mục `autogenerated/audio-cache/`.
- Tiềm ẩn rủi ro đồng bộ file trên các hệ thống tệp khác nhau khi render song song.
- Thiếu giải pháp encode AAC chuẩn native in-memory từ nguồn bất kỳ (WAV PCM, MP3, AAC, FLAC...) trực tiếp vào MP4 container của từng scene.

## 2. Solution & Technical Design
Triển khai **Phương án 1: In-Memory Audio Transcoding & Encoding qua FFmpeg C FFI**:
1. **FFI Header Symbol Enhancements (`packages/core/src/ffmpeg-ffi/index.ts`)**:
   - Khai báo bổ sung các FFI symbols chuẩn: `av_opt_set_chlayout`, `av_channel_layout_describe`, `av_channel_layout_copy`, `av_write_frame`.
2. **Native AAC Audio Encoder Context trong `FFIVideoEncoder.ts`**:
   - Thiết lập audio stream #1 (`aStream`) với codec `AV_CODEC_ID_AAC` chuẩn:
     - `sample_fmt = AV_SAMPLE_FMT_FLTP` (8).
     - `sample_rate = 48000 Hz`, `bit_rate = 192 kbps`.
     - `ch_layout = AV_CHANNEL_LAYOUT_STEREO` (2 channels) sử dụng `av_channel_layout_default`.
3. **Dynamic Format-Agnostic Audio Decoding & Resampling Pipeline**:
   - `encodeAudio()` giải mã từng frame từ bất kỳ file audio đầu vào nào (`avcodec_receive_frame`).
   - Tự động cấu hình `swresample` (`swr_alloc_set_opts2`) dựa trên metadata chính xác từ frame giải mã đầu tiên (`inFrame + 384n` channel layout, offset 116 format, offset 180 sample rate).
   - Resample toàn bộ audio sang 48kHz Stereo Interleaved Float32 (`AV_SAMPLE_FMT_FLT`) và nạp vào FIFO ring buffer.
   - Chia buffer thành các khối 1024 mẫu Planar Float32 (`AV_SAMPLE_FMT_FLTP`) và nạp vào AAC encoder (`avcodec_send_frame` / `avcodec_receive_packet`).
   - Ghi packet ra container MP4 bằng `av_write_frame` với `av_packet_unref` quản lý bộ nhớ an toàn.
   - Cắt ngắn chính xác độ dài audio theo video duration của scene, đảm bảo đồng bộ tuyệt đối.
4. **Loại bỏ hoàn toàn Disk MP3 Caching**:
   - Không còn gọi hoặc tạo bất kỳ file `.mp3` trung gian nào trên ổ đĩa. Mọi định dạng audio (WAV, MP3...) được decode và encode trực tiếp trong RAM.

## 4. Key Learnings & FFmpeg Struct Offsets
- `AVFrame` trên FFmpeg 7/8 Windows x64: `nb_samples` (offset 112), `format` (offset 116), `pts` (offset 136), `sample_rate` (offset 180), `ch_layout` (offset 384, 24 bytes).
- Ghi stream audio bằng `av_write_frame` + `av_packet_unref` đem lại tính ổn định cao và giải phóng memory tức thì mà không xung đột với cơ chế unref nội bộ của `av_interleaved_write_frame`.
