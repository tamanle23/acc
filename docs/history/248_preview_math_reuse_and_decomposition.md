# 248 - Studio Preview: Effect Engines Math Reuse & Subcomponent Decomposition

## Overview
Decomposed `Preview.tsx` into modular enterprise-grade subcomponents under `apps/studio/src/components/preview/`, eliminated duplicated canvas rendering math by delegating multi-track layer compositing to `UniversalCanvasEngine.renderLayers()`, and implemented an Observer pattern in `AssetTextureCache` to ensure real-time reactive redraws when image and video elements finish decoding.

## Problems Solved
1. **Boilerplate & Monolithic Viewport**: `Preview.tsx` had grown into a large component mixing transform gizmos, HUD control bars, safe guides, subtitles, keyboard shortcuts, and direct canvas 2D matrix rendering.
2. **Duplicated Canvas Math**: Canvas aspect ratio fitting (`cover` vs `contain`), modifier blend modes, and affine transform matrix calculations were duplicated directly inside `Preview.tsx` instead of leveraging `@acc/effect-engines`.
3. **Scrubber Lag on Asset Loading**: `AssetTextureCache` loaded images and video frames asynchronously, but lacked a notification mechanism. When an asset loaded, the canvas stayed on the placeholder until the user manually moved the scrubber.

## Solution Architecture
1. **Math Engine Reuse (`packages/effect-engines/src/canvas/UniversalCanvasEngine.ts`)**:
   - Added `VisualLayerItem` interface defining `drawable`, `sourceWidth`, `sourceHeight`, `fitMode` (`cover` | `contain`), `blendMode`, and GSAP affine matrix transforms (`x`, `y`, `scale`, `rotation`, `opacity`).
   - Implemented `renderLayers(ctx: CanvasRenderingContext2D, layers: VisualLayerItem[]): void` to centralize multi-track layer rendering and matrix stack management (`ctx.save()`, `translate`, `rotate`, `scale`, `globalAlpha`, `drawImage`, `ctx.restore()`).
2. **Observer Pattern in Texture Cache (`apps/studio/src/lib/textures/AssetTextureCache.ts`)**:
   - Implemented `subscribe(callback: () => void): () => void` and `notify(): void`.
   - Connected `img.onload` and `video.onloadeddata` to `notify()`, triggering immediate re-renders in `Preview.tsx`.
3. **Subcomponent Decomposition (`apps/studio/src/components/preview/`)**:
   - `ViewportControlBar.tsx`: Viewport zoom presets, pan hand tool, safe guide toggles, checkerboard backdrop, and VFX ambiance switches.
   - `ViewportSafeGuides.tsx`: Broadcast 16:9 action/title safe overlays and 9:16 social interactive zone overlays.
   - `ContextualActionPill.tsx`: Floating action bar above selection with duplicate, center alignment, lock/unlock, reset transform, and delete actions.
   - `SubtitlesOverlay.tsx`: Interactive subtitle caption overlays.
4. **Preview.tsx Clean Integration**:
   - Wires `AssetTextureCache.subscribe()` to trigger reactive canvas re-renders upon asset decode.
   - Converts active visual sequences into `VisualLayerItem[]` and delegates directly to `engine.renderLayers(ctx, layersToDraw)`.
