# 355: Unify Isomorphic Resource & Asset Management with Blob & Streaming Pipeline

## 1. Problem Statement
1. **Critical Memory Overhead at Studio Startup (~1GB)**:
   - On initial launch of `@acc/studio`, `WebAudioEngine.syncFromIR()` eagerly decoded every audio preset in the project into uncompressed 32-bit float PCM arrays (`Float32Array[]`) and cached them indefinitely in `AudioAssetCache` with zero eviction policy.
2. **Rapid Native GPU Memory Leaks During Timeline Playback (>2.5GB)**:
   - `WorkerRenderStrategy.syncTextures()` invoked `createImageBitmap(visualAsset.source)` unconditionally on every 60Hz tick for all active visual sequences.
   - Each transferred 1080p frame (~8.3MB) was placed in `preview.worker.ts`'s `textureCache`, overwriting old keys without invoking `ImageBitmap.close()`. This leaked ~250MB to ~500MB of GPU memory per second during playback.
3. **In-Memory Heap Thrashing Across Monorepo**:
   - Resource caching strategies previously only accepted contiguous `Uint8Array` byte arrays via `get()` and `set()`. Caching large video/audio assets required reading entire files into RAM buffers instead of utilizing zero-copy WHATWG `ReadableStream<Uint8Array>` and platform-native `Blob` handles.

## 2. Plan
1. **Extend Core Isomorphic Cache Interfaces (`@acc/core-isomorphic`)**:
   - Augment `IContentCacheStrategy` in `packages/core-isomorphic/src/cache/types.ts` with optional methods: `getBlob`, `setBlob`, `getStream`, `setStream`, and `getMetadata`.
   - Preserve 100% backward compatibility for all existing `Uint8Array` methods.
2. **Implement Isomorphic Stream Utilities (`streamUtils.ts`)**:
   - Provide zero-copy stream transformations (`uint8ArrayToStream`, `streamToUint8Array`, `blobToStream`, `streamToBlob`, `blobToUint8Array`, `computeStreamChecksumAndSize`) with deterministic reader lock disposal.
3. **Bound In-Memory Cache (`MemoryCacheStrategy.ts`)**:
   - Implement an LRU byte ceiling (`maxSizeBytes`, default 64MB) and zero-copy `Blob`/`ReadableStream` storage.
4. **Upgrade Web & Native Strategies (`@acc/core-web`, `@acc/core`)**:
   - Implement native streaming (`response.body`), `response.blob()`, and `Response(blob)` in `WebCacheStrategy`.
   - Implement direct `Blob` storage in `IndexedDbCacheStrategy`.
   - Implement chunked filesystem streams (`fs.createReadStream` / `createWriteStream`) and Blob handles in `NativeFileCacheStrategy`.
5. **Eliminate Studio Memory Leaks (`@acc/studio`)**:
   - Deduplicate `createImageBitmap` generation in `WorkerRenderStrategy` via `syncedSources`.
   - Bound `textureCache` to 32 entries and call `existing.close()` in `preview.worker.ts`.
   - Implement LRU eviction on `AudioAssetCache` (8 entries, 64MB PCM cap) and lazy proximate preloading in `WebAudioEngine`.
   - Bound image, video, and canvas caches in `AssetTextureCache`.
   - Route file uploads in `LeftSidebar.tsx` directly to `ContentCacheRegistry.get().setBlob(assetId, file)`.
6. **Verification & Git Protocol**:
   - Validate with unit tests in `autogenerated-tests/`.
   - Register history document in `docs/history/README.md`.

## 3. Changes Made
- **`packages/core-isomorphic/src/cache/types.ts`**:
  - Added optional `getBlob`, `setBlob`, `getStream`, `setStream`, and `getMetadata` to `IContentCacheStrategy`.
- **`packages/core-isomorphic/src/cache/streamUtils.ts`**:
  - Created high-performance streaming helpers across Web, Web Worker, Node.js, and Bun runtimes.
- **`packages/core-isomorphic/src/cache/MemoryCacheStrategy.ts`**:
  - Implemented LRU eviction with byte ceiling (`maxSizeBytes`, default 64MB) and native Blob/Stream storage.
- **`packages/core-isomorphic/src/cache/index.ts`**:
  - Exported `streamUtils` helpers.
- **`packages/core-isomorphic/src/assets/IAssetBlob.ts` & `AssetProtocolRegistry.ts`**:
  - Added `blob?(): Promise<Blob>` to `IAssetBlob` and registered `BlobAssetBlob` and `CachedAssetBlob`.
- **`packages/core-web/src/cache/WebCacheStrategy.ts`**:
  - Implemented zero-copy `getStream` returning `response.body`, `getBlob` returning `response.blob()`, and `setBlob`/`setStream` writing native responses.
  - Eliminated all `fallbackMemory` in-memory Maps; strategy operates strictly on its own CacheStorage capacity with zero heap retention.
- **`packages/core-web/src/cache/IndexedDbCacheStrategy.ts`**:
  - Implemented direct IndexedDB `Blob` persistence with streaming bridges.
  - Eliminated all `fallbackMemory` in-memory Maps; strategy operates strictly on its own IndexedDB capacity with zero heap retention.
- **`packages/core-web/src/index.ts`**:
  - Added `bootstrapClient = bootstrapCoreWeb` alias.
- **`packages/core/src/cache/NativeFileCacheStrategy.ts`**:
  - Added chunked Node/Bun streaming via `fs.createReadStream` / `createWriteStream` and Web `Blob` support.
- **`apps/studio/src/renderer/strategies/WorkerRenderStrategy.ts`**:
  - Deduplicated `createImageBitmap` using `syncedSources` map to avoid 60Hz 8.3MB allocations.
- **`apps/studio/src/renderer/workers/preview.worker.ts`**:
  - Added `safeSetTexture()` with LRU eviction (cap at 32 bitmaps) and mandatory `existing.close()`.
- **`apps/studio/src/lib/audio/AudioAssetCache.ts` & `WebAudioEngine.ts`**:
  - Added LRU cache (8 entries, 64MB cap) and restricted preloading to audio clips within 10s of playhead.
- **`apps/studio/src/lib/textures/AssetTextureCache.ts`**:
  - Added LRU bounding on images (32), videos (6), canvases (32), data URLs (32), and placeholders (16).
- **`apps/studio/src/components/LeftSidebar.tsx`**:
  - Uploaded files saved directly to `ContentCacheRegistry.get().setBlob(assetId, file)`.
- **`autogenerated-tests/core_isomorphic_universal_services.test.ts` & `web_cache_strategy.test.ts`**:
  - Added test suites for streaming and Blob operations.
