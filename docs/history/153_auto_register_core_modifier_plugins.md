# Task History 153: Auto-Register Core Modifier Plugins & Composite Execution

**Date**: 2026-10-09  
**Status**: Completed  
**Scope**: IRMasterRenderer, ModifierPluginRegistry, Depth3DPlugin, CLI Runner Backward-Compatibility

---

### Context & Problem Statement
The Universal Video IR engine defines 6 foundational concrete modifier plugins:
1. `vfx/depth3d`: Stylized card borders (polaroid/comic) and subtle breathing parallax zoom.
2. `sfx/dynamic_ducking`: Sidechain audio level attenuation during voiceover dialogue.
3. `editorial/split_edit`: J-cut and L-cut audio/video overlap lead times.
4. `transition/crossfade`: Linear crossfade and dip-to-black alpha transitions.
5. `overlay/blend_mode`: Multi-track compositing modes (`multiply`, `screen`, `overlay`, `color_dodge`, `soft_light`).
6. `overlay/canvas_particles`: Procedural particle systems (`rain`, `snow`, `dust`, `embers`, `light_leak`, `vhs`).

In `sample-story` rendering outputs, plugins appeared unapplied because:
1. `registerCoreModifierPlugins()` was defined in `packages/ir/src/plugins/index.ts` but never invoked automatically upon renderer initialization. Consequently, `ModifierPluginRegistry.getInstance()` was empty (`size: 0`), and `IRMasterRenderer` silently bypassed all `seq.modifiers` and `track.modifiers`.
2. In `IRMasterRenderer.ts`, base image rendering blitted directly without modifier context transformation, and phase 4 master composite modifiers were not invoked prior to copying pixel buffer data.
3. Root `cli.ts` required the exported `runCli` alias from `@acc/cli` to preserve backward compatibility.

---

### Key Implementations

1. **Auto-Registration of Core Plugins (`packages/ir/src/renderer/IRMasterRenderer.ts`)**:
   - In the `IRMasterRenderer` constructor, initialized `this.pluginRegistry` via `registerCoreModifierPlugins()`.
   - Guaranteed all 6 modifier plugins are automatically loaded and ready to process incoming sequence, stream, and composite modifiers without requiring manual registration by external callers.

2. **Phase 2 & Phase 4 Modifier Execution Pipeline (`packages/ir/src/renderer/IRMasterRenderer.ts`)**:
   - Wrapped Phase 2 sequence-level modifier rendering within `ctx.save()` and `ctx.restore()`.
   - Forwarded `baseAsset` to the clip render context and applied context transformations (such as `Depth3DPlugin`'s breathing parallax zoom) prior to drawing base images.
   - Implemented Phase 4 master canvas compositing loop across track modifiers, executing `renderMasterComposite` handlers (e.g. `BlendModePlugin`) before final RGBA buffer blitting.

3. **Depth3D Plugin Parallax & Frame Styling (`packages/ir/src/plugins/vfx/Depth3DPlugin.ts`)**:
   - Refactored `renderClipSpace` to apply the breathing parallax zoom (`translate` -> `scale` -> `translate`) directly onto the canvas context.
   - Rendered stylized card frames (`comic` with 8px border or `polaroid` with 4px border).

4. **CLI Entrypoint Export (`apps/cli/src/index.ts`)**:
   - Exported `runCli` alias to ensure compatibility with root forwarding wrappers (`cli.ts`).
