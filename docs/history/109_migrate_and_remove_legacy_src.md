# History Log: [089] Migrate & Remove Legacy /src Folder to Monorepo Workspaces

**Date**: 2026-10-01  
**Status**: [x] Completed  
**Component**: Repository Layout / Turborepo Monorepo Migration (`@acc/core`, `@acc/effect-engines`, `@acc/cli`)

---

## 1. Problem Statement
- The repository had undergone migration to a Turborepo monorepo layout (`packages/core`, `packages/effect-engines`, `apps/cli`, `packages/ir`, `packages/proto`, `packages/exporters`).
- However, the legacy `/src` directory still physically existed in the repository and contained duplicated implementation files (such as 27 overlay effect generators, sound effect generators, and Python workers) using relative legacy imports (`../core`) rather than referencing the workspace packages (`@acc/*`).
- Root CLI entry points (`cli.ts`, `auto-config.ts`, `overlay-effects-cli.ts`, `sound-effects-cli.ts`, `effects-registry.json`) and test files still contained imports referencing `./src/...`.

---

## 2. Plan & Approach
1. **Verification & Parity Check**:
   - Perform line-by-line verification between legacy `/src` and workspace packages (`packages/core`, `packages/effect-engines`, `apps/cli/src/pipelines/04-generative-story`) to ensure 100% logic and feature parity with zero code loss.
2. **Refactor Entry Points**:
   - Update `cli.ts`, `auto-config.ts`, `effects-registry.json`, `scripts/batch-benchmark-ai.ts`, and test files in `autogenerated-tests/` to import directly from `@acc/core`, `@acc/effect-engines`, and `@acc/cli`.
3. **Complete Cleanup**:
   - Remove the legacy `/src` directory completely (Option B strategy).
4. **Enhanced Test Coverage & Verification**:
   - Add `autogenerated-tests/monorepo_migration.test.ts` to assert package exports, overlay generators, sound effect routing, platform settings resolution, and root entrypoint integrity without `/src`.
   - Update FFmpeg Manager system binary detection for cross-platform Linux/macOS shared builds.

---

## 3. Key Changes Made
1. **`effects-registry.json`**:
   - Updated `module_path` for all 27 overlay generators from `./src/overlay-effects/generators/...` to `./packages/effect-engines/src/overlay-effects/generators/...`.
2. **`cli.ts` & `auto-config.ts`**:
   - Refactored imports to reference `@acc/core`, `@acc/effect-engines`, and `apps/cli/src/pipelines/04-generative-story/` directly while preserving all inline comments and JSDoc documentation.
3. **`apps/cli/src/commands/sfx.ts`**:
   - Corrected `RegistryManager` import to point to `@acc/effect-engines` for sound effect routing.
4. **`packages/core/src/FFmpegManager.ts` & `ffmpeg-ffi/index.ts`**:
   - Added system-wide FFmpeg detection (`which ffmpeg` / `which ffprobe`) on Linux/macOS and added Unix shared library lookup (`.so` / `.dylib`).
5. **`packages/core/src/SceneWorker.ts`**:
   - Updated worker thread import from `../../../src/depth3d` to `@acc/effect-engines`.
6. **Removed Legacy `/src`**:
   - Deleted the `/src` folder entirely.
7. **Added Monorepo Migration Test Suite**:
   - Created `autogenerated-tests/monorepo_migration.test.ts`.
