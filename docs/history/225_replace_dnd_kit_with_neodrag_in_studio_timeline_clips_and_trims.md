# History Record 225: Replace @dnd-kit with @neodrag/react in Studio Timeline Clips & Trimming

## Problem
In `apps/studio/src/components/Timeline.tsx`, timeline clip items and trim handles were governed by a nested `@dnd-kit` `<DndContext>`. High-frequency pointer moves triggered top-level React Context updates across all tracks during scrubbing and dragging. Moreover, vertical track hopping lacked media-type validation, permitting invalid assignments (e.g. video to audio tracks).

## Plan
1. Create `trackCompatibility.ts` with strict sequence-to-track validation rules.
2. Refactor `TrimHandle.tsx` to use `@neodrag/react` with `axis: 'x'` and `data-trim-handle`.
3. Refactor `ClipItem.tsx` with `@neodrag/react` and `cancel: '[data-trim-handle]'`.
4. Update `DroppableTrackLane.tsx` with `data-track-lane-id` and `isDropTarget` highlight states.
5. Remove `<DndContext>` and `@dnd-kit` sensors from `Timeline.tsx`, implementing point-in-rect lane hopping with compatibility checks.
6. Author unit tests in `autogenerated-tests/timeline_track_compatibility.test.ts`.
7. Verify with Bun tests and Vite production build.
