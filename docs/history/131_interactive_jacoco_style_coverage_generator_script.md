# History Log 131: Interactive JaCoCo-Style Coverage Generator Script

## Problem
In our polyglot monorepo, code coverage reports are generated by different tools and stored in disparate locations:
1. Java backend (`apps/backend`): Maven JaCoCo plugin outputs to `apps/backend/unipost-fw/target/site/jacoco/`.
2. TypeScript frontend (`apps/console`): Vitest v8 outputs Istanbul reports to `apps/console/coverage/`.
3. Sandbox simulation engine (`packages/sandbox`): Vitest v8 outputs to `packages/sandbox/coverage/`.

Developers and CI workflows lacked a single unified, interactive, JaCoCo-style HTML report that aggregates monorepo coverage with visual red/green meters, sortable tables, breadcrumbs, search filters, and source file inspection.

## Plan
1. Create a cross-platform Node.js script `scripts/generate-coverage-report.mjs` with zero runtime dependencies.
2. Implement JaCoCo CSV/XML parser to extract Java backend instruction, branch, line, complexity, and method metrics.
3. Implement Istanbul/Vitest `coverage-final.json` parser to extract TypeScript frontend and sandbox statements, branches, lines, and functions.
4. Generate a self-contained, interactive JaCoCo-style single-page HTML report (`coverage/index.html`) featuring:
   - JaCoCo horizontal Red/Green meter bars
   - Monorepo breadcrumb navigation
   - KPI summary cards with $\ge 90\%$ pass badges
   - Real-time search filter and column sorting
   - Drill-down views: Monorepo -> Modules -> Packages -> Files -> Source Code Viewer
   - Dual theme support (Liquid Glass Dark & Classic JaCoCo Light)
   - CLI flags: `--open`, `--run`, `--json`, `--out`
5. Wire scripts into root `package.json` (`pnpm coverage:report`, `pnpm coverage:open`, `pnpm coverage:all`).
6. Document in walkthrough `apps/console/doc/walkthrough_119.md` and commit per Rule 6 & 7.

## Changes
- **`scripts/generate-coverage-report.mjs`**: Core generator script that aggregates Java JaCoCo and TypeScript Vitest coverage into an interactive HTML dashboard.
- **`package.json`**: Added root npm scripts `coverage:report`, `coverage:open`, and `coverage:all`.
- **`apps/console/doc/walkthrough_119.md`**: Created paired walkthrough documentation.
