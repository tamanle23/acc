# 351: Studio Phase 1 Enterprise Cleanup & Worker Pipeline Consolidation

## Problem
During rapid iteration on `@acc/studio`, several dead, orphaned, or duplicated modules accumulated across `apps/studio/src`:
1. `apps/studio/src/components/Sidebar.tsx` (1,317 lines / 57.5 KB) was completely superseded by `LeftSidebar.tsx` and `RightSidebar.tsx` yet remained exported in `components/index.ts`.
2. Web Worker preview rendering files were scattered across three separate directories (`src/lib/worker/`, `src/lib/workers/`, and `src/renderer/workers/`), alongside an unused `src/lib/timeline/strategies/ITimelineRenderStrategy.ts` stub.
3. `apps/studio/src/renderer/AssetTextureCache.ts` maintained its own duplicate `Map` methods rather than delegating all `IPreviewTextureProvider` contracts (`get`, `set`, `has`, `delete`, `loadBlob`, `clear`, `dispose`) directly to the authoritative `apps/studio/src/lib/textures/AssetTextureCache.ts`.
4. Unused chat/questionnaire UI files (`bubble.tsx`, `message-scroller.tsx`, `questionnaire.tsx`, `trace.tsx`), an unused hook (`use-highlighted-code.ts`), and 12 unused Shiki language grammars in `src/lib/highlighter.tsx` bloated the Vite production bundle by over 1 MB.

## Plan
1. Remove dead `Sidebar.tsx` and update `apps/studio/src/components/index.ts`.
2. Consolidate `PreviewWorkerBridge`, `PreviewRenderWorkerCore`, `DecodedFrameCache`, and `preview.worker.ts` under `apps/studio/src/renderer/workers/` with `Disposable` (`[Symbol.dispose]`) support and duplicate `transferControlToOffscreen` protection (`__transferred`).
3. Delete obsolete directories `src/lib/worker/`, `src/lib/workers/`, and `src/lib/timeline/strategies/`.
4. Unify `IPreviewTextureProvider` and bounded LRU eviction (`MAX_CACHE_ENTRIES = 128`) + `<video>` decoder disposal inside `apps/studio/src/lib/textures/AssetTextureCache.ts`, and simplify `apps/studio/src/renderer/AssetTextureCache.ts` to a pure re-export.
5. Remove unused chat/questionnaire UI primitives and restrict Shiki dynamic imports in `apps/studio/src/lib/highlighter.tsx` to `json` (the only grammar used by the Studio Visual IR JSON Debugger).
