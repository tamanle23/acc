# 381. Truly Isomorphic Audio Pipeline via MediaEngineStrategy & UniversalAudioMixer

## Problem
In [`UniversalAudioMixer.ts`](file:///c:/Users/Admin/workspace/git/acc/packages/ir/src/renderer/audio/UniversalAudioMixer.ts), audio asset decoding was coupled directly to Node.js/Bun runtime internals (`typeof process !== 'undefined' && process.versions?.node` requiring `@acc/core`). In browser environments and Web Workers (such as `export.worker.ts` and `preview.worker.ts`), `process.versions?.node` evaluates to `undefined`, causing `decodeAsset()` to immediately return `null`. As a consequence, exported videos from Studio contained silent or missing audio.

Additionally, [`IRMasterRenderer.render()`](file:///c:/Users/Admin/workspace/git/acc/packages/ir/src/renderer/IRMasterRenderer.ts) executed a redundant second call to `sink.initialize()`, which in `MediabunnyClientSink` lacked an idempotency guard and wiped out the initialized MP4 output, audio sample source, and writable stream.

Finally, client export should never be coupled to preview-player caches such as `AudioAssetCache` (which is an LRU pool specifically scoped to player preview in the main thread).

## Solution
1. **First-Class `IAudioDecoder` Interface on `IMediaEngineStrategy`**:
   - Added `DecodedAudioPCM` and `IAudioDecoder` interfaces in [`packages/core-isomorphic/src/media-engine/types.ts`](file:///c:/Users/Admin/workspace/git/acc/packages/core-isomorphic/src/media-engine/types.ts).
   - Added `createAudioDecoder?(): IAudioDecoder` to `IMediaEngineStrategy`.
2. **Strategy Implementations**:
   - [`BunFFIEngineStrategy`](file:///c:/Users/Admin/workspace/git/acc/packages/core/src/media-engine/strategies/BunFFIEngineStrategy.ts): Delegates to `FFIAudioDecoder.decodeToPCM()` for zero-copy native FFI decoding in Bun.
   - [`MediabunnyServerStrategy`](file:///c:/Users/Admin/workspace/git/acc/packages/core/src/media-engine/strategies/MediabunnyServerStrategy.ts): Decodes audio via `@mediabunny/server` / `AudioSampleSink` or FFI into 48kHz stereo Float32Array PCM.
   - [`MediabunnyClientStrategy`](file:///c:/Users/Admin/workspace/git/acc/packages/core-web/src/media-engine/MediabunnyClientStrategy.ts): Decodes audio in browser/worker contexts via `AssetProtocolRegistry`, `OfflineAudioContext`, or Mediabunny `Input` + `AudioSampleSink`.
3. **Decoupled `UniversalAudioMixer`**:
   - Removed all ad-hoc Node/browser checks and inline Web Audio contexts from `UniversalAudioMixer.ts`.
   - Queries the default/active strategy directly via `MediaEngineRegistry.get()` (with asynchronous fallback).
   - Replaced flat DC offset (`0.04`) procedural fallback with audible `ProceduralAudioSynthesizer.synthBGM()` waveform.
4. **Idempotency Guard**:
   - Added `isInitialized()` and an idempotency check to [`MediabunnyClientSink.initialize()`](file:///c:/Users/Admin/workspace/git/acc/packages/core-web/src/media-engine/MediabunnyClientSink.ts) and [`IRMasterRenderer.ts`](file:///c:/Users/Admin/workspace/git/acc/packages/ir/src/renderer/IRMasterRenderer.ts).
5. **Worker Isolation**:
   - `export.worker.ts` remains completely independent from main-thread preview-player caches (`AudioAssetCache`), decoding assets deterministically on its own thread via `MediabunnyClientStrategy`.
