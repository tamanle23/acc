# History Record 334: Implement Configurable MediaEngine, OnnxModelManager, and Cross-Platform Universal ONNX Provider (Iteration 32)

## Context & Objectives
1. **Configurable MediaEngine Pipeline**:
   - Eliminate hardcoded `'bun-ffi'` references in `@acc/effect-engines/src/depth3d`, `apps/legacy-story-renderer`, and `SceneWorker`.
   - Enable runtime configuration of the video encoding engine (`bun-ffi`, `mediabunny`, `fluent-ffmpeg`, `mediabunny-client`) via config settings (`settings.mediaEngine` / `settings.engine`), CLI options (`-e, --engine <name>`), or platform auto-detection (`MediabunnyClientStrategy` on web, `BunFFIEngineStrategy` on native Node/Bun).
2. **`OnnxModelManager` in `@acc/core-isomorphic`**:
   - Create a pure isomorphic model manager centralizing ONNX model registration, metadata, and storage using `ContentCacheRegistry`.
   - On Node/Bun: resolves or stores weights using `NativeFileCacheStrategy` / project cache.
   - On Web: resolves or stores weights using `IndexedDbCacheStrategy` or URL fetch.
3. **Cross-Platform Universal ONNX Runtime Fallback Hierarchy**:
   - Resolve the fatal `MODULE_NOT_FOUND` error on macOS `x64` (`darwin/x64/onnxruntime_binding.node`) where Microsoft dropped pre-built native binaries in npm releases.
   - Hierarchy:
     - Web: Uses `onnxruntime-web` (WebGPU / WASM).
     - Node/Bun: Probes whether native `onnxruntime-node` exists. If present, runs native module. If absent (e.g. `darwin/x64`) or fails, seamlessly falls back to `transformers.web.js` (`onnxruntime-web` WASM / WebGPU). If WASM fails, gracefully degrades to mathematical heuristics (GrabCut / depth gradient) with zero unhandled exceptions.
