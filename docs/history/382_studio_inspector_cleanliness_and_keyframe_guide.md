# 382. Studio Inspector Cleanliness, Keyframe Diamond UI & Temporal Coordinate Guide

## Problem
1. **Inspector Tooltip Incompatibility**: `KeyframeDiamondButton.tsx` in `apps/studio` was using an outdated prop interface (`Tooltip content="..."`), violating Radix UI / shadcn compound component structure (`<Tooltip><TooltipTrigger asChild>...</TooltipTrigger><TooltipContent>...</TooltipContent></Tooltip>`) and causing TypeScript build errors.
2. **Missing Modifier Node Target**: `ModifierControlStrategies.tsx` instantiated a procedural audio modifier node without explicitly passing `target: 'audio'`, failing type check against `TypedModifierNode`.
3. **Keyframe Coordinate Documentation**: Architectural ambiguity between discrete `frame` (integer) and continuous `timeSec` (floating-point seconds) representation needed a formal, permanent guide in `./docs/guide/` detailing pros, cons, and trade-offs of frame vs. second storage in VideoIR.
4. **Export Test Headless Canvas Initialization**: `studio_phase3_decomposition_and_60fps.test.ts` attempted export in a headless Bun environment without a fallback canvas adapter registered, resulting in an unhandled OffscreenCanvas error.

## Plan
1. Refactor `KeyframeDiamondButton.tsx` to cleanly wrap the button in Radix compound tooltip primitives.
2. Correct the modifier node instantiation in `ModifierControlStrategies.tsx` by providing `target: 'audio'`.
3. Provide `docs/guide/VIDEO_IR_KEYFRAME_TEMPORAL_COORDINATE_GUIDE.md` detailing the pros/cons/trade-offs of Option A (`timeSec`), Option B (`frame | timeSec`), and Option C (`frame`), with migration considerations and recommended hybrid approach.
4. Ensure universal canvas adapter fallback is registered in test beforeAll hooks.
5. Verify with full test suite and production `@acc/studio` Vite build.

## Changes
- `apps/studio/src/components/inspector/KeyframeDiamondButton.tsx`: Refactored to Radix compound tooltip (`<Tooltip><TooltipTrigger asChild>{button}</TooltipTrigger><TooltipContent>...</TooltipContent></Tooltip>`).
- `apps/studio/src/components/inspector/ModifierControlStrategies.tsx`: Added `target: 'audio'` to procedural SFX modifier node.
- `docs/guide/VIDEO_IR_KEYFRAME_TEMPORAL_COORDINATE_GUIDE.md`: Created detailed architectural guide covering temporal coordinates, cross-fps scaling, audio DSP sync, and serialization.
- `autogenerated-tests/studio_phase3_decomposition_and_60fps.test.ts`: Added `UniversalCanvasProvider.registerAdapter(new NapiCanvasAdapter(), true)` in `beforeAll` for Bun headless execution parity.
