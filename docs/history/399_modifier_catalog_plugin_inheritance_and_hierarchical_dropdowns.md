# 399: AvailableModifierDef Plugin Inheritance, Hierarchical Inspector Modifiers and Multi-Domain Dropdown Effects

## Problem
In earlier iterations of Studio, modifier definitions in the inspector (`AvailableModifierDef`) were standalone presentation objects (`apps/studio/src/components/inspector/modifierCatalog.ts`) that did not formally inherit the core Video IR `ModifierPlugin` contract. Furthermore:
1. The "+ Add Effect" header dropdown in `RightSidebar.tsx` was only rendered when `currentMode === 'sequence'` and a sequence was selected (`currentMode === 'sequence' && selectedSeq`), making it impossible to attach track-level modifiers (such as `timed_text/style`) or timeline-level modifiers (such as `timeline/photometric_bloom` and `timeline/anamorphic_glare`) directly from the Studio UI.
2. The available modifiers inside the dropdown were only filtered against sequence context, ignoring whether a track or the timeline master was being inspected.
3. Track and timeline inspector panels (`TrackInspector.tsx` and `ProjectInspector.tsx`) lacked interactive modifier listing and management sections, meaning any attached track or timeline modifiers could not be viewed, enabled/disabled, parameter-tuned, or removed.

## Plan
1. **Contract Inheritance (`apps/studio/src/components/inspector/modifierCatalog.ts`)**:
   - Update `AvailableModifierDef` to extend `ModifierPlugin<Record<string, unknown>>` from `@acc/ir`, declaring `targetScope: ModifierTargetScope` and optional `allowedSequenceTypes?: readonly SequenceType[]`.
   - Update `getAvailableModifiersFromRegistry` to automatically call `registerCoreModifierPlugins(registry)` and map all registered plugins while preserving full `ModifierPlugin` lifecycle and scope properties.
2. **Context-Aware Dropdown Hierarchy & Dispatch (`apps/studio/src/components/RightSidebar.tsx`)**:
   - Compute `canAddEffect` across all three inspector modes: `sequence` (when sequence selected), `track` (when track selected), and `timeline` (master project mode).
   - Dynamically filter `relevantModifiers` via `ModifierPluginRegistry.getInstance().isModifierAllowedOnEntity(mod.type, targetContext)` based on the active entity:
     - Sequence: `{ type: 'sequence', sequenceType: selectedSeq.type }`
     - Track: `{ type: 'track' }`
     - Timeline: `{ type: 'timeline' }`
   - Dynamically compute attached status for each effect item from the corresponding active entity (`selectedSeq.modifiers`, `selectedTrack.modifiers`, or `irState.doc.modifiers`).
   - Enhance `handleAddEffect` to dispatch `IRStateManager.getInstance().addModifier(...)` targeting sequence IDs, track IDs, or `'timeline'`.
3. **Dedicated Modifier Management in Track and Project Inspectors**:
   - In `TrackInspector.tsx`: Render an accordion of attached track modifiers (`selectedTrack.modifiers`) using `DynamicModifierInspector`, with reset, remove, and active switch toggling.
   - In `ProjectInspector.tsx`: Render an accordion of attached master timeline modifiers (`irState.doc.modifiers`) using `DynamicModifierInspector`, with reset, remove, and active switch toggling.
4. **Command Architecture Verification & Tests**:
   - Author Test Vector 8 in `autogenerated-tests/modifier_targets_dynamic_sync.test.ts` verifying that `AvailableModifierDef` satisfies `ModifierPlugin`, entity-aware filtering isolates sequence, track, and timeline effects, and `UpdateModifierCommand`/`RemoveModifierCommand` correctly execute and undo timeline-level modifiers.

## Changes
- `apps/studio/src/components/inspector/modifierCatalog.ts`:
  - Extended `AvailableModifierDef` from `ModifierPlugin<Record<string, unknown>>`.
  - Added `registerCoreModifierPlugins` invocation inside `getAvailableModifiersFromRegistry`.
  - Guaranteed `targetScope` resolution across all registry and fallback catalog entries.
- `apps/studio/src/components/RightSidebar.tsx`:
  - Updated "Add Effect" dropdown trigger to show across sequence, track, and timeline inspector modes.
  - Contextually filtered available modifiers using `isModifierAllowedOnEntity(mod.type, targetContext)`.
  - Updated `handleAddEffect` to dispatch modifiers to sequence, track, or timeline.
- `apps/studio/src/components/inspector/TrackInspector.tsx`:
  - Added "Track Modifiers" accordion section rendering attached modifiers with `DynamicModifierInspector`, reset, remove, and enabled switch controls.
- `apps/studio/src/components/inspector/ProjectInspector.tsx`:
  - Added "Timeline Master Effects" accordion section rendering attached timeline modifiers with `DynamicModifierInspector`, reset, remove, and enabled switch controls.
- `apps/studio/src/lib/commands/UpdateModifierCommand.ts`:
  - Added timeline-level modifier update and undo support.
- `apps/studio/src/lib/commands/RemoveModifierCommand.ts`:
  - Added timeline-level modifier removal and undo support.
- `apps/studio/src/lib/ir/irState.ts`:
  - Resolved modifier target to `'video'` for timeline and `'text'` for `timed_text` tracks.
- `autogenerated-tests/modifier_targets_dynamic_sync.test.ts`:
  - Added Test Vector 8 covering `AvailableModifierDef` plugin inheritance, dynamic context filtering across sequence, track, and timeline, and timeline command execution with undo/redo.

## Verification
- Verified schema and plugin compliance: All available modifiers conform strictly to `ModifierPlugin` with valid `targetScope`.
- Verified context filtering:
  - Sequence mode: Sequence modifiers (`transform`, `vfx/partial`, `motion/vector_blur`) permitted; track and timeline modifiers rejected.
  - Track mode: Track modifiers (`timed_text/style`) permitted; sequence and timeline modifiers rejected.
  - Timeline mode: Timeline modifiers (`timeline/photometric_bloom`, `timeline/anamorphic_glare`) permitted; sequence and track modifiers rejected.
- Verified timeline modifier command execution and reversibility with full undo/redo state parity.

## Walkthrough
1. **Selecting a Sequence**: The "+ Add Effect" dropdown in the inspector header displays visual, motion, and transition modifiers allowed on the sequence type. Attached modifiers appear in `SequenceInspector`.
2. **Selecting a Track**: Clicking a track pill in the breadcrumbs navigates to `TrackInspector`. The "+ Add Effect" dropdown now displays track-compatible stream modifiers (e.g. `timed_text/style`). Attached track modifiers render with interactive parameter sliders.
3. **Selecting Project / Timeline**: Clicking the project pill navigates to `ProjectInspector`. The "+ Add Effect" dropdown displays master timeline effects (`timeline/photometric_bloom`, `timeline/anamorphic_glare`). Attached timeline modifiers render with live dynamic inspectors and remove/reset controls.
