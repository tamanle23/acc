# Task 416: Video IR & Modifiers Schema-First Parity, 9-Component Governance & Automation Pipeline

## Problem
`schema/modifiers.schema.json` had not been updated since October 25, 2026, leaving 35 modern modifier plugins (including all 18 Time-Space generators, timeline effects, vector blur, solid backdrop, auto-reframe, shapes, and studio-grade color wheels) without JSON Schema definitions. Additionally, `.agents/rules/01-workspace-specific.md` did not mandate automated drift prevention for modifier schemas.

## Plan
1. Synchronize `schema/modifiers.schema.json` to cover all 53 registered modifier plugins and define `ModifierTypeEnum`.
2. Reconcile `packages/ir/src/types/modifiers.ts` with color grading wheels, shapes, and complete `StandardModifierNode` union coverage.
3. Expand `packages/ir/src/schema/VideoIRSchemaValidator.ts` with deep parameter validation for modern modifier types while maintaining zero external npm dependencies.
4. Correct standalone sequence filtering in `packages/ir/src/plugins/ModifierPluginRegistry.ts`.
5. Create `scripts/generate-ir-schemas.ts` with `--check` and `--write` flags for automated drift detection in CI.
6. Create comprehensive automated verification test `autogenerated-tests/modifiers_schema_first_sync.test.ts`.
7. Update Master Rules Reference in `docs/master_rules_reference.md` (Section 14) and update `.agents/rules/01-workspace-specific.md`.
