# 380. Metadata Unified Sandbox Consolidation & Ad-Hoc Mock Pruning

### Problem
1. **Ad-Hoc Mock Platform Violation**: `apps/console/src/features/metadata/data/mock-metadata.ts` (2,148 lines) and `MetadataServiceStrategy` ran a private, ad-hoc mock store bypassing the Unified Sandbox Platform (`packages/sandbox`), violating `.agents/rules/02-unified-sandbox.md`.
2. **Dual-Mode UI Branching**: `MetadataServiceStrategy` branched between `http` and `mock` modes directly in client code, duplicating interceptor capabilities.
3. **Tenant Spoofing Vulnerability**: Tenancy was previously derived from untrusted client `X-Tenant-Id` request headers rather than the authenticated JWT principal.

### Plan
1. Extract canonical seed metadata definitions to `packages/sandbox/src/handlers/data/metadata.ts`.
2. Implement `MetadataSandboxRepository` and `metadataSandboxHandler` in `packages/sandbox/src/handlers/metadata-sandbox-handler.ts` with token-derived tenancy and state reset integration.
3. Register `metadataSandboxHandler` into `packages/sandbox/src/index.ts`.
4. Delete `apps/console/src/features/metadata/data/mock-metadata.ts` (pruning 2,148 lines) and retire `MetadataServiceStrategy` in `metadata-service.ts`.
5. Point all test suites and console re-exports to `@acc/sandbox`.
6. Add formal verification in `autogenerated-tests/metadata_unified_sandbox_parity.test.ts`.
