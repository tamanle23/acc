# 349: Refactor PreviewWorkerBridge to Options-Based Clean API

## Problem
`PreviewWorkerBridge` still had positional signatures tightly coupling `popOutIntensity`:
1. `updateTimeline(timeline, totalFrames, fps, popOutIntensity?, assets?)` forced callers to pass `undefined` as the 4th argument simply to provide `assets`.
2. `renderFrame(frame, lod, popOutIntensity?, isScrubbing, clearColor, debugMode)` forced callers to pass `undefined` for `popOutIntensity` before supplying subsequent options like `isScrubbing`, `clearColor`, or `debugMode`.

## Plan
1. Introduce `WorkerRenderOptions` interface (`lod`, `isScrubbing`, `clearColor`, `debugMode`, `popOutIntensity`).
2. Refactor `updateTimeline(timeline, totalFrames, fps, assets?)` to eliminate the unnecessary `popOutIntensity` parameter.
3. Overload `renderFrame(frame, optionsOrLod?, ...)` and `requestFrame(...)` to accept a clean options object or backward-compatible positional values.
4. Clean up `Preview.tsx` to pass options cleanly without dummy `undefined` values.

## Changes
- `apps/studio/src/lib/worker/PreviewWorkerBridge.ts`:
  - Added `WorkerRenderOptions` interface.
  - Refactored `updateTimeline` to `(timeline, totalFrames, fps, assets?)`.
  - Refactored `renderFrame` and `requestFrame` to support `(frame, options?: WorkerRenderOptions)`.
- `apps/studio/src/components/Preview.tsx`:
  - Called `bridge.updateTimeline(timeline, totalFrames, fps, assetsMap)` directly.
  - Replaced positional calls with clean options `{ lod, clearColor, debugMode }` and `{ lod, isScrubbing }`.
- `apps/studio/src/lib/worker/preview.worker.ts`:
  - Removed unused `data.popOutIntensity` from `updateTimeline` handler.
