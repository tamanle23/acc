# Task 228: Restore Robust @dnd-kit Drag-and-Drop Architecture in Studio

## Problem
An experimental migration from `@dnd-kit` to `@neodrag/react` across `apps/studio` caused critical regressions:
1. **Broken Timeline Clip Drag & Drop:** Timeline clips could not be repositioned across lanes or shifted in time.
2. **Broken Edge Trimming:** Trim handles failed to initiate edge resizing.
3. **Broken Staging Drops:** Dragging presets/assets from the sidebar onto the viewport or timeline lanes did not fire collision or drop events.
4. **Root Cause Analysis:**
   - **Stale Closure Bug in `@neodrag/core`:** The internal `draggable.update(options2)` method updates configuration properties (`axis`, `bounds`, etc.) but does *not* update `options2.onDragStart`, `options2.onDrag`, or `options2.onDragEnd`. React re-renders mutate state (`activeDragState`), causing `@neodrag`'s internal handlers to continually call stale closures from mount (`activeDragState === null`), prematurely aborting all drag and drop operations.
   - **Global Event Listener Collisions:** `@neodrag` attaches pointer event listeners to `window` rather than isolated scoped containers. In virtualized timelines with dozens of clips and trim handles, hundreds of global listeners fire concurrently, clashing with nested targets.
   - **Absence of Native Droppables & Collision Engines:** `@neodrag` is purely a transform positioner; it lacks concepts of droppable zones (`useDroppable`), collision algorithms (`rectIntersection`, `pointerWithin`), or decoupled portals (`<DragOverlay>`).

## Plan
1. Revert experimental `@neodrag/react` migration files in `apps/studio` cleanly back to the proven `@dnd-kit` implementation.
2. Remove `@neodrag/react` from `apps/studio/package.json` and reconcile `pnpm-lock.yaml`.
3. Purge orphaned migration utilities, tests, and temporary doc plans.
4. Update unit test suite `autogenerated-tests/studio_phase9_dnd_kit_architecture.test.ts` to inspect decomposed timeline and preview submodules properly.
5. Verify production Vite build and test suites pass with zero warnings or errors.
