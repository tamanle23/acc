## 1. Context & Motivation

In high-throughput, multi-worker parallel rendering and enterprise-grade environments, workloads face memory spikes, heavy AI inference loads (SAM 2, Depth Anything v2, neural TTS), external network interruptions, and hardware encoder constraints.

Prior to Phase 3:
1. Concurrency could exceed system RAM headroom, risking Out-Of-Memory (OOM) kills or NVENC driver session allocation faults.
2. Models stored in memory lacked reference counting, leaving concurrent workers vulnerable to mid-stream evictions.
3. Errors in sidecars or hardware encoders caused catastrophic pipeline failure instead of progressive degradation.
4. Failures during distributed execution left orphaned temporary chunks, uncleared cloud assets, and unrecorded diagnostic states.

## 2. Key Architecture & Implementation Changes

### 2.1 Adaptive Resource Governor (`AdaptiveResourceGovernor`)
- **File**: `packages/core/src/resilience/AdaptiveResourceGovernor.ts`
- Real-time hardware watchdog inspecting `os.freemem()`, `os.totalmem()`, and CPU core count.
- Evaluates system pressure ratios, calculates worker memory allocations ($\approx 1.2\text{ GB}$ per chunk worker), and dynamically down-throttles worker concurrency when RAM is constrained.
- Implements `yieldForBackpressure` to pause incoming frame production during critical memory spikes and allow garbage collection.
- Directly integrated into `IRChunkWorkerPool` to govern concurrency bounds before slicing timelines.

### 2.2 Reference-Counted Model Handle Registry (`ModelHandleRegistry`)
- **File**: `packages/core/src/models/ModelHandleRegistry.ts`
- Extends `FlyweightModelRegistry` with reference-counting locks (`acquireLock(id)` / `releaseLock(id)`).
- Enforces LRU model eviction (`evictLowestPriorityHandle()`) that strictly skips models with active locks ($\text{refCount} > 0$), preventing mid-stream model disposal during multi-worker chunk rendering.

### 2.3 Hierarchical Render Circuit Breakers (`RenderCircuitBreaker`)
- **File**: `packages/core/src/resilience/RenderCircuitBreaker.ts`
- Implements standard `CLOSED` $\to$ `OPEN` $\to$ `HALF_OPEN` state machine with execution timeouts and failure threshold tracking.
- Protects external AI inference calls and hardware encoders, automatically cascading to deterministic fallbacks (e.g., CUDA OOM $\to$ procedural 2D Ken Burns motion).

### 2.4 Conductor SAGA Distributed Transactions & Dead Letter Queue (DLQ)
- **File**: `packages/core/src/saga/ConductorSagaOrchestrator.ts`
- Coordinators manage multi-step pipelines with automated reverse rollback compensation (e.g., cleans up temporary disk chunks, revokes ephemeral tokens).
- Captures unrecoverable failure snapshots, error stacks, and context states into `DeadLetterQueue` for post-mortem telemetry.
