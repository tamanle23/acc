# 446. Migration of `tekgo-ui` to Astro 5 (Hybrid/SSR) + Preact + Tailwind CSS v4

## Problem
`apps/tekgo-ui` previously ran on Next.js 15 / React 19 App Router. While functional, every editorial page bundled the entire React runtime (~140KB baseline), virtual DOM reconciliation overhead, and heavy client components for simple interactive widgets (theme toggle, mobile navigation, search dialog). The application required modernization to a zero-JavaScript-by-default architecture while maintaining 100% feature parity, Liquid Glass editorial design tokens, and dynamic CMS capabilities.

## Plan
1. **Scaffolding:** Transition from Next.js to Astro 5 (Hybrid/SSR), `@astrojs/preact` with React compatibility (`compat: true`), `@tailwindcss/vite` for Tailwind CSS v4, and `@astrojs/node` standalone adapter.
2. **Layout & Anti-FOUC:** Implement `BaseLayout.astro` with inline theme resolution script, Google Space Grotesk fonts, and SEO/OpenGraph meta tags.
3. **Content Engine:** Standardize content layer with Zod schemas (`blogPostSchema`, `authorSchema`) and retain the dual-mode Service Layer (`contentProvider`) for immediate SSR dynamic webhook invalidation.
4. **Islands Boundary:** Convert static page frames and reading views to pure `.astro` templates (0 KB client JS); migrate interactive components (`ThemeSwitch`, `MobileNav`, `SearchModal`, `Comments`, `BlogFilterList`, `ScrollTopAndComment`) to Preact islands using Nano Stores for cross-island reactive state.
5. **WinterTC API Endpoints:** Implement WHATWG compliant `/api/newsletter` and `/api/revalidate` endpoints with Web Crypto HMAC-SHA256 signature verification.

## Walkthrough
1. **0 KB Editorial Prose:** Navigating to `/blog/[...slug]` renders articles entirely on the server without virtual DOM hydration scripts.
2. **Instant Theme Toggle:** Clicking the theme toggle switches between Light, Dark, and System states via Nano Stores; page reloads execute anti-FOUC script before body render.
3. **Liquid Glass Command Palette:** Hitting `Cmd+K` or clicking search opens `SearchModal.tsx`, querying `/search.json` and filtering articles in real time.
4. **WinterTC Edge Webhooks:** Revalidate endpoint cryptographically verifies HMAC-SHA256 signatures with Web Crypto `crypto.subtle` within a 300-second replay window.
