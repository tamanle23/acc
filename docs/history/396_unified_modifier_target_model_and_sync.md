# 396: Unified Modifier Target Model, Dynamic Registry Validation & 7-Package Synchronization

## 1. Problem Formulation
Following the creation of discrete spatio-temporal and particle motion plugins, the VideoIR modifier ecosystem faced several architectural scaling issues:
1. **Target Ambiguity**: Modifiers previously had ambiguous or multi-target definitions (`targetScope: 'both'`, array targets), creating confusion between modifiers that act as contextual filters on existing media versus modifiers that act as standalone procedural generators.
2. **UI Routing Friction**: Studio interface lacked deterministic rules to know which modifiers belong in the **Left Sidebar** (Asset/Element Creation Vault) versus the **Right Sidebar** (Entity Inspector).
3. **Overlay Sequence Incompatibilities**: Standalone generative sequences on transparent `type: 'overlay'` sequences could accidentally have heavy footage-centric modifiers attached (e.g. AI Depth Estimation, 3D Camera Projection, Color LUTs), leading to runtime canvas crashes.
4. **Naming Inconsistency**: `text/style` was ambiguously named despite being solely designed for subtitle/caption tracks, blocking future standalone typography overlay plugins (`text/*`).
5. **Monorepo Invariant Drift**: Full synchronization across monorepo packages was required to preserve zero-alloc render loops and bit-identical parity.

## 2. Implementation Plan
- **Phase 1: Registry Contracts & Dynamic Query APIs (`packages/ir`)**:
  - Implement `ModifierTargetScope = 'standalone' | 'sequence' | 'track' | 'timeline'`.
  - Update `ModifierPlugin` with `targetScope: ModifierTargetScope` and `allowedSequenceTypes?: readonly SequenceType[]`.
  - Implement `getAvailableModifiersForTarget()`, `getGeneratorsForLibrary()`, and `isModifierAllowedOnEntity()`.
  - Update all existing plugins with explicit `targetScope` and `allowedSequenceTypes`.
- **Phase 2: Strict Rename `text/style` $\to$ `timed_text/style` across Monorepo**:
  - Update `CaptionModifierPlugin.ts` (`type = 'timed_text/style'`, `targetScope = 'track'`).
  - Update `VideoIRSchemaValidator.ts` (deprecates/rejects `text/style`, approves `timed_text/style`).
  - Update `IRCanvasCompositor.ts`, presets, commands, and all demo documents.
  - Implement backward-compatible migration on document load in `IRStateManager`.
- **Phase 3: Studio UI Dynamic Wiring (`apps/studio`)**:
  - Wire `RightSidebar.tsx` to dynamically query available modifiers via `isModifierAllowedOnEntity()`.
  - Enforce that `'overlay'` sequences strictly allow `transform`, `overlay/blend_mode`, and transitions.
  - Wire `LeftSidebar.tsx` to surface `'standalone'` procedural generators.
- **Phase 4: Expanded Studio-Grade Plugins (`packages/ir`)**:
  - Implement `motion/vector_blur` plugin (`targetScope: 'sequence'`).
  - Implement `generator/solid_backdrop` plugin (`targetScope: 'standalone'`).
  - Implement `timeline/photometric_bloom` and `timeline/anamorphic_glare` plugins (`targetScope: 'timeline'`).
  - Register new plugins in `registerCoreModifierPlugins()`.
- **Phase 5: CLI & Cross-Package Verification**:
  - Create comprehensive formal verification test `autogenerated-tests/modifier_targets_dynamic_sync.test.ts`.

## 4. Verification
- `modifier_targets_dynamic_sync.test.ts` verified:
  1. Strict Single-Target Isolation: every plugin returns strictly one of `'standalone' | 'sequence' | 'track' | 'timeline'`.
  2. Overlay sequence isolation: querying sequence modifiers for `'overlay'` returns strictly `transform`, `overlay/blend_mode`, and transitions.
  3. `timed_text/style` rename: approves `timed_text/style` on subtitle track and rejects legacy `text/style`.
  4. Standalone generator resolution: validates solid backdrop without media asset requirement.
  5. Studio-grade plugins: executes `vector_blur`, `solid_backdrop`, `photometric_bloom`, and `anamorphic_glare` safely.
  6. Dynamic entity compatibility checker: correctly approves/rejects target placements.
