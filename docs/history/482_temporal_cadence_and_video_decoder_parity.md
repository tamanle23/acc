# 482 - Temporal Cadence Preview Worker Integration & Video Decoder Strategy Parity

## Problem
1. **Temporal Cadence Studio Preview Parity**:
   `TemporalCadenceResolver` was integrated into `IRMasterRenderer` to map timeline frame numbers to source media timestamps considering `trimInSec`, `speed`, and frame-rate conversions. However, in Studio preview (`apps/studio/src/renderer/workers/preview.worker.ts`), sequence frames were computed naively as `localFrame = Math.max(0, frame - seq.startFrame)`. As a result, trimmed or retimed clips (`trimInSec`, `speed`) did not reflect the conformed media timestamp during Studio preview and prewarming.
2. **Video Decoder Strategy Parity**:
   `FFIVideoDecoder` (the native FFI libavcodec implementation used by `BunFFIEngineStrategy`) was the sole video decoder implementing `IVideoDecoder` and `seekTimestamp`. `MediabunnyServerStrategy` did not implement `createVideoDecoder` or `seekTimestamp`, leaving an architectural asymmetry between media engine strategies.

## Plan
1. **Integrate `TemporalCadenceResolver` into Studio Web Workers**:
   - In `apps/studio/src/renderer/workers/preview.worker.ts`, resolve `cadence = TemporalCadenceResolver.resolve({ timelineFrame, timelineFps, sequenceStartFrame, trimInSec, speed })` and pass `cadence.sourceFrameIndex` to `requestSequentialFrame` and `requestFrame`.
   - In `apps/studio/src/renderer/workers/WorkerClipPrewarmer.ts`, resolve `cadence` to prewarm the true conformed hero frame rather than hardcoded frame 0.
2. **Implement `MediabunnyVideoDecoder` in `MediabunnyServerStrategy`**:
   - Create `MediabunnyVideoDecoder` implementing `IVideoDecoder` (`open()`, `close()`, `readNextFrame()`, and `seekTimestamp(targetSeconds: number)`).
   - Expose `createVideoDecoder(filePath, targetWidth, targetHeight): IVideoDecoder` on `MediabunnyServerStrategy` backed by `mediabunny.CanvasSink`.
3. **Automated Verification**:
   - Write unit tests in `autogenerated-tests/mediabunny_video_decoder.test.ts` verifying interface compliance and seek execution.
   - Run all 7 UMACE conformance test suites and execute Studio production build.

## Changes
- **`apps/studio/src/renderer/workers/preview.worker.ts`**:
  - Imported `TemporalCadenceResolver` from `@acc/ir`.
  - Replaced naive `localFrame` calculation with `TemporalCadenceResolver.resolve(...)`.
- **`apps/studio/src/renderer/workers/WorkerClipPrewarmer.ts`**:
  - Prewarms sequence hero frame derived from `TemporalCadenceResolver.resolve(...)` respecting clip `trimInSec` and `speed`.
- **`packages/core/src/media-engine/strategies/MediabunnyServerStrategy.ts`**:
  - Implemented `MediabunnyVideoDecoder` leveraging `mediabunny.CanvasSink`.
  - Added `createVideoDecoder(filePath, targetWidth, targetHeight): IVideoDecoder` factory to `MediabunnyServerStrategy`.
- **`autogenerated-tests/mediabunny_video_decoder.test.ts`**:
  - Created test suite verifying `MediabunnyVideoDecoder` and `MediabunnyServerStrategy.createVideoDecoder`.
