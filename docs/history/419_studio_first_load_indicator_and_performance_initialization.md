# 419. Studio First-Load Indicator & Performance-Tuned Initialization Sequence

## Problem
When loading `@acc/studio`, users previously experienced a blinding white flash due to [`index.html`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/index.html) having `bg-slate-50` while Vite fetched and parsed ~2.1 MB of minified JavaScript, WASM, and stylesheets. This violated Nielsen Norman Usability Heuristic #1 (Visibility of System Status), provided zero visual feedback on slow or cold connections, caused layout shift when the docked multi-panel workspace suddenly popped in, and eagerly loaded on-demand modals (`ExportConfigModal`, `ExportProgressModal`, `SettingsModal`) directly into the main entry bundle.

## Plan
1. **Pre-Hydration Splash (Tier 1)**: Embed an instant Obsidian Liquid Glass boot splash (`#app-boot-splash`) in `index.html` with critical inline CSS using strictly GPU-composited properties (`transform`, `opacity` with `will-change`) to guarantee a smooth 60 FPS animation while V8 compiles the main thread.
2. **First-Paint Synchronization (Tier 2)**: Implement `StudioBootController.ts` using a double `requestAnimationFrame` pattern to ensure the Viewport Canvas and Timeline have completed their initial paint before fading out over 400ms.
3. **Resource Pruning**: Automatically remove `#app-boot-splash` and `#boot-splash-style` from the DOM once faded out to release compositor layers.
4. **Code-Splitting via React.lazy**: Defer on-demand modals (`ExportProgressModal`, `ExportConfigModal`, `SettingsModal`) wrapped in `<Suspense fallback={null}>` in `App.tsx` to reduce initial bundle TTI.
5. **Slow-Network Progressive Telemetry**: Add non-blocking timers updating status at 5s and presenting an accessible reload recovery button at 10s.
6. **Verification**: Write unit/integration tests in `autogenerated-tests/studio_boot_splash_lifecycle.test.ts` and verify clean production build.

## Changes
- **`apps/studio/index.html`** [MODIFY]: Replaced `bg-slate-50` with `#070a13`, added critical inline `<style id="boot-splash-style">`, added `#app-boot-splash` with cinematic aperture SVG, progress shimmer rail, ARIA attributes, and slow-network fallback timer.
- **`apps/studio/src/lib/boot/StudioBootController.ts`** [NEW]: Controller managing status updates, preview worker and canvas warmup synchronization (`waitForEngineWarmup`), minimum 2.5s dwell time enforcement, double-rAF first-paint synchronization, smooth 700ms cinematic crossfade, and DOM node cleanup.
- **`apps/studio/src/renderer/PreviewWorkerCoordinator.ts`** [MODIFY]: Added `waitForWarmup(timeoutMs)` resolving when `WARMED_UP` arrives from sidecar `preview.worker.ts`.
- **`apps/studio/src/components/preview/useViewportRenderStrategy.ts`** [MODIFY]: Notifies `StudioBootController.notifyCanvasReady()` when Viewport Canvas worker is initialized.
- **`apps/studio/src/lib/playhead/PlayheadController.ts`** [NEW]: Re-export facade to maintain clean import resolution across studio components.
- **`apps/studio/src/App.tsx`** [MODIFY]: Replaced eager modal imports with `React.lazy()` wrapped in `<Suspense fallback={null}>`, connected `StudioBootController.waitForEngineWarmup()` inside `useEffect`.
- **`autogenerated-tests/studio_boot_splash_lifecycle.test.ts`** [NEW]: Formal test suite covering pre-hydration HTML/ARIA invariants, GPU compositor keyframes, reduced motion rules, double-rAF controller lifecycle, worker warmup orchestration, and modal code-splitting.
