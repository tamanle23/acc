# History Entry 384: Frontend-Backend API Contract & Zero-`any` Synchronization (Iteration 52 Phase 2)

## Problem & Context
During Iteration 52 review of `@acc/console`:
1. In `apps/console/src/features/workflow-executions/api/use-workflow-executions.ts`, queries used untyped `get<any>`, and all 6 mutation error callbacks used `onError: (err: any)`.
2. In `apps/console/src/features/workflows/api/workflow-api.ts`, 6 mutation error callbacks used `onError: (err: any)`.
3. In `apps/console/src/features/metadata/api/use-billing.ts`, DTO interfaces (`TenantBillingSummary`, `QuotaUsage`, `VatInvoiceInfo`, `BillingTransaction`) were duplicated locally rather than imported from `@acc/client` shared contracts.

## Plan
1. Create enterprise error utility `apps/console/src/core/utils/error-extractor.ts` providing `getErrorMessage(err)` and `ApiErrorResponse`.
2. Refactor `use-workflow-executions.ts`:
   - Replace `springApiClient.get<any>` with typed `springApiClient.get<WorkflowExecution[]>`.
   - Explicitly type all `onError` callbacks with `AxiosError<ApiErrorResponse> | Error` and `getErrorMessage(err)`.
3. Refactor `workflow-api.ts`:
   - Replace all 6 `onError: (err: any)` handlers with typed callbacks and `getErrorMessage(err)`.
4. Refactor `use-billing.ts`:
   - Re-export `TenantBillingSummary`, `QuotaUsage`, `VatInvoiceInfo`, `BillingTransaction`, `SubscriptionTier`, `CreatePaymentLinkPayload`, and `CheckoutResponse` from `@acc/client`.
5. Implement formal verification suite in `autogenerated-tests/console_api_contract_typing.test.ts`.

## Changes Completed
- Created:
  - `apps/console/src/core/utils/error-extractor.ts`: `getErrorMessage(err)` and `ApiErrorResponse`.
  - `autogenerated-tests/console_api_contract_typing.test.ts`: Formal assertions for zero `any`, typed queries, and contract imports.
- Refactored:
  - `apps/console/src/features/workflow-executions/api/use-workflow-executions.ts`: Typed query contract and typed mutation error callbacks.
  - `apps/console/src/features/workflows/api/workflow-api.ts`: Typed mutation error callbacks.
  - `apps/console/src/features/metadata/api/use-billing.ts`: Re-exported contracts from `@acc/client`.

  - Zero instances of `get<any>` or `onError: (err: any)` exist in workflow execution and definition hooks.

  - `getErrorMessage` safely resolves error messages from Axios responses and Error instances.
