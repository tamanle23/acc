# 421. Transform Gizmo Studio-Grade Elevation & Dynamic Bounds Alignment

## Problem
In Studio viewport manipulation, the interactive transform gizmo overlay (`TransformGizmoOverlay.tsx` and `useGizmoTransform.ts`) suffered from three fundamental alignment and usability deficiencies:
1. **Target Boundary Mismatch**: The gizmo bounding box was hardcoded to a static 50% width and 50% height (`0.5` norm dimensions), failing to wrap the actual geometry of target text overlays, vector badges, shapes, or media clips.
2. **Clip-Space Translation & Origin Drift**: In `TextModifierPlugin`, an artificial `if (!hasPrecedingTransform)` check skipped translating to `(originX, originY)` when a sequence had an accompanying transform modifier. Consequently, text was drawn at `(0, 0)` clip space while the gizmo was drawn at the authored `(normX, normY)` position. Furthermore, `TransformModifierPlugin` defaulted rotation and scale anchors to canvas center `(0.5, 0.5)` instead of the object's authored center, causing wide orbital rotation.
3. **Absence of Pro NLE HUD & Precision Controls**: The overlay lacked essential NLE feedback: no center pivot reticle, no live floating telemetry badge (displaying live `X/Y`, `W/H`, `Scale`, `Angle`), and no keyboard micro-nudging (1px with arrow keys, 10px with Shift+Arrow, Delete, Escape).

## Plan
1. **Coordinate System & Plugin Centering**:
   - Update `TextModifierPlugin.ts` to always apply `canvasCtx.translate(originX, originY)` in clip space.
   - Update `TransformModifierPlugin.ts` to anchor transforms around `params.normX` and `params.normY` (falling back to `anchorPoint` or `0.5`).
2. **Dynamic Sequence Bounding Box Resolution**:
   - Update `CanvasHitTester.ts` to export `resolveSequenceBounds(seq, width, height, paddingPx = 8)`.
   - Calculate exact bounds for `text/draw`, `shape/draw`, `timed_text/style`, and media clips.
3. **Gizmo Transformation Hook Modernization**:
   - Update `useGizmoTransform.ts` to use real sequence bounding boxes.
   - Add telemetry state (`mode`, `deltaX`, `deltaY`, `widthPx`, `heightPx`, `scale`, `rotation`, `activeGuides`).
   - Implement keyboard listeners for 1px arrow nudges, 10px Shift+Arrow nudges, Delete/Backspace, and Escape.
4. **TransformGizmoOverlay UI/UX Polish**:
   - Position and size the gizmo using dynamic `${bounds.normWidth * 100}%` and `${bounds.normHeight * 100}%`.
   - Add a center pivot reticle crosshair (`+`).
   - Add a floating live telemetry HUD pill.
   - Refine corner and edge handles with Liquid Glass styling and specular highlights.
5. **Formal Verification**:
   - Write comprehensive unit tests in `autogenerated-tests/studio_transform_gizmo_bounds.test.ts`.
   - Run tests, check schema drift (`scripts/generate-ir-schemas.ts --check`), and execute production Vite build.

## Changes
- **`packages/ir/src/plugins/text/TextModifierPlugin.ts`**:
  - Removed conditional branch that omitted translation when a transform modifier was present.
- **`packages/ir/src/plugins/transform/TransformModifierPlugin.ts`**:
  - Dynamically resolved `anchorNormX` and `anchorNormY` from `params.normX` and `params.normY`.
  - Added directional scaling support via `params.scaleX` and `params.scaleY`.
- **`apps/studio/src/lib/hit-test/CanvasHitTester.ts`**:
  - Added `SequenceBounds` interface.
  - Implemented and exported `CanvasHitTester.resolveSequenceBounds(seq, canvasWidth, canvasHeight, paddingPx = 8)`.
  - Refactored `resolveSequenceRegion` to delegate to `resolveSequenceBounds`.
- **`apps/studio/src/components/preview/useGizmoTransform.ts`**:
  - Replaced hardcoded `baseW = 0.5, baseH = 0.5` with dynamic `targetBounds` from `CanvasHitTester`.
  - Added `lockAspectRatio` handling (uniform corner scaling; 1D edge stretching; center-origin scaling with Alt).
  - Added live `telemetry` state and keyboard listeners for 1px/10px nudging, deletion, and deselection.
- **`apps/studio/src/components/preview/TransformGizmoOverlay.tsx`**:
  - Applied dynamic bounding box dimensions.
  - Rendered Center Pivot Reticle Crosshair (`+`).
  - Rendered Floating Live Telemetry HUD Badge (`POS`, `SIZE`, `ANGLE`, `SNAP`).
- **`apps/studio/src/components/Preview.tsx`**:
  - Wired `telemetry={gizmo.telemetry}` and `targetBounds={gizmo.targetBounds}` into `TransformGizmoOverlay`.
- **`autogenerated-tests/studio_transform_gizmo_bounds.test.ts`**:
  - Created test suite validating bounds resolution, padding, off-center presets, transform anchoring, and Pro NLE handle scaling.
