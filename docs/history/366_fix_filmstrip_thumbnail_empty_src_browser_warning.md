# 366. Fix FilmstripThumbnail Empty src Attribute Browser Warning

## Problem
In `@acc/studio`, the console reports:
```text
FilmstripThumbnail.tsx:30 An empty string ("") was passed to the src attribute. This may cause the browser to download the whole page again over the network. To fix this, either do not render the element at all or pass null to src instead of an empty string.
```

### Root Cause Analysis
1. **Unconditional DOM Rendering in [`FilmstripThumbnail.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/timeline/FilmstripThumbnail.tsx)**:
   When `thumbUrl` is `""` (empty string) or invalid, the component still rendered `<img src={thumbUrl} />`, resulting in `<img src="" />`. Under HTML / browser standards and React 18/19, setting `src=""` on an `<img>` causes the browser to attempt to reload the current page document over the network and emits a warning.
2. **Scratch Canvas `toDataURL` Incompatibility in Browser Runtime**:
   [`AssetTextureCache.getThumbnailDataUrl()`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/lib/textures/AssetTextureCache.ts) acquired scratch canvases from `UniversalCanvasProvider.acquireScratchCanvas()`. In modern browsers, `WebCanvasAdapter` provisions `OffscreenCanvas` instances, which do not implement `.toDataURL()` synchronously (they only offer async `convertToBlob()`). Because `typeof raw.toDataURL === 'function'` evaluated to false and no exception was thrown, `dataUrl` remained `""` and never fell back to `getTextureCanvas()`, causing `getThumbnailDataUrl()` to continuously return `""` in the browser client.

## Plan
1. In [`FilmstripThumbnail.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/timeline/FilmstripThumbnail.tsx):
   - Return `null` when `thumbUrl` is null, empty string, or whitespace, preventing any empty `<img>` tags or unnecessary slice DOM allocations.
2. In [`AssetTextureCache.ts`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/lib/textures/AssetTextureCache.ts):
   - Sanitize `assetId` and safe dimensions (`Math.max(1, ...)`).
   - Add explicit fallback to `getTextureCanvas(assetId, ...)` if scratch canvas does not implement `.toDataURL()`.
3. In [`autogenerated-tests/studio_texture_cache.test.ts`](file:///c:/Users/Admin/workspace/git/acc/autogenerated-tests/studio_texture_cache.test.ts):
   - Add unit test verifying empty or whitespace asset IDs return `""` cleanly and safely without throwing.
