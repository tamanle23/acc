# 425 - Fix Anchor Point Pivot Rotation and Scaling in Transform Modifier & Viewport Gizmo

## Problem
Even when changing `anchorPoint` (e.g. from the center `[0.5, 0.5]` to a corner `[0.0, 0.0]` or edge `[0.0, 0.5]` via the Viewport interactive Anchor tool or Inspector), rotating the object still rotated around its geometric center.

Investigation revealed three interconnected issues:
1. **TransformModifierPlugin Canvas Render Disconnect**:
   In `TransformModifierPlugin.renderClipSpace`, the canvas anchor was hardcoded to `anchorNormX = baseNormX` and `anchorNormY = baseNormY` (the center of the object), completely ignoring `params.anchorPoint`.
2. **TransformGizmoOverlay CSS transformOrigin Omission**:
   In `TransformGizmoOverlay.tsx`, the overlay box used `transform: translate(-50%, -50%) scale(...) rotate(...)` without defining `transformOrigin`. In CSS, `transformOrigin` defaults to `50% 50%` (center), pinning rotation strictly around the box center regardless of `anchorPoint`.
3. **Gizmo Drag Calculation**:
   `Gizmo2DTransformation.computeDragTransform` calculated the rotation angle relative to `startBox.x, startBox.y` (the box center) without factoring in the anchor offset.

## Solution
1. **Canvas Pivot Calculation (`TransformModifierPlugin.ts`)**:
   - Resolved normalized pivot coordinates:
     $$pivotNormX = baseNormX + (\text{anchor}[0] - 0.5) \times normW$$
     $$pivotNormY = baseNormY + (\text{anchor}[1] - 0.5) \times normH$$
   - Shifted matrix transformation: `translate(pivotX + motion.x, pivotY + motion.y)` -> `rotate(...)` -> `scale(...)` -> `translate(-pivotX, -pivotY)`.
2. **Dynamic CSS transformOrigin (`TransformGizmoOverlay.tsx`)**:
   - Calculated `pivotPercentX` and `pivotPercentY` from object bounds and `anchorPoint`.
   - Set `transformOrigin: `${anchor[0] * 100}% ${anchor[1] * 100}%``.
   - Positioned container with `left: pivotPercentX%`, `top: pivotPercentY%`, and `transform: translate(${-anchor[0] * 100}%, ${-anchor[1] * 100}%) scale(...) rotate(...)`.
3. **Rotation Handle Drag Math (`Gizmo2DTransformation.ts`)**:
   - Added `anchorPoint` support to `computeDragTransform`, computing `Math.atan2` relative to the rotated pivot pin.
4. **Transform State Synchronization (`useGizmoTransform.ts`)**:
   - Forwarded `anchorPoint`, `normWidth`, and `normHeight` to both ephemeral overrides and persistent `updateModifier` calls.
