# Task 229: Fix InvalidStateError Detached Image in Studio Preview Worker & Compositor

## Problem
During video playback and playhead scrubbing in Studio Preview (`apps/studio/src/workers/preview.worker.ts`), the preview worker crashed with:
```
preview.worker.ts:129 [preview.worker] Render error at frame 214 InvalidStateError: Failed to execute 'drawImage' on 'OffscreenCanvasRenderingContext2D': The image source is detached
    at IRCanvasCompositor.renderTrackSequences (IRCanvasCompositor.ts:450:19)
    at IRCanvasCompositor.renderFrame (IRCanvasCompositor.ts:178:28)
    at IRPreviewEngine.renderFrame (IRPreviewEngine.ts:137:24)
    at renderCurrentFrame (preview.worker.ts:123:12)
    at self.onmessage (preview.worker.ts:287:7)
```

## Root Cause Analysis
1. `PreviewFrameMemoryManager` and `MediabunnyWorkerReader` aggressively evict older/distant video frames using LRU and window-bounding (`pruneOutsideWindow`).
2. When a frame was evicted, `bitmap.close()` was executed synchronously.
3. Because video decoding, prewarming, and user scrubbing happen asynchronously in the worker, frames were being closed while an active or queued render pass had already referenced them in `textureCache`.
4. In Web APIs, calling `ImageBitmap.close()` detaches the underlying graphic buffer and sets `width` and `height` to `0`. Passing a closed/detached bitmap to `ctx.drawImage()` triggers `DOMException: InvalidStateError: The image source is detached`.

## Changes
1. **`packages/ir/src/renderer/shared/IRCanvasCompositor.ts`**:
   - Added pre-draw validation ensuring `rawAsset.width > 0 && rawAsset.height > 0`.
   - Wrapped `ctx.drawImage` in a `try/catch` block with neutral placeholder fallback to prevent any detached bitmap from crashing the render pipeline.
2. **`apps/studio/src/workers/MediabunnyWorkerReader.ts` & `PreviewFrameMemoryManager.ts`**:
   - Deferred `bitmap.close()` by 50ms using `setTimeout` so in-flight compositor draw passes finish safely before GPU resources are released.
3. **`apps/studio/src/workers/preview.worker.ts`**:
   - Added dimension validation before populating `textureCache`. If a cached bitmap is found detached, a fresh decode request is dispatched.
