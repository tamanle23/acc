# 215: Refactor CLI Subcommands & Interactive Wizard with @clack/prompts

## Context & Objectives
Refactored the CLI entrypoint (`apps/cli/src/index.ts`) and subcommands (`apps/cli/src/commands/sfx.ts`, `apps/cli/src/commands/studio.ts`, `apps/cli/src/commands/overlay.ts`, `apps/cli/src/commands/ir-render.ts`) using `@clack/prompts` and created a dedicated shared prompt utility module:

1. **Clean Separation of Concerns**:
   - Kept `@clack/prompts` strictly for interactive wizards and interactive CLI entrypoints (`acc` with zero args, `acc overlay` wizard, `acc sfx` wizard).
   - Preserved fast, structured, quiet telemetry via `Logger` for non-interactive / headless CI commands.

2. **Legacy Core Interactive Elimination**:
   - Completely deleted `packages/core/src/interactive.ts` and its re-export from `packages/core/src/index.ts`.
   - Removed legacy `askChoice`, `askQuestion`, `askYesNo`, and `closeInteractiveConsole` across the monorepo.

3. **Shared CLI Prompts Utility Module (`apps/cli/src/prompts.ts`)**:
   - Implemented `guardCancel<T>()` asserting against Clack cancel symbols and cleanly invoking `cancel()` with `process.exit(0)`.
   - Implemented strongly typed `promptSelect<T>()`, `promptText()`, `promptPath()`, `promptNumber()`, and `promptConfirm()`.

4. **Subcommand Standardization & Registry Path Resolution**:
   - Refactored `sfx.ts` with typed options, dynamic model selection, and duration input validation.
   - Refactored `overlay.ts` with typed options, dynamic effect selection, and resolved generator module paths in `effects-registry.json`.
   - Refactored `studio.ts` with interactive path fallback, status notes (`note()`), and graceful `SIGINT`/`SIGTERM` signal handlers.
   - Refactored `ir-render.ts` with path resolution, diagnostic error logging, and preserved OpenTelemetry tracing spans.

5. **Automated Verification**:
   - Created `autogenerated-tests/cli_prompts_architecture.test.ts`.
   - Verified 100% green tests across existing CLI suites (`cli_interactive_ux.test.ts`, `phase6_unified_cli.test.ts`).
   - Verified zero unauthorized native import boundary leaks via `bun run scripts/check-native-imports.ts`.
