## 1. Context & Motivation
Following the completion of the Media Prober Chain (Phase 1), Classifier Strategies (Phase 2), PipelineIR Builder & Director Preset Factory (Phase 3), and Legacy Bridge Adapter (Phase 4), the system needed a single, cohesive **Facade** (`AutoConfigEngineFacade`) that encapsulates the complete end-to-end scaffolding workflow for both headless and interactive callers. Additionally, the root `auto-config.ts` CLI required modernization into an intuitive terminal experience powered by `@clack/prompts` that supports dual file emission (`pipeline-ir.json`, `omnichannel-config.json`, and `story-config.json`).

## 2. Technical Implementation
1. **`AutoConfigEngineFacade` (GoF Facade Pattern) in `packages/core/src/autoconfig/AutoConfigEngineFacade.ts`**:
   - `inspectDirectory(dirPath)`: Non-destructive probing and archetype scoring for interactive previews.
   - `scaffoldDirectory(dirPath, options)`: Orchestrates the entire pipeline:
     - Media asset discovery via `MediaAssetProberChain`.
     - Archetype classification via `PipelineClassifierRegistry`.
     - Universal AST construction via `PipelineIRBuilder` (v3.0.0).
     - Fine-grained director configuration synthesis via `DirectorPresetFactory`.
     - Legacy `story-config.json` adaptation via `AutoConfigLegacyBridgeAdapter`.
     - File emission to target directory: `pipeline-ir.json`, `omnichannel-config.json`, and `story-config.json` (with dry-run support).
     - Automatic title preservation when re-scaffolding existing workspaces with `story-config.json`.
2. **Modernized Interactive CLI (`auto-config.ts`)**:
   - Powered by `@clack/prompts` with dynamic spinners, informative discovery summaries, and interactive selection.
   - Supports non-interactive automated execution via `-y` / `--yes`.
   - CLI flags: `--pipeline`, `--aspect`, `--fps`, `--depth`, `--transitions`, `--dry-run`.
   - Outputs step-by-step guidance on how to render deliverables with `bun run cli.ts`.
3. **Exports & Types**:
   - Re-exported `AutoConfigEngineFacade` via `packages/core/src/autoconfig/index.ts` and `@acc/core`.
