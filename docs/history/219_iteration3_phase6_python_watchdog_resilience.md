# 219: Master Integration Plan (Iteration 3) Phase 6: Python Backend Resilience & Watchdog

## Overview & Context
Implements enterprise-grade daemon resilience, PID file management, cross-platform parent process watchdog monitoring, and standard `grpc.health.v1` health check servicer for the Python AI subsystem (`apps/ai-supervisor/python-backend`).

Strictly satisfies Iteration 3's Zero-Crash / Zero-Zombie Guarantee:
- If the parent process (`apps/ai-supervisor` or host process) terminates or crashes, the background watchdog thread auto-terminates the Python child daemon immediately, preventing orphaned zombie processes.
- PID file management tracks active daemon PIDs and auto-heals stale locks.
- Standardized gRPC health check servicer (`grpc_health.v1`) exposes real-time `SERVING` status to `@acc/core`'s `IPCFacade` and the Electrobun Supervisor.

---

## Key Implementations

1. **`apps/ai-supervisor/python-backend/src/watchdog.py`**:
   - `PIDManager`: Manages `.acc-python.pid` in `~/.acc/`, writes PID on startup, cleans up on exit, and detects stale dead locks.
   - `is_pid_alive(pid)`: Native cross-platform alive check (Windows `ctypes.windll.kernel32.OpenProcess` with exit code verification, Linux/macOS `os.kill(pid, 0)`).
   - `start_parent_watchdog(parent_pid, poll_interval_sec, on_terminate)`: Spawns a daemon thread monitoring `parent_pid` every 1.0s. If the parent dies, triggers graceful cleanup and terminates immediately.

2. **`apps/ai-supervisor/python-backend/src/server.py`**:
   - Integrated `grpc_health.v1.health.HealthServicer` registering `SERVING` status for root and individual AI services (`acc.v1.TTSService`, `acc.v1.VisionService`, `acc.v1.LLMService`).
   - Signal trapping: Intercepts `SIGINT`, `SIGTERM`, and Windows `SIGBREAK` for clean server stopping (`grace=1.0s`) and PID file removal.
   - CLI & Environment support: Parses `--parent-pid` argument or `ACC_PARENT_PID` environment variable.

3. **`apps/ai-supervisor/src/bun/SupervisorEngine.ts`**:
   - Injected `ACC_PARENT_PID: String(process.pid)` into `execEnv` when spawning the Python backend daemon via `uv run`.

4. **Dependencies**:
   - Added `grpcio-health-checking>=1.84.0` to `apps/ai-supervisor/python-backend/pyproject.toml`.
