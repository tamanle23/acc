# History Log 138: Add Workspace Rule for Zero-Alloc Frame Loop and Native FFI Memory Invariance

- **Task**: Establish an immutable workspace agent rule banning per-frame heap allocations, buffer clones, and JS array allocations in native FFI frame loops.
- **Date**: 2026-10-04
- **Branch**: `main`

---

## 1. Context & Problem
During high-concurrency 1080x1920 (TikTok) rendering across 6 workers, Bun experienced a memory explosion to 4.19GB and crashed with a segmentation fault (`0x2ACB8B60000`).
While an earlier fix (commit `069`) had introduced pre-allocated C memory pointers (`this.srcDataC`) to avoid segfaults, a later commit (`e57226c`) accidentally reintroduced `Buffer.from(rgbaBuffer)` and nursery heap typed arrays (`BigUint64Array`, `Int32Array`) directly inside `encodeRgbaFrame()`.

Because video rendering processes tens of thousands of frames at 8.3 MB/frame:
- Duplicating or cloning raw frames on the JS heap floods garbage collection with >1.5 GB/s of churn per process.
- Passing temporary JS heap typed array pointers to long-running native C functions (like `sws_scale`) risks pointers becoming invalid if Bun's nursery garbage collector relocates heap memory during execution.
- Repeating phrase splitting regex calculations inside per-frame subtitle rendering compounds nursery allocation churn.

To ensure this pattern is never reintroduced during future refactorings, an explicit, permanent rule is required in both the master rules reference and the workspace-specific agent guidelines.

## 3. Changes Made
- **`docs/master_rules_reference.md`**:
  - Added Section 14: `Zero-Allocation Frame Loop & Native FFI Memory Invariance Protocol (ZERO-ALLOC-FRAME-LOOP)`.
  - Defined explicit rules regarding raw buffer passing via `ptr(rgbaBuffer)`, pre-allocated native C memory structures via `av_malloc`, frame-invariant subtitle snapshot caching via `WeakMap`, and concurrency heap budgets.
- **`.agents/rules/01-workspace-specific.md`**:
  - Appended `- **ZERO-ALLOC-FRAME-LOOP**` constraint enforcing:
    1. Zero buffer clones (`Buffer.from(rgbaBuffer)` strictly banned; pass `ptr(rgbaBuffer)` directly).
    2. Pre-allocated native C memory (`av_malloc`) for FFI pointer arrays (`srcDataC`, `srcStrideC`), banning per-frame nursery JS typed array allocations.
    3. Structural phrase/regex caching across frames (e.g., `WeakMap`).
