## 1. Context & Motivation
Direct usage of raw `spawn(...)` calls was previously dispersed across multiple core files in `@acc/ai-supervisor`:
- `WindowHost.ts`
- `NativeTrayBridge.ts`
- `StartupManager.ts`
- `HardwareProfiler.ts`
- `OllamaManager.ts`

This created primitive obsession, tight coupling to Node/Bun OS child process mechanics, inconsistent buffer and error handling, and potential orphaned zombie processes.

Additionally, in `ThemeSwitcher.tsx`, the responsive Tailwind utility `hidden sm:inline` prevented the theme label from appearing on compact or default webview window dimensions.

---

## 2. Architectural Design & Implementation

### A. Infrastructure Layer: Platform Process Runner
Created [`apps/ai-supervisor/src/bun/platform/IProcessRunner.ts`](file:///Users/anle/workspace/acc/apps/ai-supervisor/src/bun/platform/IProcessRunner.ts) and [`BunProcessRunner.ts`](file:///Users/anle/workspace/acc/apps/ai-supervisor/src/bun/platform/BunProcessRunner.ts):
- **Structured Lifecycle**: Central tracking of active child processes with automatic cleanup on `SIGINT`, `SIGTERM`, and `beforeExit`.
- **Result Pattern**: Returns `Result<ProcessOutput, ProcessError>` avoiding uncaught runtime rejections.
- **Path Resolution**: Provides cached and OS-normalized `which(tool)` lookups.

### B. Polymorphic Presentation Strategies (`IWindowStrategy`)
Refactored [`WindowHost.ts`](file:///Users/anle/workspace/acc/apps/ai-supervisor/src/bun/WindowHost.ts) into a Composite Facade delegating to modular strategy classes:
- `MacWKWebViewStrategy`: Mach-O helper invoking native WebKit.
- `WindowsWebView2Strategy`: Windows Form + WebView2 control via PowerShell.
- `LinuxWebKit2Strategy`: PyGObject WebKit2GTK wrapper.
- `ChromiumAppModeStrategy`: Cross-platform `--app` mode launcher for Chromium/Chrome/Edge/Brave.
- `DefaultBrowserStrategy`: Universal fallback opening the system browser.

### C. Polymorphic System Tray Strategies (`ITrayStrategy`)
Refactored [`NativeTrayBridge.ts`](file:///Users/anle/workspace/acc/apps/ai-supervisor/src/bun/NativeTrayBridge.ts) into a clean facade delegating to:
- `MacNativeTrayStrategy`: Mach-O NSStatusBar runner.
- `LinuxAppIndicatorTrayStrategy`: AppIndicator3/Gtk3 runner.
- `WindowsPoshTrayStrategy`: WinForms NotifyIcon runner.

### D. Core Service Purge of Raw `spawn`
- Refactored `HardwareProfiler.ts` (`sysctl`, `nvidia-smi`) to execute via `IProcessRunner`.
- Refactored `StartupManager.ts` (`launchctl`, `powershell`) to execute via `IProcessRunner`.
- Refactored `OllamaManager.ts` to discover `ollama` via `runner.which()`.

### E. ThemeSwitcher UI Visibility
- In `ThemeSwitcher.tsx`:
  - Removed `hidden sm:inline` to ensure theme preset name is always visible.
  - Added explicit testids (`data-testid="theme-switcher"`, `data-testid="theme-switcher-button"`, `data-testid="theme-dropdown"`).
  - Rebuilt production UI bundle with `bun run build:ui`.
