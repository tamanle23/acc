# 394: Advanced Spatio-Temporal Generators & Studio Multi-Domain Showcase

## 1. Problem Formulation
Following the decomposition of the monolithic `time_space` plugin in Iteration 53, the visual effects engine needed expansion into higher-order mathematical, scientific, and artistic generative capabilities:
1. **Mathematical Scope**: Need for advanced non-linear generative effects including standing acoustic cymatics (Chladni plates), chaotic strange attractors (Clifford / De Jong), relativistic black hole singularities with Doppler beaming, multi-octave topographic contours, hyperbolic Poincaré disk tessellations, and multi-pendulum kinetic harmonographs.
2. **Deterministic Time-Space Conformance**: All generators must adhere to the `TimeSpaceStateMachine` invariant: zero mutable cross-frame state, zero `Math.random()`, seeded deterministic noise, and seamless responsiveness to `space.toPixels(...)`.
3. **Studio Demonstration Coverage**: Studio required dedicated production showcase projects to demonstrate these new effects in realistic scientific, educational, and cinematic contexts, expanding beyond the 4 existing demo projects.

## 2. Implementation Plan
- **Phase 1**: Implement 6 mathematical generator factories in `packages/core-isomorphic/src/math/time-space/TimeSpaceRegistry.ts`:
  - `cymatic_chladni`: High-order Chladni standing acoustic waves.
  - `strange_attractor`: Clifford and De Jong chaotic iterative maps.
  - `relativistic_blackhole`: Kerr gravitational lensing, Einstein rings, and Doppler beaming.
  - `topographic_contour`: Multi-octave curl turbulence isolines.
  - `hyperbolic_poincare`: Poincaré disk conformal Möbius tessellations.
  - `kinetic_harmonograph`: Damped 4-pendulum Lissajous epicycles.
- **Phase 2**: Implement 6 discrete 1:1 modifier plugins under `packages/ir/src/plugins/time-space/` inheriting from `BaseTimeSpacePlugin<TParams>`, export via barrel, and register in `registerCoreModifierPlugins`.
- **Phase 3**: Synchronize `VideoIR` types in `packages/ir/src/types/modifiers.ts` and runtime schema validation in `packages/ir/src/schema/VideoIRSchemaValidator.ts`.
- **Phase 4**: Expose all 6 plugins in Studio Inspector (`modifierCatalog.ts`), create 2 production showcase demo projects (`quantumPhysicsDemoIR.ts`, `astroTelemetryDemoIR.ts`), and expand the template switcher in `irState.ts` and `Titlebar.tsx`.
- **Phase 5**: Create comprehensive verification test suite `autogenerated-tests/advanced_timespace_generators.test.ts`.
