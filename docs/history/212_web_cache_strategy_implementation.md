# Task: WebCacheStrategy Implementation Using Web Cache API Standard

## Problem
In client-side web, Service Worker, and Web Worker environments, caching binary video chunks, AI model weights, images, and audio buffers can benefit from the standard Web Cache API (`window.caches` / `self.caches` / `CacheStorage`) alongside `IndexedDbCacheStrategy`. The application needed an enterprise-grade `WebCacheStrategy` adhering to the `IContentCacheStrategy` strategy pattern contract.

## Plan
1. Inspect `IContentCacheStrategy` contract in `@acc/core-isomorphic` and existing reference `IndexedDbCacheStrategy.ts`.
2. Implement [`WebCacheStrategy.ts`](file:///c:/Users/Admin/workspace/git/acc/packages/core-web/src/cache/WebCacheStrategy.ts) implementing `IContentCacheStrategy`:
   - Configurable `cacheName` and `baseUrlPrefix`.
   - Access to `caches` / `window.caches` / `self.caches`.
   - Maps storage keys to standard HTTP `Request` URLs (`${baseUrlPrefix}/${encodeURIComponent(key)}`).
   - Persists data as standard `Response` objects with metadata headers (`Content-Type`, `Content-Length`, `x-acc-checksum`, `x-acc-created-at`, `x-acc-meta-json`).
   - Non-destructive `ArrayBuffer` slice handling to prevent detached buffer mutations.
   - Graceful fallback in-memory cache for SSR, test environments, or restricted permissions.
   - Implementation of `has`, `get`, `set`, `delete`, `clear`, and `getKeys`.
3. Export `WebCacheStrategy` from `packages/core-web/src/cache/index.ts` and `packages/core-web/src/index.ts`. Register in `bootstrapClient()`.
4. Create rigorous formal test suite in [`autogenerated-tests/web_cache_strategy.test.ts`](file:///c:/Users/Admin/workspace/git/acc/autogenerated-tests/web_cache_strategy.test.ts) covering fallback memory mode, simulated Web Cache API environment, Response headers serialization, and `ContentCacheRegistry` interoperability.
