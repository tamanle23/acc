## Context & Objectives
As part of Iteration 7, ACC eliminated Three.js (`three`, `@types/three`) and all WebGL shader context overhead. Three.js added over 600 KB to the client bundle and introduced WebGL initialization latency. The objective was to transition to a high-performance, isomorphic 2D/2.5D visual engine powered by **GSAP** and **Pts.js**:
- **Client Side (`apps/studio`)**: Operates on standard HTML5 Canvas 2D (`CanvasRenderingContext2D`).
- **Server Side (`@acc/effect-engines`)**: Operates on `@napi-rs/canvas`.
- **Deterministic Time Stepping**: GSAP ticker is paused; all animations, particle fields, and procedural HUDs are evaluated deterministically via frame math (`timeline.seek(timeSec)` where `timeSec = currentFrame / fps`).
