# History Entry 093: Turborepo Monorepo Unified CLI Documentation & Subcommand Router

## Problem
Following the architectural migration to a Turborepo + Bun Workspaces monorepo (`packages/core`, `packages/ir`, `packages/effect-engines`, `packages/exporters`, `packages/proto`, `apps/cli`, `apps/python-backend`), the user documentation (`README.md`) and project guides did not reflect the new Unified CLI v3.0 capabilities, subcommands (`run`, `stream`, `serve`, `list`, `overlay`, `sfx`), the 6 canonical multi-pipeline engines, or how to invoke them across the monorepo.

## Plan
1. Create dedicated, comprehensive manual `docs/CLI_GUIDE.md` detailing:
   - Monorepo package architecture & Turborepo tasks (`turbo run test`, `turbo run build`).
   - Unified CLI command reference (`run`, `stream`, `serve`, `list`, `overlay`, `sfx`, `auto-config`, legacy shorthand).
   - 6 Canonical Pipelines overview with I/O matrices & exporter channels.
   - Comprehensive flags reference table and practical recipe cheatsheet.
2. Update root `README.md` to showcase the unified architecture, CLI commands, and links to all technical specifications.
3. Wire `overlay` and `sfx` subcommands directly into `apps/cli/src/index.ts` and root `cli.ts` for unified entrypoint dispatch.
4. Add convenience scripts (`"cli"`, `"overlay"`, `"sfx"`) into root `package.json`.
5. Verify test suite across all 16 test files.
