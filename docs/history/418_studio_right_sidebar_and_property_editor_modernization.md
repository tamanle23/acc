# 418. Studio RightSidebar & Dynamic Property Inspector Modernization

## Problem
[`RightSidebar.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/RightSidebar.tsx) is the central inspector hub of `@acc/studio`. It had accumulated monolithic technical debt, spanning 362 lines and violating the strict `< 350 lines` architectural limit enforced by `studio_inspector_ux_improvements.test.ts`. Furthermore, it lacked studio-grade precision controls (virtual scrubbers, math expression evaluation), real-time parameter filtering, modifier execution stack reordering, and suffered from a clunky nested dropdown UX for discovering and adding modifiers.

## Plan
1. **Architectural Decomposition**: Break down `RightSidebar.tsx` into modular single-responsibility components under `apps/studio/src/components/inspector/` targeting $< 250$ lines.
2. **Virtual Scrubber & Math Evaluation**: Implement `ScrubbableNumberInput.tsx` with horizontal click-drag scrubbing (Shift 10x, Alt 0.1x), AST/safe arithmetic evaluation, and double-click reset.
3. **Searchable Modifier Command Palette**: Implement `ModifierAddPicker.tsx` with popover search, category pills, tags, and attached status.
4. **Real-Time Property Filter**: Implement `PropertySearchFilter.tsx` to search parameters across all open modifier accordions.
5. **Modifier Execution Reordering & Card Header**: Implement `ReorderModifierCommand.ts`, wire into `IRStateManager`, and create `ModifierCardHeader.tsx` strictly adhering to Rule 229.
6. **Keyframe Indicator**: Implement `KeyframeAnchor.tsx` and integrate with `NumberControlStrategy`.
7. **Verification**: Write comprehensive automated unit/integration tests and verify all existing suites pass.
