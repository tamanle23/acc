# 404. 3D LUT Pipeline Integration & Tetrahedral Color Grading

## 1. Problem Statement
The monorepo contained initial standalone implementations of `.cube` parsing and generation (`packages/ir/src/plugins/lut/CubeParser.ts` and `LutCubeGenerator.ts`), but they were orphaned from the live media rendering pipeline:
1. `ColorGradingPlugin.ts` and `ColorGradingEngine.ts` only applied basic CSS filters (`contrast`, `saturation`, `exposure`), lacking pixel-level 3D LUT transformation.
2. Demo projects (`cinemaMasteringDemoIR.ts`, etc.) declared LUT references (`lut: 'cool_steel'`, `'bleach_bypass'`, `'warm_golden'`), but they had no runtime execution engine to resolve presets into color transforms.
3. No declarative select schema existed in `ColorGradingPlugin` to expose LUT presets to the studio inspector.
4. `@acc/effect-engines` must remain decoupled from `@acc/ir` to prevent circular dependencies.

## 2. Plan & Architecture
1. **Tetrahedral Color Interpolation (`LutApplicator.ts`)**:
   - Implement the Sakamoto tetrahedral interpolation algorithm over 3D LUT grids (`Float32Array`).
   - Deliver industry-standard 6-tetrahedron volumetric interpolation matching DaVinci Resolve and Adobe Premiere color precision.
2. **Preset Resolution & Persistent Caching (`LutPresetRegistry.ts`)**:
   - Map all 8 canonical LUT presets (`teal_and_orange`, `kodak_2383`, `bleach_bypass`, `sci_fi_moody`, `light_and_airy`, `cyberpunk`, `vintage_faded`, `monochrome_noir`) plus studio aliases (`warm_golden`, `cool_steel`).
   - Integrate with `ContentCacheRegistry.namespace(CacheNamespace.VFX)` to cache baked `Float32Array` buffers as Blobs, amortizing generation costs to $O(1)$ across sequential frames.
3. **Circular-Dependency-Free Engine Integration (`ColorGradingEngine.ts`)**:
   - Extend `ColorGradingEngine` in `@acc/effect-engines` with `applyLutToCanvas(...)`.
   - Embed internal tetrahedral interpolation so `@acc/effect-engines` operates independently of `@acc/ir`.
4. **Declarative Schema & Inspector Binding (`ColorGradingPlugin.ts` & `modifierCatalog.ts`)**:
   - Update `ColorGradingPlugin.schema.fields.lut` with type `'select'` populated with all presets.
   - Upgrade `renderClipSpace` and `renderMasterComposite` to asynchronous pipelines that resolve LUT presets and execute `applyLutToCanvas`.
   - Update studio `modifierCatalog.ts` with default `lut: ''`.
5. **Formal Verification Suite**:
   - Create comprehensive test suite `autogenerated-tests/lut_colorgrading_integration.test.ts` verifying all presets, tetrahedral accuracy, identity invariant, monochrome invariant, FFmpeg filter generation, and Inspector schema options.
