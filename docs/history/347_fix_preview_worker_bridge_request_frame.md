# 347: Fix Preview Worker Bridge requestFrame TypeError

## Problem
When `StudioSidecarCoordinator` fired `onModifierWarmed`, `Preview.tsx` invoked `bridge.requestFrame(playhead?.currentFrame || 0)`. However, `PreviewWorkerBridge` only implemented `renderFrame(...)`, leading to:
`TypeError: bridge.requestFrame is not a function at Preview.tsx:231:16`.

## Plan
1. Add `requestFrame` method alias to `PreviewWorkerBridge` that calls `this.renderFrame(...)`.
2. Update `Preview.tsx` to call `bridge.renderFrame(playhead?.currentFrame || 0)`.
3. Verify with unit tests and production build.

- `apps/studio/src/lib/worker/PreviewWorkerBridge.ts`: Added `requestFrame(frame, lod, popOutIntensity, isScrubbing, clearColor, debugMode)` method aliasing `renderFrame`.
