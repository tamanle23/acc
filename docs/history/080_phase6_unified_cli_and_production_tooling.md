# History Entry 080: Phase 6: Unified CLI Dispatcher & Production Tooling

## Problem
Following the completion of all 6 multi-pipeline engines (Scraper/Summarizer, DB Templating, Repurposing Recycler, Generative Storyteller, Rule & Math Logic, and Ambient Stream) and the branching Exporter suite (Video, Audio, Social, Static Web), the system lacked a unified top-level command-line interface. Users needed a standardized way to execute any pipeline, initiate 24/7 RTMP live streams, spawn webhook ingestion daemons, or query available pipelines while maintaining 100% backward compatibility for legacy workflows like `bun run cli.ts ./sample-story`.

## Plan
1. Implement Unified CLI Router in `apps/cli/src/index.ts`:
   - `acc run <pipeline_id> [--config <file>] [--exporters <comma-list>] [--out <dir>]`: Runs any of the 6 canonical pipelines and formats multi-channel outputs.
   - `acc stream <pipeline_id> --rtmp <url> [--config <file>] [--duration <sec>]`: Dispatches real-time RTMP stream with YouTube-compliant GOP and clock pacing.
   - `acc serve [--port <number>]`: Launches the high-performance Bun.serve webhook listener daemon.
   - `acc list`: Displays registry of all 6 pipelines and supported export channels.
   - `acc help`: Prints comprehensive CLI manual and usage guide.
2. Enhance `AmbientStreamPipeline.ts`:
   - Implement `renderProceduralFrame(config, frameIndex, fps)` for per-frame procedural canvas generation.
   - Implement `streamToRtmp(rtmpUrl, config, maxFrames)` using zero-process `FFIVideoEncoder` + `RtmpLiveStreamEncodingStrategy`.
3. Update root `cli.ts`:
   - Route CLI subcommands (`run`, `stream`, `serve`, `list`, `help`) directly to `apps/cli/src/index.ts`.
   - Preserve legacy path input fallback (`bun run cli.ts ./sample-story`) with 100% zero-regression behavior.
4. Add comprehensive test suite in `autogenerated-tests/phase6_unified_cli.test.ts`.
5. Verify with full 9-suite regression test and baseline `sample-story` video render.
