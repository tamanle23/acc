# 237: Timeline Sequences Drag-and-Drop Optimization (@dnd-kit)

## Problem Statement
In `@acc/studio`, timeline sequence and trimming manipulation via `@dnd-kit` needed optimization against production standards:
1. **Sensor Hygiene & False Drag Activations**:
   The `PointerSensor` was configured with a minimal `3px` distance constraint. On high-DPI displays or during quick clicks on sequence sub-elements (transition blocks, split razor cut triggers, A/V unlink toggles), micro-mouse movements would occasionally trigger an unwanted drag lifecycle rather than registering clicks.
2. **Transform & Transition Lag**:
   Active clip items in the lane retained CSS `transition-all`, causing them to lag behind rapid pointer movements during drag-out and drop. Furthermore, `<ClipDragProxy>` lacked explicit GPU rasterization hints (`will-change: transform`).
3. **Collision Strategy & Event Frequency**:
   `TimelineDom`'s `DndContext` omitted explicit collision detection, relying on default rectangle intersections. High-frequency pointer move events (up to 144Hz - 240Hz) synchronously executed full snap calculations, guideline emissions, and React state updates on every event.

## Applied Architecture & Changes

1. **Sensor Hygiene & Click Preservation (`apps/studio/src/components/timeline/TimelineDom.tsx`)**:
   - Upgraded `PointerSensor` activation constraint from `distance: 3` to `distance: 5` (`activationConstraint: { distance: 5 }`).
   - Kept `KeyboardSensor` intentionally omitted on timeline sequence manipulation to preserve global NLE playback and navigation shortcuts (Space, Arrow keys, J-K-L).
2. **Transform & Transition Optimization (`apps/studio/src/components/timeline/ClipItem.tsx` & `ClipDragProxy.tsx`)**:
   - In `ClipItem.tsx`, dynamically set `transition-none` when `isBeingDragged` is active, avoiding positional animation latency.
   - In `ClipDragProxy.tsx`, added `willChange: 'transform'` to accelerate GPU compositing in the elevated portal overlay.
3. **Collision Strategy & rAF Throttling (`apps/studio/src/components/timeline/TimelineDom.tsx`)**:
   - Added `collisionDetection={pointerWithin}` to `DndContext` for responsive vertical track hit testing.
   - Throttled `handleDragMove` using `requestAnimationFrame` with a cleanup hook on unmount and drag end. This batches snap math and React state updates to at most once per display refresh frame.
4. **Stable Identifiers Verified**:
   - Confirmed all draggables and droppables use stable primitive identifiers: `clip-${seq.id}`, `trim-${handle}-${seq.id}`, and `track-${track.id}`.
