# 242. Studio Phase 9: Unified @dnd-kit Architecture (Replacing Manual Drag-and-Drop Movement Boilerplate in Timeline & Preview)

## Context & Problem
Previously, drag-and-drop interactions in Studio suffered from fragmented implementation strategies:
1. **Timeline Manual Drag Boilerplate**: Interactive clip trimming relied on manual `window.addEventListener('mousemove')` and `window.addEventListener('mouseup')` handlers. Furthermore, clips lacked direct manipulation to shift along time or migrate across multi-track lanes.
2. **Preview Canvas Manual Drag Boilerplate**: The 2D bounding box and 8-point handles relied on manual `handleMouseMove` and `window.addEventListener('mouseup')` event tracking with window listeners.
3. **Missing Command Pattern Support for Sequence Movement**: `IRStateManager` lacked a `MoveSequenceCommand` to record, execute, and undo/redo sequence moves and cross-track lane migration.

## Implementation Details

1. **`MoveSequenceCommand` & State Management (`apps/studio/src/lib/`)**:
   - Implemented `MoveSequenceCommand.ts` (implements `ICommand`), enabling horizontal time shifting and cross-track lane transfers in `VideoIRDocument`.
   - Records `previousTrackId` and `previousStartFrame` for 100% exact undo restoration.
   - Added command merging (`tryMerge`) for rapid consecutive moves of the same sequence.
   - Added `moveSequence` to `IRStateManager.ts`.

2. **Declarative Multi-Track Timeline Direct Manipulation (`apps/studio/src/components/Timeline.tsx`)**:
   - Replaced manual `window.addEventListener('mousemove')` and `window.addEventListener('mouseup')` event boilerplate with `@dnd-kit/core`.
   - Built modular sub-components:
     - `TrimHandle`: Left and right clip handles as `useDraggable({ id: 'trim-...' })` with magnetic snap calculations.
     - `TimelineClipItem`: Clips as `useDraggable({ id: 'clip-...' })` with live visual displacement and activation constraints protecting single clicks and razor cut mode.
     - `DroppableTrackLane`: Track rows as `useDroppable({ id: 'track-...' })` with hover highlight states.
   - Implemented magnetic snapping to playhead and adjacent clips with overlap collision prevention.

3. **In-Canvas 2D Vector Transform Overlay (`apps/studio/src/components/Preview.tsx`)**:
   - Replaced manual window listeners with an isolated `@dnd-kit` `DndContext`.
   - Built modular sub-components:
     - `TransformBodyDraggable`: The bounding box body as a draggable element.
     - `TransformHandle`: 8 corner/edge resize handles and top rotation stalk as `useDraggable`.
   - Live GSAP transform updates and magnetic guidelines during `onDragMove`, persisting to VideoIR on `onDragEnd`.
