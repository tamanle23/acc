# 296: Studio UI & Tailwind v4 Consistent Theming Integration

## Context & Objectives
Integration of `@acc/studio` liquid glass theme system with Tailwind CSS v4 design tokens and normalization of styling across all studio interface components ([`apps/studio/src/index.css`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/index.css), [`apps/studio/src/lib/theme/ThemeProvider.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/lib/theme/ThemeProvider.tsx), Titlebar, LeftSidebar, RightSidebar, Preview, Timeline, and UI primitives).

## Summary of Changes
1. **Tailwind v4 Token Decoupling**:
   - In [`apps/studio/src/index.css`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/index.css), defined an `@theme` block exposing semantic color tokens (`--color-background`, `--color-foreground`, `--color-card`, `--color-muted`, `--color-primary`, `--color-accent-theme`, `--color-accent-glow`, `--color-glass-surface`, `--color-glass-border`, `--color-glass-border-highlight`).
   - Added custom variants `@custom-variant glass-cyber`, `glass-frosted`, and `glass-specular` to enable optical glass declarative styling.
   - Synchronized `[data-accent="..."]` with shadcn `--primary` and `--ring` variables across all 5 accents (cyan, violet, emerald, amber, rose).
2. **ThemeProvider State & Lifecycle**:
   - Updated [`ThemeProvider.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/lib/theme/ThemeProvider.tsx) to automatically synchronize `document.documentElement.style.colorScheme` with `preferences.mode`, ensuring native scrollbars and controls honor the active theme.
   - Exported `ACCENT_CONFIGS` as an SSOT dictionary mapping accent colors to labels, hexes, and HSL tokens.
3. **UI Component Normalization**:
   - Extended [`Button`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/ui/button.tsx) and [`Badge`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/ui/badge.tsx) with semantic `accent` and `glass` variants.
   - Replaced over 70 hardcoded `slate-*`, `indigo-*`, and arbitrary variable bracket notation instances with semantic tokens (`bg-card`, `bg-muted`, `border-border`, `text-muted-foreground`, `bg-accent-theme`) across [`Titlebar.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/Titlebar.tsx), [`LeftSidebar.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/LeftSidebar.tsx), [`RightSidebar.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/RightSidebar.tsx), [`Sidebar.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/Sidebar.tsx), [`Preview.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/Preview.tsx), [`Timeline.tsx`](file:///c:/Users/Admin/workspace/git/acc/apps/studio/src/components/Timeline.tsx), and sub-inspectors.
