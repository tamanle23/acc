# 🏛️ History Log: [115] Burn Captions & Subtitles on Video / B-Roll Scenes

## 1. Problem Statement
In `sample-story/story-config.json`, the B-Roll video scene (`assets/b-roll-nature.mp4`) had full word-level captions configured, but when rendering the video, no captions were displayed on the video scene.

Investigation revealed two root causes:
1. **Captions Discarded in `FFISceneEngine.renderScene`**: For video scenes (`hasVideo === true`), `scene.captions` and `config.settings.captions` were omitted from the parameters passed to `renderVideoScene`.
2. **Direct Frame Encoding Without Overlay**: `renderVideoScene` decoded packets via libavcodec and directly called `encoder.encodeRawFrame(frame, srcW, srcH, srcFmt)`, bypassing canvas subtitle rendering.

---

## 2. Implementation Plan
1. **Parameter Passing**:
   - Update `FFISceneEngine.renderScene` to forward `scene.captions` and `config.settings.captions` to `renderVideoScene`.
2. **In-Memory Frame Compositing & Subtitle Burning**:
   - In `renderVideoScene`, when captions are present:
     - Allocate a native RGBA `AVFrame` via `FFI.avutil.av_frame_alloc` and `FFI.avutil.av_frame_get_buffer`.
     - Initialize `swscale` to convert decoded frames (`srcW, srcH, srcFmt`) directly to `(width, height, AV_PIX_FMT_RGBA)`.
     - Map native memory to Skia Canvas `ImageData` using zero-copy `toArrayBuffer`.
     - Overlay synchronized frame captions using `drawCanvasCaptions(ctx, captions, timeSec, captionSettings, width, height)`.
     - Encode composited frames via `encoder.encodeRgbaFrame(canvas.data())`.
3. **Looping & Fast Path**:
   - Maintain fast direct `encodeRawFrame` for video scenes without captions.
   - Support seamless looping via `av_seek_frame` and `avcodec_flush_buffers` if the video duration is shorter than the scene audio.
4. **Verification**:
   - Add formal unit test `autogenerated-tests/video_scene_captions.test.ts` covering both captioned and raw video scenes.
   - Run complete test suite (133 tests).

---

## 3. Changes Made
- **`packages/core/src/ffmpeg-ffi/index.ts`**:
  - Added `avcodec_flush_buffers` to `avcodec` bindings.
  - Added `av_seek_frame` to `avformat` bindings.
- **`packages/core/src/ffmpeg-ffi/FFISceneEngine.ts`**:
  - Added `ImageData` and `Structs` imports.
  - Updated `renderScene` to pass `captions` and `captionSettings` to `renderVideoScene`.
  - Implemented RGBA AVFrame decoding, canvas image rendering, `drawCanvasCaptions` overlay, and looping in `renderVideoScene`.
- **`autogenerated-tests/video_scene_captions.test.ts`**:
  - Created persistent tests for video scenes with and without captions.

## 5. Walkthrough
1. When a scene specifies `"video": "assets/b-roll-nature.mp4"` with `"captions": [...]`:
2. `FFISceneEngine.renderScene` receives the scene and config.
3. `renderVideoScene` decodes each video frame, converts it to RGBA in native memory, places it on the canvas, applies styled karaoke/active-word captions, and encodes the frame.
4. If captions are empty, it uses the zero-copy hardware raw frame path for maximum encoding speed.
