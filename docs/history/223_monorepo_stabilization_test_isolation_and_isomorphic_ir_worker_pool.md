# 223: Monorepo Stabilization, Test Suite Isolation & Isomorphic IR Worker Pool

**Target Systems:**
- `@acc/core` (`packages/core/src/media-engine`, `packages/core/src/ir-server`, `packages/core/src/FFmpegManager.ts`, `packages/core/src/index.ts`)
- `@acc/core-isomorphic` (`packages/core-isomorphic/src/crypto`, `packages/core-isomorphic/src/index.ts`)
- `@acc/ir` (`packages/ir/src/server`, `packages/ir/src/renderer/IRMasterRenderer.ts`)
- `autogenerated-tests/` (`inspect_packets.test.ts`, `ai_supervisor_sse.test.ts`, `enterprise_parallel_chunking.test.ts`, `chunk_worker_pool_parity.test.ts`, `enterprise_tier5_chaos_hardening.test.ts`)

---

## 1. Problem Statement
1. Cleanup in recent iterations removed `packages/core/src/media-engine/types.ts`, breaking relative imports (`../types`) across media-engine sinks and strategies in `@acc/core`.
2. `inspect_packets.test.ts` attempted to open a non-existent file (`Dinosaur_Story_125.mp4`), returning error `-2` and passing `0n` directly to `avformat_find_stream_info(0n, 0n)`, triggering a native segfault (`0x210`) inside `avformat-63.dll` on Windows.
3. Tests importing `../packages/ir/src/server` (`IRChunkWorkerPool`, `IRMasterRenderer`) failed because `IRChunkWorkerPool` had platform-dependent imports (`fs`, `path`, `os`, `crypto`) and resided only in `packages/core/src/ir-server`.
4. `ai_supervisor_sse.test.ts` failed on Windows because `MockProcessRunner` only simulated Unix `ps` commands, returning empty responses for Windows PowerShell `Get-Process` sampling.
5. In `IRMasterRenderer.ts`, an undeclared `AssetType` identifier caused runtime `ReferenceError` during timeline asset preloading.

---

## 2. Changes Made
1. **Direct Media-Engine Imports**:
   - Migrated `FFIVideoEncoderSink.ts`, `FluentPipeVideoSink.ts`, `MediabunnyServerSink.ts`, `MediabunnyServerStrategy.ts`, and `FFIVideoDecoder.ts` to import directly from `@acc/core-isomorphic`.
   - Re-exported `@acc/core-isomorphic` from `packages/core/src/media-engine/index.ts`.
2. **Universal Hasher in `@acc/core-isomorphic`**:
   - Implemented `UniversalHasher` in `packages/core-isomorphic/src/crypto/UniversalHasher.ts` dynamically using Node crypto on server runtimes and WebCrypto Subtle in browser/worker environments.
3. **Isomorphic `IRChunkWorkerPool` in `@acc/ir`**:
   - Authored `packages/ir/src/server/IRChunkWorkerPool.ts` completely free of static `fs`, `path`, `os`, or `crypto` imports, using `ContentCacheRegistry`, isomorphic path helpers, dynamic concurrency detection, and `UniversalHasher`.
   - Created `packages/ir/src/server/index.ts` re-exporting `IRMasterRenderer`, `IRChunkWorkerPool`, and `FFIChunkConcatMuxer`.
   - Re-exported `@acc/ir/server` from `packages/core/src/ir-server/index.ts`.
4. **Inspect Packets Segfault Prevention**:
   - Created a verified fixture `autogenerated-tests/fixtures/test_sample.mp4`.
   - Added assertions verifying `ret === 0` and `inCtx !== 0n` in `inspect_packets.test.ts` before probing stream info.
5. **AI Supervisor OS Process Sampler**:
   - Updated `MockProcessRunner` in `autogenerated-tests/ai_supervisor_sse.test.ts` to handle both `Get-Process` (Windows) and `ps` (Unix).
6. **FFmpegManager Resilient Local Probing**:
   - Enhanced `FFmpegManager.getBinDir()` to auto-probe `~/.acc/bin/ffmpeg-shared` if already unpacked on disk.
7. **IRMasterRenderer Asset Type Fix**:
   - Corrected `assetDef.type === 'image' || assetDef.type === 'video'` in `IRMasterRenderer.ts`.
