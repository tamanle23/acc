# 220. Isomorphic Platform & Feature Detection with Synchronized Registry Defaults

## Problem Statement
Prior to this task, registry defaults in `@acc/core-isomorphic`, `@acc/core-web`, and `@acc/core` were either statically hardcoded (such as `MediaEngineRegistry` defaulting to `'bun-ffi'`, which fails on pure Node.js) or inconsistently resolved without runtime capability probing. Furthermore, `UniversalCanvasProvider` and `MediaEngineRegistry` operated independently, risking mismatched pairings (such as server engines running with browser canvas adapters or failing during private browsing).

## Solution Plan & Implementation
1. **Isomorphic Platform Detection (`@acc/core-isomorphic/src/platform/`)**:
   - Implemented `RuntimeEnvironment` (`Bun`, `Node`, `Browser`, `WebWorker`, `Unknown`) and `OperatingSystem` (`Windows`, `MacOS`, `Linux`, `IOS`, `Android`, `Unknown`) TypeScript enums for strict compile-time and runtime type-safety.
   - Defined `RuntimeCapabilities` (`hasBunFFI`, `hasFileSystem`, `hasIndexedDb`, `hasWebCache`, `hasWebCodecs`).
   - Built `PlatformDetector` to probe the host environment across `process.platform`, `process.versions`, `navigator.userAgentData`, `navigator.userAgent`, and browser storage APIs (`caches`, `indexedDB`).
2. **Synchronized Resolvers**:
   - `resolveDefaultCanvasAdapter()`: Maps Browser/WebWorker to `'web'` and Bun/Node to `'node'`.
   - `resolveDefaultMediaEngine()`: Maps Bun to `'bun-ffi'`, Browser/WebWorker to `'mediabunny-client'`, and Node.js to `'mediabunny-server'`.
   - `resolveDefaultCacheStrategy()`: Probes server vs client capabilities, selecting `'native-file'` on servers and `'indexeddb'` / `'web-cache'` / `'memory'` on clients.
3. **Registry & Bootstrap Integration**:
   - `UniversalCanvasProvider.detectEnvironment()` delegates directly to `PlatformDetector.resolveDefaultCanvasAdapter()`.
   - `MediaEngineRegistry.reset()` initializes default media engine via `PlatformDetector.resolveDefaultMediaEngine()`.
   - `bootstrapClient()` in `@acc/core-web`: Registers `WebCanvasAdapter` and sets `MediabunnyClientStrategy` as active default engine, and resiliently configures client cache defaults.
   - `bootstrapNode()` in `@acc/core`: Automatically resolves `options.defaultMediaEngine || PlatformDetector.resolveDefaultMediaEngine()` and sets `NativeFileCacheStrategy` as default cache.
4. **Integration Master Plan & Verification**:
   - Documented the full architecture in `docs/integration_master_plan_iteration26.md`.
   - Implemented unit and simulation tests in `autogenerated-tests/platform_detector.test.ts`.
