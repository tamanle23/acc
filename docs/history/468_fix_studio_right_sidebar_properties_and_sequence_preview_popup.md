# 468. Fix Studio RightSidebar Property Modifications and Sequence Preview Popup Positioning

## Problem
Following the migration of `@acc/studio` to SolidJS, users encountered two blocking UI/UX issues:
1. **Property Modification in RightSidebar**:
   Editing parameters in `SequenceInspector.tsx` or `DynamicModifierInspector.tsx` caused active inputs and sliders to lose focus and pointer capture immediately. Modifying a number, color, or slider triggered document cloning in `UpdateModifierCommand` (`JSON.parse(JSON.stringify(doc))`), generating brand-new object references. Because `<For each={filteredModifiers()}>` reconciled items strictly by referential equality (`===`), every edit destroyed the entire accordion item and parameter control DOM tree, breaking interactive scrubbing and typing.
2. **Timeline Sequence Preview Popup Mispositioning**:
   In `apps/studio/src/components/ui/hover-card.tsx`, `HoverCardTrigger` enforced `display: contents` via `class="contents"`. In the CSS box model, an element with `display: contents` generates no box in the layout tree, causing `getBoundingClientRect()` to evaluate to `{ x: 0, y: 0, width: 0, height: 0, top: 0, left: 0 }`. Kobalte's Floating UI engine was forced to anchor the popup (`ClipInsightCard`) at `(0, 0)`—the top-left corner of the window—rather than centering it over the hovered sequence on the timeline.

## Plan
1. **Fix HoverCard Trigger & Sequence Preview Popup Positioning**:
   - Eliminate `display: contents` (`class="contents"`) from `hover-card.tsx`.
   - Transform `ClipHoverHUD` into a polymorphic container that renders `HoverCardTrigger as="div"` directly as the physical clip element, merging `@dnd-kit/solid` draggable refs, physical `leftPx`/`widthPx` coordinates, and styling.
2. **Fix Modifier List DOM Churn in `SequenceInspector.tsx`, `TrackInspector.tsx`, and `ProjectInspector.tsx`**:
   - Replace `<For each={...}>` with `<Index each={...}>` across modifier accordion lists. In `<Index>`, items are indexed by position and receive reactive accessors, preventing DOM node disposal and recreation during document state updates.
3. **Stabilize Schema Entries in `DynamicModifierInspector.tsx`**:
   - Reconcile schema fields by stable string keys (`schemaFieldKeys()`) rather than re-allocating transient `[fieldKey, descriptor]` array tuples on every reactive pass.
4. **Synchronize Timing Properties**:
   - Direct timing inputs in `SequenceInspector.tsx` to read `seq().time` directly, preventing stale asynchronous DAG compilation states from reverting live inputs.
5. **Formal Verification**:
   - Create `autogenerated-tests/studio_right_sidebar_properties_and_popup.test.ts`.
   - Run full studio test suite (`bun test`) and verify production build (`pnpm --filter @acc/studio build`).

## Changes
- `apps/studio/src/components/ui/hover-card.tsx`:
  - Removed `local.asChild && "contents"` from `HoverCardTrigger`.
  - Configured `HoverCardContent` with standard `sideOffset={8}`.
- `apps/studio/src/components/timeline/ClipHoverHUD.tsx`:
  - Refactored `ClipHoverHUD` to forward all container attributes (`ref`, `style`, `class`, `onClick`, `onMouseEnter`, `onMouseLeave`) directly to `HoverCardTrigger as="div"`.
- `apps/studio/src/components/timeline/ClipItem.tsx`:
  - Bound `draggable.ref`, physical coordinates (`left: ${leftPx()}px; width: ${widthPx()}px`), and badges directly to `ClipHoverHUD`, removing redundant wrapper divs.
- `apps/studio/src/components/inspector/SequenceInspector.tsx`:
  - Replaced `<For each={filteredModifiers()}>` with `<Index each={filteredModifiers()}>`.
  - Updated timing accessors (`currentStartNumber`, `currentDurationNumber`, `resolvedStartFrame`, `resolvedDurationFrames`) to read reactive `currentSeqTime()` directly.
- `apps/studio/src/components/inspector/DynamicModifierInspector.tsx`:
  - Replaced transient tuple allocation with `schemaFieldKeys`, `extraRuntimeKeys`, and `fallbackParamKeys` string lists reconciled by value.

  - Replaced `<For each={track().modifiers}>` with `<Index each={track().modifiers}>`.
- `apps/studio/src/components/inspector/ProjectInspector.tsx`:
  - Replaced `<For each={props.irState.doc.modifiers}>` with `<Index each={props.irState.doc.modifiers}>`.

  - Exported both `ClipInsightCard` function and named alias.
