# Task 500: Complete Migration from python-backend to ai-control-plane

## Problem Statement
The monorepo previously relied on `apps/python-backend` (a Python gRPC service on port 50051) for TTS, audio synthesis, and LLM utilities, with tightly coupled gRPC protocol buffers (`packages/proto`), direct IPC facades (`IPCFacade` and `PythonBackend` in `packages/core`), and gRPC-specific stream consumers in `apps/worker`. 

The objective was to completely eliminate `apps/python-backend` without fallback, decommission `packages/proto`, strip all AI generation and IPC baggage from `packages/core` (returning it to a pure native media foundation), and standardize all AI inference communication onto `apps/ai-control-plane` (FastAPI HTTP port 50051) via the modern `@acc/ai-control-plane-sdk`.

## Architecture Plan & Decisions
1. **SDK Standardization**:
   - Renamed SDK package to `@acc/ai-control-plane-sdk` across the monorepo.
   - Updated `AIInferenceClient` constructor to support flexible base URLs (defaulting to port 50051) and multi-backend fallbacks.
   - Guaranteed all consumer services route inference through `AIInferenceClient` (no raw fetch/socket calls or bypasses).

2. **Core AI Purge**:
   - Removed `src/ai-backend/` (`PythonBackend.ts` and Python worker scripts) from `packages/core`.
   - Removed `src/ipc/` (`IPCFacade.ts`) from `packages/core`.
   - Removed AI sound effect generators from `packages/core/src/effects/sound-effects/generators/ai/`.
   - Extracted shared fauna sound definitions to `faunaDictionary.ts` so `GenericLibrary.ts` operates autonomously without AI dependencies.

3. **Fleet & Worker Orchestration**:
   - Replaced gRPC dependencies in `apps/worker` (`@grpc/grpc-js`, `@grpc/proto-loader`, `@acc/proto`).
   - Replaced `PythonBackendAdapter` with `AIControlPlaneAdapter` implementing `IBackendAdapter` with capabilities `['tts', 'llm', 'vram-purge', 'vision', 'diffusion']`.
   - Updated `SupervisorEngine` to govern the consolidated fleet: `["ai-control-plane", "worker", "studio"]` on HTTP port 50051.
   - Removed legacy `PythonGrpcStreamConsumer`; wired telemetry via `DomainTelemetryPoller` utilizing `AIInferenceClient.fetchHealth()`.
   - Updated `configStore` from `pythonPort` to `aiControlPlanePort`.

4. **UI Apps & Tooling**:
   - Updated `apps/supervisor-desktop` (types, console tabs, fleet cards, and telemetry cards) from `python-backend` to `ai-control-plane`.
   - Updated `apps/studio` telemetry companion card to inspect `ai-control-plane`.
   - Updated CLI pipelines (`apps/cli`) and `apps/legacy-story-renderer` to use `AIInferenceClient`.

5. **Deletions**:
   - Permanently deleted `apps/python-backend/`.
   - Permanently deleted `packages/proto/`.
   - Removed obsolete gRPC and Python watchdog autogenerated tests.

## Key Changes
- `packages/ai-control-plane-sdk/`: Renamed to `@acc/ai-control-plane-sdk`; added flexible options/baseUrl handling and fallback ports; built and verified.
