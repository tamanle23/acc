# 477. Fix Sidecar Worker Single Warmup Dispatch & Passive Barrier

## Problem
During studio application boot, the console repeatedly logged `"Sidecar worker successfully warmed up."` twice.
Root-cause analysis uncovered dual asynchronous drivers racing to trigger worker warmup:
1. `initWorker()` in `PreviewWorkerCoordinator.ts` called `scheduleWarmup()`, which scheduled a deferred callback via `requestIdleCallback` (or 100ms `setTimeout`).
2. Almost simultaneously during the boot sequence, `StudioBootController.waitForEngineWarmup()` invoked `coordinator.waitForWarmup()`.
3. `waitForWarmup()` unconditionally invoked `this.warmup()`, dispatching the first `{ type: 'WARMUP' }` message to the worker.
4. Because there was no in-flight guard (`isWarmingUp`), when the idle callback / timeout fired 100-1000ms later while the worker was still asynchronously initializing vision models, it checked `if (this.worker && !this.isWarmedUp)` and dispatched a *second* `{ type: 'WARMUP' }` message.
5. The worker processed both messages sequentially and returned two `WARMED_UP` responses, logging twice.
6. Silent message drops in response handlers were rejected per architectural invariants; the root dispatch authority had to be unified.

## Plan
- Make `initWorker()` the sole driver initiating warmup immediately upon worker creation.
- Eliminate `scheduleWarmup()` entirely to remove background timer/idle callback races.
- Convert `waitForWarmup()` into a passive Promise barrier by removing its active `this.warmup()` call.
- Add `isWarmingUp` state tracking and enforce an in-flight guard inside `warmup()`.
- In `handleWorkerMessage('WARMED_UP')`, reset `isWarmingUp = false`, set `isWarmedUp = true`, notify resolvers, and log `Logger.warn` if a duplicate response is ever received.

## Changes
- `apps/studio/src/renderer/PreviewWorkerCoordinator.ts`:
  - Added `private isWarmingUp = false;` and `public getIsWarmingUp(): boolean`.
  - Replaced `this.scheduleWarmup()` with direct `this.warmup()` in `initWorker()`.
  - Removed `scheduleWarmup()` method entirely.
  - Removed `this.warmup()` from `waitForWarmup()`.
  - Guarded `warmup()` with `if (this.isWarmedUp || this.isWarmingUp) return;` and set `this.isWarmingUp = true;`.
  - Updated `handleWorkerMessage('WARMED_UP')` to log `Logger.warn` if already warmed up instead of silently ignoring, else `Logger.info`.
- `autogenerated-tests/studio_sidecar_warmup_single_dispatch.test.ts`:
  - Added unit test suite covering in-process fallback, single dispatch in worker environment, passive barrier behavior of `waitForWarmup()`, in-flight guard, and duplicate message warning.
