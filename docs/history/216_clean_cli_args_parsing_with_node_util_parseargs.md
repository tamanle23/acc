# 216: Clean Declarative CLI Argument Parsing with node:util parseArgs

## Context & Objectives
Refactored the argument parsing logic in `apps/cli/src/index.ts` from an imperative, 100-line index-hopping `for` loop (`args[++i]`) into a clean, declarative two-phase parser using standard `node:util parseArgs`:

1. **Two-Phase Architecture**:
   - **Phase 1: Command & Shorthand Resolution**: Fast `KNOWN_COMMANDS.has(...)` inspection, handling top-level help triggers (`-h`, `--help`, `help`), and preserving legacy path shorthand (`acc ./sample-story` $\rightarrow$ `run story -c ./sample-story`).
   - **Phase 2: Declarative Schema Parsing (`node:util parseArgs`)**: Strictly typed mapping for all long and short flags (`-c`, `-i`, `-o`, `-f`, `-e`, `-r`, `-p`, `-d`, `-n`, `-j`, `-w`, `-s`, `-v`, `-h`).

2. **Strict Mode & Defensive Guardrails**:
   - Enabled `strict: true` to prevent silent propagation of typos or invalid flags.
   - Wrapped schema evaluation in a `try / catch` block that outputs friendly diagnostics and returns `{ command: 'help' }` to guide the user rather than crashing unceremoniously.

3. **Multi-Syntax Parity**:
   - Supports both space-separated (`--config ./path`) and equal-separated (`--config=./path`) flag values.
   - Supports clustered short booleans (`-sn` for `--sandbox --dry-run`).

4. **Automated Verification**:
   - Re-verified all core CLI test suites: `cli_interactive_ux.test.ts`, `phase6_unified_cli.test.ts`, `cli_prompts_architecture.test.ts`, `enterprise_ir_render_tracing.test.ts`, and `video_ir_phase6_cli_scaling.test.ts` (16 passing across 4 suites).
   - Verified zero unauthorized native import leaks via `bun run scripts/check-native-imports.ts`.
