# 407: Studio Preview Playback Smoothness (Iteration 60)

## Problem
Playback stutter despite a 60 FPS badge: stale async React `renderFrame` dispatches (out-of-order frames), integer-step needle judder, duplicate worker renders, full-resolution isolation scratch canvases, and GPU readback stalls (`willReadFrequently: false`).

## Plan
`docs/iterations/master_implementation_plan_iteration_60.md` + companion `docs/preview_playback_smoothness_and_decoupling_plan.md`.

## Changes
- `StudioPlayheadController`: `fractionalFrame` on `seek()` and subscribers; low-freq sync 250 ms.
- `useShuttleEngine`: raw fractional + discrete frame; audio-master only when `WebAudioEngine.isContextRunning()` (new); React scrub throttle 250 ms.
- `Timeline.tsx`: needle glides on fractional frame during playback.
- `useViewportRenderStrategy`: React render pass suppressed while playing; `lastDispatchedFrameRef` dedupe.
- `WorkerRenderStrategy`: skip identical integer frame while playing.
- `IRCanvasCompositor`: isolation scratch canvas sized to `(bufferW, bufferH)` with `scale(scaleX, scaleY)`.
- `preview.worker.ts`: `willReadFrequently: true`.
