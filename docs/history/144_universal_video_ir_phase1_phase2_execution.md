## 1. Problem Statement
The automated video generation suite needed a future-proof, deterministic, and platform-agnostic Video Intermediate Representation (IR). The schema and execution engine had to decouple temporal topology (the "When") from media processing (the "How") following the Open-Closed Principle (OCP), while serving both headless batch rendering and frontend visual video timeline editing (preview mode). Furthermore, the existing `story_config` rendering flow had to be incorporated as a pioneer end-to-end verification baseline.

---

## 2. Plan of Action
1. **Phase 1: IR Schema & Pioneer Adapter**
   - Implement canonical Video IR V1.0-Stable TypeScript interfaces (`VideoIRDocument`, `IRTrack`, `IRSequence`, `ModifierNode`, etc.).
   - Implement `VideoIRSchemaValidator` for Draft-07 polymorphic validation with type discriminators.
   - Implement `AssetMetadataProber` for header stream probing (including WAV RIFF byte-rate decoding) without full payload reads.
   - Implement `StoryConfigToUniversalIRAdapter` to adapt `story_config.json` into canonical V1.0-Stable IR documents.
2. **Phase 2: Two-Pass Relational DAG Compiler & Deterministic Timing**
   - Implement two-pass `RelationalDAGCompiler` with Kahn's algorithm for topological duration and start frame resolution, with circular dependency detection.
   - Implement `DeterministicAudioClock` using Bresenham integer accumulation for zero audio-video drift across 100,000+ frames.
   - Implement `IntervalTreeIndex` providing $O(\log M)$ active sequence lookups for sub-16ms interactive timeline seeking.
3. **Verification:**
   - Author formal tests in `autogenerated-tests/video_ir_phase1_phase2.test.ts` and `autogenerated-tests/sample_story_ir_pioneer.test.ts`.
