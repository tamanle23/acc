# 350: Studio Viewport Pipeline & Architecture Modernization

## Problem
Over several feature releases (OffscreenCanvas Web Worker, Sidecar AI preflight, 3D Pop-Out depth warping, 2D Vector Gizmo handles, dynamic safe guides, and WebAudio integration), the `apps/studio` viewport subsystem accumulated architectural technical debt:
1. Two conflicting implementations of `AssetTextureCache.ts` (`src/renderer/` vs `src/lib/textures/`).
2. A monolithic ~852-line God component in `Preview.tsx` coupling worker lifecycle, OffscreenCanvas transfer, playhead tick coalescing, `@dnd-kit` gizmo calculations, and fallback rendering.
3. Ad-hoc `if (workerRef.current) ... else ...` branching distributed across React effects.

## Plan
1. **Phase 1: Texture Cache Consolidation** - Standardize on `apps/studio/src/lib/textures/AssetTextureCache.ts` as the authoritative singleton. Refactor `apps/studio/src/renderer/AssetTextureCache.ts` into a lightweight, backward-compatible adapter delegating to the authoritative singleton for both `new AssetTextureCache()` and `.getInstance()`.
2. **Phase 2: Render Strategy Abstraction** - Implement the GoF Strategy Pattern with `IPreviewRenderStrategy`, `WorkerRenderStrategy` (OffscreenCanvas + `PreviewWorkerBridge`), and `MainThreadRenderStrategy` (`IRPreviewEngine` fallback), auto-negotiated via `createPreviewRenderStrategy()`.
3. **Phase 3: Domain Hooks Extraction** - Extract orthogonal concerns into co-located hooks under `apps/studio/src/components/preview/`:
   - `useViewportPanZoom.ts`: Fit/ratio zoom, spacebar panning & mouse offsets.
   - `useGizmoTransform.ts`: `@dnd-kit` sensors, drag/rotate math & magnetic snapping guides.
   - `usePreviewHotkeys.ts`: Keyboard shortcuts (`Space`, `Shift+V`, `Ctrl/Cmd+D`, `Del/Backspace`, `Esc`).
   - `useViewportRenderStrategy.ts`: Strategy lifecycle, canvas transfer, texture sync (`createImageBitmap`), and frame dispatch.
4. **Phase 4: Preview.tsx Decomposition** - Refactor `apps/studio/src/components/Preview.tsx` into a declarative host composing the domain hooks and mounting modular overlays.
5. **Phase 5: Verification & Zero-Regression Parity** - Verify test suites with `bun test` and ensure production build clean execution via `pnpm --filter @acc/studio build`.
