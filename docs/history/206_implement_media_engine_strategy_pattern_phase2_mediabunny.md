## 2. Changes Implemented

### 2.1. `@acc/core` Mediabunny Foundation
- **Dependencies (`packages/core/package.json`)**:
  - Added `mediabunny@1.61.5` and `@mediabunny/server@1.61.5` (providing NodeAV FFmpeg bindings and pure TypeScript MP4 container muxing/demuxing).
- **`packages/core/src/media-engine/sinks/MediabunnyServerSink.ts`**:
  - Server-side frame sink utilizing `mediabunny`'s `VideoSampleSource`, `VideoSample`, `Output`, and `Mp4OutputFormat`.
  - Lazy initialization of server codecs via `registerMediabunnyServer()`.
  - Accepts raw RGBA `Uint8Array` frame buffers and converts them directly into `VideoSample` instances with deterministic PTS calculation.
  - Guarantees immediate memory safety with `sample.close()`.
  - Implements two-pass audio multiplexing with `FFAudioMuxer.mux()` when audio PCM is provided during `finalize(audioResult)`.
- **`packages/core/src/media-engine/sinks/MediabunnyClientSink.ts`**:
  - Browser/client-ready sink targeting in-memory `BufferTarget` with zero server filesystem dependencies.
  - Outputs completed MP4 container to memory buffer / Blob, exposing `stats.inMemoryBufferSize`.
- **`packages/core/src/media-engine/strategies/MediabunnyServerStrategy.ts`**:
  - Concrete `IMediaEngineStrategy` with `id: 'mediabunny-server'`.
  - **`MediabunnyProbeStrategy`**: Pure TypeScript MP4 container prober extracting duration, display dimensions, FPS, and video/audio codecs using `Input` and `ALL_FORMATS` without spawning `ffprobe` or calling native C bindings.
  - **`MediabunnyConcatStrategy`**: Lossless packet-level demux-remux chunk concatenation. Extracts elementary encoded video/audio packets using `EncodedPacketSink`, offsets microsecond timestamps, and pushes them into an `Output` stream with `EncodedVideoPacketSource`/`EncodedAudioPacketSource`. Zero subprocesses, zero transcoding.
  - **`MediabunnyAudioMuxerStrategy`**: Audio multiplexing into container with rock-solid fallback.
  - **`MediabunnyServerChunkPolicy`**: Concurrency governed by RAM ($\lfloor\text{free\_ram}/1.5\text{GB}\rfloor$) and CPU cores, using `worker-thread` execution mode.
- **`packages/core/src/media-engine/strategies/MediabunnyClientStrategy.ts`**:
  - Concrete `IMediaEngineStrategy` with `id: 'mediabunny-client'` and `supportsBrowserRuntime: true`.
  - Validates `globalThis.VideoEncoder` or polyfilled server codecs.
  - Defines `MediabunnyClientChunkPolicy` with `executionMode: 'web-worker'`.
- **`packages/core/src/media-engine/index.ts`**:
  - Exported all new sinks and strategies.
  - Auto-registered `mediabunny-server` and `mediabunny-client` in `MediaEngineRegistry`.
