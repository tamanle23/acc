# 232. Fix Settings Modal Text Contrast Across Dark & Light Liquid Glass Themes

## Context & Problem
In `apps/studio/src/components/SettingsModal.tsx`, text elements (dialog header, theme option labels, descriptions, and buttons) were hardcoded with fixed white and light slate utility classes (such as `text-slate-100`, `text-slate-200`, and `text-slate-400`). While this looked acceptable on Dark Obsidian backgrounds, switching the Studio to Light Frosted Acrylic mode (`--glass-bg: rgba(255, 255, 255, 0.72)`) resulted in white text rendering over a near-white background, rendering the modal completely unreadable.

Additionally, Dialog primitive components in `apps/studio/src/components/ui/dialog.tsx` contained hardcoded `text-slate-900` and `border-slate-200` without adaptive dark/light tokens.

## Implementation Details
1. **Dynamic Theme Tokens in `SettingsModal.tsx`**:
   - Replaced `text-slate-100` on Dialog header and titles with semantic `text-foreground`.
   - Replaced `text-slate-200` on setting option titles with `text-foreground/90` and active text with `text-foreground`.
   - Replaced `text-slate-400` descriptions with `text-muted-foreground`.
   - Replaced `border-white/10` and `border-white/5` with semantic glass borders: `border-[var(--glass-border)]`, `hover:border-[var(--glass-border-highlight)]`, and hover states with `hover:bg-foreground/5`.
   - Replaced hardcoded cyan accents (`border-cyan-500/50`, `bg-cyan-500/10`) with dynamic accent tokens (`border-[var(--accent-primary)]`, `bg-[var(--accent-primary)]/15`, `shadow-[0_0_15px_var(--accent-glow)]`).
   - Added `cursor-pointer` to all option buttons and reset actions for improved UX feedback.

2. **Dialog Primitive Theme Harmony in `apps/studio/src/components/ui/dialog.tsx`**:
   - Updated overlay backdrop to `bg-black/60` for balanced contrast in both light and dark modes.
   - Updated modal container from `border-slate-200 bg-white` to `border-border bg-card text-card-foreground`.
   - Updated `DialogTitle` to use `text-foreground`.
   - Updated `DialogDescription` to use `text-muted-foreground`.

3. **Automated Verification**:
   - Extended `autogenerated-tests/studio_liquid_glass_theme.test.ts` to assert that `SettingsModal.tsx` and `dialog.tsx` contain zero hardcoded white/light slate text classes and strictly use semantic theme tokens.
   - Verified that all 67 tests in the studio test suite pass cleanly (`bun test studio`).
   - Verified production build clean compilation (`bun run studio:build`).
