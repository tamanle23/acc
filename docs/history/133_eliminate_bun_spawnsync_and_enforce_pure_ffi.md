# History Log: 133 - Eliminate Bun.spawnSync and Enforce Pure bun:ffi Execution

**Date:** 2026-10-02 (2026-10-03 local)  
**Task:** Eliminate Bun.spawnSync and Enforce Pure bun:ffi Execution Across All FFmpeg Operations  
**Affected Component:** `@acc/core` (`packages/core/src/FFmpegExecutor.ts`, `packages/core/src/ffmpeg-ffi/FFIVideoEncoder.ts`, `packages/core/src/ffmpeg-ffi/FFISceneEngine.ts`)

---

## 1. Context & Problem
- In adherence to system constraint `FFMPEG-MANAGER` ("Tuyệt đối không sử dụng Bun.spawnSync, sử dụng ffmpeg phải thông qua bun:ffi"):
  - `packages/core/src/FFmpegExecutor.ts` retained a legacy fallback block executing `Bun.spawnSync([ffmpegBin, ...args])` when a complex filtergraph was present.
  - In `FFIVideoEncoder.ts` and `FFISceneEngine.ts`, pointer offset arithmetic in `sws_scale` calls (`this.frame + 64n`, `srcFrame + 64n`) lacked explicit `BigInt()` casting, causing potential `TypeError: Invalid mix of BigInt and other type in addition` during fast raw frame encoding.

---

## 2. Changes Made
1. **`packages/core/src/FFmpegExecutor.ts`**:
   - Completely eliminated `Bun.spawnSync` and all process spawning logic.
   - Routed multi-input stream operations directly to `FFIConcatMuxer.concatenate(inputPaths, outputFile)` (zero-copy bitstream concat via pure `bun:ffi`).
   - Routed single-input media operations to `FFISceneEngine.renderScene(...)` or lossless file copying.
2. **`packages/core/src/ffmpeg-ffi/FFIVideoEncoder.ts`**:
   - Fixed `encodeRawFrame` to wrap `srcFrame` and `this.frame` in `BigInt()` before pointer offset additions (`srcPtr + 64n`, `dstPtr + 64n`).
3. **`packages/core/src/ffmpeg-ffi/FFISceneEngine.ts`**:
   - Defensively wrapped frame pointer arguments in `BigInt()` before sws_scale pointer offsets.
