## 2. Context & Objectives
Phase 3 of Master Integration Plan Iteration 2 requires validating and benchmarking the hardware-accelerated video encoding subsystem implemented in Phase 2.
Key objectives:
1. Measure frame ingestion throughput (FPS) across CPU (`libx264`) and GPU (`h264_nvenc`) pipelines.
2. Measure JS Heap vs Native RSS memory stability under sustained frame ingestion (100+ frames) to guarantee adherence to the **ZERO-ALLOC-FRAME-LOOP** rule.
3. Verify bitstream integrity and container demuxing parity using FFmpeg demuxing APIs (`avformat_open_input`, `avformat_find_stream_info`, `av_read_frame`).
4. Validate concurrent temporal chunk encoding (`-j 6+` emulation) without pointer corruption or cross-chunk race conditions.
5. Prove bit-identical parity and deterministic frame math across repeated runs.
