## 1. Context & Motivation
Following the initial quarantine of legacy disk-based rendering code, `apps/cli` still retained internal legacy files and responsibilities for legacy multi-pass rendering. 

In **Iteration 31**, we executed full, complete architectural isolation by creating a dedicated application package:
`@acc/legacy-story-renderer` (`apps/legacy-story-renderer`).

This permanently cleanses `@acc/cli` of legacy disk-stitching routines (`SceneWorkerPool`, intermediate MP4 files, temporary ASS files, raw `FFmpegFilterGraph` string transitions, and legacy AST preparation), establishing a strict physical package boundary.

---

## 2. Key Architecture & Implementation Changes

### 2.1 Dedicated Application Package (`apps/legacy-story-renderer`)
- **`package.json`**: Defined `@acc/legacy-story-renderer` as a private workspace package with dependencies on `@acc/core`, `@acc/core-isomorphic`, `@acc/ir`, and `@acc/effect-engines`.
- **`tsconfig.json`**: Extends the monorepo root `tsconfig.json`.
- **`LegacyDiskStoryRenderer.ts`**: Encapsulated the complete 500+ line disk-based multi-pass scene renderer, worker pool lifecycle, dynamic RAM throttling, fallback audio/image assets, and complex FFmpeg filtergraph stitch routines.
- **`LegacyIRPreparationAdapter.ts`**: Extracted legacy AST enrichment, safe-zone validation, and NLE cut calculation (`prepareIR()`).
- **`encodingFlags.ts`**: Self-contained FFmpeg codec and encoding resolution.
- **`index.ts`**: Cleanly exports the package API.

### 2.2 Purging `@acc/cli`
- Permanently deleted `apps/cli/src/pipelines/04-generative-story/legacy/`.
- Added `"@acc/legacy-story-renderer": "workspace:*"` to `apps/cli/package.json`.
- Updated `apps/cli/src/pipelines/04-generative-story/VideoEditPipelineOrchestrator.ts` to import `LegacyDiskStoryRenderer` and `LegacyIRPreparationAdapter` from `@acc/legacy-story-renderer`.
- Preserved 100% backward-compatible signatures for `VideoEditPipelineOrchestrator.renderStoryVideo()` and `prepareIR()`.

### 2.3 Monorepo Path Mapping & Turbo Build
- Registered `@acc/legacy-story-renderer` path mappings in root `tsconfig.json`.
- Verified Turbo build (`turbo build`) succeeds across all 12 monorepo packages.
